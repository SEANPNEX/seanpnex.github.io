### Decomposition of Value Added

* For portfolio with multiple asset classes, active return can be decomposed to two sources
  1. **Active asset allocation**: active weights of asset classes against benchmark portfolio
  2. **Security selection**: active weights of security within asset classes
* $$R_A = \underbrace{\sum_{i=1}^{N} (w_i^P - w_i^B) R_i^B}_{\text{active asset allocation}} + \underbrace{\sum_{i=1}^{N} w_i^P (R_i^P - R_i^B)}_{\text{security selection}}$$
