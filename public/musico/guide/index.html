Downloads, First-Run Setup & In-App Updates v1.3.4

Grab the latest builds directly below or from GitHub Releases. Every release includes SHA256SUMS.txt and an in-app updater on desktop & Android.

Installer (.exe) ↓ 52.8 MB Portable (.zip) ↓ 71.6 MB Release (.apk) ↓ 20.2 MB Debug (.apk) ↓ 28.0 MB Disk Image (.dmg) ↓ 10.8 MB Unsigned (.ipa) ↓ 4.4 MB SHA256SUMS.txt ↗ SHA-256
  • Windows 10 / 11 (x64, self-contained .NET 8): Run MusicoWindows-<ver>-win-x64-Setup.exe for per-user install with Start Menu / Desktop shortcuts, system tray, and single-instance focus — or unzip MusicoWindows-<ver>-win-x64-portable.zip anywhere and keep portable.txt beside MusicoWindows.exe so your library, queues, extensions, and settings live inside .\Data\ instead of %LOCALAPPDATA%\Musico.
  • Android 8.0+ (API 26+): Install the persistently signed MusicoAndroid-<ver>-release.apk so in-app FileProvider upgrades install smoothly without losing data (or grab debug.apk for local testing).
  • macOS (Catalyst): Open Musico-<ver>-macOS.dmg and drag Musico.app into Applications. Because builds are ad-hoc signed, right-click then choose Open on first launch if Gatekeeper asks.
  • iOS 17+ / iPadOS: Sideload or re-sign Musico-<ver>-iOS-unsigned.ipa using AltStore, SideStore, Sideloadly, or Xcode.

In-App Updater & Checksum Verification

  1. Check for Updates: Desktop (Windows Setup/Portable & macOS) and Android clients automatically poll GitHub releases/latest, or you can trigger a check manually from Settings.
  2. Skip Version or Upgrade: Choose Skip Version to silence a specific release banner, or proceed to download — Windows and Android verify SHA256SUMS.txt before launching the self-replacing Portable zip, Setup installer, or Android FileProvider installer (macOS downloads and opens the new .dmg).
  3. iOS Note: Because personal-team sideloaded IPAs cannot self-update in place, re-sign and install new .ipa releases via AltStore, SideStore, Sideloadly, or Xcode.

Folders, Scanning, Relocate & Safe Deletion

Musico treats your directory tree as the source of truth — never flattening folders into a black-box database.

OS Default Roots: macOS starts with Music; iOS/iPadOS watches Files › On My iPhone/iPad › Musico; Android uses Musico Folder plus any Storage Access Framework (SAF) directory; Windows starts with MyMusic (or .\Data\ in Portable mode).

Day-to-Day Folder Workflow

  1. Mount Local Folders: Open Folders → Add Folder to pick any local or SAF directory without copying or altering your subfolders.
  2. Rescan for New Tracks: Tap Rescan (or pull to refresh on iOS/Android) whenever you add new audio files to a mounted folder.
  3. Desktop Drag-and-Drop: Drop folders onto the macOS or Windows window to mount them directly in Folders, or drop audio files to play immediately (tracks outside your library copy neatly into your default music folder).
  4. Relocate & Restore Subfolders: Moved a folder or unplugged an external drive? Pick Locate Again… (Relocate) to reconnect the path while keeping playlists, queue history, and play stats intact. Hidden a subfolder by mistake? Use Restore Removed Subfolders anytime.
  5. Remove vs. Delete on Disk: Removing a track or folder gives an explicit choice — Remove from Library (hides it from Musico only) or disk deletion (Move to Trash on macOS, Move to Recycle Bin on Windows, or Delete from Device on iOS/Android, including Android's Musico folder).

Library Views, Context Menu & Song Info / Tag Editor

5 Core Library Views

  • Folders: Browse your exact directory hierarchy, mount local or cloud roots, and drag tracks via the ≡ handle.
  • Songs: Sort by Title, Artist, Album, or Date Added, filter with instant diacritic-insensitive search, or switch to an enabled search extension.
  • Albums: Automatically grouped and sorted cleanly by disc number and track number.
  • Artists: Jump straight to every track and album belonging to an artist.
  • Playlists & Favourites: Manage custom playlists alongside the built-in Favourites collection.

Track Context Menu Actions

Tap the ellipsis (···) or right-click any track for 8 quick actions: Play Next (deduplicated), Add to Queue, Add to Another Queue, Play in New Queue, Add to Playlist, Add/Remove Favourites, Song Info, and Remove / Delete.

Song Info & Inline Tag Editor

Open Song Info on any track to inspect audio precision, sample rate, bit rate, file size, channels, and play count, quick-search by Artist/Album/Genre, or edit Title, Artist, Album, Genre, and cover art inline (plus folder/track sidecar covers).

Multiple Independent Queues, Deduplicated Play Next & Mobile Swipes

Keep separate listening moods running side by side — each queue saves its own track list, playback timestamp, shuffle order, and repeat mode.

  1. Create & Switch Parallel Queues: Spin up, rename, reorder, clear, or delete queues anytime in Queues (or the desktop Queue side panel). Every queue persists its exact track, position, shuffle state, and repeat mode (Off / All / One).
  2. Deduplicated Play Next (v1.3.3+): Triggering Play Next moves an existing non-current occurrence of that song right after the active track instead of creating a duplicate, leaving the currently playing song untouched.
  3. Isolated Drag Reorder (v1.3.4): Grab the ≡ handle in Folders or Queues to reorder songs smoothly — horizontal swipe gestures stay strictly isolated from the drag handle.

Equalizer, Synced Lyrics, Sleep Timer, Stats & OS Media Controls

10-Band ISO Equalizer

Flip the master EQ switch, dial preamp from -12 dB to +12 dB, and sculpt 10 ISO bands (31 Hz–16 kHz) backed by native AVAudioUnitEQ, Android DynamicsProcessing, and Windows NAudio BiQuadFilter. Pick from 8 presets (Flat, Bass Boost, Treble Boost, Rock, Pop, Jazz, Classical, Vocal) or save your own Custom curve.

Offline-First & On-Demand Online Lyrics

  1. 4-Tier Offline Playback Lookup: During playback, Musico never hits the network automatically — it checks Imported .lrc/.txt → exact Sidecar .lrc/.txt → non-recursive Same-Folder Fuzzy Match → Embedded tags, decoding UTF-8, UTF-16 BOM, and GB18030 (including multi-timestamp .lrc).
  2. Live Lyrics Controls: Tap any timed line to seek, customize font size & alignment, and hit Sync to current line after scrolling ahead.
  3. On-Demand Search Online…: Query Auto, built-in LRCLIB & NetEase, or enabled "lyrics" extensions, preview candidates live, toggle bilingual translations, and confirm to save (optionally exporting a sibling .lrc file).

Sleep Timer, Listening Stats & System Media Controls

Set a Sleep Timer for 5–90 minutes, a custom duration, or End of current song. Inspect Stats across Recent, Plays, Top Artists, Top Albums, Not Lately, and Never. Playback hooks natively into Apple Lock Screen / Control Center (MPNowPlayingInfoCenter), Android MediaSessionService, and Windows 10 SMTC.

Unified Settings, Custom Appearance & Desktop Power Tools

Press Cmd+, (macOS), Ctrl+, (Windows), or open Settings to tune language, themes, contrast, and desktop windows:

  1. Language & Theme Mode: Switch live between English and 简体中文 (or Follow System), and choose System, Light, or Dark mode.
  2. Colors, Live Preview & WCAG 2.1 Check: Pick curated presets or custom hex/RGB/system colors while watching the live Now Playing Preview. Built-in WCAG 2.1 contrast warnings include one-click Auto-fix Contrast.
  3. Background Image & Desktop Glass: Add a custom background with adjustable Image Visibility and Background Blur. macOS uses NSVisualEffectView translucency + independent sidebar color (no sidebar opacity on macOS); Windows 11 adds DWM rounded corners/backdrop, Acrylic, and independent sidebar color & opacity.
  4. Command Palette & Floating Mini-Player: Press Cmd+K / Ctrl+K to jump anywhere via the Global Command Palette, or press Cmd+Shift+N / Ctrl+Shift+N to pop out the Floating Mini-Player.

Cloud Hangouts, Offline Sync & Google Drive OAuth 2.0

Mount remote playlists and cloud folders directly alongside local directories in Folders:

  1. Paste URL or Share Text: Open Folders → Add Cloud Folder and paste a URL, share-sheet snippet, or ID (surrounding text is stripped automatically). Leave Auto-Detect on or pick a provider.
  2. Built-In Providers & Extensions: Mount YouTube / YouTube Music (playlists, RD mixes, album browse URLs, single videos, Shorts), Bilibili (single/multi-part BV/av, favlist, collections, b23.tv), Google Drive (public/shared folders with resourcekey recursive audio discovery & single audio URLs with zero login), or any enabled JS extension.
  3. Save Offline & Incremental Sync: Open a cloud folder or track menu and click Save to Local Folder… (with download quality picker). Synced directories write a .musico-cloud.json manifest so Update from Cloud pulls only newly added tracks.
  4. Per-Folder Cookies & Proxy: Add a cookie only for private items or higher quality — each Cloud Folder isolates its own cookie. On Windows, configure an HTTP Proxy (e.g. 7890 or http://127.0.0.1:7890) for YouTube, Drive, and proxy-capable extensions.
Cookie Isolation, Drive OAuth 2.0 & Windows HTTP Proxy (・ω・)ﾉ

Each mounted Cloud Folder keeps its own strictly isolated Cookie (needed only for private playlists or higher quality). Google Drive public/shared links stay zero-login, while optional OAuth 2.0 lives in Settings → Google Drive Account. On Windows, you can also configure an HTTP proxy (e.g. 7890 or http://127.0.0.1:7890) for YouTube, Google Drive, and proxy-capable extensions.

Optional: Google Drive OAuth 2.0 Client ID Setup Guide (6 Steps)

Why bring your own Client ID? Public/shared Google Drive links work with zero login. Google classifies drive.readonly as a restricted scope, so personal free Desktop app OAuth credentials let you access private Drive folders and bypass large-file confirmation prompts with zero Google app review.

  1. Open Google Cloud Console and create or select a project.
  2. Go to APIs & Services → Library, search for Google Drive API, and click Enable.
  3. Open Google Auth Platform (or OAuth consent screen): set User Type to External, keep publishing status in Testing, add your own Gmail under Test users, and add scopes https://www.googleapis.com/auth/drive.readonly and https://www.googleapis.com/auth/userinfo.email.
  4. Open Clients → + Create Client (or Credentials → OAuth client ID), select Desktop app (Musico uses automatic http://127.0.0.1:<port>/oauth2callback loopback across macOS, Windows, Android, and iOS with zero manual redirect URI setup), and copy your Client ID and Client Secret.
  5. In Musico, open Settings → Google Drive Account, paste your Client ID & Secret, and tap Sign In with Google.
  6. 7-Day Testing Mode Expiry: Testing refresh tokens expire after 7 days — just tap Reconnect Google Drive in Settings whenever prompted.

How to import on your device

Apple (iOS / iPadOS / macOS):

Open Extensions in the sidebar (Cmd+8 on macOS/iPadOS, or tap the puzzle icon in Folders on iOS) → Import from HTTPS URL… (or Import from File…) → paste the URL → inspect declared permissions.hosts → tap Approve & Enable.

Android:

Open Folders → tap the puzzle-piece Extensions button in the top bar → Import URL (or Import File) → paste the .zip, .musicoext, or .musico.js → review permissions and enable.

Windows 10 / 11:

Open Extensions in the left navigation pane → click Import URL (or Import File…) → paste/select the package → review permissions.hosts and click Approve & Enable.

Permission Review, Sign-In & Ephemeral Search

  1. Permission Review: Newly imported plugins stay disabled until you inspect their declared permissions.hosts and capabilities and tap Approve & Enable. Every bundled plugin sets updateUrl for automatic updates.
  2. Signing In & Diagnostics: Authenticate via native QR Code Login (qr_login), isolated ephemeral Web Login (web_login), or masked Extension Cookie / cookies.txt import. Mounted Cloud Folders always prioritize their own folder cookie over the extension cookie, and the 200-entry log viewer automatically redacts cookies.
  3. Ephemeral Cloud Search: Enabling a "search" plugin reveals the Search Source Switcher in Songs (defaulting to Local). Submit queries explicitly, filter by kind pills, play in an ephemeral Search (<Ext>): <query> queue excluded from Library & Stats, or save/preview via Save to Local Folder… and Add as Cloud Folder.
How Ephemeral Search & Extension Cookies Stay Clean (｡・ω・｡)ﾉ♡

When a "search" plugin is enabled, Songs shows a Search Source Switcher (defaulting to Local, and completely hidden when zero search plugins are enabled). Results play in an ephemeral Search (<Ext>): <query> queue excluded from Library tabs & Stats unless you choose Save to Local Folder… or Add as Cloud Folder. Sign in cleanly via QR Login (qr_login), isolated Web Login (web_login), or masked cookies.txt file import — mounted Cloud Folders always prefer their own folder cookie over the extension-level cookie.

Per-Plugin Settings & Audio Quality Reference
  • YouTube Search (youtube-search): youtubeMode (music / youtube), youtubeAudioFormat (auto / m4a / opus; Apple enforces M4A/AAC), and 4 quality tiers (highest, high, standard, low).
  • Bilibili Search (bilibili-search): biliSearchOrder (totalrank / click / pubdate / stow) and 4 quality tiers including Hi-Res/FLAC (30251 → 30280 → 30232 → 30216).
  • NetEase Cloud Music (com.seanpnex.musico.netease): quality across 9 tiers (highest cascading jymaster → hires → lossless → exhigh → standard, plus sky, jyeffect, higher), allowTrialPreview (30s VIP preview toggle), and customApiHeaderOs (pc / android / ios).
  • Apple Music (com.seanpnex.musico.applemusic): serverUrl (your self-hosted companion server URL), codec (aac-web / aac-he-web / alac / atmos), and optional Bearer token pasted into the extension Cookie field.
