Downloads, Portable Mode & Updates v1.2.11

Grab the latest builds directly below or from GitHub Releases. Desktop and Android clients include an in-app updater that checks releases/latest, verifies SHA256SUMS.txt, and supports Skip Version.

Windows Installer (.exe) ↓ 52.5 MB Windows Portable (.zip) ↓ 71.1 MB Android Release (.apk) ↓ 20.0 MB macOS Catalyst (.dmg) ↓ 8.6 MB iOS Unsigned (.ipa) ↓ 3.5 MB SHA256SUMS.txt ↗ SHA-256
  • Windows 10 / 11 (x64, self-contained .NET 8): Use MusicoWindows-<ver>-win-x64-Setup.exe for per-user install, or unzip MusicoWindows-<ver>-win-x64-portable.zip anywhere and keep portable.txt beside MusicoWindows.exe so your library, queues, extensions, and settings live neatly inside .\Data\ instead of %LOCALAPPDATA%\Musico.
  • Android 8.0+ (API 26+): Install the persistently signed MusicoAndroid-<ver>-release.apk so in-app FileProvider upgrades install smoothly without losing data.
  • macOS (Catalyst): Open Musico-<ver>-macOS.dmg and drag Musico.app into Applications. Because builds are ad-hoc signed, right-click then choose Open on first launch if Gatekeeper asks.
  • iOS 17+ / iPadOS: Sideload or re-sign Musico-<ver>-iOS-unsigned.ipa using AltStore, SideStore, Sideloadly, or Xcode.

Folder-First Library, Relocate & Formats

Musico respects your directory tree as the source of truth. Head to Folders then Add Folder to mount directories, and tap Rescan (or pull to refresh on mobile) when adding new files.

  • Default root locations: macOS starts with Music; iOS/iPadOS watches Files › On My iPhone/iPad › Musico; Android uses Musico Folder plus any Storage Access Framework (SAF) directory; Windows starts with MyMusic.
  • Locate Again… (Relocate): Unplugged an external SSD or renamed a parent folder? Use Relocate to reconnect the root path without losing playlists, queue history, or play counts.
  • Restore Removed Subfolders: Accidentally hid a folder from your library view? Restore hidden subfolders anytime from folder options.

Cloud Hangouts & Offline Sync

In Folders → Add Cloud Folder, paste any URL, share-sheet snippet, or ID. Musico automatically strips surrounding share text! Leave provider on Auto-Detect or pick a built-in source or enabled JS extension.

  • YouTube / YouTube Music: Playlists, RD mixes, album browse URLs, single videos, and Shorts. Public playlists and tracks stream with zero login.
  • Bilibili: Single or multi-part BV/av videos, favlist, collections/series, and b23.tv short links.
  • Google Drive: Shared folders (including resourcekey links with recursive nested audio discovery) and single audio file URLs, with automatic large-file virus-scan confirmation handling.
  • Save to Local Folder & Incremental Sync: Open a cloud folder or track menu and pick Save to Local Folder…. Synced directories store a .musico-cloud.json manifest so clicking Update from Cloud pulls only newly added tracks.
Cookie Isolation & Windows HTTP Proxy (・ω・)ﾉ

Each mounted Cloud Folder keeps its own strictly isolated Cookie (needed only for private playlists, restricted Drive links, or higher Bilibili quality). On Windows, you can also configure an HTTP proxy (e.g. 7890 or http://127.0.0.1:7890) for YouTube, Google Drive, and proxy-capable extensions.

Multiple Queues, 10-Band EQ & Lyrics

  • Parallel Queues: Create, rename, reorder, clear, or delete independent queues anytime. Every queue remembers its current track, exact playback position, shuffle order, and repeat mode (Off / All / One). Grab the drag handle (≡) in Folders or Queues to reorder tracks.
  • Track Context Menu: Tap or right-click any track for Play Next, Add to Queue, Add to Another Queue, Play in New Queue, Add to Playlist, Favourites, and Song Info.
  • 10-Band ISO Equalizer: Tune 31 Hz to 16 kHz plus -12 dB to +12 dB preamp, or pick from 8 presets (Flat, Bass Boost, Treble Boost, Rock, Pop, Jazz, Classical, Vocal) and Custom.
  • Local-First Lyrics & On-Demand Online Search: During playback, Musico stays strictly offline and checks Imported → Sidecar (.lrc/.txt) → Same-Folder Fuzzy Match → Embedded tags, decoding UTF-8, UTF-16 BOM, and GB18030 with tap-to-seek. Tap Search Online… to query Auto, built-in LRCLIB & NetEase, or enabled "lyrics" extensions, preview candidates, toggle bilingual lines, and optionally export a sibling .lrc file on confirm.

How to import on your device

Apple (iOS / iPadOS / macOS):

Open Extensions in the sidebar (Cmd+8 on macOS/iPadOS, or tap the puzzle icon in Folders on iOS) → Import from HTTPS URL… (or Import from File…) → paste the URL → inspect declared permissions.hosts → tap Approve & Enable.

Android:

Open Folders → tap the puzzle-piece Extensions button in the top bar → Import URL (or Import File) → paste the .zip, .musicoext, or .musico.js → review permissions and enable.

Windows 10 / 11:

Open Extensions in the left navigation pane → click Import URL (or Import File…) → paste/select the package → review permissions.hosts and click Approve & Enable.

How Ephemeral Search & Extension Cookies Stay Clean (｡・ω・｡)ﾉ♡

When a "search" plugin is enabled, Songs shows a Search Source Switcher (defaulting to Local, and completely hidden when zero search plugins are enabled). Results play in an ephemeral Search (<Ext>): <query> queue excluded from Library tabs & Stats unless you choose Save to Local Folder… or Add as Cloud Folder. Mounted Cloud Folders always prefer their own folder cookie over the extension-level cookie.
