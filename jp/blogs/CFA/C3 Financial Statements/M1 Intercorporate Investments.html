長期の持分投資 ​

上のとおり、長期の持分投資は支配力の強さに応じて 4 つに分かれる：

  • 金融資産への投資：重要な支配力も影響力もない
  • 関連会社への投資：重要な影響力を及ぼす
  • 共同支配企業：支配を共有する
  • 企業結合：支配持分を取得する

適切な区分の判断には、通常持分比率を使う：

  • (0,20) 影響力なし
  • (20,50) 重要な影響力
  • (50,100) 支配

金融資産の分類 ​

復習ノート ​

分類 ​

負債性金融商品

  • 契約上のキャッシュフローの回収を目的に保有 → AMC（償却原価）、固定の価値（発行利回りで割り引いた DCF）
  • 回収と売却の両方を目的に保有 → FVOCI、その他の包括利益に計上（公正価値）
  • 売買目的 → FVPL、損益計算書に計上（公正価値）

資本性金融商品

  • 回収と売却の両方を目的に保有 → FVOCI、その他の包括利益に計上
  • 売買目的 → FVPL、損益計算書に計上

NOTE

  • 保有による収益（受取利息）は、償却原価 × 発行利回りで一定であり、損益計算書に計上する

  • 評価損益の扱いが異なる：AMC は無視、FVOCI は OCI、FVPL は損益計算書

分類変更 ​

  • IFRS は資本性金融商品の分類変更を認めない
  • 負債性金融商品は、ビジネスモデルが変わった場合に分類変更できる

開示 ​

いずれの場合も公正価値の開示が求められる

会計処理 ​

持分法 ​

NOTE

関連会社・共同支配企業の定義：重要な影響力はあるが支配はしていない

貸借対照表での処理 ​

  • 持分投資の簿価は取得原価で計上
  • +調整後の純利益（報告純利益 - 公正価値の償却 - 未実現利益）
  • -配当
  • =期末の持分投資簿価

損益計算書での処理 ​

  • 取得企業の純利益
  • +被取得企業の調整後純利益
  • =連結純利益

内在するのれん ​

内在するのれん = 取得原価 − %× FVNIA（識別可能純資産の公正価値）

公正価値の償却 ​

FVA = FV(PPE)−BV(PPE)N（定額法）

未実現利益（繰延利益） ​

ダウンストリーム：取得企業 → 被取得企業

アップストリーム：被取得企業 → 取得企業

ダウンストリームもアップストリームも純利益として扱わず、損益計算書から控除する。

持分法の分析上の論点 ​

  • 負債比率を過小に見せる
  • 純利益率を過大に見せる（NI/REV=(NIA+NIB)/REVA）

取得法 ​

NOTE

子会社・VIE の定義：投資企業が投資先の事業活動を支配している

類型：A+B = (A+B)、A+B = A

VIE や SPE は、ある会社が別の事業体を所有せずに支配を維持するための法的な仕組みである

貸借対照表の状況 ​

  • プレミアム付きの部分取得：全部のれん > 部分のれん、全部の非支配持分 > 部分の非支配持分
  • 全部取得：全部のれん = 部分のれん、全部の非支配持分 = 部分の非支配持分 = 0
  • 割安購入：損益計算書で利得を計上

取得後の A の連結損益計算書：

項目計算式

親会社に帰属する純利益Z + % × z

手順：

  1. B の損益計算書を公正価値で調整（公正価値の償却と繰延利益）
  2. 100% 連結
  3. 親会社に帰属する純利益を計算
