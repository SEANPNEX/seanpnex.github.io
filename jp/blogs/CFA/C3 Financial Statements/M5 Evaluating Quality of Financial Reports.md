# 財務報告の質の評価

> [!Note]
>
> 試験での重要度は非常に低い。概念、警告サイン、2 つのモデルの読み方に集中すればよく、式を覚える必要はない。

## 2 つの次元

財務報告の質には 2 つの別個の次元がある。

* **報告の質**：情報は**意思決定に有用**か。つまり**目的適合的**で、**忠実に表現**されている（完全、中立、誤謬がない）か。**報告書**に関わる。
* **利益（業績）の質**：利益は**持続可能**で、投下資本に対して**十分なリターン**をもたらしているか。**事業そのもの**に関わる。

両者はつながっている。報告の質が高い場合にのみ、利益の質を判断できる。会社が忠実に報告していても、利益の質が低いことはありうる。例えば資本コストを下回るリターンを正直に報告している場合である。

**質のスペクトル**（最良から最悪へ）：

| | 報告 | 利益 |
| --- | --- | --- |
| 1 | GAAP 準拠、意思決定に有用 | 持続可能、十分なリターン |
| 2 | GAAP 準拠、意思決定に有用 | **利益の質が低い**：持続不可能、または十分なリターンでない |
| 3 | GAAP 準拠だが、会計上の選択に**偏り**がある（積極的または保守的） | |
| 4 | GAAP 準拠だが、実際の行動による利益**調整**（目標達成のための売上時期の調整や研究開発費の削減など） | |
| 5 | **GAAP からの逸脱**：基準に準拠しない会計処理 | |
| 6 | **架空**の取引：不正 | |

最初の 2 行より下では報告はもはや意思決定に有用ではないので、利益の質は評価できない。

### 積極的な報告と保守的な報告

どちらも**偏った**選択であり、どちらも報告の質を下げる。

* **積極的な**選択は、**当期の**報告利益や財政状態を高める。例えば収益の早期認識、費用処理すべきコストの資産計上、長い耐用年数の採用など。
* **保守的な**選択は、それらを**当期に**低くする。例えば多額の引当金や早期の評価減で、引当金を取り崩すときに**後の期間を膨らませる**ことが多い（**「クッキージャー」**引当金）。

保守主義も中立ではない。期間の間で利益を移して平準化し、変動を隠す。保守主義の一部は基準自体に組み込まれている。例えば減損損失は認識するが、非金融資産の未実現利益の多くは認識しない。

### 分類上の選択

金額が正しくても、項目を**どこに**表示するかで印象は変わる。

* **損益計算書**：経常的な費用を「非経常」や営業外の項目に移すと、アナリストが重視しがちな**営業**利益が上がる。
* **貸借対照表**：売掛金を非流動に、借入金を長期に分類すると、流動性比率が変わる。
* **キャッシュフロー計算書**：IFRS では支払利息と支払配当を CFO にも CFF にも分類でき、コストを資産計上すると現金流出が CFO から CFI に移る。どちらもキャッシュフロー総額を変えずに CFO を増やす。

### M&A に関する論点

買収は財務結果を調整する**機会と動機**の両方をもたらす。

* **動機**：オーガニック成長が鈍化している会社は、**減速を覆い隠し**、報告結果を年度間で比較しにくくするために買収を行うことがある。
* **取得原価の配分**：価格のより多くを**償却されないのれん**に、より少なくを減価償却・償却される識別可能資産（PP&E、顧客リスト）に配分すると、**将来の費用が減る**。このように過大計上されたのれんは、後に**減損**として現れる。
* **キャッシュフロー**：買収で支払った現金は **CFI** に入るが、取得した運転資本は後に **CFO** で現金化されるので、買収する会社は CFO を押し上げられる。
* **買収対象の数字**：買収対象は価格を上げるために取引前に利益を上方に調整することがあり、被買収会社の不適切な報告は買収者の帳簿に入ってくる。

## 2 つのモデル

2 つの統計モデルが、財務比率を使ってリスクを示す。数学や背後の経済学を理解する必要はなく、スコアの意味だけわかればよい。

**Beneish モデル：利益操作の確率。** **プロビット**・モデルが 8 つの変数を **M スコア**にまとめる。

| 変数 | 捉えるもの |
| --- | --- |
| **DSR** 指数：売上債権回転日数 | 売掛金が売上より速く伸びている（収益の水増し） |
| **GM** 指数：売上総利益率 | 利益率の低下（操作への圧力） |
| **AQ** 指数：資産の質 | より多くのコストが資産計上されている |
| **SG** 指数：売上成長率 | 成長企業は成長を維持する圧力が大きい |
| **DEP** 指数：減価償却 | 減価償却率の低下 |
| **SGA** 指数：SG&A | 売上に対する SG&A の上昇 |
| **LVG** 指数：レバレッジ | レバレッジの上昇（財務制限条項の圧力） |
| **TATA**：総発生高 / 総資産 | 現金の裏付けのない利益 |

* **M スコアが高い**ほど、**利益操作の確率が高い**。
* M スコアは z 値であり、確率は標準正規分布の確率 $N(M)$ である。
* **M > −1.78** は操作の可能性が高いシグナルとされる。−1.78 は約 3.8% の確率に相当する。

**例。** ある会社の M スコアは −1.50 である。−1.78 を上回るので警告の対象になる。操作の確率は $N(-1.50)=6.7\%$ である。

**Altman モデル：倒産申請の確率。** 判別分析で **Z スコア**を求める。

$$Z=1.2\,A+1.4\,B+3.3\,C+0.6\,D+1.0\,E$$

| | 比率 | 捉えるもの |
| --- | --- | --- |
| A | 運転資本 / 総資産 | 流動性 |
| B | 利益剰余金 / 総資産 | 累積の収益性 |
| C | EBIT / 総資産 | 現在の収益性 |
| D | 株式時価総額 / 負債簿価 | 市場から見た支払能力 |
| E | 売上高 / 総資産 | 資産回転率 |

**Z スコアが高い**ほど、**倒産の確率は低い**。

| Z スコア | 倒産の確率 |
| --- | --- |
| **3.0** 超 | 低い |
| **1.81** から 3.0 | グレーゾーン |
| **1.81** 未満 | 高い |

**例。** A の比率が 0.10、B が 0.20、C が 0.08、D が 0.90、E が 1.10：

$$Z=1.2(0.10)+1.4(0.20)+3.3(0.08)+0.6(0.90)+1.0(1.10)=2.30$$

この会社は**グレーゾーン**にある。

> [!Note]
>
> **両モデルの限界。** 特定の企業サンプルの**過去データ**で推計されているので、他の業種（Altman モデルは金融会社ではなく製造業をもとに作られた）や他の時期には当てはまらないことがある。使うのは単一期間のデータである。そしてモデルはよく知られているので、選別されると予想する経営者は自ら**比率を調整**できる。

## 利益の質 {#quality-of-earnings}

出発点は**経常的な利益**である。非経常項目（リストラ費用、資産売却益、非継続事業）を取り除き、今後も続くと期待できる利益を求める。毎年発生する「非経常」項目に注意する。

**利益の持続性。** 将来も続く利益は質が高い。翌年の利益を今年の利益に回帰する。

$$\text{Earnings}_{t+1}=\alpha+\beta_1\,\text{Earnings}_t+\varepsilon$$

$\beta_1$ が大きいほど利益の持続性は高い。利益を**現金**部分と**発生主義（アクルーアル）**部分に分け、それぞれに別のベータを与える。

$$\text{Earnings}_{t+1}=\alpha+\beta_1\,\text{Cash flow}_t+\beta_2\,\text{Accruals}_t+\varepsilon$$

研究によれば $\beta_2<\beta_1$ である。アクルーアルには見積りが多く含まれ、時間とともに反転するので、**アクルーアル部分は現金部分より持続性が低い**。したがって、アクルーアルの割合が大きい利益は**質が低い**。

**例。** $\alpha=0$、$\beta_1=0.8$、$\beta_2=0.5$ として、2 社がそれぞれ今年 100 の利益を上げる。

* A：キャッシュフロー 90、アクルーアル 10。翌年の予想：$0.8(90)+0.5(10)=77$
* B：キャッシュフロー 40、アクルーアル 60。翌年の予想：$0.8(40)+0.5(60)=62$

今年の利益は同じだが、B の利益は続く可能性が低い。

**アクルーアル比率**は、平均純営業資産（NOA）で基準化したアクルーアル部分を測る。

$$\text{Accruals ratio (balance sheet)}=\frac{\text{NOA}_{\text{end}}-\text{NOA}_{\text{beg}}}{\overline{\text{NOA}}}$$

$$\text{Accruals ratio (cash flow)}=\frac{\text{NI}-\text{CFO}-\text{CFI}}{\overline{\text{NOA}}}$$

**アクルーアル比率が高い**ほど**利益の質は低い**。例えば NOA が 1,000 から 1,200 に増えると、貸借対照表ベースのアクルーアル比率は $200/1{,}100=18.2\%$ である。

利益の質に関する**その他の警告サイン**：

* アナリスト予想などのベンチマークを、わずかな差で**一貫して達成する、あるいは少しだけ上回る**
* 質が低いことを示す**外部の兆候**：規制当局による処分、財務諸表の修正再表示
* **収益**：売掛金が売上より速く伸びる（売上債権回転日数の上昇）、預かり販売（bill-and-hold）、押し込み販売、収益を純額でなく総額で計上する
* **費用**：コストの資産計上、耐用年数の延長、棚卸資産が売上より速く伸びる（棚卸資産回転日数の上昇）
* **NI が一貫して CFO を上回る**

## 平均回帰

高すぎる、あるいは低すぎる利益は、時間とともに**業界平均に回帰する**傾向がある。競争が異常に高いリターンを削り、リターンの低い企業はリストラ、買収、撤退に向かう。

* アナリストは異常に高い、あるいは低い利益を**そのまま外挿してはならない**。通常の水準に戻っていくと予測する。
* **アクルーアル**に支えられた利益は、現金に裏付けられた利益より**速く**回帰する。

## キャッシュフローの質

CFO は純利益より**会計上の見積りの影響を受けにくい**ので、主要な基準になる。質の高い営業キャッシュフローは次のようなものである。

* **プラス**である
* **持続可能な源泉**から生じる：一時的な運転資本の削減や資産売却ではなく、中核事業から
* 設備投資、配当、債務返済を賄うのに**十分**である
* 同業他社と比べて**変動が小さい**

CFO は操作されにくいが、それでも調整は可能である。

* **タイミング**：買掛金の支払を遅らせる、売掛金を早く回収する、あるいは売却する（ファクタリング、証券化）、在庫を減らすことで、事業を改善せずに 1 期間だけ CFO を増やせる。
* **分類**：営業費用を資産計上すると流出が CFI に移り、IFRS では支払利息と支払配当を CFO の外に移せる。

CFO が NI を上回る会社は通常質が高いが、理由を確認する。繰り返せない運転資本の削減で押し上げられた CFO は持続しない。

## 貸借対照表の質

質の高い貸借対照表は次を備えている。

1. **網羅性**：すべての義務が貸借対照表に載っている。注記で**オフバランス**項目を探す。購入契約（テイク・オア・ペイ契約）、保証、ジョイント・ベンチャーや非連結の事業体への投資などである。
2. **偏りのない測定**：資産と負債が公正に測定されている。判断が最も重要なのは**のれん**などの無形資産、**レベル 3 の公正価値**、年金債務、棚卸資産である。多額ののれんの減損は、過去の買収で**払いすぎた**ことを示唆する。
3. **明瞭な表示**：項目が適切に分類され、理解できる程度に分解されている。

## リスクに関する情報源

* **財務諸表**：レバレッジ、流動性、収益性の比率と、Altman の Z スコアなどのモデルの結果。
* **監査報告書**：**無限定適正**（クリーン）意見、または限定付適正意見、不適正意見、意見不表明。**継続企業**に関する段落と、**監査上の主要な検討事項**を確認する。報告書の警告は限定的で、**遅れる**ことが多い。期末後に出され、クリーンな意見でも不正がないとは限らない。
* **財務諸表の注記**：会計方針と見積り、偶発事象、コミットメント、関連当事者取引、リスクの開示。
* **MD&A**：主要なリスク、傾向、不確実性に関する経営陣の見解。
* **SEC への提出書類**（米国）：
  * **Form NT 10-K**（または NT 10-Q）：提出が**遅れる**旨の通知。会計上の問題の警告サインであることが多い
  * **Form 8-K**：**監査人の交代**、上級経営者の退任、修正再表示などの重要事象
  * **Form 144**：**内部者による株式売却**予定の通知
  * **委任状説明書（proxy statement）**：役員報酬と関連当事者取引
* **経済メディア**：調査報道が、規制当局や監査人より先に問題を明らかにすることがある。
