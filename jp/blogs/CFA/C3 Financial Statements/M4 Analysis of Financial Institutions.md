# 金融機関の分析

## 分類

金融機関は預金者、保険契約者、投資家から資金を受け入れ、それを金融資産で運用する。主な種類は次のとおり。

* **銀行**：**預金**を受け入れて**貸出**を行い、両者の利ざやを稼ぐ
* **保険会社**：**保険料**を集めて**保険金**を支払う
  * **生命・医療保険**：長期の契約（生命保険、年金、医療保障）
  * **損害保険（P&C）**：主に短期の契約（財物損害、賠償責任）
* **その他**：投資銀行、ブローカー・ディーラー、資産運用会社、クレジットカード会社

### 特徴：システミックな重要性

金融機関の際立った特徴は**システミックな重要性**である。1 つの機関の破綻が金融システム全体と経済全体を脅かしうる。

銀行は最もシステミックに重要になりやすい。貸出、預金、決済、銀行間エクスポージャーを通じて、他の銀行、企業、家計、政府という**あらゆる主体の間につながり**を生み出すからである。

**金融危機の伝播（コンテイジョン）**は、ある機関の問題が他の機関に広がる仕組みである。銀行が破綻すると、取引相手は貸した資金で損失を被り、他の銀行の預金者は信頼を失って資金を引き出しうる。ストレス下の銀行は投げ売り価格で資産を売り、他のすべての銀行の保有資産の価値を押し下げる。最も大きく、最もつながりの多い銀行は**グローバルなシステム上重要な銀行（G-SIB）**に指定され、追加の資本を保有しなければならない。

### 厳しい規制

破綻のコストはシステム全体に及ぶので、金融機関は**厳しく規制されている**。国際機関が基準を定め、各国の規制当局がそれを適用する。

| 機関 | 役割 |
| --- | --- |
| **バーゼル銀行監督委員会** | 銀行の資本、流動性、資金調達に関する国際基準（**バーゼル III**）を定める |
| **金融安定理事会（FSB）** | 世界の金融システムを監視し、各国の規制当局を調整する。G-SIB を指定する |
| **国際預金保険協会（IADI）** | 預金保険制度の基準を定める |
| **保険監督者国際機構（IAIS）** | 保険監督の基準を定める |
| **証券監督者国際機構（IOSCO）** | 証券市場規制の基準を定める |

### 資産と負債

金融機関の貸借対照表は、他の企業のものと大きく異なる。

* **資産**は、棚卸資産や PP&E ではなく、**貸出金や有価証券**などの**金融資産**が中心である。多くは**公正価値**か、それに近い償却原価で測定されるので、貸借対照表は市場価値に近く、信用、市場、流動性リスクにさらされやすい。
* 多くの銀行の**負債**は主に**預金**からなり、顧客はすぐに引き出せる一方、それが賄う貸出は長期である。この**期間のミスマッチ**が銀行業の中核的なリスクである。
* **レバレッジ**が高い。資本は通常総資産のごく一部なので、資産のわずかな損失で資本の大部分が失われうる。このため、資本と流動性が分析の中心になる。

## 銀行の分析

### 自己資本の充実度

バーゼル委員会は 2008 年の金融危機の後、**バーゼル III** と呼ばれる銀行の国際的な規制枠組みを策定した。その目的は次のとおり。

* 原因を問わず、金融・経済ストレスから生じる**ショックを吸収する**銀行の能力を高める
* **リスク管理**とガバナンスを改善する
* 銀行の**透明性と開示**を強化する

3 種類の要件を定めている。

1. **最低所要自己資本**：資産のリスクに見合う、損失を吸収できるだけの資本
2. **最低流動性**：短期間のストレスを乗り切れるだけの流動資産（[LCR](#liquidity-position)）
3. **安定調達**：銀行の長期資産に見合う十分な長期資金（[NSFR](#liquidity-position)）

#### CAMELS アプローチ {#camels-approach}

**CAMELS** は、もともと米国の規制当局が開発した、銀行分析に広く使われる枠組みである。6 つの要素からなる。

| 文字 | 要素 | 主な問い |
| --- | --- | --- |
| **C** | 自己資本の充実度 | 損失を吸収するのに十分な資本があるか |
| **A** | 資産の質 | 貸出金や有価証券はどれだけリスクがあり、損失に引当てがされているか |
| **M** | 経営能力 | リスクは適切に識別、管理、報告されているか |
| **E** | 収益の十分性 | 収益は十分に高く、持続可能か |
| **L** | 流動性の状況 | ストレス下でも義務を果たせるか |
| **S** | 市場リスクへの感応度 | 金利や価格の変化が収益と資本にどれだけ影響するか |

##### 自己資本の充実度

自己資本の充実度は、**銀行の資産のうち資本で賄われている割合**で表される。資産はリスクが異なるので、資本は総資産ではなく**リスク・アセット（RWA）**と比較する。

$$\text{Capital adequacy ratio}=\frac{\text{Capital}}{\text{Risk-weighted assets}}$$

**リスク・アセット。** 各資産（とオフバランスのエクスポージャー）に、規制当局が定める、または銀行の承認済み内部モデルで推計した**リスク・ウェイト**を掛ける。

$$\text{RWA}=\sum_i \text{Exposure}_i\times\text{Risk weight}_i$$

安全な資産ほどウェイトは低い。現金と高格付の国債は **0%**、事業法人向け貸出は通常 **100%** で、よりリスクの高いエクスポージャーは 100% を超えるウェイトになりうる。RWA には**市場リスク**と**オペレーショナル・リスク**の所要額も含まれる。

**資本の階層（バーゼル III）。** 資本は損失吸収力によって分けられる。

| 階層 | 含まれるもの | 損失を吸収する時期 |
| --- | --- | --- |
| **普通株式等 Tier 1（CET1）** | 普通株式、利益剰余金、AOCI から、のれん、その他の無形資産、繰延税金資産などの**控除項目を差し引いたもの** | 最初に。銀行が**継続企業**である間 |
| **その他 Tier 1（AT1）** | **満期がなく**、支払が**裁量的で非累積的**な商品。例：永久非累積型優先株式、偶発転換社債（CoCo 債） | 同じく継続企業である間、CET1 の後 |
| **Tier 1 = CET1 + AT1** | | |
| **Tier 2** | 当初満期 5 年以上の**劣後債**と、一部の貸倒引当金 | 銀行が破綻したときのみ（**清算ベース**）、預金者や上位債権者より先に |
| **総資本 = Tier 1 + Tier 2** | | |

**最低所要水準**（RWA に対する割合）：

| 比率 | 最低水準 |
| --- | ---: |
| CET1 / RWA | ≥ 4.5% |
| Tier 1 / RWA | ≥ 6% |
| 総資本 / RWA | ≥ 8% |

最低水準に加えて、バーゼル III は CET1 で 2.5% の**資本保全バッファー**（したがって実質的に CET1 は 7%）、信用が過度に伸びたときに最大 2.5% の**カウンターシクリカル・バッファー**、**G-SIB** への追加賦課を設けている。リスクに基づかない**レバレッジ比率**（Tier 1 資本 / 総エクスポージャー ≥ 3%）が、銀行の内部モデルで過小評価されうるリスク・ウェイトを補完する。

**例（説明用のリスク・ウェイト）。**

| 資産 | エクスポージャー | リスク・ウェイト | RWA |
| --- | ---: | ---: | ---: |
| 現金 | 100 | 0% | 0 |
| 国債 | 300 | 0% | 0 |
| 住宅ローン | 400 | 35% | 140 |
| 事業法人向け貸出 | 200 | 100% | 200 |
| **合計** | **1,000** | | **340** |

CET1 が 25、AT1 が 5、Tier 2 が 8 のとき：

* CET1 比率 $=25/340=7.4\%$（最低 4.5%、資本保全バッファー込みで 7%）
* Tier 1 比率 $=(25+5)/340=8.8\%$（最低 6%）
* 総自己資本比率 $=(25+5+8)/340=11.2\%$（最低 8%）

総資産は 1,000 だが、要件の計算に入るのは 340 だけである。同じ 1,000 を住宅ローンと国債から事業法人向け貸出に移すと、総資産は変わらないまま RWA と必要な資本が増える。

##### 資産の質

**資産の質**は、銀行の資産に含まれる**既存および潜在的な信用リスク**の大きさに関わる。アナリストは次を見る。

1. **資産の構成**：流動性の高い資産（現金、国債）と、貸出金やリスクの高い有価証券の割合、および有価証券の測定方法（償却原価、FVOCI、FVPL、公正価値ヒエラルキーのレベル 1・2・3）
2. **貸出金の信用力**と、その予想損失に対する**引当金の十分性**

**貸出金は償却原価で測定し**、引当金を控除する。

* **貸倒引当金**は、予想信用損失（減損）に対する**貸借対照表**の資産控除勘定である。
* **貸倒引当金繰入額**は**損益計算書**の費用で、引当金を**増やす**。
* **実際の貸倒損失**（回収控除後の償却）は引当金を**減らす**。

$$\text{Allowance}_{\text{end}}=\text{Allowance}_{\text{beg}}+\text{Provision}-\text{Net charge-offs}$$

繰入額は経営陣の見積りなので、利益を動かす手段になる。引当不足は今期の利益を押し上げ、損失を先送りする。引当金を検証する比率は 3 つある。

| 比率 | わかること |
| --- | --- |
| **引当金 / 不良債権** | すでに問題を抱えた貸出金のうちどれだけがカバーされているか（カバレッジ比率） |
| **引当金 / 純償却額** | 引当金が実際の損失の何年分を吸収できるか |
| **繰入額 / 純償却額** | 損失による取り崩しと同じ速さで引当金を積み増しているか。1 未満なら引当金が取り崩されている |

比率が低下している、あるいは同業他社を大きく下回る場合、銀行は**引当不足**の可能性がある。

##### 経営能力

**有効な経営**は、健全な**内部統制**、経営陣による**透明な**コミュニケーション、高い**財務報告の質**、リスク管理とガバナンスの全体的な有効性に表れる。直接測るのは難しい。弱さの兆候には、財務諸表の修正再表示、規制上の制裁、重要な見積りの頻繁な変更がある。

##### 収益の十分性

**質の高い収益**は、一時的なものではなく**持続可能**であり、銀行の資本コストを賄い、資本を積み上げるのに十分なものである。銀行の収益の主な源泉は 3 つある。

1. **純金利収益**：貸出金と有価証券の受取利息から、預金と借入の支払利息を引いたもの
2. **役務収益**：手数料（口座、決済、資産運用）
3. **トレーディング収益**：トレーディング目的の有価証券やデリバティブからの利益

**純金利収益と役務収益**の割合が大きいほど、通常は**持続性が高い**。トレーディング収益は変動が大きく予測しにくい。純金利収益そのものの**変動が小さい**ことも望ましい。

収益の質は、その背後にある**見積り**にも左右される。貸倒引当金繰入額と、銀行独自のモデルに依存するレベル 3 資産の公正価値である。

##### 流動性の状況 {#liquidity-position}

CFA カリキュラムは、バーゼル III の 2 つの流動性比率に焦点を当てる。

$$\text{LCR}=\frac{\text{High-quality liquid assets}}{\text{Net cash outflows over 30 days under stress}}\ge100\%$$

$$\text{NSFR}=\frac{\text{Available stable funding}}{\text{Required stable funding}}\ge100\%$$

* **流動性カバレッジ比率（LCR）**は**短期**の指標である。保有する流動資産で 30 日間のストレス・シナリオを乗り切れるか。
* **安定調達比率（NSFR）**は 1 年を対象とする**構造的**な指標である。銀行の**資産基盤**が安定した**調達源**（資本、長期債務、安定したリテール預金）で賄われているか。長期貸出などの流動性の低い資産ほど、多くの安定調達を必要とする。

アナリストは次も見る。

* **調達の集中**：少数の大口預金者や、すぐに消えうる短期のホールセール調達への依存
* **契約上の満期ミスマッチ**：資産の満期と負債の期日のずれ

##### 市場リスクへの感応度 {#sensitivity-to-market-risk}

**市場リスク**は、金利、為替レート、株価、商品価格の変動から損失を被るリスクである。アナリストは次を見る。

* トレーディング勘定の**バリュー・アット・リスク（VaR）**と、**VaR 1 単位あたりのトレーディング収益**
* 資産と負債の満期、**金利更改の頻度**、**参照金利**の**ミスマッチ**。これが、金利変化に対して純金利収益と資本価値がどう反応するかを決める
* 為替エクスポージャー

## 保険会社の分析

保険会社は保険料を先に受け取り、保険金は後で支払う。その間に保険料を運用する（**フロート**）ので、**引受**の結果と**運用**の結果の両方を得る。

**損害保険（P&C）**会社は財物損害と賠償責任を引き受ける。その事業は次のような特徴を持つ。

* **景気循環的**である。これが**アンダーライティング・サイクル**である。高い利益が競争を呼び、保険料が下がり、引受能力が市場から退出して保険料が回復するまで損失が増える。
* **支払備金**に依存する。保険金は保険料を稼得した後に報告・決済されるので、保険会社は将来の保険金を見積もらなければならない。**支払備金の管理**が裁量の主な源泉である。備金の積み不足は当期利益を押し上げ、後に過去の備金を修正すること（**備金の進展**）で見積りの良し悪しが明らかになる。

**引受に関する比率：**

| 比率 | 式 | わかること |
| --- | --- | --- |
| **損害率（損害調査費込み）** | (損害額 + 損害調査費) / **既経過**正味保険料 | 引き受けたリスクの見積りの的確さ。低いほどよい |
| **事業費率** | 引受費用 / **元受**正味保険料 | 新たな保険料を得るために使った資金の効率。低いほどよい |
| **コンバインド・レシオ** | 損害率 + 事業費率 | 引受業務全体の効率。**100% 未満**なら引受利益 |
| **契約者（株主）配当率** | 契約者（株主）配当 / 既経過正味保険料 | 配当として還元される保険料の割合 |
| **配当後コンバインド・レシオ** | コンバインド・レシオ **+** 契約者配当率 | 契約者に還元した現金を考慮した後の引受効率 |

**例。** ある損害保険会社の元受正味保険料は 1,000、既経過正味保険料は 980 である。損害額と損害調査費は 640、引受費用は 300、契約者配当は 20 である。

* 損害率 $=640/980=65.3\%$
* 事業費率 $=300/1{,}000=30.0\%$
* コンバインド・レシオ $=65.3\%+30.0\%=95.3\%$：引受利益
* 契約者配当率 $=20/980=2.0\%$
* 配当後コンバインド・レシオ $=95.3\%+2.0\%=97.3\%$

> [!Note]
>
> コンバインド・レシオが **100% を超えても**必ずしも損失ではない。フロートの**運用収益**が引受損失を賄えば、保険会社は全体として利益を上げられる。

**運用。** 損害保険会社は、保険金が急に発生して支払わなければならないことがあるので、受け取った保険料を**保守的に**、主に高格付の債券で運用する。アナリストは運用資産の構成、流動性、運用利回りを見る。

**資本。** 銀行のバーゼル III と違い、保険会社には**世界共通の自己資本規制がない**。要件は各国が定める。例えば米国のリスク・ベース資本や EU の**ソルベンシー II** で、そのため資本比率は国をまたいで比較しにくい。
