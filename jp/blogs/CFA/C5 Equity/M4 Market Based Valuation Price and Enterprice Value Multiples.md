# 市場ベースの評価：株価倍率と企業価値倍率

倍率を使って株式を評価する。似た資産と比べる（比較対象法）か、予測したファンダメンタルズから倍率を導く（理論倍率）。P/E、P/B、P/S、株価キャッシュフロー倍率、配当利回り、EV 倍率を扱い、次に国際比較、モメンタム指標、倍率の平均のとり方を扱う。

## 2 つの方法

| | 比較対象法 | 予測したファンダメンタルズに基づく方法 |
| --- | --- | --- |
| 考え方 | 似た資産（比較対象、「ガイドライン企業」）の倍率から価値を求める | 会社自身の DCF や残余利益モデルから倍率を導く |
| 根拠 | **一物一価の法則**：似た資産は似た価格で売れる | 価値 = 将来キャッシュフローの現在価値で、収益性、成長、リスクで決まる |
| 結論 | **相対的な**価値（比較対象そのものが誤って価格付けされているかもしれない） | 絶対的な（本源的）価値 |

* **理論倍率**とは、どちらかの方法で求めた倍率の適正値である。理論値 > 実際値 → 割安。
* 外れ値を抑えるため、同業他社の**中央値**を使う。例えば、同業他社の P/B 中央値 2.2 × BVPS \$23 = \$50.60。残余利益による価値 \$46 は、理論 P/B 46/23 = **2.0** を意味する。

**例（最も単純な比較）。** A の EPS は \$1.50、競合 B の P/E は 22。\$37.50 では A の P/E は 25 > 22 → A は B に対して**割高**。B の P/E なら A の価値は 1.50 × 22 = **\$33**。

## 株価収益率（P/E）

| 根拠 | 欠点 |
| --- | --- |
| 収益力が価値の主な源泉 | EPS がゼロ、マイナス、ごく小さい → P/E は意味をなさない |
| 最も広く使われ、認知されている倍率 | 経常的な利益と一時的な利益を分けにくい |
| P/E の違いは長期リターンと関係がある | 経営陣の裁量が EPS をゆがめ、比較可能性を損ないうる |

### 実績 P/E と予想 P/E

* **実績 P/E** = 株価 ÷ 直近 4 四半期の EPS（TTM）。
* **予想（フォワード）P/E** = 株価 ÷ 翌年の予想 EPS：次の 4 四半期、次の 12 か月（NTM）、次の会計年度（FY1、FY2）。すべての会社に**同じ定義**を使う。利益が増加しているときは、予想 P/E は実績 P/E を下回る。
* 予想があるとき、あるいは大型買収やレバレッジの変化の後は予想 P/E が好まれる。利益が予測できないときは実績 P/E を使う。
* **NTM EPS** は会計年度の予想を時間で加重した組み合わせで、例えば (10/12) × FY1 + (2/12) × FY2。

**例。**

* **IBM**、株価 \$137.90：FY1 EPS \$13.91 → **9.9**、FY2 EPS \$14.17 → **9.7**。
* **Selene Gaming**（EPS の変動が大きい）、2020 年 8 月 9 日の株価 \$12.20：

| 定義 | EPS | P/E |
| --- | --- | --- |
| 次の 4 四半期（−0.10 − 0.50 + 0.70 + 0.80） | 0.90 | **13.6** |
| NTM：(5/12)(−0.50) + (7/12)(1.50) | 0.67 | **18.2** |
| FY2020 | (0.50) | −24.4 → 意味がない |
| FY2021 | 1.50 | **8.1** |

利益がこれほど不安定で景気に連動する場合は、正常化する。

### EPS の調整

1. **希薄化**：比較には希薄化後 EPS が好ましい。例えばシーメンス：基本 €7.12、希薄化後 €7.01、株価 €95.94 → P/E 13.47 対 **13.69**。
2. **一時的な項目** → **基礎的な**（中核的で持続的な）利益。会社が報告する「コア EPS」はルールのない非 IFRS/非 GAAP 指標であり、自分の判断を使う。損益計算書の分類だけでは不十分である。
3. **景気循環** → **正常化**（循環の中間点の）EPS。景気循環株の P/E は循環の底で高く、天井で低い（**モロドフスキー効果**）。
4. **比較可能性**：会計の違い（例：LIFO と FIFO）を調整する。

**例（Evergreen、一時的な項目）。** 株価 £50.11。報告上の TTM EPS £4.52 → P/E **11.1**。会社のコア EPS £6.01 → **8.3**。アナリストの見方（訴訟引当金だけが一時的で、償却と繰り返されるリストラは継続的）では EPS £4.60 → **10.9**。

| 正常化の方法 | 正常化 EPS | 注 |
| --- | --- | --- |
| 過去の平均 EPS | 直近の完全な 1 循環の平均 EPS | 会社の**規模**の変化を無視する |
| 平均 ROE | 循環期間の平均 ROE × **現在の** BVPS | 規模を反映する。通常こちらが好まれる |

長期の ROA × 総資産、あるいは長期の ROE × 株主資本も使える（会社が損失を計上した場合に役立つ）。

**例（Zenlandia Chemical）。** 株価 \$18.21。2014–20 年の EPS：0.74、0.63、0.61、0.54、1.07、0.88、1.08。平均 ROE 22.6%、現在の BVPS \$4.82。

* 平均 EPS = \$0.79 → P/E = **23.1**。
* 平均 ROE：0.226 × 4.82 = \$1.09 → P/E = **16.7**。BVPS は 61% 増えたので、ROE 法は大きくなった会社を反映し、より割安に見える。

**マイナスまたはごく小さい利益。** P/E は意味なし（NM）と報告する。正常化 EPS や予想 EPS を使うか、**益回り**（E/P）で順位をつける。株価がマイナスになることはないので順位は一貫し、E/P は外れ値にゆがめられにくい。例えばテスラの EPS −7.72 では、P/E は NM、E/P は −2.51%。

| 株価倍率 | 逆数 | コメント |
| --- | --- | --- |
| P/E | E/P（益回り） | どちらも一般的 |
| P/B | B/P（簿価時価比率） | 簿価がマイナスになることはまれ。研究では B/M が好まれる |
| P/S | S/P | ほとんど使われない |
| P/CF | CF/P（キャッシュフロー利回り） | どちらも一般的 |
| P/D | D/P（配当利回り） | D/P の方がはるかに一般的（無配企業では P/D は定義できない） |

### 理論 P/E と予測 P/E

ゴードン成長モデルから：

$$
\frac{P_0}{E_1}=\frac{1-b}{r-g}
$$

$$
\frac{P_0}{E_0}=\frac{(1-b)(1+g)}{r-g}
$$

どの DCF モデルでも、理論 P/E は $r$（リスク）とともに下がり、$g$ とともに上がる。より複雑なモデルでは、理論 P/E = DCF の価値 ÷ EPS。

**例。**

* **BP**：内部留保率 40%、$g$ 3.5%、$r$ 7.6% → $P_0/E_1$ = 0.60/0.041 = **14.6**。
* **トヨタ**：FCFE による価値 ¥6,980、FY2020 の EPS ¥720 → 理論予想 P/E **9.7**、市場は 6,688/720 = 9.3 → 約 4% 割安。

**予測 P/E** は、ファンダメンタルズ（配当性向、ベータ、成長）に対するクロスセクション回帰から求める。例えば、予測 P/E = 12.12 + 2.25(0.45) − 0.20(0.9) + 14.43(0.08) = **14.1** で、実際の 18 を下回る → **割高**。限界：回帰はその標本と期間にしか有効でない。係数と説明力は時とともに変わる。**多重共線性**により個々の係数の解釈が難しい。

### P/E の比較

どの倍率でも手順は同じ：（1）倍率を選んで計算する。（2）比較対象を選び、**ベンチマーク**（中央値または平均）を計算する。（3）ベンチマークを当てはめ、必要ならファンダメンタルズで調整する。（4）違いがファンダメンタルズで説明できるかを確認する。

* ベンチマーク：同業他社グループ、業界やセクター、株価指数、あるいは株式**自身の過去**。
* 比較対象は最も狭い GICS（サブ・インダストリー）や ICB（サブセクター）のグループから始め、規模や対象市場で絞り込む。
* 他の条件が同じなら：**成長が高い → 理論 P/E は高い。リスクが高い → 理論 P/E は低い**。

**例（ベライゾンと同業他社）。** 実績 P/E：AT&T 13.20、Comcast 16.23、CenturyLink NM、China Telecom 13.14、Charter 70.67、Verizon 15.03、Windstream 19.01。平均（CenturyLink を除く）24.55 は Charter にゆがめられているので、**中央値の 15.03** を使う。ベライゾンは中央値にある → 適正。AT&T、China Telecom、CenturyLink は割安に見える。キャッシュフローも確認する。通信会社は非現金費用が大きい。

**PEG レシオ** = P/E ÷ 予想 EPS 成長率（% 表示）。低いほど魅力的で、1 未満を魅力的とみなす人もいる。限界：P/E と成長の**線形**関係を仮定し、**リスク**や成長がどれだけ続くかを無視する。

**例（通信会社、ファンダメンタルズを考慮）。** CenturyLink：予想 P/E 8.89、成長率 8.52%、PEG 1.04（低 P/E 銘柄の中で最低）→ 相対的に割安。AT&T：予想 EPS \$3.63 × 同業他社の中央値 11.99 を 13.0 に引き上げ（優れた収益性、平均を下回るリスク）= **\$47.19**、株価 \$33.98 に対して → 割安。

**業界・市場との比較。** 大きなグループは個別の価格の誤りを打ち消すが、類似性は低い。時価総額加重の指数の P/E は最大の銘柄に支配されるので、中型株には**中央値**を使う。

**例（S&P 500 との比較）。** 指数の P/E 21.8。銘柄 A：P/E 15.2、過去は指数の 80%（→ 17.4）。銘柄 C：P/E 15.2、過去は 105%（→ 22.9）→ **C が割安**。銘柄 B：P/E 30、過去は 120%（26.2）→ 割高。過去の関係がまだ成り立つことが前提である。

**市場全体のモデル。**

* **FED モデル**：市場の予想 E/P が 10 年国債利回りを下回れば市場は割高。理論 P/E = 1 ÷ 国債利回り。例えば利回り 2.72% → 理論 P/E 36.8、実績 P/E は 18.9。批判：ERP と成長を無視し、インフレの扱いが不十分で、低金利では非線形になり、小さな金利の変化に非常に敏感である。
* **Yardeni モデル**：益回り = CBY − b × LTEG + 残差なので、

$$
\frac{P}{E}=\frac{1}{CBY-b\times LTEG}
$$

  ここで CBY は A 格の社債利回り、LTEG は 5 年の利益成長率のコンセンサス、$b$ は過去 0.10（その後 0.10、0.20、0.25）。CBY が高い → P/E は低い。成長が高い → P/E は高い。

**株式自身の過去。** 理論株価 = 自身の過去の P/E のベンチマーク × 直近の（または正常化した）EPS。事業構成、レバレッジ、金利、インフレが変わっていると成り立たない。

**例（ホンダ）。** 5 年間の P/E 6.9、10.0、10.9、10.8、9.7：中央値 **10.0**、平均 9.7。EPS ¥381.93 → 理論株価 ¥3,819（中央値）または ¥3,704（平均）。最近の株価約 ¥2,817–2,837 は約 24–26% 下 → 割安の可能性。

**インフレと P/E。** 実質成長がなく、全額配当、費用インフレ $I$ の転嫁率 λ、実質要求収益率 $\rho=r-I$ のとき：

$$
\frac{P_0}{E_1}=\frac{1}{\rho+(1-\lambda)I}
$$

完全転嫁（λ = 1）なら P/E = 1/ρ、まったく転嫁しない（λ = 0）なら 1/$r$。転嫁が不完全なら、**インフレが高い → P/E は低い**。インフレが同じなら、**転嫁が多い → P/E は高い**。例えば ρ = 3% のとき、λ = 75% で $I$ = 6% → **22.2**、$I$ = 2% → **28.6**。$I$ = 6% で λ = 90% → **27.8**、λ = 70% → **20.8**。

### 倍率によるターミナル・バリュー

$$
V_n=\text{Trailing P/E}\times E_n
$$

$$
V_n=\text{Forward P/E}\times E_{n+1}
$$

* **ファンダメンタルズに基づく**ターミナル倍率は、GGM を倍率として書き直したもの（$r$、配当性向、$g$ に敏感）。
* **比較対象に基づく**倍率（業界の P/E の中央値や平均、株式自身の過去の P/E）は市場のデータに根ざしているが、市場の価格の誤りをターミナル・バリューに持ち込む。

**例（石油探鉱会社）。** $r$ 10%、成熟期の配当性向 45%、業界の ROE 13%、$E_3$ \$3.00、業界の P/E 14.3。

* 比較対象：14.3 × 3.00 = **\$42.90**。
* GGM：$D_3$ = 1.35、$g$ = 0.55 × 13% = 7.15% → $V_3$ = 1.35(1.0715)/(0.10 − 0.0715) = **\$50.76**（18.3% 高い）。

## 株価純資産倍率（P/B）

| 根拠 | 欠点 |
| --- | --- |
| EPS がプラスでなくても簿価は通常プラス | 貸借対照表にない価値を無視する：人的資本、評判、自己創設のブランドや研究開発 |
| BVPS は EPS より安定している | 資産集約度やビジネスモデルが異なると誤解を招く |
| 主に流動資産を持つ会社（銀行、保険会社、投資会社）に合う | 会計：取得原価か公正価値か、インフレ、技術、資産の年数 |
| 継続企業として存続しないと予想される会社に合う | **自社株買い**が過去との比較をゆがめる |
| P/B の違いは長期リターンと関係がある | |

* 例えば 5 年間で、コルゲート・パーモリーブの P/E は 5.5% 上がったが P/B は 125.9% 上がった。主に簿価を上回る価格での自社株買いが簿価を減らしたためである（\$24 億 8,000 万 → \$15 億 3,000 万）。
* 銀行の P/B はビジネスモデルによって異なる（シティグループ 0.69、ウェルズ・ファーゴ 1.21、USバンコープ 1.63）。

$$
BVPS=\frac{\text{Equity}-\text{Preferred}}{\text{Common shares}}
$$

優先株には未払いの優先株配当を含める。

**例（TD 銀行）。** 2018 年の BVPS = (80,040 − 5,000)/1,830.4 = **CAD41.00**（2017 年：38.23、2016 年：37.58）。株価 CAD73.03 → **P/B 1.78**。

**調整**：**有形簿価**を使う（少なくとものれんは除く。特許など分離可能な無形資産は残してよい）。LIFO を FIFO に換算する。オフバランス項目を含める。公正価値に修正する。

**例（バークレイズ、2012 年）。** 株価 £2.4239、希薄化後株式数 12,614m、株主資本 £62,957m、のれんと無形資産 £7,915m。金融資産の公正価値は帳簿価額より £17,333m 低く、負債は £399m 低い。

* BVPS £4.9910 → P/B **0.49**、有形 BVPS £4.3636 → **0.56**。
* 調整後 BVPS = (62,957 − 7,915 − 17,333 + 399)/12,614 = £3.0211 → **0.80**。

**理論 P/B**（$g$ = $b$ × ROE の GGM、$B_0$ に基づく）：

$$
\frac{P_0}{B_0}=\frac{ROE-g}{r-g}
$$

$$
\frac{P_0}{B_0}=1+\frac{PV(RI)}{B_0}
$$

ここで $PV(RI)$ は予想される残余利益の現在価値である。

* 例えば ROE 12%、$r$ 10%、$g$ 7% → (0.12 − 0.07)/(0.10 − 0.07) = **1.67**。
* P/B を決めるのは **$r$ に対する ROE** である。ROE = $r$ なら P/B = 1、$g$ = 0 なら P/B = ROE/$r$。P/B が同じなら、ROE の高い株の方が割安である。

**例（証券会社）。** E\*TRADE の P/B 0.65 は、シュワブ（2.31）や TD Ameritrade（2.53）の 30% 未満で、自身の平均（1.14）の 60% 未満である。しかし、簿価と売上の予想成長率の低さ（1.5%、−1.0%）と高いベータ（1.65）がそれを説明する。

## 株価売上高倍率（P/S）

| 根拠 | 欠点 |
| --- | --- |
| 売上は操作しにくい | 利益や現金を伴わない売上成長は価値ではない |
| EPS がプラスでなくても売上はプラス | P/S は価格（資金調達後）を資金調達**前**のフローと比べている。EV/売上高を使う |
| P/E より安定している | コスト構造の違いを無視する |
| 成熟企業、景気循環企業、赤字企業に合う | 収益認識がそれでもゆがめうる |
| P/S の違いは長期リターンと関係がある | |

P/S = P/E × 純利益率。

**例（Stora Enso）。** 売上高 €10,486m、約 788.5m 株 → 1 株あたり売上高 €13.30。株価 €10.34 → **P/S 0.778**。

収益認識の危険信号：インターネット企業同士の広告の**バーター**取引（1998–2000 年）、**預かり販売**（Diebold：SEC と \$2,500 万で和解）、**総額か純額か**（Groupon の修正再表示で売上は半分以上減った）。操作が疑われるなら、より高いリスク・プレミアム（より低い理論 P/S）を使うか、その株を避ける。

**理論 P/S：**

$$
\frac{P_0}{S_1}=\frac{(E_1/S_1)(1-b)}{r-g}
$$

$$
\frac{P_0}{S_0}=\frac{(E_0/S_0)(1-b)(1+g)}{r-g}
$$

利益率とともに、直接にも成長を通じても上がる：$g=b\times PM\times\frac{Sales}{TA}\times\frac{TA}{Equity}$。

**例。**

* **Getinge**：$r$ 9%、予想利益率 9%、配当性向 35%、$g$ 7% → $P_0/S_1$ = 0.09 × 0.35/0.02 = **1.575**。2019 年の 1 株あたり売上高 SEK94.3 で、価値は **SEK148.52** となり、株価 SEK133.70 を上回る → 割安。
* **比較対象**：Getinge の P/S 1.54 は最も低い（CMD 3.96、NEO 8.79）ので最も割安に見える。しかし利益率（−2.49%）、レバレッジ、EV/売上高（1.88）は NEO（利益率 14.53%）より CMD に近いので、CMD の方がよい比較対象である。

## 株価キャッシュフロー倍率

| 根拠 | 欠点 |
| --- | --- |
| キャッシュフローは利益より操作しにくい | CF = EPS + 非現金費用は、非現金収益や運転資本の変化を無視する |
| P/E より安定している | 理論的には FCFE が望ましいが、変動が大きくマイナスのことも多い |
| 会計の保守性の違いを避けられる | CFO は調整できる（売掛債権の証券化、買掛金のアウトソーシング） |
| P/CF の違いは長期リターンと関係がある | IFRS と US GAAP で利息と配当の分類が異なる |

| キャッシュフローの尺度 | 注 |
| --- | --- |
| **CF** = EPS + 減価償却費、償却費、減耗償却費 | 簡単な近似 |
| **CFO**（キャッシュフロー計算書から） | 一時的な項目と IFRS/GAAP の違いを調整する |
| **FCFE** | 理論との結びつきが最も強い。変動が大きい（設備投資のタイミング）ので、平均や DCF の価値を使う |
| **EBITDA** | 利息前 → 株価ではなく **EV** と組み合わせる |

**例。**

* **減価償却の方法**：キャッシュフローは同じだが、A は定額法（EPS は \$10 で横ばい）、B は加速償却（EPS は毎年 29% 成長、7.50 → 12.50）。CF はどちらも 1 株 \$15。EPS の成長は会計上の産物でありうる。
* **フィリップス**：EPS €1.41 + 1 株あたり D&A €1.17 = CF €2.58。株価 €36.31 → **P/CF 14.1**。
* **コルゲート、理論倍率**：FCFE₀ \$2.66、CF \$3.26、$r$ 7.4%、$g$ 3.2% → $V_0$ = 1.032(2.66)/0.042 = **\$65.36**。理論 P/CF = 65.36/3.26 = **20.05**、P/FCFE = **24.57**。
* **2 つの会社**：A の P/CF は 9.8、B は 11.4 だが、A の成長予想は 280 bp 高く、FCFE はプラス（B はマイナス）→ A が相対的に割安。

## 配当利回り

* **根拠**：トータル・リターンの構成要素であり、リスクの小さい部分である。
* **欠点**：リターンの一部にすぎない。**配当による利益の置換**（今払うと将来の成長が下がる。ただし配当性向は将来の収益性と相関しうる）。「より安全」という議論は、市場がリスクを誤って価格付けしていることを前提とする。
* **実績利回り** = 配当率（直近の四半期配当 × 4、半期配当が不均等なら直近 1 年の合計）÷ 株価。**予想利回り** = 翌年の予想配当 ÷ 株価。

**例（BCE、BT）。** BCE：4 × 0.58 = \$2.32 ÷ \$39.53 = **5.87%**。BT（不均等な半期配当）：\$0.976/\$15.20 = **6.42%**。

**理論配当利回り**（GGM）：

$$
\frac{D_0}{P_0}=\frac{r-g}{1+g}
$$

成長が高い → 利回りは低い（高利回りのスクリーニングはバリュー志向）。$r$ が高い → 利回りは高い。配当の**安全性**を確認する：配当性向、インタレスト・カバレッジ、純有利子負債/EBITDA。

**例（公益事業）。** Duke の利回りは 4.24% だが配当性向は 89%（配当にリスクがある）。PPL の利回りは 5.37% だが成長は 0.60% だけ。Portland General は利回り 2.76% に成長 5.20% を加えて ≈ **7.96%** の期待リターンがあり、目立ったマイナス要因がない → こちらに注目する。

## 企業価値倍率

$$
\begin{aligned}
EV={}&\text{Equity}+\text{Preferred}\\
&+\text{Minority interest}+\text{Debt}\\
&-\text{Cash and ST investments}
\end{aligned}
$$

（すべて時価）。現金を差し引くのは、買収者がそれを手に入れるからである。EV は正味の買収価格である。負債は時価を使い、なければ簿価やマトリックス・プライシングの価値を使う。**総投下資本**（TIC）= 株主資本 + 負債で、現金は差し引か**ない**。

| EV/EBITDA の根拠 | 欠点 |
| --- | --- |
| **レバレッジ**の異なる会社では P/E よりよい（EBITDA は利息前） | 運転資本が増えているときは CFO を過大評価する。収益認識の影響を無視する |
| 減価償却費の違いを除ける → 資本集約的な会社（ケーブル、鉄鋼） | FCFF の方が価値と結びつく。EBITDA が設備投資を反映するのは D&A ≈ 設備投資のときだけ |
| EPS がマイナスでも EBITDA はプラスのことが多い | |

EV 倍率は**支配**の立場をとり、株価倍率よりレバレッジに鈍感である。

**例（コルゲート・パーモリーブの EV/EBITDA、\$m）。** 時価総額 863 × \$66.48 = 57,372。負債（長期借入金 6,354 + 1 年内返済分 0 + その他の非流動負債 2,269）= 8,623。非支配持分 299。現金 726 → **EV 65,034**。EBITDA = NI 2,400 + 支払利息 143 + 税金 906 + D&A 511 = **3,960** → **EV/EBITDA 16.6**。

* 優先株があれば、EBITDA は優先株主と普通株主の**両方**に帰属する純利益から始める。
* 理論 EV/EBITDA は予想 **FCFF 成長率**と **ROIC**（税引後営業利益 ÷ 投下資本）とともに上がり、**WACC** とともに下がる。
* 同業他社より低い EV/EBITDA → 相対的に割安（判断材料の 1 つ）。

**例（家庭用品）。** EV/EBITDA：コルゲート 16.9、キンバリー・クラーク 14.7、クロロックス 17.6、チャーチ & ドワイト 22.5（TIC/EBITDA でも順位は同じ。現金保有に大きな差がある場合にのみ順位が変わりうる）。コルゲートはクロロックスやチャーチ & ドワイトより割安で（チャーチ & ドワイトより成長が遅い）、キンバリー・クラークより割高である（利益率 14.8% 対 9.8%）。

**EV のその他の分母**（純利益から積み上げる）：

| 尺度 | 利息 | 税金 | 減価償却費 | 償却費 | その他 |
| --- | --- | --- | --- | --- | --- |
| FCFF | +（税引後） | | + | + | − WCInv − FCInv |
| EBITDA | + | + | + | + | |
| EBITA | + | + | | + | 償却費が大きく減価償却費が大きくないとき |
| EBIT | + | + | | | どちらも大きくないとき |

業界特有の尺度には EV/EBITDAR（航空会社）、EV/加入者数、EV/埋蔵量がある。**EV/売上高**は、資本構成の異なる会社について P/S の不整合を直す。例えば Stora Enso の株主資本 €8,154m + 負債 €2,970m − 現金 €1,130m = **€9,994m** → EV/売上高 = **0.953**。

## 理論倍率のまとめ

| 倍率 | 理論値（GGM ベース） | 上がる要因 | 下がる要因 |
| --- | --- | --- | --- |
| 予想 P/E | $(1-b)/(r-g)$ | $g$、配当性向 | $r$ |
| 実績 P/E | $(1-b)(1+g)/(r-g)$ | $g$、配当性向 | $r$ |
| P/B | $(ROE-g)/(r-g)$ | ROE − $r$ | $r$ |
| 予想 P/S | $PM_1(1-b)/(r-g)$ | 利益率、$g$ | $r$ |
| 実績 P/S | $PM_0(1-b)(1+g)/(r-g)$ | 利益率、$g$ | $r$ |
| D/P | $(r-g)/(1+g)$ | $r$ | $g$ |
| P/CF、P/FCFE | DCF の価値 ÷ CF | $g$ | $r$ |
| EV/EBITDA | （定性的） | FCFF 成長率、ROIC | WACC |

## 国際比較

違いは会計基準、文化、経済、リスク、成長機会から生じる。同じ業界の P/E も、市場全体の P/E も、国によって大きく異なる。

IFRS を US GAAP に調整したときの典型的な影響（Harris と Muller）：

| 区分 | 利益 | 株主資本 |
| --- | --- | --- |
| のれん | − | + |
| 繰延法人税 | + | + |
| 為替換算の調整 | + | − |
| 研究開発費 | − | − |
| 年金費用 | − | + |
| 有形資産の再評価 | + | − |
| その他 | − | − |

最も頻繁な調整は年金、金額で最大なのはのれんである。**P/CFO と P/FCFE は会計の違いの影響を最も受けにくく**、P/B、P/E、EBITDA 倍率は**最も受けやすい**。インフレと転嫁率の違いも P/E をゆがめる。

## モメンタム指標

| 指標 | 定義 |
| --- | --- |
| 予想外の利益（サプライズ） | $UE_t=EPS_t-E(EPS_t)$。サプライズの % = UE ÷ 予想 EPS |
| 標準化したサプライズ | UE ÷ **アナリスト予想**の標準偏差（ばらつき） |
| 標準化した予想外の利益 | $SUE_t=\dfrac{EPS_t-E(EPS_t)}{\sigma[EPS_t-E(EPS_t)]}$、**過去のサプライズ**の標準偏差（例：20 四半期）を使う |
| 相対力 | 一定期間の株式の複利リターン（株価モメンタム）、または株式 ÷ 指数。始点を 1.0 にそろえることが多い |

根拠：プラスのサプライズの後に持続的な超過リターンが続くことがあり、リターンには持続や反転が見られることがある。注意点：データ・スヌーピングと後知恵バイアス、そしてテクニカルなルールは広く使われると効かなくなる傾向がある。モメンタムは、株価が本源的価値に**いつ**収束するかのヒントになりうる。

**例。**

* **BP の標準化したサプライズ**：コンセンサス \$3.26、最高予想 \$3.74、予想の標準偏差 \$0.29 → (3.74 − 3.26)/0.29 = **1.66**。
* **SUE**：サプライズ \$0.05 で過去のサプライズの標準偏差 \$0.20 → SUE 0.25。標準偏差 \$0.07 なら → 0.71。エクソン、2013 年 9 月：(1.79 − 1.77)/0.1250 = **0.16**。フォルクスワーゲンのサプライズの % はより大きかったが、エクソンの SUE の方が大きく振れた（標準偏差が小さい）ので、「精度」は尺度による。
* **S&P 500 に対する相対力**（2018 年 3 月 = 1.0）：2019 年 8 月までに TLT **1.067**（指数比 +6.7%）、FEU **0.847**（−15.3%）、EEM **0.743**（−25.7%）。2018 年 12 月には EEM の相対力が 0.852 から 0.872 に上がり、FEU は 0.909 から 0.885 に下がった。

## 倍率の平均

$$
X_H=\frac{n}{\sum_{i=1}^{n}1/X_i}
$$

$$
X_{WH}=\frac{1}{\sum_{i=1}^{n}w_i/X_i}
$$

* 時価総額をウェイトとする**加重調和平均**が、ポートフォリオの真の合計倍率である（指数提供会社が使う）。
* 調和平均は（すべての値が等しくない限り）算術平均を下回る。高い倍率のウェイトが小さくなるので、**大きな**外れ値の影響は減るが、**小さな**外れ値の影響は増幅されうる（ゼロが下限）。
* **中央値**は両方向の外れ値を抑える。

**例（2 銘柄のポートフォリオ）。** 時価総額 €715m で利益 €71.5m（P/E 10）、時価総額 €585m で利益 €29.25m（P/E 20）。ポートフォリオの P/E = 1,300/100.75 = **12.90**。

| 尺度 | 計算 | P/E |
| --- | --- | --- |
| 算術平均 | (10 + 20)/2 | 15.00 |
| 加重平均 | 0.55(10) + 0.45(20) | 14.50 |
| 調和平均 | 1/[0.5(0.1) + 0.5(0.05)] | 13.33 |
| **加重調和平均** | 1/[0.55(0.1) + 0.45(0.05)] | **12.90** |

**例（通信会社の P/E）。** Charter の 70.67 を含めると、算術平均 25.30、中央値 15.23、調和平均 17.70（中央値に近い）。外れ値を除くと 16.43、15.03、15.39。

**複数の指標を使う。** アナリストは DCF の価値と倍率（P/E、EV/EBITDA、配当利回り）を組み合わせる。バックテストでは、**ルックアヘッド・バイアス**（当時まだ報告されていなかったデータの使用）に注意する。

**スクリーニング**は基準で銘柄の母集団を絞り込む。限界：EPS などの入力値の計算方法を管理できず、定性的要因もない。

**例（Larsen のスクリーニング）。** P/E < 20、P/B < 2、PEG < 1、利回り ≥ 3%、時価総額 > \$100 億 → 10 銘柄。彼女は**大型バリュー**の投資家で、モメンタム指標は使っていない。限界：収益性やリスクの基準がない（低い P/E は低い収益性や高いリスクを反映しているかもしれない）、データベースの入力値が調整されていない、定性的要因がない。
