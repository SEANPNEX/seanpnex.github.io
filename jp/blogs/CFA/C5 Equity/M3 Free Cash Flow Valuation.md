# フリーキャッシュフローによる評価

企業へのフリーキャッシュフロー（FCFF）と株主へのフリーキャッシュフロー（FCFE）。純利益、CFO、EBIT、EBITDA からの計算方法、予測方法、配当・自社株買い・レバレッジの影響、そして 1 段階・2 段階・3 段階の評価。優先株、実質（インフレ調整後）モデル、感応度分析、ESG、非事業資産を含む。

## FCFF と FCFE

| | FCFF | FCFE |
| --- | --- | --- |
| キャッシュフローの帰属先 | すべての資本提供者（負債、優先株、普通株） | 普通株主のみ |
| 差し引くもの | 営業費用、税金、固定資本（FCInv）と運転資本（WCInv）への投資 | 同じものに**加えて**、利息と元本（新規借入を差し引く） |
| 割引率 | **WACC** | **株主資本の要求収益率** $r$ |
| 得られるもの | 企業価値 → 株主価値 = 企業価値 − 負債（− 優先株） | 株主価値を直接 |

$$\text{Firm value}=\sum_{t=1}^{\infty}\frac{FCFF_t}{(1+WACC)^t}$$

$$\text{Equity value}=\sum_{t=1}^{\infty}\frac{FCFE_t}{(1+r)^t}$$

$$WACC=w_d\,r_d(1-t)+w_e\,r$$

ここで $w_d=D/(D+E)$、$w_e=E/(D+E)$。**時価**（または目標）のウェイトと**限界**税率を使う。

**どちらを使うか：**

* 資本構成が安定している → **FCFE**（より簡単で直接的）。
* 会社にレバレッジがあり FCFE が**マイナス**、あるいは**資本構成が変化している**なら **FCFF**（FCFF の成長はファンダメンタルズを反映し、WACC は $r$ よりレバレッジに鈍感である）。
* **調整現在価値**（APV）：企業価値 = レバレッジなしの価値（レバレッジなしの株主資本コストで FCFF を割り引く）+ 負債の正味価値（節税効果 − 財務的困難のコスト）。

**FCFE の所有者の視点。** FCFE は、会社が価値を損なわずに支払**える**額であり、実際に支払う額ではない。**支配株主**はその使い道を変えられるので、FCF モデルは支配の立場（あるいは買収対象）に合っている。

一定成長の場合（FCFF と FCFE の成長率は同じでなくてよい）：

$$
\text{Firm value}=\frac{FCFF_0(1+g)}{WACC-g}
$$

$$
\text{Equity value}=\frac{FCFE_0(1+g)}{r-g}
$$

**例（Cagiati）。** FCFF CHF7 億、$r_d$ 5.7%、$r$ 11.8%、負債/株主資本のウェイト 20/80、税率 33.33%、$g$ 5%、負債 CHF22 億、2 億株。

* WACC = 0.20(5.7%)(0.6667) + 0.80(11.8%) = **10.2%**。
* 企業価値 = 700(1.05)/(0.102 − 0.05) = 735/0.052 = CHF14,134.6m → 株主価値 = 14,134.6 − 2,200 = CHF11,934.6m → **1 株 CHF59.67**。

## FCFF と FCFE の計算

> [!IMPORTANT]
> 覚えるべき 6 つの式：
>
> $$\begin{aligned}FCFF={}&NI+NCC+Int(1-t)\\&-FCInv-WCInv\end{aligned}$$
>
> $$FCFF=CFO+Int(1-t)-FCInv$$
>
> $$\begin{aligned}FCFF={}&EBIT(1-t)+Dep\\&-FCInv-WCInv\end{aligned}$$
>
> $$\begin{aligned}FCFF={}&EBITDA(1-t)+Dep\cdot t\\&-FCInv-WCInv\end{aligned}$$
>
> $$\begin{aligned}FCFE={}&FCFF-Int(1-t)\\&+\text{Net borrowing}\end{aligned}$$
>
> $$\begin{aligned}FCFE&=NI+NCC-FCInv-WCInv\\&\quad+\text{Net borrowing}\\&=CFO-FCInv+\text{Net borrowing}\end{aligned}$$

構成要素：

* **NI**：普通株主に帰属する純利益（優先株配当の後）。
* **NCC**：非現金費用の純額（減価償却費、償却費、下表の項目）。
* **Int(1 − t)**：利息は債権者のものなので、FCFF では足し戻す。FCFF と WACC は整合していなければならない。税引後の利息には税引後の WACC。
* **FCInv**：設備投資 − 資産売却による収入。現金による買収は設備投資に数える。株式や負債で支払った買収はキャッシュフロー計算書に表れないが、**予測**には重要である。
* **WCInv**：**現金と短期借入を除く**運転資本の増加（支払手形と長期借入金の 1 年内返済分は財務）。
* **純借入**：新規借入 − 返済。
* EBIT からは減価償却費を全額足し戻す。EBITDA からは、その**節税効果** $Dep\times t$ だけを加える（減価償却費は差し引かれていない）。

**例（Cane Distribution、\$000）。** 税率 30%、金利 7%。

| | 2018 | 2019 | 2020 |
| --- | --- | --- | --- |
| 純利益 | 97.52 | 107.28 | 118.00 |
| + 減価償却費 | 45.00 | 49.50 | 54.45 |
| + Int(1 − t) | 10.98 | 12.08 | 13.28 |
| − FCInv | 0.00 | (50.00) | (55.00) |
| − WCInv | (56.00) | (11.60) | (12.76) |
| **FCFF** | **97.50** | **107.26** | **117.97** |

* CFO（86.52 / 145.18 / 159.69）+ Int(1 − t) − FCInv → 同じ FCFF になる。
* FCFE = FCFF − Int(1 − t) + 純借入（22.40 / 24.64 / 27.10）= **108.92 / 119.82 / 131.79**。

**例（Pitts Corporation、2020 年、\$m）。** NI 240、減価償却費 300、支払利息 100、税率 40%、設備投資 400、CFO 495、EBIT 500、EBITDA 800。WCInv = Δ売掛金 40 + Δ棚卸資産 30 − Δ買掛金 15 − Δ未払費用 10 = **45**（現金と支払手形を除く）。純借入 = Δ支払手形 50 + Δ長期借入金 25 = **75**。

| 出発点 | 計算 | 結果 |
| --- | --- | --- |
| NI → FCFF | 240 + 300 + 60 − 400 − 45 | **155** |
| CFO → FCFF | 495 + 60 − 400 | **155** |
| EBIT → FCFF | 500(0.6) + 300 − 400 − 45 | **155** |
| EBITDA → FCFF | 800(0.6) + 300(0.4) − 400 − 45 | **155** |
| FCFF → FCFE | 155 − 60 + 75 | **170** |
| NI → FCFE | 240 + 300 − 400 − 45 + 75 | **170** |
| CFO → FCFE | 495 − 400 + 75 | **170** |

ここで FCFE が FCFF を上回るのは、借入が大きかったからにすぎない。

### キャッシュフロー計算書における利息と配当

| | IFRS | US GAAP |
| --- | --- | --- |
| 受取利息 | 営業または投資 | 営業 |
| 支払利息 | 営業**または財務** | 営業 |
| 受取配当 | 営業または投資 | 営業 |
| 支払配当 | 営業または財務 | 財務 |

> [!IMPORTANT]
> CFO から FCFF を求めるとき、Int(1 − t) を足し戻すのは **CFO で支払利息が差し引かれている場合だけ**である。IFRS の会社が支払利息を財務に入れていれば足し戻さない。支払配当を営業に入れていれば、それを CFO に足し戻す。

### 非現金項目と運転資本

| 非現金項目 | NI からの調整 |
| --- | --- |
| 減価償却費 | 足し戻す |
| 無形資産の償却と減損 | 足し戻す |
| リストラ費用（費用） | 足し戻す |
| リストラ費用（戻入による収益） | 差し引く |
| 社債**ディスカウント**の償却 | 足し戻す |
| 社債**プレミアム**の償却 | 差し引く |
| 営業外活動の損失 | 足し戻す |
| 営業外活動の利得 | 差し引く |
| 繰延税金 | 注意して足し戻す |

* **売却益**：簿価 €60,000 の設備を €100,000 で売却 → NI から €40,000 の利得を差し引く。€100,000 は投資に表れる（FCInv を減らす）。
* **繰延税金負債**：すぐに**解消**するなら足し戻さない。成長企業が無期限に繰り延べられるなら足し戻す（買収者は後でそれを負うかもしれない）。
* **繰延税金資産**（例：損金不算入のリストラ費用から）：繰り返すと予想される場合だけ差し引く。
* **ストック・オプション**：費用は非現金だが、行使による現金と税の便益の一部は財務に入る。持続しないキャッシュフローは予測せず、**予想される**株式数（希薄化）を使う。
* 基準年から**一時的な**項目を除く。

**例（Duplico、持続可能な運転資本）。** 設備投資と減価償却費は €9 億 9,780 万と €2 億 3,540 万（2020 年）から €3 億 1,760 万と €3 億 920 万（2022 年）になった。減価償却費の増加は **NI を** Dep(1 − t) **下げる**が、**CFO を** Dep × t（節税効果）**上げる**。棚卸資産と売掛金の増加は CFO と FCFE を減らし、買掛金と未払費用の増加はそれらを増やす。資産の縮小や買掛金の増加は永遠には続かず、成長企業の運転資本の必要額も増えていく。

### フリーキャッシュフローの使途

使途は源泉に等しくなければならない。これは整合性のチェックであり、資本構成の方針も示す。

* FCFF の使途 = Δ現金 + Int(1 − t) + (返済 − 新規借入) + 配当 + (自社株買い − 発行)。
* FCFE の使途 = Δ現金 + 配当 + (自社株買い − 発行)。

**例（Pitts）。** FCFF 155 = Δ現金 10 + 60 − 75 + 配当 160 + 0。FCFE 170 = 10 + 160 + 0。CFO（495）が設備投資（400）を賄ったので、新規借入は実質的に配当の支払に回った → レバレッジが上昇。

## FCFF と FCFE の予測

1. （正常化した）基準値に**一定の成長**を当てはめる。例えば Pitts を 15% で：FCFF 155 → 178.25 → 204.99 → 235.74。
2. **構成要素を予測する**。通常は売上に結びつけ、(FCInv − Dep) と WCInv が**売上の増加分**の一定割合だと仮定する。

$$
\text{Incremental FC rate}=\frac{\text{Capex}-\text{Dep}}{\Delta\text{Sales}}
$$

$$
\text{Incremental WC rate}=\frac{\Delta WC}{\Delta\text{Sales}}
$$

$$
\begin{aligned}
FCFF={}&EBIT(1-t)\\
&-(FCInv-Dep)\\
&-WCInv
\end{aligned}
$$

目標負債比率 DR で新規投資の純額を賄う場合（非現金費用は減価償却費だけ）：

$$
\begin{aligned}
FCFE={}&NI\\
&-(1-DR)(FCInv-Dep)\\
&-(1-DR)\,WCInv
\end{aligned}
$$

**例（Pitts、売上ベース）。** 売上高 \$30 億（前年に \$3 億増加）、EBIT マージン 16.67%、税率 40%。増分固定資本率 = (400 − 300)/300 = **33.33%**、増分運転資本率 = 45/300 = **15%**。翌年の売上 +10%：

| | FCFF | FCFE（純利益率 8%、DR 50%） |
| --- | --- | --- |
| 売上高 | 3,300 | 3,300 |
| EBIT(1 − t) / NI | 330 | 264 |
| 増分固定資本 | (100) | (100) |
| 増分運転資本 | (45) | (45) |
| 純借入 | | 72.50 |
| **結果** | **185** | **191.50** |

5 年間で EBIT マージンが 16.67% から 14.5% に下がる場合：FCFF は 185.00、188.98、195.90、202.31、208.05。減価償却費以外に重要な非現金費用があると、この方法の精度は下がる。

### FCF を変えるもの、変えないもの

* **配当、自社株買い、株式発行は** FCFF も FCFE も**変えない**。それらはフリーキャッシュフローの**使途**である。
* **レバレッジの上昇**は FCFF を変えない。FCFE は新規借入の年にその額だけ増え、その後は Int(1 − t) だけ減る。負債が増えると利息の節税効果も増える。
* **FCFE と DDM**：入力値が整合していれば（FCFE = 配当）、同じ価値になる。配当がゼロや低い場合、裁量的な場合（収益性のシグナルとして弱い）、会社が買収対象の場合は、FCF モデルが好まれる。両者を動かす力は同じで、急成長企業は配当が低く、**しかも** FCFE も低い。
* 第三者の「フリーキャッシュフロー」の数値は評価向けにつくられていないことが多い。定義を確認する。

> [!IMPORTANT]
> **純利益は FCFE ではない**：設備投資、運転資本投資、純借入を無視している（等しくなるのは、設備投資 = 減価償却費で、運転資本投資も純借入もない場合だけ）。**EBITDA は FCFF ではない**：税引前であり、減価償却の節税効果、設備投資、運転資本を無視している。FCFE の代わりとしてはさらに悪い（利息と借入も無視する）。EBITDA を割り引くなら税引前の割引率が必要になる。

### 優先株

* NI から FCFF を求める：**優先株配当を足し戻す**（税引後利息に似ているが、損金算入できない）。
* NI から FCFE を求める（すでに優先株配当の後）：追加の調整はない。優先株の純**発行**は純借入と同じように扱う。
* 株主価値 = 企業価値 − 負債 − 優先株。

**例（Welch Corporation、\$m）。** 社債 400（金利 8%）、優先株 100（配当率 8%）、普通株 500（12%）。NI 110、支払利息 32、優先株配当 8、減価償却費 40、FCInv 70、WCInv 20、純借入 25、税率 30%。FCFF の成長率 4%、FCFE の成長率 5.4%。

* WACC = 0.4(8%)(0.7) + 0.1(8%) + 0.5(12%) = **9.04%**。
* FCFF = 110 + 40 + 32(0.7) + 8 − 70 − 20 = **90.4** → 企業価値 = 90.4(1.04)/0.0504 = 1,865.40 → 株主価値 = 1,865.40 − 400 − 100 = **1,365.40**。
* FCFE = 110 + 40 − 70 − 20 + 25 = **85** → 株主価値 = 85(1.054)/(0.12 − 0.054) = **1,357.42**。

## 1 段階モデル：バリエーションと感応度

**実質（インフレ調整後）モデル**は、外国株や、インフレが高いか変動が大きいところで役立つ。

$$
V_0=\frac{FCFE_0(1+g_{\text{real}})}{r_{\text{real}}-g_{\text{real}}}
$$

実質の $r$ は、業界、規模、レバレッジで調整したその国の実質リターンである。実質の $g$ は、その国の実質成長率を基準にする。

**例（Mukamba Ventures、コンゴ民主共和国）。** FCFE₀ CDF1,400、$r$ = 7.30% + 0.80% − 0.33% − 0.12% = **7.65%**、$g$ = 3.0% − 0.5% = 2.5% → $V_0$ = 1,435/0.0515 = **CDF27,864**。

**感応度分析**は入力値を 1 つずつ変えて、どれが最も重要かを見る。価値は**基準年**の FCF に比例して動く。

**例（Petrobras）。** FCFE₀ BRL2.59、$g$ 7%、$r$ = 8.9% + 1.4(5.3%) = 16.32% → $V_0$ = 2.59(1.07)/0.0932 = **BRL29.73**。

| 入力値 | 低 → 価値 | 高 → 価値 |
| --- | --- | --- |
| ベータ 1.2 / 1.6 | 33.55 | 26.70 |
| $r_f$ 7.9% / 9.9% | 33.31 | 26.85 |
| ERP 4.3% / 6.3% | 34.99 | 25.85 |
| **FCFE 成長率 5% / 9%** | **24.02** | **38.57**（最も幅が広い） |

## 多段階モデル

$$
\begin{aligned}
V_{\text{firm}}={}&\sum_{t=1}^{n}\frac{FCFF_t}{(1+WACC)^t}\\
&+\frac{FCFF_{n+1}}{WACC-g}\\
&\quad\times\frac{1}{(1+WACC)^n}
\end{aligned}
$$

$$
\begin{aligned}
V_{\text{equity}}={}&\sum_{t=1}^{n}\frac{FCFE_t}{(1+r)^t}\\
&+\frac{FCFE_{n+1}}{(r-g)(1+r)^n}
\end{aligned}
$$

* 第 2 段階の成長率は長期の持続可能な率である。衰退業界なら GDP 成長率をやや下回り、成長業界ならやや上回る。
* 第 1 段階の成長率は一定でも、**低下していく**（H モデルのように）ものでもよい。
* 「成長率」は売上、純利益、FCF そのもののいずれの成長率でもありうる。どれかを確認する。ターミナル・バリューは $FCF_{n+1}$ への GGM か倍率（P/E × EPS）から求め、通常は価値の大部分を占める。

> [!IMPORTANT]
> 成長が鈍ると、投資の必要額が利益より速く減るので、FCFE が**跳ね上がる**ことがある。$FCFE_{n+1}$ は常に第 2 段階の前提から計算し、$FCFE_n$ を $g_L$ で伸ばすだけにしない。

**例（TechnoSchaft、各段階で一定成長）。** 1 株あたり売上高 €25、3 年間 20% 成長しその後 6%。純利益率 10%。純 FCInv は売上の増加分の 50%、WCInv は 20%。40% を負債で賄う。$r$ = 7% + 1.2(4.5%) = 12.4%。

| 年 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| 1 株あたり売上高 | 30.000 | 36.000 | 43.200 | 45.792 |
| EPS | 3.000 | 3.600 | 4.320 | 4.579 |
| 純 FCInv | 2.500 | 3.000 | 3.600 | 1.296 |
| WCInv | 1.000 | 1.200 | 1.440 | 0.518 |
| 負債による調達 | 1.400 | 1.680 | 2.016 | 0.726 |
| **FCFE** | **0.900** | **1.080** | **1.296** | **3.491**（+169%） |

$TV_3$ = 3.491/(0.124 − 0.06) = €54.55、現在価値は 38.415 → **$V_0$ = 0.801 + 0.855 + 0.913 + 38.415 = €40.98**（ターミナル・バリューが約 94%）。

**例（Sindhuh、第 1 段階で EPS 成長率が低下）。** EPS₀ \$2.40。成長率 30、18、12、9、7%、その後 7%。1 株あたり純設備投資 3.00、2.50、2.00、1.50、1.00（その後 +7%）。WCInv = 純設備投資の 50%。30% を負債で賄う。$r$ = 6% + 1.1(4%) = 10.4%。

| | 2020 | 2021 | 2022 | 2023 | 2024 |
| --- | --- | --- | --- | --- | --- |
| EPS | 3.120 | 3.682 | 4.123 | 4.494 | 4.809 |
| FCFE | −0.030 | 1.057 | 2.023 | 2.919 | 3.759 |

$V_{2023}$ = 3.759/(0.104 − 0.07) = \$110.56、現在価値は 74.425 → **$V_0$ = \$78.73**。実績 P/E は現在 78.73/2.40 = 32.8、2024 年初めには 110.56/4.494 = 24.6 で、成長が衰えるにつれて P/E は下がる。

**例（Medina Werks、売上成長率と利益率が低下）。** 売上高 C\$6 億。成長率 20、16、12、10、8、7%。純利益率 14、13、12、11、10.5、10%。純設備投資は売上の増加分の 60%、運転資本は 25%。負債 40%。$r$ = 6% + 1.1(4.5%) = 10.95%。7,000 万株。

* 1–5 年目の FCFE：39.600、49.824、61.137、65.480、74.703（現在価値 ≈ 208.57）。FCFE₆ = 79.235。
* $TV_5$ = 79.235/0.0395 = C\$2,005.95m、現在価値は 1,193.12。
* 株主価値 = **C\$1,401.69m → 1 株 C\$20.02**。

**3 段階モデル**は、一定の第 1 段階、低下する（または一定の）第 2 段階、安定した第 3 段階を組み合わせる。実際のキャッシュフローが変動する場合のよい近似になる。

**例（Reliant Home Furnishings、3 段階 FCFF）。** FCFF₀ \$7 億 4,500 万、3 億 939 万株。$r$ = 5.04% + 0.9(5.5%) = 9.99%。WACC = 0.2(7.1%)(0.66) + 0.8(9.99%) = **8.93%**。負債 \$15 億 1,800 万。成長率 8.8%（1–4 年目）、その後 7.4%、6.0%、4.6%、そして 3.2%。

* FCFF：811、882、959、1,044、1,121、1,188、1,243。8 年目は 1,283。
* 1–7 年目の現在価値 = \$5,097m。$TV_7$ = 1,283/(0.0893 − 0.032) = \$22,391m、現在価値は \$12,304m。
* 企業価値 \$17,401m → 株主価値 \$15,883m → **1 株 \$51.34**。

**モデルの選択。** 安定した成熟企業（成長が経済の成長率以下）には 1 段階、高成長の後に安定する場合は 2 段階、成長 → 移行 → 成熟には 3 段階。価値を市場価格と比べて、割高か割安かを判断する。

## ESG と非事業資産

* 数値化できる ESG 項目（罰金、追加の設備投資）→ **キャッシュフロー**を調整する。数値化しにくい ESG リスク → 判断による**プレミアムを株主資本コストに加える**。

**例（American Copper Mining Co.、ESG を含む 3 段階 FCFF）。** 段階：新しい鉱山の操業前、操業中、閉山後。ESG の調整：許可が 3 年から 5 年に遅れ、水関連の設備投資で設備投資が 10% 増え、労働のリスクで株主資本コストが **75 bp** 上がる。$r_d$ = 5%(0.75) = 3.75%、$r_e$ = 3% + 1.2(5%) + 0.75% = 9.75%、WACC = 0.5(3.75%) + 0.5(9.75%) = **6.75%**。FCFF の現在価値の合計 \$19 億 3,600 万 − 負債 \$9 億 6,800 万 = 株主価値 \$9 億 6,800 万 → **1 株 \$97**、株価 \$110 に対して → **売り**。

**非事業資産**（余剰の現金と有価証券、投資目的で保有する土地、事業に使わない金融投資）は**時価で別に**評価し、加える。

$$
\begin{aligned}
V_{\text{firm}}={}&\text{Operating assets}\\
&+\text{Non-operating assets}
\end{aligned}
$$
