# 残余利益による評価

**残余利益**（RI）とは、純利益から株主資本コストの負担を差し引いたもの、つまり**すべての**資本の対価を払った後に残る利益である。RI モデルは株式の価値を、簿価に将来の予想残余利益の現在価値を加えたものとして評価する。RI、EVA、MVA、一般・1 段階・多段階の RI モデル、RI と P/B・配当モデル・フリーキャッシュフロー・モデルの関係、そしてモデルに必要な会計上の調整を扱う。

## 残余利益、EVA、MVA

純利益はすでに**負債**のコスト（利息）を差し引いているが、**株主資本**のコストは差し引いていない。そのため純利益がプラスでも価値を損なっていることがある。

$$
RI=NI-r_e\times\text{Equity capital}
$$

すべての資本提供者から見ると：RI = NOPAT − 資本コストの総額（金額で表した WACC）=（ROIC − 実効資本コスト率）× 期首資本。負債の限界コストが現在のコストに等しく、資本のウェイトが**簿価**のウェイトなら、2 つの見方は一致する。

**例（Axis Manufacturing）。** 資産 €200 万、50% を負債（税引前 7%）、50% を株主資本（12%）で賄う。EBIT €200,000、税率 30%。

* NI = (200,000 − 70,000) × 0.7 = €91,000、株主資本の負担 0.12 × 1,000,000 = €120,000 → **RI = −€29,000**。
* 資本の見方：NOPAT €140,000 − (120,000 + 0.07 × 0.7 × 1,000,000 = 169,000) = **−€29,000**。ROIC は 7% で、資本コスト率 8.45% を下回る。
* 評価：100,000 株、簿価 €10。毎年 1 株 €0.29 の価値を損なう → 現在価値 0.29/0.12 = €2.42 → 株価 ≈ **€7.58**（E/P = 0.91/7.5833 = 12%）、P/B 0.7583。RI がマイナス → P/B は 1 未満。

**経済的付加価値**（Stern Stewart の商用版）：

$$
EVA=NOPAT-(C\%\times TC)
$$

ここで $C\%$ は資本コスト、TC は総資本である。典型的な調整：研究開発費を資産計上して償却する（研究開発費の純額を NOPAT に足し戻す）。リターンが遅れる戦略的投資について資本コストの負担を一時停止する。現金ベースの税金を使う（繰延税金を除く）。LIFO 準備金を資本に加え、その増加分を NOPAT に加える。オペレーティング・リースをキャピタル・リースとして扱う。一時的な項目を調整する。

**市場付加価値：**

$$
\begin{aligned}
MVA={}&\text{Market value of the company}\\
&-\text{Book value of total capital}
\end{aligned}
$$

長期にわたるプラスの経済的利益 → 市場価値が資本の簿価を上回る。研究結果はまちまちである。付加価値の指標は ROA や ROE よりわずかにリターンとの相関が高いが、業績の予測では利益成長と比べて優れていない。

**用途。** RI モデルは個別株と指数（例：ダウ）の評価に使われる。商用版は主に**社内の業績測定**と**役員報酬**の決定のために売り込まれており、株主資本の評価のためではない。別名：経済的利益、異常利益、割引異常利益モデル、Edwards–Bell–Ohlson モデル、米国の税務評価では**超過収益法**。

## 一般的な RI モデル

$$
V_0=B_0+\sum_{t=1}^{\infty}\frac{RI_t}{(1+r)^t}
$$

$$
\begin{aligned}
V_0&=B_0+\sum_{t=1}^{\infty}\frac{E_t-rB_{t-1}}{(1+r)^t}\\
&=B_0+\sum_{t=1}^{\infty}\frac{(ROE_t-r)B_{t-1}}{(1+r)^t}
\end{aligned}
$$

* 1 株あたり RI = EPS − $r$ × **期首** BVPS。ここでの ROE は平均ではなく**期首**の簿価を使う。
* このモデルは**クリーン・サープラス関係** $B_t=B_{t-1}+E_t-D_t$ を使って DDM から導かれる。
* 将来の RI の現在価値がプラスなら、価値は簿価を上回る。

**例（カナディアン・ナショナル鉄道）。** $r$ = 1.75% + 1.02 × 7.5% = **9.40%**。BVPS CAD24.32。EPS 6.23（2019 年）と 6.96（2020 年）、DPS 2.15 と 2.32。2019 年の RI = 6.23 − 0.094 × 24.32 = **3.94**。$B_{2019}$ = 24.32 + 6.23 − 2.15 = 28.40。2020 年の RI = 6.96 − 0.094 × 28.40 = **4.29**。

**例（Bugg Properties、清算）。** EPS 2.00、2.50、4.00。DPS 1.00、1.25、12.25（清算）。$B_0$ \$6.00、$r$ 10%。

| 年 | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 期首簿価 | 6.00 | 7.00 | 8.25 |
| ROE | 33.33% | 35.71% | 48.48% |
| 株主資本の負担 | 0.60 | 0.70 | 0.825 |
| RI | 1.40 | 1.80 | 3.175 |
| 期末簿価 | 7.00 | 8.25 | 0.00 |

* RI モデル：6.00 + 1.2727 + 1.4876 + 2.3854 = **\$11.15**。DDM：0.9091 + 1.0331 + 9.2036 = **\$11.15**。
* 価値は同じだが、RI モデルは $t$ = 0 で \$6.00 を認識し、DDM は最終年から \$9.20 を得る。**RI の方が早く価値を認識する**。

**例（Alphabet、ROE が低下していく）。** $r$ 8.2%、$B_0$ \$255.40。ROE は 2019 年に 20.2% で、毎年 0.5 ポイント下がって 2043 年に 8.2% になる（以後 RI = 0）。無配。2019 年：EPS = 0.202 × 255.40 = \$51.59、負担 \$20.94、RI \$30.65、現在価値 \$28.33。2042 年まで合計すると **\$972.25** で、株価 \$1,037.39 と比べる。

## 理論 P/B と RI の決定要因

一定成長、$g = b\times ROE$ の場合：

$$
\frac{P_0}{B_0}=\frac{ROE-g}{r-g}=1+\frac{ROE-r}{r-g}
$$

$$
V_0=B_0+\frac{ROE-r}{r-g}\,B_0
$$

* RI を決めるのは **$r$ に対する ROE** と簿価である。
* ROE = $r$ → 価値 = 簿価（P/B = 1）。ROE < $r$ → P/B は 1 未満。
* RI モデルと最も密接に関係するのは **P/B** である。予想 RI の現在価値がプラスのとき、ちょうど理論 P/B が 1 を超える。
* **トービンの q** = 負債と株主資本の時価 ÷ 総資産の**再調達原価**。P/B と違い、総資本を総資産で割り、取得原価ではなく（インフレを反映する）再調達原価を使う。資産の生産性が高い → q が高い（トービンは q の平均が 1 になると予想した）。再調達原価は測るのが難しい。

## 1 段階 RI モデル

1 段階モデルは ROE と $g$ が**永久に**一定だと仮定するので、超過リターンが無限に続く。実際には ROE は平均に回帰する。高 ROE の業界には競合が参入し、低 ROE の業界は退出によって改善する。

**例（フィリップス）。** $B_0$ €13.22、株価 €35.40、ROE 12%、$g$ 6.75%、$r$ 8.5%（数値は €）：

$$
\begin{aligned}
V_0&=13.22+\frac{0.12-0.085}{0.085-0.0675}\times13.22\\
&=39.66
\end{aligned}
$$

**インプライド成長率**：$35.40=13.22+\frac{0.12-0.085}{0.085-g}\times13.22$ を解く → **$g$ = 6.41%**。ROE が $r$ を上回るので、株価は簿価の約 2.7 倍になっている。

## 多段階 RI と継続残余利益

$T$ 年分の RI を明示的に予測し、簿価を上回るターミナル・プレミアムを加える。

$$
\begin{aligned}
V_0={}&B_0+\sum_{t=1}^{T}\frac{E_t-rB_{t-1}}{(1+r)^t}\\
&+\frac{P_T-B_T}{(1+r)^T}
\end{aligned}
$$

* 現在の簿価が総価値の大きな部分を占めることが多いので、ターミナル・バリューの重要性は DDM や FCF モデルより**小さい**。
* $P_T$ はどのモデルから求めてもよい：DDM、P/E、P/B。
* **継続残余利益**は予測期間後の RI である。よく使われる仮定：
  1. RI がプラスの水準で無限に続く（インフレに合わせて成長、つまり実質で一定の場合もある）。
  2. ターミナルの年から RI はゼロ。
  3. ROE が $r$ に回帰するにつれて RI がゼロに下がる。
  4. RI は ROE が平均的な水準（例：業界の ROE。Lee–Swaminathan の業界平均への収束）に回帰することを反映する。

**持続性モデル**（Dechow、Hutton、Sloan）：

$$
\begin{aligned}
V_0={}&B_0+\sum_{t=1}^{T-1}\frac{E_t-rB_{t-1}}{(1+r)^t}\\
&+\frac{E_T-rB_{T-1}}{(1+r-\omega)(1+r)^{T-1}}
\end{aligned}
$$

持続性係数 ω は 0 と 1 の間にある。ω = 1 → RI は永久年金として続く。ω = 0 → RI は $T$ 年後に止まる。ω が高い → 価値が高い。見いだされた平均の ω は約 **0.62**（RI は年約 38% ずつ減衰する）。

| 持続性が低い | 持続性が高い |
| --- | --- |
| 極端な ROE | 配当性向が低い |
| 極端な特別（一時的）項目 | 業界の過去の持続性が高い |
| 極端な会計上の発生高 | |

**例（Zenlandia Chemical、3 つのターミナルの仮定）。** 株価 ZL\$95.6、$r$ 12%、$B_{2019}$ ZL\$28.8517。EPS 7.162 と 8.356、DPS 2.9995 と 3.2995。その後 ROE は 25%（2022–26 年）と 20%（2027–39 年）、内部留保率 60%。

| 継続 RI の仮定 | 価値 | 結論 |
| --- | --- | --- |
| 2039 年以降 RI = 0 | **ZL\$86.41** | 割高 |
| 2039 年の RI が永久に続く：TV = 23.8664/0.12 = 198.8867、PV = 198.8867/1.12²⁰ = 20.6179 | 86.41 + 20.62 = **ZL\$107.03** | 割安 |
| 持続性 ω = 0.60：23.8664/[(1 + 0.12 − 0.60)(1.12)¹⁹] = 5.33 | 83.93 + 5.33 = **ZL\$86.26** | やや割高 |

**例（URS Holdings、ターミナルの P/B）。** $B_0$ €15.00、$r$ 7.95%、EPS = 期首簿価の 25%、配当性向 30%、$P_6$ = 1.80 × $B_6$。

* 1–6 年目の RI：2.558、3.005、3.531、4.149、4.875、5.728、現在価値 **17.755**、$B_6$ = 39.475。
* ターミナル・プレミアム = 0.8 × 39.475 = 31.580、現在価値は **19.956**。
* $V_0$ = 15.000 + 17.755 + 19.956 = **€52.711**。
* DDM での確認：配当の現在価値 7.810 + $P_6$（71.054）の現在価値 44.901 = **€52.711**。

## RI と配当モデル・フリーキャッシュフロー・モデル

* 3 つは理論的に整合している。予測が整合し、割引率が同じなら（DDM、FCFE、RI は $r$、FCFF は WACC）、同じ価値になる。
* DDM と FCF モデルは将来のキャッシュフローを割り引く。RI モデルは簿価から出発して RI の現在価値を加えるので、**価値をより早く認識し**、不確実なターミナル・バリューへの感応度も低い。

**例（永久年金）。** EPS \$1.00 が永久に続き、配当性向 100%、簿価 \$6.00、$r$ 10%。DDM：1.00/0.10 = **\$10.00**。RI = 1.00 − 0.60 = 年 \$0.40 → 6.00 + 0.40/0.10 = **\$10.00**。RI モデルでは簿価が価値の 60% を占める。DDM では最初の 5 年の配当は \$3.79（約 38%）にすぎない。

RI モデルは理論倍率（RI の価値 ÷ EPS = 理論 P/E）を与え、他のモデルを検証することもできる。大きく食い違えば、前提が整合しているかを確認する。

| 長所 | 短所 |
| --- | --- |
| ターミナル・バリューが総価値のごく一部 | 会計データは操作されうる |
| 入手しやすい会計データを使う | 会計の入力値に大きな調整が必要なことがある |
| 無配の会社や近い将来 FCF がマイナスの会社にも使える | クリーン・サープラスが成り立つか、調整が必要 |
| キャッシュフローが予測できないときに使える | 支払利息が負債コストを正しく反映していると仮定する |
| 経済的な収益性に焦点を当てる | |

| 最も適している | 最も適していない |
| --- | --- |
| 無配、または配当が予測できない | クリーン・サープラスからの大きな乖離 |
| 予測期間内に予想 FCF がマイナス | 簿価と ROE が予測できない |
| 他のモデルではターミナル・バリューの不確実性が大きい | |

FCF がプラスで予測可能だが無配の会社には、**FCF モデル**の方が合っている。

#### 試験の落とし穴

* 株主資本の負担には**期首**簿価を使う。
* RI の成長 ≠ NI の成長：Mannistore（下記）では NI は 8% 成長するが、RI は約 2% 減る。
* RI がマイナスでも純利益がマイナスとは限らない。

## 会計上の論点

**相殺効果**（Bauman）：積極的な会計処理は簿価を上げるが将来の利益を下げ、**クリーン・サープラスが成り立てば**両者は相殺される。実際には成り立たないことが多く、アナリストは過去の利益を外挿する。例えば簿価 \$1,000,000、\$50,000 を費用処理した後の税引前利益 \$200,000 → ROE 20%。その \$50,000 を資産計上すると \$250,000/\$1,050,000 = **23.81%** になる。その ROE を単純に外挿すると価値を過大評価する。

### 1. クリーン・サープラスの不成立（ダーティ・サープラス、OCI）

損益計算書を通らない項目：

* 一部の金融商品の未実現の公正価値の変動（IFRS の FVOCI の株式、US GAAP の売却可能有価証券）
* 外貨換算調整
* 一部の年金の調整
* 一部のヘッジの損益の一部
* PP&E と無形資産の再評価剰余金（**IFRS のみ**）
* 自身の信用リスクによる一部の負債の公正価値の変動（**IFRS のみ**）

簿価は正しい（OCI の累計を含む）が、RI の目的では**純利益と ROE が誤表示されている**。不成立分の現在価値が差し引きゼロにならない場合にのみバイアスが生じる。自社株買いや株式発行は 1 株あたりの ROE をゆがめるので、過去の ROE は総額（NI ÷ 株主資本）で計算する。

**例。**

* **ノキアと SAP（2018 年）**：利益を通らない換算調整は +€3 億 4,100 万（ノキア）と +€8 億 8,700 万（SAP、「資本のその他の構成要素」）。どちらも利益を増やしていたはずなので、傾向が続くなら ROE を上方修正するのが妥当かもしれない（ただし為替は反転しうる）。
* **OCI を考慮した予測**：株主資本 \$1,000 に対して NI \$120（12%）、OCI −\$100、$r$ 10%。翌年の RI の成長率：将来の OCI がなければ **12%**（ROE と整合）、OCI が繰り返されれば **2.2%**、反転すれば **21.8%**。OCI が繰り返される場合に包括利益を使うと、RI は +\$20.40 ではなく 22.40 − 102 = **−\$79.60** になる。
* **Mannistore**：$r$ 10%。$P_5$ = \$68.40 の DDM → **\$43.59**。NI だけからの RI → **\$44.42**（誤り：2 年目の OCI −\$1.00 を無視している）。NI + OCI からの RI（2 年目の RI は 1.45 ではなく 0.45）→ **\$43.59** で DDM と一致する。6 年目：NI 4.56 × 1.08 = 4.92、RI 4.92 − 2.204 = 2.72 → NI は 8% 成長するのに RI の成長は約 **−2%**。

### 2. 貸借対照表の公正価値への調整

棚卸資産（LIFO、IFRS では認められない）、繰延税金、オペレーティング・リース（株主資本には影響しないが将来の利益に影響する）、引当金、無形資産を見直す。

### 3. 無形資産

自己創設の無形資産（例：広告で築いたブランド）は、取得したものでない限り認識されない。

**例（Alpha が Beta を買収）。** Alpha：簿価 5,000、ROE 12% → 価値 = 5,000 + (0.02/0.10)5,000 = **6,000**。Beta：簿価 1,000、ROE 15% → **1,500**。合計 7,500。Alpha は現金 €1,500 を支払い、超過分 €500 は 10 年のライセンスである。

* €50 の償却がある場合：NI 700、ROE 14% → 価値 **7,000**（過小評価）。
* 償却を足し戻す：NI 750、ROE 15% → **7,500** で正しい。
* 株式で支払う：簿価 6,500、ROE 11.538% → **7,500**（支払形態は価値を変えない）。

認識されていなかった資産を認識し、後で償却しても、RI の価値には**影響がない**（$B_0$ の増加が、償却と資本コストの負担で相殺される）。研究開発費を資産計上する場合と比べ、費用処理すると今の ROE は下がるが、後の ROE はわずかに上がる。成熟企業では、調整しなくても ROE は研究開発の生産性を反映している。

### 4. 一時的な項目

RI は**経常的な**利益から予測する。簿価の調整は不要である。異常項目、特別項目（US GAAP のみ）、リストラ費用、非継続事業、会計方針の変更を確認する。**毎期**計上されるリストラ費用は、実際には通常の営業費用かもしれない。SG&A と相殺されている営業外の利得に注意する。

### 5. 積極的な会計処理

収益の前倒し（注文されていない商品の出荷）や費用の繰延べ（資産計上）は、利益と簿価の両方を膨らませる。「クッキージャー」引当金：早い時期に過大な費用を計上し、後で取り崩して利益を押し上げる。

### 6. 国際的な考慮事項

Frankel と Lee は、調整しない RI が 20 か国の株価のクロスセクションの変動の約 70% を説明することを見いだした。重要な問い：利益予想は信頼できるか。クリーン・サープラスの系統的な不成立があるか。会計は認識が遅れる「質の低い」ものか。これらの問題が深刻なところでは、会計への依存が少ないモデル（例：FCFE）を使う。
