# 非上場企業の評価

非上場企業の評価には、上場企業と同じ DCF と倍率の道具を使う。違いは 3 か所の調整にある。**正常化した利益とキャッシュフロー**（分子）、**割引率**（分母）、そして支配権と市場性に関する**ディスカウントやプレミアム**である。これらの調整と、インカム・アプローチ、マーケット・アプローチ、資産ベースのアプローチを扱う。

## 上場企業と非上場企業

| 上場企業 | 非上場：企業固有 | 非上場：株式固有 |
| --- | --- | --- |
| 成熟 | ライフサイクルの初期または後期 | 株式の**流動性が低い**（主な要因） |
| 株式の流動性が高い | 規模が小さい → 要求収益率が高い | **支配の集中**（少数株主から価値を移転できる） |
| 透明性が高く、開示が標準化されている | 所有が集中し、開示が限られる | 株式の**売却の制限**（株主間契約） |
| 所有者と経営者が分離 | 所有者が経営することが多い → **プリンシパル・エージェント問題が少なく**、長期的な視点 | |

* 株式固有の要因は一般に価値を**下げる**。企業固有の要因はどちらにも働きうる（創業者が率いるスタートアップは上場同業他社より速く成長するかもしれない）。
* リスクとリターンの幅は上場企業より広い。同族企業（例：ドイツの *Mittelstand*）が多くの経済で支配的である。

## 用途と注目点

| 取引 | コンプライアンス | 訴訟 |
| --- | --- | --- |
| ベンチャー・キャピタル（初期段階、略式の評価）、プライベート・エクイティの成長投資（少数持分）や買収（支配）、負債による資金調達、IPO、買収と事業売却、倒産（継続企業か清算か）、**株式報酬** | 財務報告（例：のれんの減損テスト、ファンドの運用成績）、税務申告（再編、移転価格、相続税・贈与税） | 損害賠償、逸失利益、株主間の紛争、離婚 |

**価値の基準**は状況による。公正市場価値（報告と税務用）は、シナジーを持つ買い手にとっての**投資価値**と異なりうる。

3 つの注目点：

1. **キャッシュフローと利益の調整** → 分子
2. **割引率と要求収益率の調整** → 分母
3. **ディスカウントやプレミアム**（支配、市場性）→ 最後に適用する

## 利益とキャッシュフローの正常化

* 非上場企業の財務諸表は監査済みではなく、**レビュー**（限定的保証）や**コンピレーション**（監査人の意見なし）であることがあるので、通常は調整が必要である。
* ここでの**正常化利益**は、一時的・非経済的な項目に**加えて**継続的な異常も除き、新しい所有者の下で効率的に運営される上場企業と比較できるようにしたものである。
* 典型的な調整：関連会社への市場条件でない売上（売上高）、関連当事者への報酬や不動産の使用（費用）、ゆがんだ減価償却費、調整後の利益に対する税金、所有者への分配と上場企業の配当。
* **一度きり**の出来事（所有者が資産を拠出・引出し）と、**継続的な**ゆがみ（独立第三者間でない関連当事者取引）を区別する。
* 市場を上回る所有者の報酬（課税所得を下げる）、会社を通した個人的な費用・住宅・航空機・車両、生命保険、株主からの借入に注意する。赤字企業の所有者は自分に**少なく**しか払わず、費用を過小に見せていることがある。
* **不動産**：その不動産の収益と費用を除き、市場賃料を費用とし、不動産は（リスクと成長の異なる）非事業資産として扱う。

$$
\begin{aligned}
EBIT_{\text{norm}}={}&\text{Reported EBIT}\\
&+\text{Excess owner pay}\\
&+\text{Non-operating costs}\\
&-\text{Market rent owed}
\end{aligned}
$$

#### 例：Fyt for Life（FLI）

負債が最適水準を下回っているため、**税引後営業利益**を正常化する（利息は無視する）。税率は 17% である。

**ステップ 1. 調整。**

* CEO の報酬は 1.5m で、市場水準は 0.5m → SG&A −1.0m。
* 事業に使っていない牧場とコンドミニアム → SG&A −0.3m、減価償却費 −0.1m。

**ステップ 2. 正常化後の損益計算書。**

| SGD m | 報告値 | 調整 | 正常化後 |
| --- | ---: | ---: | ---: |
| 売上高 | 50.0 | | 50.0 |
| 売上原価（COGS） | (30.0) | | (30.0) |
| SG&A | (5.0) | +1.3 | (3.7) |
| EBITDA | 15.0 | | 16.3 |
| 減価償却費（D&A） | (1.0) | +0.1 | (0.9) |
| **EBIT** | **14.0** | | **15.4** |
| 税金（17%） | (2.38) | | (2.618) |
| **税引後営業利益** | **11.62** | | **12.782** |

**前提が異なっていた場合は？**

* 所有者（Xin）がその 1.5m を給与ではなく**配当**として受け取っていたなら、利益を**下方に**正常化する（市場水準の給与 0.5m を差し引く）。
* 同族が所有する建物を無償で使っている → 市場賃料を差し引く。

**キャッシュフローの論点。** 評価する持分（少数持分か株主資本全体か）によって前提が変わる。結果が非常に不確実なことがある（IPO、売却、倒産、承認のマイルストーン）ので、**シナリオ分析**を使う。経営陣の予測は偏っていることがある。のれんの減損テストでは**過大**、オプションの付与では**過小**になりがちである。予測に将来の資本需要が含まれているかを確認する。

$$V_0=\frac{\sum_i p_i\,V_{i,T}}{(1+r)^T}$$

#### 例：Nano Beta（シナリオ）

WACC は 15% である。仮承認の確率は 80% で、その後、最終承認が幅広い承認（40%）、限定的な承認（40%）、失敗（20%、価値は 0）となる。価値は結果が判明する $t$ = 2 時点のものである。

**ステップ 1. $t$ = 2 時点で各シナリオを評価する**（€m、キャッシュフローはそれぞれ 5% と 2% で成長）：

$$
\begin{aligned}
V_{\text{broad}}&=\frac{200\times 1.05}{0.15-0.05}=2{,}100\\
V_{\text{limited}}&=\frac{50\times 1.02}{0.15-0.02}=392.3
\end{aligned}
$$

**ステップ 2. 確率で加重し、割り引く。**

$$
\begin{aligned}
E(V_2)&=\underbrace{0.8\times 0.4}_{0.32}\times 2{,}100\\
&\quad+0.32\times 392.3\\
&=797.5\\
V_0&=\frac{797.5}{1.15^2}=603.1
\end{aligned}
$$

**€603.1m。**

**感応度。** 仮承認 60%、幅広い承認 60%、限定的な承認 20% の場合：

$$
\begin{aligned}
E(V_2)&=0.36\times 2{,}100+0.12\times 392.3\\
&=803.1\\
V_0&=\frac{803.1}{1.15^2}=607.2
\end{aligned}
$$

差はわずか €4.2m である。

## 割引率

検討すべき調整：

* **規模プレミアム**は一般的である（ただし小型株のプレミアムのデータは、関係のない財務的困難を反映しているかもしれない）。
* **負債の利用可能性とコスト**：負債を利用しにくい → 株主資本が増える → WACC が高い。営業リスクが高い → 負債コストが高い。
* **買収**：**対象会社**のリスクと資本構成を使う。買い手のより低い WACC を使うと、買い手が自ら持ち込む価値に対して売り手に支払うことになる。
* **予測のリスク**：情報が少ない、あるいは経験の浅い経営陣による予測 → 判断による高めのプレミアム。

$$
\begin{aligned}
\text{CAPM: }r_e={}&r_f+\beta\times ERP\\
\text{Expanded: }r_e={}&r_f+\beta\times ERP\\
&+SP+SCRP\\
\text{Build-up: }r_e={}&r_f+ERP+SP\\
&\pm IP+SCRP
\end{aligned}
$$

ここで SP は小型株プレミアム、SCRP は企業固有のリスクプレミアム、IP は業界プレミアムである。ビルドアップ法には**暗黙の β = 1** がある。

* CAPM は合わないことがある。非上場企業の所有者は分散投資していないことが多く、小規模企業はベータを持つ上場同業他社と比較できない。
* よいガイドラインとなる上場企業がない場合は、ビルドアップ法を使う。

#### 例：FLI の割引率

| 入力 | 値 |
| --- | --- |
| $r_f$ / ERP / ベータ | 3.8% / 5% / 1.1 |
| 小型株 / 企業固有 / 業界プレミアム | 3% / 1% / 0% |
| 負債コスト | 税引前 7.5%、税率 17% で税引後 $7.5\%\times 0.83=6.225\%$ |
| 負債/資本 | 同業他社 20%、最適 10%、実際 2% |

| 尺度 | 計算（%） | 結果 |
| --- | --- | --- |
| CAPM | 3.8 + 1.1 × 5 | **9.3%** |
| 拡張 CAPM | 3.8 + 5.5 + 3 + 1 | **13.3%** |
| ビルドアップ法 | 3.8 + 5 + 3 + 0 + 1 | **12.8%** |
| 実際の負債 2% での WACC（$r_e$ 13%） | 0.02 × 6.225 + 0.98 × 13 | **12.9%** |
| 最適な負債 10% での WACC | 0.10 × 6.225 + 0.90 × 13 | **12.3%** |

* 拡張 CAPM と CAPM の差は大部分が**規模プレミアム**である（4 ポイントのうち 3）。
* 要因が多いのに、ビルドアップ法の結果は拡張 CAPM を下回る。業界プレミアムが 0 で、ERP にベータ 1.1 を掛けていないからである（−0.5 ポイント）。
* 売却の場合は**最適な**ウェイトを使う（買収者はそこに移行するだろう）。ただし、そのより低い WACC で価格を付けると、**買い手**が行う変化に対して売り手に支払うことになる。非上場企業は通常、上場同業他社の負債水準には届かない。

## ディスカウントとプレミアム

価値の高いものから低いものへ：

1. **戦略的な支配**（シナジーのある戦略的買い手）← シナジーを含む支配権プレミアム
2. **財務的な支配**（シナジーのない財務的買い手）← 支配権プレミアム
3. 比較可能な上場企業の価値 = 市場性のある少数持分
4. 支配権のない少数持分 ← **支配権欠如ディスカウント（DLOC）**
5. 支配権がなく、**市場性もない**少数持分 ← **市場性欠如ディスカウント（DLOM）**

$$
DLOC=1-\frac{1}{1+\text{Control premium}}
$$

$$
\begin{aligned}
\text{Total}&=1-(1-DLOC)\\
&\quad\times(1-DLOM)
\end{aligned}
$$

* **DLOC**：支配権がなければ、投資家は取締役会や経営陣を選んだり、現金を分配したり、資産を売買したり、資金調達を手配したりできない。支配株主が**不釣り合いなリターン**を得る場合に正当化され、上場企業の買収で支払われた支配権プレミアムから推定する。
* キャッシュフローと割引率が支配ベース（最適な資本構成）なら、DCF の価値は通常**支配**の価値である。そうでなければ、すでに支配権の欠如を反映している。
* **DLOM**：流動的な市場がないこと（流動化の見通し、譲渡制限、買い手の層、集中度による）。通常は支配権のない持分に適用する。IPO や売却が近ければ小さく、配当がなく流動化の見込みもなければ大きい。
* DLOM の根拠：**譲渡制限付株式**の取引（間もなく取引可能になる）、**IPO 前**の取引、**プット・オプション**の価格（アット・ザ・マネーのプットのプレミアム ÷ 株価）。プットは**ボラティリティ**を通じてリスクを直接捉えるが、与えるのは価格の保護であって**流動性**ではなく、上昇余地も残すので、市場性を正確にはモデル化しない。
* その他のディスカウント：キーパーソン、ポートフォリオ（均質でない資産）、無議決権株式。
* ディスカウントは順に**掛け合わせて**適用する。まず支配、次に市場性。

#### 例：Everfloat（DLOC と DLOM） {#example-everfloat-dloc-and-dlom}

Everfloat の支配価値は GBP1.65bn、支配権プレミアムは 15% である。DLOM は Shipline のアット・ザ・マネーの 6 か月プット（株価 50、σ 60%、フォワード $50e^{0.025}=51.27$）の価格 8.40 から推定する。

**ステップ 1. DLOC。**

$$
\begin{aligned}
DLOC&=1-\frac{1}{1.15}=13.0\%\\
\text{Minority}&=1.65\times(1-0.13)\\
&=1.4355
\end{aligned}
$$

**ステップ 2. DLOM。**

$$
\begin{aligned}
DLOM&=\frac{\text{Put premium}}{\text{Share price}}\\
&=\frac{8.40}{50}=16.8\%
\end{aligned}
$$

**ステップ 3. 掛け合わせて統合する。**

$$
\begin{aligned}
\text{Total}&=1-(1-0.13)(1-0.168)\\
&=1-0.87\times 0.832\\
&=27.6\%
\end{aligned}
$$

**27.6%** であり、$13\%+16.8\%=29.8\%$ ではない。

#### 試験の落とし穴

* DLOC ≠ 支配権プレミアム（30% のプレミアム → 23.1% の DLOC）。
* ディスカウントは掛け合わせる。足さない（13% + 16.8% ≠ 27.6%）。

## 評価のアプローチ

| アプローチ | 方法 | 最も適している対象 |
| --- | --- | --- |
| **インカム**（絶対） | DCF（FCFF を WACC で、FCFE を $r_e$ で）、キャッシュフロー資本化法、超過収益法 | キャッシュフローが予測できる。予測できるなら多段階 DCF が好ましい |
| **マーケット**（相対） | ガイドライン上場企業法、ガイドライン取引法、過去の取引法 | 最もよく使われる。実際の市場データに基づくが、真の比較対象が必要 |
| **資産ベース**（絶対） | 資産の公正価値 − 負債の公正価値 | 資産の多い会社、持株会社、清算中の会社 |

ターミナル・バリューの選択肢：キャッシュフロー資本化、超過収益（RI/($r$ − $g$)）、市場倍率。

### キャッシュフロー資本化法

1 段階で成長する永久年金で、予測がなく市場の証拠も少ない安定した会社に役立つ。

$$
\begin{aligned}
V_{\text{firm}}&=\frac{FCFF_1}{WACC-g}\\
&=\frac{EBIT_1(1-t)(1-RIR)}{WACC-g}
\end{aligned}
$$

$$
RIR=\frac{g}{WACC}
$$

$$
V_{\text{equity}}=\frac{FCFE_1}{r_e-g}
$$

ここで RIR は再投資率、$r_e-g$ は**資本化率**である。株主価値 = 企業価値 − 負債の時価（負債が小さく事業が安定していれば額面でもよい）。

#### 例：Vinuvia

| 入力 | 値 |
| --- | --- |
| $FCFF_0$ | BRL15m |
| $r_e$ / 税引前 $r_d$ | 15% / 10% |
| 税率 | 34% |
| 負債 | 資本の 10%（BRL5m） |
| $g$ | 5% |

**ステップ 1. WACC。**

$$
\begin{aligned}
WACC&=0.1\times 10\%\times 0.66\\
&\quad+0.9\times 15\%\\
&=14.16\%
\end{aligned}
$$

**ステップ 2. 企業価値と株主価値。**

$$
\begin{aligned}
V_{\text{firm}}&=\frac{15\times 1.05}{0.1416-0.05}\\
&=\frac{15.75}{0.0916}=171.9\\
V_{\text{equity}}&=171.9-5=166.9
\end{aligned}
$$

**BRL166.9m。**

**感応度。** $g$ = 2% のとき：

$$
\begin{aligned}
V_{\text{equity}}&=\frac{15\times 1.02}{0.1416-0.02}-5\\
&=125.8-5=120.8
\end{aligned}
$$

**BRL120.8m** で 25% 超低い：この方法は成長率に非常に敏感である。

### 超過収益法

有形資産を公正価値で評価し、その要求リターンを上回る利益を無形資産に帰属させる。

$$
RI=NI_{\text{norm}}-WC\cdot r_{WC}-FA\cdot r_{FA}
$$

$$
RV=\frac{RI(1+g)}{r_{RI}-g}
$$

ここで $NI_{\text{norm}}$ は正常化した利益、WC と FA は運転資本と固定資産である。企業価値 = 有形資産の公正価値 + RV（無形資産の価値）。要求リターンは運転資本（最低）から固定資産、無形資産（最高）へと高くなる。会社全体に使うことはまれ（ごく小さな会社だけ）だが、財務報告で**無形資産**を評価する方法としては広く受け入れられている。

#### 例：Digigraf

| 入力 | 値 | 要求収益率 |
| --- | ---: | ---: |
| 運転資本 | €200k | 5% |
| 固定資産 | €800k | 11% |
| 無形資産（残余利益） | | 12% |
| 正常化利益 | €120k | |
| RI の成長率 | 3% | |

**ステップ 1. 残余利益。**

$$
\begin{aligned}
RI&=120-\underbrace{0.05\times 200}_{10}-\underbrace{0.11\times 800}_{88}\\
&=22
\end{aligned}
$$

**ステップ 2. 無形資産の価値。**

$$RV=\frac{22\times 1.03}{0.12-0.03}=251.778$$

**ステップ 3. 企業価値。**

$$V=\underbrace{200+800}_{\text{tangible}}+251.778=1{,}251.778$$

**€1,251,778。**

**感応度。** 要求収益率が 4%、10%、11% の場合：RI = 120 − 8 − 80 = €32k、RV = 32 × 1.03/0.08 = €412k となり、企業価値は **€1,412,000** である。

キャッシュフロー資本化法は割引率が**1 つ**（WACC）で済むが、超過収益法は複数必要である。どちらも上場の比較対象を必要としない。

### ガイドライン上場企業法

業界**に加えて**、規模、レバレッジ、ライフサイクルの段階、リスク、成長で比較対象を選ぶ。EV 倍率は P/E より一般的である（資本構成の変化に対応できる）。レバレッジでベータを調整する。

$$
\beta_U=\frac{\beta_L}{1+(1-t)(D/E)}
$$

$$
\beta_L^*=\beta_U\left[1+(1-t^*)(D/E)^*\right]
$$

#### 例：Quik Chip

同業他社の平均ベータは 1.21、D/E は 50%、税率は 21.6% である。Quik Chip は D/E が 25%、税率が 18% で、売上高 €250m に対して EBIT が €35m である。

**ステップ 1. 同業他社のベータをアンレバーする。**

$$
\begin{aligned}
\beta_U&=\frac{1.21}{1+(1-0.216)\times 0.50}\\
&=\frac{1.21}{1.392}=0.8693
\end{aligned}
$$

**ステップ 2. Quik Chip の資本構成でリレバーする。**

$$
\begin{aligned}
\beta^*&=0.8693\times\left[1+(1-0.18)\times 0.25\right]\\
&=0.8693\times 1.205\\
&=1.0475
\end{aligned}
$$

**ステップ 3. 同業他社の倍率から EV を求める。**

| 倍率 | 同業他社 | × Quik Chip | EV |
| --- | ---: | ---: | ---: |
| EV/EBIT | 17.3 | €35m | **€605.5m** |
| EV/売上高 | 2.0 | €250m | **€500m** |

EV/売上高の方が小さくなるのは、Quik Chip の EBIT マージン（14%）が同業他社（11.6%）を上回るからである。

* 複数セグメントの会社には、各セグメントの売上高や EBITDA のシェアで加重した**合成**倍率（または事業構成が同じ同業他社）を使う。
* 長所：会社の母集団が大きく、データが豊富。短所：比較可能性。リスクと成長に関する主観的な調整。
* 上場企業の取引倍率は一般に少数持分の価値である。支配権プレミアムは、買い手の**種類**（戦略的 > 財務的）、**業界**が「買収の渦中」にあるか、**支払形態**（株式による取引は信頼性が低い）による。
* 比較対象は負債比率**ではなく**、リスクと成長で選ぶ（非上場企業は負債を利用しにくい）。

**ガイドライン取引法**：会社全体の買収からの倍率。他の条件が同じなら、**支配**持分にとって最も関係の深い証拠である。シナジー、条件付き対価（例：規制当局の承認に連動したアーンアウト）、現金以外の支払、取引の件数、取引と評価日の間の時間、規模・国・税金・レバレッジの違いを考慮する。

**過去の取引法**：会社自身の株式の過去の実際の取引。

## 評価の演習

### インカム・アプローチ（FLI）

手順：（1）WACC。（2）基準年の FCFF。（3）予測 FCFF とターミナル・バリューから EV。（4）ディスカウントとプレミアム。

$$
\begin{aligned}
FCFF={}&EBITDA(1-t)+Dep\times t\\
&-\Delta\text{LT assets}-\Delta WC
\end{aligned}
$$

支配権のない立場から：

**ステップ 1. WACC = 12.55%。** $r_e$ = 13%（13.3% と 12.8% の平均）で、WACC は負債比率の前提の平均をとる。

**ステップ 2. 基準年の FCFF**（SGD m、Δ長期資産 1.2、Δ運転資本 0.5）：

$$
\begin{aligned}
FCFF&=16.3\times 0.83+0.9\times 0.17\\
&\quad-1.2-0.5\\
&=11.982
\end{aligned}
$$

同様に、$15.4\times 0.83+0.9-1.7=11.982$ である。

**ステップ 3. EV と株主価値。** FCFF は 5 年間 2%（悲観）、5%（基本）、8%（楽観）で成長し、その後 3% 成長する：

$$TV_5=\frac{FCFF_5\times 1.03}{0.1255-0.03}$$

| SGD 百万 | 悲観 | 基本 | 楽観 |
| --- | --- | --- | --- |
| 5 年目の FCFF | 13.229 | 15.292 | 17.605 |
| ターミナル・バリュー | 142.680 | 164.934 | 189.881 |
| EV | 124.027 | 140.202 | 158.161 |
| 株主価値（− 負債 2.5） | 121.527 | 137.702 | 155.661 |
| 18% の DLOM 適用後（DLOC なし） | **99.653** | **112.916** | **127.642** |

**ステップ 4.** 18% の DLOM を適用する（DLOC はなし：キャッシュフローはすでに非支配ベースである）。表の最終行のとおりとなる。

### マーケット・アプローチ（Everfloat）

手順：（1）事業ごとに比較対象を選ぶ。（2）倍率を集めて加重する。（3）倍率から EV（上場企業相当の価値）を求める。（4）DLOC と DLOM を適用する。

$$
\text{Composite}=\sum_i w_i\times\text{Multiple}_i
$$

#### 例：Everfloat（合成倍率）

| GBP m | 海運 | 物流 | エネルギー | 合計 |
| --- | ---: | ---: | ---: | ---: |
| 売上高 | 700 | 250 | 50 | 1,000 |
| EBITDA | 187.5 | 75 | −12.5 | 250 |
| 同業他社の EV/売上高 | 2.8 | 1.1 | 8.0 | |
| 同業他社の EV/EBITDA | 8.2 | 8.1 | 20.0 | |

**ステップ 1. EV/売上高**（売上高で加重）：

$$
\begin{aligned}
\text{Composite}&=0.70\times 2.8+0.25\times 1.1\\
&\quad+0.05\times 8.0\\
&=2.635\\
EV&=2.635\times 1{,}000=2{,}635
\end{aligned}
$$

セグメント別：1,960 / 275 / 400（物流が最も価値が低い）。

**ステップ 2. EV/EBITDA**（EBITDA で加重）：

$$
\begin{aligned}
\text{Composite}&=0.75\times 8.2+0.30\times 8.1\\
&\quad-0.05\times 20.0\\
&=7.58\\
EV&=7.58\times 250=1{,}895
\end{aligned}
$$

エネルギーの EBITDA はマイナスのためマイナスの価値を意味するので、エネルギーは代わりに売上高で評価する。

**ステップ 3. 合計 27.6% のディスカウントを適用する**（[上](#example-everfloat-dloc-and-dlom)を参照）：

| | EV/売上高 | EV/EBITDA |
| --- | ---: | ---: |
| 上場企業相当の EV | 2,635 | 1,895 |
| × (1 − 0.276) | **1,907.74** | **1,371.98** |

平均は **GBP1,639.86m** である。

> [!NOTE]
>
> **教科書の問題点。**
>
> * FLI：ある例では実際の構成での WACC を 12.9% と計算しているが、まとめの表は 12.8% としている。選んだ WACC 12.55% は 12.8% と 12.3% の平均である。悲観シナリオのターミナル・バリューは最初 SGD141,295,059 と示され、その後 142,680,302 と計算されている（表は 142.680 を使う）。式は「(1 + 0.02)」と書かれているが、計算では FCFF₅ をターミナルの 3% で伸ばしている。FCFF の表は EBITDA（16.3m）を「EBIT」としている。表の EV は再現できる。
> * Vinuvia：$g$ = 2% の式の分子はまだ BRL15,750,000 となっているが、答えの BRL1 億 2,080 万は 15m × 1.02 = 15.3m を使っている。後の確認問題は WACC を 15% とし、RIR = 5%/15% = 33.3% と計算している。例の 14.2% なら約 35% になる。
> * Digigraf：確認問題は残余利益を「EUR 32,000,000」と書いているが、EUR32,000 である。
> * Quik Chip：解答はリレバー後のベータをアンレバーのベータと同じ 0.8693 と印刷している。0.8693 × [1 + 0.82 × 0.25] = 1.0475。
> * Everfloat：ある例は合成 EV/売上高を 2.6 に丸めているが、他の箇所では 2.635 である。
