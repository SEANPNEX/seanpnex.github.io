# 株式評価

「価値」とは何か、認識される価格の誤りはどこから来るのか。評価は何に使われるのか。そして 5 段階の評価プロセス。絶対評価モデルと相対評価モデル、サム・オブ・ザ・パーツ評価、モデルの選び方を含む。株式分野の残りの土台となる単元である。

## 価値と価格

**評価（バリュエーション）**とは、資産の将来リターンに関わる変数、似た資産との比較、あるいは（関係がある場合は）清算時に得られる額から、資産の価値を推定することである。

### 本源的価値と市場価格

* **本源的価値**（IV）は、投資家が資産の投資特性を完全に理解したうえで付ける価値である。
* 効率的市場では、価格は IV の最良の推定値である。しかし **Grossman–Stiglitz のパラドックス**によれば、価格が完全に効率的なら誰も分析にお金を払わないので、価格は効率的になりえない。**合理的な効率的市場**の見方：投資家は、コストを賄える高いリターンが期待できる場合にのみ情報を集める。IV を特定するのは難しく、取引にはコストがかかるので、価格は価値から乖離しうる。
* **アルファ**（超過リターン）は、リスクに見合うリターンを上回る部分である。**認識される価格の誤り**は、推定した IV から価格を引いたものである。

$$
\begin{aligned}
\text{Ex ante alpha}={}&E(R)\\
&-\text{Required return}\\
\text{Ex post alpha}={}&R_{\text{actual}}\\
&-R_{\text{required, same period}}
\end{aligned}
$$
* 投資家の期間内に価格が価値に収束するには、**カタリスト**（市場や企業の出来事）が必要なことがある。

認識される価格の誤りには 2 つの源泉がある。

$$
\begin{aligned}
E(IV)-P ={}& \underbrace{(IV-P)}_{\text{true mispricing}}\\
&+\underbrace{(E(IV)-IV)}_{\text{valuation error}}
\end{aligned}
$$

超過リターンを生むのは真の価格の誤りだけである。一貫して勝つには、アナリストの予想が**コンセンサスと異なり、かつ平均して正しく**なければならない。

### 価値の定義

| 定義 | 意味 |
| --- | --- |
| **継続企業価値** | 会社が予見可能な将来にわたって事業を続け、価値を最大化するように資産を使い、最適な資金調達ができると仮定した価値。これらの単元の焦点 |
| **清算価値** | 会社が解散し、資産を個別に売却した場合の価値。通常は継続企業価値を下回る（資産がともに働き、人的資本も加わると価値が増す）が、長く赤字が続く会社は「生きているより死んだ方が価値がある」ことがある。**秩序ある**清算は、強制的な即時売却より多くを得る |
| **公正市場価値** | 強制されていない、情報を持つ自発的な買い手と売り手の間の価格。税務や非上場企業の売買契約に使う。経営陣が所有者のために行動すれば、長期の市場価格はこれに近づくはず |
| **公正価値**（財務報告） | 知識のある自発的な当事者間で、独立第三者間取引により交換される額。例えば減損テストに使う。公正市場価値と関連するが同じではない |
| **投資価値** | **特定の**買い手にとっての価値。その買い手のシナジーや要件を含む |

> [!IMPORTANT]
> **上場株式**について関係する定義は、**継続企業の前提の下での本源的価値**である。

## 株式評価の用途

* **銘柄選択**（主な用途）：IV と比較対象に照らして、株式は適正価格か、割高か、割安か。
* **市場の期待の推測**：モデルを価格に等しいとおき、1 つを除くすべての入力値を入れて、その 1 つを解く（リバース・エンジニアリング）。
* **企業の出来事の評価**：合併・買収、事業売却、スピンオフ、非公開化取引（および通貨として使う買収者の株式の価値）。
* 合併条件に関する**フェアネス・オピニオン**。
* **事業戦略とビジネスモデルの評価。**
* アナリストや株主との**コミュニケーション**。
* **非上場企業の鑑定評価**（取引、税務、IPO）。
* **株式報酬**。

## 評価のプロセス

1. **事業を理解する**：業界・競争分析と利益の質。
2. 会社の業績を**予測する**。
3. 適切な評価モデルを**選ぶ**。
4. 予測を評価に**変換する**。
5. 評価の結論を**適用する**。

### 1. 事業の理解

**業界・競争分析**は 3 つの問いを立てる。

* 会社の属する業界は、どれだけ**魅力的**か（持続的な収益性の見通し）？ → 業界構造、ポーターの 5 つの力。
* 会社の**相対的な競争上の地位**と戦略は何か？ → 市場シェアの水準と推移、基本戦略。
* 戦略をどれだけうまく**実行**してきたか、見通しはどうか？ → 長期にわたる財務報告（10 年前、5 年前、直近 2 年）と定性的要因。単純な外挿は避ける。長期では、成長は**平均に回帰する**（経済の成長率）。

| ポーターの 5 つの力 | 業界の収益性にとって有利な条件 |
| --- | --- |
| 業界内の競争 | 競合が少ない、および/またはブランドが強い |
| 新規参入の脅威 | 参入コストその他の障壁が高い |
| 代替品の脅威 | 代替品が少ない、または切り替えコストが高い |
| 供給者の交渉力 | 供給者が多い |
| 買い手の交渉力 | 顧客が多い |

ポーターの 3 つの競争戦略：

1. **コスト・リーダーシップ**：最も低コストの生産者になり、同等の製品を業界平均またはその近くの価格で売る。
2. **差別化**：買い手が評価する独自の製品を、プレミアム価格で提供する。
3. **集中**：対象とするセグメントで、コスト集中か差別化集中によって勝つ。

**ビジネスモデル**とは、会社がどう稼ぐか（顧客、製品、提供方法、資金調達）である。例えば、座席クラスが 1 つ、機材が 1 種類の格安航空会社。

* 新しい会社や製品では、**非財務的な指標**（臨床試験の結果、ユニーク訪問者数）が重要になる。
* 情報源：規制当局への提出書類（10-K/20-F の事業の説明と MD&A、10-Q/6-K の中間報告）、決算発表、カンファレンス・コール、IR、第三者。**Regulation FD** と CFA 基準は、重要な未公開情報の利用を禁じている。
* ESG の情報源（例：米国の自動車）：サステナビリティ報告書、OSHA、EEOC、SASB、カーボン・ディスクロージャー・プロジェクト、Ceres。

**利益の質の分析**は、**すべての**財務諸表を精査し、（1）業績がどれだけ**持続可能か**、（2）報告が経済的実態をどれだけ正確に反映しているかを見る。

* 一時的な部分（訴訟の勝訴、一時的な減税、営業外資産の売却益）が大きい利益は質が低い。
* まず**純利益と営業キャッシュフローを比べる**。現金部分の方が**持続性が高い**。アクルーアルが大きいと将来の ROA が低くなる（Sloan 1996）、つまり利益の質が低い。

$$
\begin{aligned}
\text{Accrual component}\\
=NI-(CFO+CFI)
\end{aligned}
$$
* 資産勘定が売上よりはるかに速く伸びていれば（売掛金、繰延費用）、積極的な会計処理を示している可能性がある。

| 分野 | 警告サイン | 考えられる意味 |
| --- | --- | --- |
| 収益と利得 | 収益の早期認識（預かり販売、据付・検収前の売上計上） | 利益を押し上げ、業績の悪化を隠す |
| | 営業外の収益や利得を営業に分類 | 一時的かもしれない。悪化を隠す |
| 費用と損失 | 引当金（リストラ、貸倒、繰延税金資産の評価性引当金）が多すぎる、または少なすぎる | 期間の間で利益を移す |
| | 支出（顧客獲得、製品開発）の資産計上 | 将来の利益を犠牲にして当期の利益を押し上げる |
| | 積極的な見積り（減損、長い耐用年数と償却期間、高い年金の割引率、低い昇給率、高い制度資産の期待収益率） | 当期の利益を押し上げる。変更が問題を隠すことがある |
| 貸借対照表 | オフバランスの資金調達（売掛債権の証券化） | 資産と負債の誤表示 |
| 営業キャッシュフロー | 当座借越の増加を営業に分類 | CFO が水増しされる |

**不正のリスク要因**（動機、機会、姿勢）：目標達成の圧力と支配的な経営陣、利益や株価に連動した報酬、収益性への圧力、財務制限条項や予想の圧力、関連当事者取引、複雑な構造、経営者・取締役・法律顧問の高い離職率、監査人との対立や監査人の交代、違反や提出遅延の履歴。

### 2. 会社の業績の予測

* **トップダウン**：経済から業界、会社へ（例：家電メーカーの販売台数を GDP × 市場シェア × 価格で求める）。
* **ボトムアップ**：詳細な予測を積み上げる（例：既存店と新店の 1 平方メートルあたり売上）。

業界分析と財務諸表分析を組み合わせ、定性的要因（経営陣の能力と誠実さ、会計の透明性）も含める。

### 3. 評価モデルの選択

**絶対評価モデル**は、資産の**本源的価値**を直接推定し、価格と比べる。

* **現在価値（DCF）モデル**（基本的なアプローチ。非上場企業の鑑定では「インカム・アプローチ」）：
  * 配当割引モデル：株主が受け取るキャッシュフロー。
  * フリーキャッシュフロー：FCFE（負債の支払後）と FCFF（支払前）。
  * 残余利益：資本の機会費用を上回る発生主義の利益。
* 株式の評価は債券より難しい。キャッシュフローは契約で決まっておらず、満期がなく、割引率は主観的である。そのため価値は**幅**で示し（Graham と Dodd）、**感応度分析**を行う。
* **資産ベースの評価**：支配する資産の市場価値。天然資源会社（例：Petrobras は埋蔵量から採掘コストを引く、Weyerhaeuser は森林）や、サム・オブ・ザ・パーツの中の 1 部門（例：Occidental）に向く。

**相対評価モデル**は、他の資産に対する相対的な価値を求める（似た資産は似た価格で売れるはず）。**株価倍率**（P/E、P/CF）や**企業価値倍率**（EV/営業利益）を使う。比較対象法である。

* 比較対象の株より P/E が低いのは、必ずしも割安ではなく**相対的に割安**という意味である。比較対象そのものが割高かもしれない。
* 保守的な使い方では、ベンチマークに対して銘柄をオーバーウェイトやアンダーウェイトにする。積極的な**相対価値投資**には**ペア・トレード**がある（市場の方向にかかわらず、相対的に割安な株を買い、割高な株を売る）。
* 利点：簡単で、市場価格に結びつき、経済的に筋が通っており、広く理解されている。比較対象が適正に評価されている場合にのみ本源的価値を与える。

**モデルの選び方。** モデルは次に合っているべきである。

* **会社の特徴**：資産の性質と、それがどう価値を生むか。銀行（資産の大半が市場性のある資産）は、サービス会社より資産ベースや相対評価（P/B）に向いている。
* **データの質と入手可能性**：配当の履歴がなければ、「より簡単な」DDM は FCF より信頼性が低いかもしれない。EPS が不安定かマイナスなら、P/E の比較は難しい。
* **分析の目的**（アナリストの立場を含む）：**支配権を持つ**買い手は、キャッシュフローの使い道を変えられるので、配当ではなく FCF を使うかもしれない。他人のレポートを読むときは、書き手の立場とバイアスに注意する。

**複数のモデル**を使うと洞察が増す（機関投資家は平均約 17 の要因を使う。総合ランキングやスクリーニングが一般的）。絶対評価モデルも相対評価モデルも**継続企業**を前提としている。

**サム・オブ・ザ・パーツ評価。** 各事業を独立した継続企業として評価し、合計する。**分割価値**または**プライベート・マーケット・バリュー**である。

* セグメントが**評価上の特性の異なる**業界にある場合や、再編（スピンオフ、スプリットオフ、トラッキング・ストック、カーブアウト）に最も役立つ。
* 分割価値が継続企業価値を上回れば、事業売却やスピンオフを促すことがある。

$$
\begin{aligned}
V_{\text{SOTP}}={}&\sum_i V_{\text{segment }i}\\
&-\text{Corporate costs}\\
&-\text{Unallocated items}
\end{aligned}
$$

**コングロマリット・ディスカウント。** 市場は、**無関係な**複数の事業を営む会社を、専業の会社より低く評価する。説明として：

* 非効率な社内の資本配分（社内資本市場は株主価値を最大化しない）。
* 内生的な要因（業績の悪い会社ほど、無関係な事業を買って拡大する傾向がある）。
* 研究上の測定誤差（ディスカウントは実際には存在しない）。

中核事業とのシナジーが少ない事業を売却すると、最もはっきり見える。

### 4. 予測から評価への変換

* **感応度分析**：入力値（売上と利益率を通じた成長、割引率、競合の反応）に応じて価値がどう変わるか。
* **状況に応じた調整**：
  * **支配権プレミアム**：支配的な持分（取締役会の支配、資産の再配置、資本構成の変更）は、一般的なモデル価値より価値が高い。
  * **市場性欠如ディスカウント**：**公開市場のない**株式には追加のリターンが必要である。
  * **流動性欠如ディスカウント**：上場しているが取引が**少ない**株式。
  * **ブロッケージ要因**：売買高に比べて大きな（ただし支配権のない）ブロックを売ると、小口の市場価格より低い額しか得られない。

### 5. 評価の結論の適用

* 利用者：**セルサイド**のアナリスト（顧客向けの証券会社のリサーチ）、**バイサイド**のアナリスト（ポートフォリオ・マネジャーや委員会向けのレポート。クオンツ・アナリストは銘柄を順位付けする）、企業や投資銀行のアナリスト（買収対象）、独立系のリサーチ会社。
* アナリストは顧客のよりよい意思決定を助け、市場をより効率的にし（資本が最もよい用途に向かう）、**経営陣を監視する**（エージェンシー・コストを減らす）。
* 有効なリサーチ・レポートは、適時で明確であり、客観的で十分に調査され、主要な仮定が示されており、**事実と意見を区別し**、分析・予測・評価・推奨が内部で整合し、読み手が評価を批判できるだけの情報があり、主要なリスクを述べ、利益相反を開示している。
* 目標株価には、根拠、期間、その不確実性が必要である。「よい会社」と「よい投資」は分けて考える。価格が重要である。
* 関連する CFA 基準：I(B) 独立性と客観性、I(C) 不実表示、V(A) 注意義務と合理的根拠、V(B) 顧客とのコミュニケーション（プロセス、限界とリスク、重要な要因、**事実と意見**）、V(C) 記録の保持。
