# 資本コスト

**加重平均資本コスト（WACC）**：
$$
WACC=w_dr_d(1-t)+w_pr_p+w_er_e
$$
ここで $t$ は税率。

* $r_d=r_f+\text{spread}$
* $r_e=r_f+(ERP+IRP)$
  * ERP：株式リスク・プレミアム
  * IRP：固有リスク・プレミアム

## 資本コストを左右する要因

| **トップダウン・外部要因**                            | **ボトムアップ・企業固有の要因**                 |
| ------------------------------------------------- | ----------------------------------------------- |
| 資本の利用可能性                              | 売上・利益・キャッシュフローの変動性      |
| 市場環境                                 | 資産の性質と流動性                      |
| 法律・規制上の考慮、カントリー・リスク | 財務の健全性、収益性、レバレッジ |
| 課税管轄                                  | 証券の条件                               |

* 資本を利用しやすい：低い
* 市場環境
  * インフレ：高い
  * 景気後退：高い
  * 景気拡大：低い
  * 金利や為替のボラティリティが低い：低い
* 法律・規制：整っているほど低い
* 限界所得税率が高い：低い（式を見ると、節税効果が大きい）

* 売上・利益・キャッシュフローの変動性：

| 要因                                  | **資本コスト** |
| --------------------------------------- | ------------------- |
| 売上の安定性が高い               | 低い               |
| 売上の集中度が高い            | 高い              |
| 利益の予測可能性が高い          | 低い               |
| 営業レバレッジと財務レバレッジが高い | 高い              |
| ESG リスクが高い                         | 高い              |

* 資産の性質と流動性

| 要因                                | **資本コスト** |
| ------------------------------------- | ------------------- |
| 代替可能な有形資産の割合が高い | 低い               |
| 流動資産の割合が高い             | 低い               |

* 財務の健全性

| 要因                              | **資本コスト** |
| ----------------------------------- | ------------------- |
| 収益性が高い                | 低い               |
| キャッシュフロー創出力が高い         | 低い               |
| インタレスト・カバレッジ、流動性が高い | 低い               |
| レバレッジ比率が高い              | 高い              |

* 証券の条件

|                     | **条件**                      | **資本コスト** |
| ------------------- | -------------------------------- | ------------------- |
| **負債**            | 期限前償還条項（コール）                      | 高い              |
|                     | プット条項                       | 低い               |
|                     | 転換条項                   | 低い               |
| **優先株式** | 累積型                       | 低い               |
| **普通株式**    | 劣後するキャッシュフロー・議決権 | 高い              |

## 負債コスト

* 取引されている負債：最終利回り（YTM）
* 取引されていない負債：信用格付けが同等で満期が近い債券の利回り。格付けがなければ：合成格付け。

**合成格付けの例**

| **格付け** | **インタレスト・カバレッジ・レシオ** | **D/E**          |
| ---------------- | --------------------------- | ---------------- |
| AAA              | IC > 10 倍               | D/E < 35%        |
| AA               | 8 < IC < 10                 | 35% < D/E < 40%  |
| A                | 5 < IC < 8                  | 40% < D/E < 42%  |
| BBB              | 3 < IC < 5                  | 42% < D/E < 44%  |
| BB               | 2 < IC < 3                  | 44% < D/E < 50%  |
| B                | 1.4 < IC < 2                | 50% < D/E < 60%  |
| CCC              | 1.0 < IC < 1.4              | 60% < D/E < 70%  |
| CC               | 0.6 < IC < 1.0              | 70% < D/E < 80%  |
| C                | 0.3 < IC < 0.6              | 80% < D/E < 100% |
| D                | IC < 0.3                    | D/E > 100%       |

* 銀行借入：直近の金利。

> [!note]
>
> 元本均等返済型の借入は、一般に満期一括返済型より負債コストが低い

* リース

  * リースの計算利子率（RIIL）

  次の等式から求める（ファイナンス・リースの場合）
  $$
  \text{PV of lease payment}+\text{PV of residual value to lessor}=\text{Fair value of leasedn asset}+\text{Lessor's direct initial cost}
  $$
  

  * 追加借入利子率（IBR）：同じ期間の担保付き借入の金利

## 株式リスク・プレミアム（ERP）

### ヒストリカル・アプローチ

$$
ERP = r_m-r_f
$$

過去のデータからさまざまな平均をとって、将来の ERP を推定できる。

**主な仮定**：

* リターンが定常である
* 市場が比較的効率的である
* 長期的には平均リターンが期待リターンの不偏推定量になる

**主な判断事項**：

* 株価指数の選択
  * 通常は幅広い銘柄をカバーする時価総額加重指数
* 期間の選択

| 期間         | **利点**                                   | **欠点**                                            |
| ------------------- | ------------------------------------------------ | ------------------------------------------------------------ |
| 長い期間  | ボラティリティの変動の影響が小さい           | *現在の市場*を*代表しない*                 |
| 短い期間 | 現在の市場環境を代表する | *ノイズが大きくなる*可能性が高い（景気循環の一部や混乱期しかカバーしない） |

* 平均の種類の選択

|                     | **利点**                                               | **欠点**                                            |
| ------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **算術平均** | • 計算が*簡単*  <br> • すべての観測値を考慮    | • *極端な*値に敏感  <br> • 富の期待最終価値を過大評価する |
| **幾何平均**  | • すべての観測値を考慮  <br> • *外れ値の重みが小さい* <br> • 富の期待最終価値を推定する |                                                              |

* 無リスク金利の代理変数の選択

|                      | **利点**                                  | **欠点**                              |
| -------------------- | ----------------------------------------------- | ---------------------------------------------- |
| 国債の最終利回り  | 株式の無限のデュレーションに*より近い* | 完全に無リスクのリターンでは*ない*            |
| 短期国債の利回り | 無リスク金利の*正確な*推定          | 株式の無限のデュレーションと*一致しない* |

**限界**：

* ERP は時間とともに変わりうる
* 生存者バイアスは ERP の過去推計を押し上げがちである

### フォワードルッキング・アプローチ

* サーベイに基づく推定
* 配当割引モデル
* マクロ経済モデル

#### サーベイに基づく推定

* 人々に予想を尋ねて期待を評価する
* 推定値は直近の市場リターンに左右されやすい

#### 配当割引モデル（DDM）

ゴードン成長モデルから、PER が一定で、利益・配当・株価が同じ率で成長すると仮定する。
$$
ERP= E(\frac{D_1}{V_0})+E(g)-r_f
$$

#### マクロ経済モデル

$$
ERP = [DY+\Delta(\frac{P}{E})+i+g-\Delta S]-E(r_f)
$$

> [!note]
>
> 経済学の**成長の式**と同様で、$\Delta S$ は自社株買い + 相対的なダイナミズムの純変化である。考え方は同じで、表記が違うだけである。

| **要因**           |                       |                              | **記号**    |
| --------------------- | --------------------- | ---------------------------- | ------------- |
| 配当利回り        |                       |                              | $DY$          |
| 期待キャピタル・ゲイン | 期待されるリプライシング    |                              | $\Delta(P/E)$ |
|                       | 1 株当たり利益の成長 | 期待インフレ率           | $i$           |
|                       |                       | 実質経済成長率         | $g$           |
|                       |                       | 発行済株式数の変化 | $\Delta S$    |

> [!note]
>
> 期待インフレ率 $i$ は $YTM_{treasury\ bond}-YTM_{TIPS}$ で推定できる

#### 限界

* サーベイ
  * 標本抽出と回答のバイアス
  * 行動バイアス
* DDM
  * 仮定が厳しすぎる
* マクロ経済モデル
  * マクロデータによるモデル化の誤差
  * 行動バイアス

## 株主資本コスト

モデル

* DDM
* 債券利回り＋リスク・プレミアム法（BYPRP）
* CAPM
* ファーマ・フレンチ

### DDM

* 条件：上場していて、配当が安定し予測可能であること
* ゴードン成長モデル：
  * $r_e=\frac{D_1}{P_0}+g$
* 複数年の財務予測：
  * $P_0 = (\sum_{t=1}^n \frac{D_1}{(1+r_e)})+\frac{P_n}{(1+r_e)^n}$。IRR の要領で $r_e$ を求める。

### BYPRP

$$
r_e =r_d+RP
$$

$RP$ は、株価指数と社債指数のリターンの差の過去平均で推定できる。

* 負債コストの推定は、債権者が求めるリターンの出発点となる
* $RP$ の決め方は比較的恣意的である
* 会社に取引されている負債が必要
* 条件の異なる取引中の負債が複数あると、どれを選ぶか難しい。

### CAPM

$$
r_e = r_f+\beta(ERP)
$$

### ファーマ・フレンチ・モデル

$$
r_e = r_f +\beta_1ERP + \beta_2 SMB + \beta_3 HML + \beta_4 RMW + \beta_5 CMA
$$

* SMB：小型株マイナス大型株、規模プレミアム
* HML：高（簿価時価比率）マイナス低、バリュー・プレミアム
* RMW：堅調マイナス脆弱、収益性プレミアム
* CMA：保守的マイナス積極的、投資プレミアム

### 拡張 CAPM

$$
r_e = r_f +\beta_{\text{peer}}(ERP)+SP+SCRP
$$

* $\beta_{\text{peer}}$：業種の $\beta$。同業の上場企業グループから求める
* SP：規模プレミアム
* SCRP：企業固有のリスク・プレミアム

### ビルドアップ法

$$
r_e=r_f+ERP+SP+IP+SCRP
$$

>[!note]
>
>業種の $\beta$ が見つからない場合は $\beta=1$ と仮定する。

* IP：業種リスク・プレミアム

### カントリー・リスク・プレミアム（CRP）

**CRP** は、新興市場への投資に伴う追加のリスクに対して投資家が求めるプレミアムである
$$
CRP = \text{Sovereign yield spread}\times \frac{\sigma_{\text{equity}}}{\sigma_{\text{bond}}}
$$

* ソブリン利回りスプレッド：新興市場の債券の利回りから先進国の国債の利回りを引いたもの。
* $\sigma_{\text{equity}}$：その国の株式市場のボラティリティ
* $\sigma_{\text{bond}}$：その国の債券市場のボラティリティ

### グローバル CAPM

* シングル・ファクター：グローバルな市場指数を $r_m$ とする
* 国ごとのリスクに大きな違いはないと仮定する

### 国際 CAPM

$$
E(r_e)=r_f+\beta_G(E(r_{gm})-r_f)+\beta_c(E(r_c)-r_f)
$$

* $r_{gm}$：グローバル指数
* $r_c$：外国通貨の指数
