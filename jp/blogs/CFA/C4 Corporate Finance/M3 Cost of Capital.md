# 資本コスト

何が会社の資本コストを決めるのか。取引されている債務、取引されていない債務、銀行借入、リースの負債コストをどう推定するか。株式リスク・プレミアムをどう推定するか。上場企業、非上場企業、国際的な企業の株主資本の要求収益率をどう推定するか。2 つのミニケースでこれらをまとめる。（2026 年のタイトル：*Cost of Capital: Advanced Topics*。）

| 用語 | 意味 |
| --- | --- |
| **負債コスト** | 発行体の税引後コスト。債券投資家が要求するリターンに基づく |
| **株主資本コスト**（$r_e$） | 株式投資家が要求するリターン。**観察できない**ので推定しなければならない |
| **ERP** | 株式の期待リターンから無リスクの基準金利を引いたもの |
| **合成信用格付** | 債務に格付がないとき、ファンダメンタルズ（インタレスト・カバレッジ、D/E）から推定する格付 |
| **マトリックス・プライシング** | 格付、満期、クーポンが似た取引されている債券から利回りを推定すること |
| **RIIL** | リースの計算利子率 |
| **IBR** | 追加借入利子率：同じ期間の担保付借入の金利 |
| **SP / IP / SCRP** | 規模プレミアム / 業界リスク・プレミアム / 企業固有リスク・プレミアム |
| **CRP** | カントリー・リスク・プレミアム |

## 加重平均資本コスト（WACC）

$$
WACC=w_dr_d(1-t)+w_pr_p+w_er_e
$$

ここで $t$ は**限界**税率で、ウェイト（非負で合計 1）は**目標**資本構成である。

$$
\begin{aligned}
r_d&=r_f+\text{Credit spread}\quad\text{(pretax)}\\
r_e&=r_f+\beta\times ERP\quad\text{(CAPM)}
\end{aligned}
$$

* CAPM は実務で最も一般的なモデルである。$\beta$ は株式の市場に対する感応度、ERP は無リスク資産ではなく株式を持つことに対して投資家が求める対価である。
* 優先株は配当が定められており、普通株に優先する請求権があるので、通常 $r_d < r_p < r_e$ である。

WACC の推定は難しい。各要素の推定方法は多く、唯一の正解はない。**長期の目標**資本構成は現在の構成と異なりうる。**限界**税率は平均税率や実効税率と異なりうる。

#### 例：優先株と利息控除の上限がある WACC

| 項目 | 目標ウェイト | 税引前コスト |
| --- | ---: | ---: |
| 負債 | 30% | 6% |
| 優先株 | 10% | 7% |
| 普通株 | 60% | 11% |

限界税率は 25% である。

**ケース 1：利息が控除できる場合。**

$$
\begin{aligned}
WACC&=0.30\times 6\%\times 0.75\\
&\quad+0.10\times 7\%+0.60\times 11\%\\
&=1.35\%+0.70\%+6.60\%\\
&=8.65\%
\end{aligned}
$$

**ケース 2：すでに利息控除の上限に達しており**、新しい負債に税の便益がない場合：

$$
\begin{aligned}
WACC&=0.30\times 6\%+0.70\%\\
&\quad+6.60\%=9.10\%
\end{aligned}
$$

## 資本コストを決める要因

| **トップダウン（外部）** | **ボトムアップ（企業固有）** |
| --- | --- |
| 資本の利用可能性 | 売上高、利益、キャッシュフローの変動性 |
| 市場環境 | 資産の性質と流動性 |
| 法律・規制環境、カントリー・リスク | 財務の健全性、収益性、レバレッジ |
| 課税法域 | 証券の特徴 |

トップダウンの要因はシステマティックで、**無リスク金利と ERP** に表れる。ボトムアップの要因は企業固有で、**信用スプレッドとベータ**に表れる。

### トップダウンの要因

* **資本の利用可能性**：利用できる資本が多い → コストは**低い**。先進国市場は、厚みのある資本市場、安定した通貨、財産の保護、法の支配を備えている。社債市場が薄いところでは、企業は銀行借入や**シャドー・バンキング**（銀行として規制されていない貸し手）に頼る。
* **市場環境**：インフレ上昇（$r_f$ 上昇）→ **高く**なる。景気後退（スプレッドと ERP の拡大）→ **高く**なる。景気拡大（スプレッドの縮小）→ **低く**なり、企業はより多く借りる。低金利、狭いスプレッド、金利と為替の低い変動性、予測可能で透明な金融政策はいずれも資本コストを下げる。
* **法律・規制**：投資家保護が強い（**コモン・ロー**に多い）、成熟した規制 → **低く**なる。弱い制度（大陸法に多い）→ 高くなる。規制業種（公益事業、金融）では、規制当局が資本構成、還元、価格設定を左右する。
* **税金**：限界税率が高い → 税引後負債コストは**低く**なる（節税効果が大きい）。**ただし**利息が控除でき、会社に課税所得がある場合に限る。

### ボトムアップの要因

| 要因 | 資本コスト |
| --- | --- |
| 売上がより安定（例：継続課金やサブスクリプションの収益） | 低い |
| 売上がより集中 | 高い |
| 利益がより予測可能 | 低い |
| 営業レバレッジと財務レバレッジがより高い | 高い |
| ESG リスクがより高い | 高い |
| 資産の代替性・有形性がより高い | 低い |
| 資産の流動性がより高い | 低い |
| 収益性、キャッシュフロー、インタレスト・カバレッジ、流動性がより高い | 低い |
| レバレッジ（負債/EBITDA、D/E）がより高い | 高い |

* **ESG リスク**（対策のとられていない炭素排出、従業員の安全、弱いガバナンス、買収防衛策）は資本コストを上げる。あるいはアナリストは、割引率ではなく**キャッシュフローの予測**を調整してもよい。
* **担保**：有形資産は担保に入れられるので、**負債**のコストを下げるが、**株主資本**のコストを上げうる（債権者が優先する請求権を持つ）。

**証券の特徴：**

| 証券 | 特徴 | 資本コスト |
| --- | --- | --- |
| 負債 | コール条項付き | 高い |
| | プット条項付き | 低い |
| | 転換条項付き | 低い |
| 優先株 | 累積型 | 低い |
| 普通株 | キャッシュフローや議決権が劣る | 高い |

* **コール**は発行体に有利なので、投資家は発行時により高い利回りを求める（後に金利が下がって借り換えられれば、コストは下がりうる）。
* **プット**や**転換**のオプションは投資家に有利なので、発行時の利回りは低いが、後にコストが上がりうる（プット後のより高い金利での借り換え、転換後の希薄化）。
* **累積型**優先株：未払いの配当は普通株の配当より前に支払わなければならないので、投資家は非累積型より低いリターンを受け入れる。

#### 試験の落とし穴

* 税率の上昇が WACC を**下げる**のは、負債の節税効果を通じてだけである。控除できない、あるいは課税所得がないなら影響はない。
* コール条項 → 発行時のコストは**高い**。プットと転換 → **低い**。
* 担保は負債コストを下げるが、株主資本コストを上げうる。

## 負債コスト

方法は、債務の種類（取引されている、取引されていない、銀行借入、リース）、流動性、格付の有無、通貨による。

* **取引されている債務**：会社の**普通**（オプションのない）債券の YTM。通常は最も長い満期のものを使う。短い債券の方が流動性が高ければ、その YTM の方が信頼できるかもしれない。YTM は、似た新しい債務を発行する現在のコストである。
* **取引されていない債務**（ほとんどの非上場企業と一部の上場企業）：YTM の気配がない、あるいは大きな**流動性プレミアム**を含んでいる。
  * **格付あり**：満期と格付が似た他社の債券から**マトリックス・プライシング**を使う。
  * **格付なし**：ファンダメンタルズ（インタレスト・カバレッジ、レバレッジ）から**合成信用格付**を推定し、その格付と満期の債券の YTM か、$r_f$ にその格付のスプレッドを加えたものを使う。
  * 発行体の格付は、個々の銘柄の格付（担保、優先順位、転換性）と異なりうる。

**合成格付の表（Brunswix Firm）：**

| 格付 | インタレスト・カバレッジ（IC） | D/E |
| --- | --- | --- |
| AAA | IC > 10 | D/E < 35% |
| AA | 8 < IC < 10 | 35% < D/E < 40% |
| A | 5 < IC < 8 | 40% < D/E < 42% |
| BBB | 3 < IC < 5 | 42% < D/E < 44% |
| BB | 2 < IC < 3 | 44% < D/E < 50% |
| B | 1.4 < IC < 2 | 50% < D/E < 60% |
| CCC | 1.0 < IC < 1.4 | 60% < D/E < 70% |
| CC | 0.6 < IC < 1.0 | 70% < D/E < 80% |
| C | 0.3 < IC < 0.6 | 80% < D/E < 100% |
| D | IC < 0.3 | D/E > 100% |

$$IC=\frac{EBIT}{\text{Interest}}\qquad D/E=\frac{\text{Debt}}{\text{Equity}}$$

2 つの比率が異なる格付を示唆する場合（例：IC 1.5 → B だが D/E 43% → BBB）、判断を使い、その**傾向**を見る。

* **銀行借入**：市場環境と会社のリスクがその後大きく変わっていなければ、最も最近の借入の金利を使う。借入は固定金利か変動金利で、全額、一部、あるいは償還なしの元本返済がありうる。**分割返済型**の借入は満期一括返済より通常コストが低い。元本が期間中に返済されるからである（デフォルト・リスクが低い）。
* **リース**：**ファイナンス・リース**は分割返済型の担保付借入に似ているので、通常は無担保借入より安い（オペレーティング・リースは費用処理）。IFRS 16 / ASC 842 の下で、**リースの計算利子率**（RIIL）は次を満たす。

$$
\begin{aligned}
&\text{PV of lease payments}\\
&+\text{PV of residual value to lessor}\\
&=\text{Fair value of the asset}\\
&+\text{Lessor's direct initial costs}
\end{aligned}
$$

  * 残存価値と貸手のコストがわからなければ、**追加借入利子率**（IBR）を使う。IBR もわからなければ、取引されていない債務の方法を使う。上場している借手の多くはリースの金利を開示している。
  * ファイナンス・リースが税務上購入とみなされる場合は利息が控除できる → 税引後の金利を使う。

#### 例：G&S Airlines のリース

| 入力 | 値 |
| --- | --- |
| 期間 | 15 年 |
| リース料 | 年 €9.0m |
| 航空機の公正価値 | €100m |
| 貸手の初期直接コスト | €5m |
| 貸手にとっての残存価値 | €10m |

**ステップ 1：RIIL の式を立てる。**

$$
\begin{aligned}
&\sum_{t=1}^{15}\frac{9}{(1+RIIL)^t}+\frac{10}{(1+RIIL)^{15}}\\
&=100+5
\end{aligned}
$$

**ステップ 2：解く。** N = 15、PV = −105、PMT = 9、FV = 10 → **RIIL = 4.08%**。

**ステップ 3：比較する。** このリースは無担保借入（IBR 6%）や株式（11%、かつ希薄化）より安く、所有のリスクを避けられるが、**レバレッジは上がる**。

* **国際**：負債コストは**キャッシュフローの通貨**で考えるべきである。成熟度の低い市場では、経済状況、政治リスク、為替リスク、証券市場の発達と規制を反映した**カントリー・リスク格付（CRR）**に基づき、カントリー・リスク・プレミアムを加える。ソブリン・リスク（国債のデフォルト）はカントリー・リスクの**一部**にすぎず、カントリー・リスクには政治の安定、経済の競争力、人間開発も含まれる。

$$
\begin{aligned}
CRP={}&\text{Median rate of the class}\\
&-\text{Benchmark's rate}
\end{aligned}
$$

#### 例：カントリー・リスク・プレミアム

| 国 | CRR | 中央値金利 | CRP |
| --- | ---: | ---: | ---: |
| A（基準） | 1 | 4.0% | 0% |
| C | 2 | 4.5% | $4.5-4.0=$ **0.5%** |
| D | 8 | 15.5% | $15.5-4.0=$ **11.5%** |

* **利息控除の制限**：会社がすでに上限に達していれば、新しい負債のコストを税で調整**しない**（それ以上の税の便益はない）。

#### 試験の落とし穴

* 古い債務のクーポンではなく、**新しい**負債の**限界**コストを使う。
* 取引の少ない債券について、流動性の高い債券からマトリックス・プライシングで求めた利回りは真のコストを過小評価する。流動性の低さの分を少し加える。
* RIIL には、支払額、残存価値、資産の公正価値、貸手の直接コスト、リース期間が必要である。

## 株式リスク・プレミアム（ERP）

大きく 2 つの方法がある。**ヒストリカル**（事後）と**フォワード・ルッキング**（事前）である。どちらも使われ、どちらにも推定誤差がある。

### ヒストリカル・アプローチ

ERP は、標本期間における幅広い株価指数のリターンと国債のリターンの差の平均である。

$$
ERP = \overline{r_m-r_f}
$$

リターンが**定常**で、市場がそれなりに**効率的**で、平均リターンが長期の期待リターンの不偏推定量であると仮定する。結果を決める選択は 4 つある。

**1. 株価指数**：通常は幅広い時価総額加重の指数（S&P 500、Russell 3000、MSCI EAFE、All Ordinaries、上海総合指数）。

**2. 期間**：

| 期間 | 長所 | 短所 |
| --- | --- | --- |
| 長い（一般に**好まれる**） | ボラティリティの変化の影響が小さい。標準誤差が小さい | **現在**の市場を代表しないかもしれない |
| 短い | 現在の環境を代表する | ノイズが多い（景気循環の一部や一度の混乱しか含まないかもしれない） |

最近の好調なリターンが続くとヒストリカルな平均が膨らむので、将来の ERP を**過大評価**しうる。

**3. 平均**：

| 平均 | 長所 | 短所 |
| --- | --- | --- |
| **算術** | 簡単。すべての観測値を使う。単一期間モデル（CAPM、マルチファクター）と整合的 | 極端な値に敏感。期末の期待資産を過大評価する |
| **幾何**（一般に**好まれる**） | すべての観測値を使う。外れ値の影響が小さい。期末の期待資産を推定する | |

算術平均は常に幾何平均以上なので、算術平均による ERP の方が**高い**。

**4. 無リスクの代理変数**：

| 代理変数 | 長所 | 短所 |
| --- | --- | --- |
| 長期国債の YTM（業界の慣行） | 株式の無限のデュレーションに近い | 完全な無リスクではない（クーポンの再投資が不明） |
| 短期国債の利回り | 完全な無リスク（ゼロクーポンでリターンが事前にわかる） | デュレーションが株式よりはるかに短い |

通常の右上がりのイールドカーブでは、短期国債に基づく ERP は長期国債に基づくものより**高い**。

**限界。** ERP は時とともに変わりうる（恒久的な変化があれば長い履歴は代表性を失う）。また**生存者バイアス**がヒストリカルな推定値を膨らませる（失敗した会社が指数から抜け落ち、遡って作られた指数の履歴も同様）。

### フォワード・ルッキング・アプローチ

フォワード・ルッキングな推定は、将来のキャッシュフローを決める変数の期待値だけを使うので、非定常性やデータのバイアスの影響を受けにくい。

**サーベイ。** 人々（しばしば専門家）に期待を尋ねる。サーベイでは、新興国市場の ERP が先進国市場よりはるかに高く、回答は最近の市場リターンに引きずられる傾向がある。

**配当割引モデル。** ゴードン成長モデルから $r_e=D_1/V_0+g$。P/E が一定で、利益、配当、価格が同じ率で成長するなら：

$$
ERP= E\left(\frac{D_1}{V_0}\right)+E(g)-r_f
$$

* P/E の変化が予想されるなら、それを調整する（P/E が上がらない限り、価格が利益より速く伸びることはない）。
* 指数の**自社株買い**を利回りに加え（総還元）、そのうえで自社株買いが成長をどう変えるかを考えるアナリストもいる。
* 成長の速い経済には**3 段階**（急成長、移行、成熟）を使い、すべての段階の現在価値が指数の水準に等しくなる率を求め、$r_f$ を引く。

#### 例：FTSE 100

配当利回りは 1.94%、期待成長率は 5.0%、英国債利回りは 1.63% である。

$$
\begin{aligned}
ERP&=1.94\%+5.0\%-1.63\%\\
&=5.31\%
\end{aligned}
$$

予測の範囲（シミュレーションに有用）：

| | 利回り | 成長率 | $r_f$ | ERP |
| --- | ---: | ---: | ---: | ---: |
| 低 | 1.5% | 4% | 2.5% | **3%** |
| 高 | 3.5% | 6% | 1.5% | **8%** |

**マクロ経済モデル（Grinold–Kroner、2001）。**

$$
\begin{aligned}
ERP ={}& DY+\Delta\left(\tfrac{P}{E}\right)+i+g-\Delta S\\
&-E(r_f)
\end{aligned}
$$

| 項 | 意味 | よく使う代理変数 |
| --- | --- | --- |
| $DY$ | 配当利回り | 指数の配当利回り |
| $\Delta(P/E)$ | 期待される再評価 | 割高・割安に関するアナリストの見方（通常は 0） |
| $i$ | 期待インフレ率 | 名目利回り − 実質（インフレ連動）利回り、満期は同程度 |
| $g$ | 実質利益成長率 | 実質 GDP 成長率 |
| $\Delta S$ | 発行済株式数の期待変化率 | 市場と時期による。与えられなければ通常 0 |

* $DY+\Delta(P/E)$ はインカムと再評価のリターン、$i+g-\Delta S$ は 1 株あたりの名目利益成長率である。純**自社株買い**は $\Delta S$ をマイナスにし、リターンを**増やす**。希薄化はリターンを減らす。
* 期待インフレ率は、同程度の満期の名目利回りとインフレ連動（TIPS）利回りから求める。

$$
\begin{aligned}
i&=\frac{1+YTM_{\text{nominal}}}{1+YTM_{\text{TIPS}}}-1\\
&\approx YTM_{\text{nominal}}-YTM_{\text{TIPS}}
\end{aligned}
$$

* 上場株式が**経済の大きな部分**を占めるところ（先進国市場）ではより信頼できる。株式市場が小さいところ（多くの途上国）には向かない。

#### 例：Grinold–Kroner のシナリオ

**ステップ 1：期待インフレ率。** 10 年米国債の利回りは 2.3%、TIPS は 0.66% である：

$$i=\frac{1.023}{1.0066}-1=1.6\%$$

**ステップ 2：2 つのシナリオの ERP**（すべて %）：

| 入力 | シナリオ 1 | シナリオ 2 |
| --- | ---: | ---: |
| DY | 2.2 | 2.0 |
| $\Delta(P/E)$ | 0 | 1.0 |
| $i$ | 1.6 | 3.0 |
| $g$ | 3.0 | 2.0 |
| $\Delta S$ | −0.7 | 0 |
| $r_f$ | 2.5 | 3.0 |
| **ERP** | $2.2+0+(1.6+3.0+0.7)-2.5=$ **5.0** | $2.0+1.0+(3.0+2.0-0)-3.0=$ **5.0** |

* 期待インフレ率の上昇は ERP に**影響しない**（$i$ と $r_f$ がともに上がる）。
* 期待インカム（DY）の低下は ERP を**引き下げる**。

**フォワード・ルッキングな推定の限界：**

* **サーベイ**：標本と回答のバイアス。行動バイアス（**直近効果**、**確証バイアス**）。
* **DDM**：P/E 一定を仮定する。利益、配当、価格の成長率が異なれば調整が必要。
* **マクロモデル**：マクロデータの誤差。予測における行動バイアス。

#### 試験の落とし穴

* Grinold–Kroner：**長期**のインフレ予測と**長期**の債券利回りを使う。自社株買い（$-\Delta S$）はリターンを増やし、希薄化は減らす。
* 短期国債ベースと算術平均の ERP は、長期国債ベースと幾何平均のものより**高い**。
* 生存者バイアスはヒストリカル ERP を**押し上げ**、標本中の一度きりの危機は**押し下げる**。

## 株主資本コスト

| 状況 | モデル |
| --- | --- |
| 上場企業 | DDM、債券利回り + リスク・プレミアム（BYPRP）、CAPM、Fama–French |
| 非上場企業 | 拡張 CAPM、ビルドアップ法 |
| 国際 | カントリー・スプレッド・モデル、グローバル CAPM、国際 CAPM |

### 配当割引モデル

配当が安定し予測可能な上場企業の場合：

$$
\text{Gordon growth: }r_e=\frac{D_1}{P_0}+g
$$

複数年予測（IRR の $r_e$ を解く）と優先株（$g$ = 0）：

$$
\begin{aligned}
P_0&=\sum_{t=1}^n \frac{D_t}{(1+r_e)^t}+\frac{P_n}{(1+r_e)^n}\\
r_p&=\frac{D}{P}
\end{aligned}
$$

#### 例：DDM による株主資本コスト

| ケース | 入力 | $r_e$ |
| --- | --- | --- |
| X 社（ゴードン） | $P_0$ €40、$D_1$ €1.04、$g$ 4% | $1.04/40+4\%=$ **6.6%** |
| $D_0$ からのゴードン | $P_0$ USD50、$D_0$ USD2.50、$g$ 5% | $2.50\times 1.05/50+5\%=$ **10.25%** |
| 複数年 | $P_0$ USD40、配当 1.00、1.25、1.35、1.50、$P_4$ USD45 | −40、1、1.25、1.35、46.5 の IRR = **6.015%** |

$g$ が高いと $r_e$ は上がり（$D_1$ と $g$ の両方が上がる）、株価が低いと $r_e$ は上がる。

### 債券利回り + リスク・プレミアム（BYPRP）

$$
r_e =r_d+RP
$$

ここで $r_d$ は通常、会社の**長期**債務の YTM、$RP$ は株価指数と社債指数のリターンの差のヒストリカルな平均であることが多い。

* 負債コストは自然な出発点である。株式投資家は会社の債権者より多くを求める。
* プレミアムはかなり恣意的で、時とともに安定しないかもしれない。
* 取引されている債務が必要である。特徴の異なる債券が複数あれば、どの利回りを使うかの決まりはない（一般的な慣行：長期債）。

### CAPM

$$
r_e = r_f+\hat\beta\,(ERP)
$$

ベータは、株式の超過リターンを市場の超過リターンに回帰する**マーケット・モデル**から得る。

$$
(r_{i,t}-r_{f,t}) = b_0 + b_1(r_{m,t}-r_{f,t}) + \varepsilon_t
$$

指数、推定期間（十分なデータか、古すぎないか）、$r_f$ の代理変数を確認する。右上がりのカーブでは、短期国債の利回りは長期債の利回りより明らかに**低い** $r_e$ を与える。上場していない会社は、**同業他社のベータをアンレバー、リレバー**して使える（ミニケース 2 を参照）。

### Fama–French モデル

$$
\begin{aligned}
r_e = r_f &+\beta_1ERP + \beta_2 SMB\\
&+ \beta_3 HML+ \beta_4 RMW\\
&+ \beta_5 CMA
\end{aligned}
$$

3 ファクター・モデルは最初の 3 つのファクターだけを使う。

* **SMB**（小型マイナス大型）：規模プレミアム
* **HML**（簿価時価比率の高いマイナス低い）：バリュー・プレミアム
* **RMW**（収益性の高いマイナス低い）：収益性プレミアム
* **CMA**（保守的マイナス積極的）：投資プレミアム

ベータは、会社の超過リターンをファクターに回帰して得る。マルチファクター・モデルの市場ベータは CAPM のベータと**異なり**、モデルが違えば答えも違う。カーブが右上がりのとき、回帰で短期の $r_f$ を使うと $r_f$ を過小評価しうる。

#### 例：5 ファクター・モデル

| ファクター | プレミアム | ベータ | 寄与 |
| --- | ---: | ---: | ---: |
| $r_f$ | | | 3.82% |
| ERP | 6.5% | 1.2 | 7.80% |
| SMB | 1.8% | 0.10 | 0.18% |
| HML | 4.0% | −0.20 | −0.80% |
| RMW | 2.0% | 0.5 | 1.00% |
| CMA | 1.0% | 0.2 | 0.20% |
| **$r_e$** | | | **12.2%** |

#### 例：CAPM と 3 ファクター

$r_f$ = 6%、期待市場リターン 10%（ERP 4%）。

$$
\begin{aligned}
r_e^{\text{CAPM}}={}&6\%+0.8\times 4\%=9.2\%\\
r_e^{\text{3F}}={}&6\%+1\%+0.75\times 4\%\\
&+0.15\times 5\%+0.05\times 2\%\\
={}&10.85\%
\end{aligned}
$$

1% は切片であり、SMB と HML で 0.85% 加わる。

### 非上場企業

**拡張 CAPM：**

$$
r_e = r_f +\beta_{\text{peer}}(ERP)+SP+SCRP
$$

* $\beta_{\text{peer}}$：同じ業界の上場企業からなる同業他社グループのベータ。
* **規模プレミアム（SP）**：規模と逆相関する。時価総額の最も小さい十分位、すなわち平均的なリスクの**超小型株**のリターンに基づく。健全な小規模企業については、ヒストリカルな SP を**下方**修正する必要があるかもしれない（小型株の標本には、凋落し困窮した企業が含まれる）。
* **企業固有リスク・プレミアム（SCRP）**：地域、キーパーソン、その他分散しにくいリスク。

手順：（1）同業他社のベータを求める。（2）CAPM の $r_e$ を計算する。（3）規模と企業のプレミアムが必要か判断する。（4）それを加える。

| SCRP：定性的要因 | SCRP：定量的要因 |
| --- | --- |
| 業界、競争上の地位、経営陣の経験 | 財務レバレッジと営業レバレッジ |
| 顧客、仕入先、地域の集中 | キャッシュフローと利益の変動性 |
| ガバナンス、資産の種類（有形か無形か） | 利益の予測可能性、価格決定力 |

非上場企業は**流動性も低い**が、流動性の低さは通常 $r_e$ のプレミアムではなく、価値に対する**市場性欠如ディスカウント**として扱う。

**ビルドアップ法：**

$$
r_e=r_f+ERP+SP+IP+SCRP
$$

ここでの ERP は**ベータで調整しない**（ベータ 1 を暗に仮定）。$r_f$ + ERP は平均的なリスクの**大型株**の要求収益率である。SP を加えると超小型株のリターンになり、さらに**業界リスク・プレミアム**（IP、リスクの高い業界向け）と SCRP を加える。比較可能な上場企業がない、あるいは比較可能性が疑わしい場合に役立つ。

### 国際的な企業

新興国株式市場の**カントリー・スプレッド・モデル**：

$$
ERP = ERP_{\text{developed}} + \lambda\times CRP
$$

ここで $\lambda$ はその国に対する会社のエクスポージャーである。**CRP** は新興国市場に投資する追加のリスク（経済状況、収用、政治リスク）を補償する。基本形は**ソブリン利回りスプレッド**で、先進国通貨建ての新興国国債の利回りから、同程度の満期の先進国国債の利回りを引いたものである。**債券**のスプレッドは**株式**のプレミアムに合わないかもしれないので、Damodaran はそれを調整する。

$$
CRP = \text{Sovereign spread}\times \frac{\sigma_{\text{equity}}}{\sigma_{\text{bond}}}
$$

ここで $\sigma_{\text{equity}}$ と $\sigma_{\text{bond}}$ は現地の株式市場と債券市場のボラティリティである。両方のリターンの履歴が必要になる。

#### 例：Makinassi

Makinassi の本社は X 国（ソブリン・スプレッド 1.5%）にある。売上の 40% を占める Y 国のスプレッドは 3.2%、株式ボラティリティは 4.0%、債券ボラティリティは 2.5% である。

**ステップ 1：関連するスプレッド**は X 国に対する Y 国の上乗せ分である：

$$3.2\%-1.5\%=1.7\%$$

**ステップ 2：株式に換算する。**

$$CRP=1.7\%\times\frac{4.0}{2.5}=2.72\%$$

**ステップ 3：エクスポージャーを掛ける。**

$$\lambda\times CRP=0.40\times 2.72\%=1.088\%$$

$r_e$ に **1.088%** を加える。

**グローバル CAPM。** 単一ファクター：世界の市場指数を $r_m$ とし、国による大きなリスクの違いはないと仮定する。問題：新興国と先進国のリターンは相関が低いので、ベータが低く、さらには**マイナス**になる。現地のデータが信頼できれば、国内指数のファクターを加えると改善する。

**国際 CAPM。**

$$
\begin{aligned}
E(r_e)={}&r_f+\beta_G\left[E(r_{gm})-r_f\right]\\
&+\beta_c\left[E(r_c)-r_f\right]
\end{aligned}
$$

* $r_{gm}$：世界の指数（MSCI ACWI、FTSE All-World）。世界経済とのつながりが弱い会社ほど $\beta_G$ は低い。
* $r_c$：**富で加重した**外貨指数（期待される為替変化にその国の $r_f$ を加えたもの）。$\beta_c$ はキャッシュフローが為替レートにどれだけ敏感か（輸入、輸出、投資）による。

**方法の選択。** **先進国**だけで事業を営むなら、グローバル CAPM か国際 CAPM が妥当である。**途上国**での事業についてはそれほど明確ではない。ソブリン・スプレッドによる CRP が使えるかもしれないが、ヒストリカルな金利に頼る。

#### 試験の落とし穴

* 複数年の DDM：**各** $D_t$ を $(1+r_e)^t$ で割り引き、$P_n$ を最終年のキャッシュフローに含める。
* BYPRP は $r_f$ ではなく、会社**自身の**債券利回りにプレミアムを加える。
* ビルドアップ法はベータ**なし**の ERP を使い、拡張 CAPM は**同業他社**のベータを使う。
* 非上場企業の流動性の低さ → 評価上のディスカウント（DLOM）であり、追加のプレミアムではない。
* カントリー・スプレッド・モデル：CRP に会社の**エクスポージャー** $\lambda$ を掛ける。Damodaran はスプレッドを $\sigma_{\text{equity}}/\sigma_{\text{bond}}$（> 1）で調整する。

## ミニケース 1：Gretna Engines

上場している小型株のエンジン・メーカー。景気循環的で固定費が高く、資産は主に棚卸資産と PP&E。優先株を償還するために無担保負債を発行する計画である。

| 資本 | ウェイト | 条件 |
| --- | ---: | --- |
| 負債 | 20% | クーポン 7%、7 年、BBB、取引は少ない |
| 優先株 | 15% | 配当 7%、額面 1,000、価格 980、額面で償還可能 |
| 普通株 | 65% | ベータ 0.91、$r_f$ 2.1%、ERP 5.5% |

**資本コストが高い理由**：景気循環的で変動の大きい売上と利益、流動性の低い資産、高い営業レバレッジ。

**ステップ 1：マトリックス・プライシングによる負債コスト**（流動性の高い BBB 債 4 本、半年払い）：

| 債券 | クーポン | 満期 | 価格 | YTM |
| --- | --- | --- | --- | --- |
| 1 | 5% | 4 | 99.50 | 5.140% |
| 2 | 7% | 4 | 106.46 | 5.191% |
| 3 | 6% | 8 | 100.00 | 6.000% |
| 4 | 8% | 8 | 112.42 | 6.021% |

Gretna の 7 年債について 4 年と 8 年の平均の間を線形補間する：

$$
\begin{aligned}
\bar y_4&=\frac{5.140+5.191}{2}=5.166\%\\
\bar y_8&=\frac{6.000+6.021}{2}=6.011\%\\
\text{Step}&=\frac{6.011-5.166}{4}=0.211\%\\
y_7&=5.166+3\times 0.211\\
&=5.799\%\approx 5.8\%
\end{aligned}
$$

Gretna の取引が少ないため、真の利回りはやや高い。

**ステップ 2：優先株のコスト。**

$$r_p=\frac{0.07\times 1{,}000}{980}=7.14\%$$

優先株を負債に置き換えた後（負債 35%、株主資本 65%）、新しい負債のコストは 5.8% より高く 7.14% より低い。価格が 980 のときに額面で償還するのは、$r_f$ が低い、あるいはスプレッドが狭い、つまりタイミングがよいことを意味する。さらにコストを下げるには、**担保付き**、**プット条項付き**、**転換条項付き**の負債を発行する。

**ステップ 3：3 通りの株主資本コスト。**

$$
\begin{aligned}
r_e^{\text{CAPM}}={}&2.1\%+0.91\times 5.5\%\\
={}&7.11\%\\
r_e^{\text{5F}}={}&2.1+0.95(5.5)+0.45(1.8)\\
&+0.14(3.9)-0.19(3.1)\\
&+0.30(3.7)=9.20\%\\
r_e^{\text{BYPRP}}={}&5.8\%+6.2\%=12.0\%
\end{aligned}
$$

**ステップ 4：妥当性の確認。**

* CAPM の 7.11% は優先株のコスト 7.14% を**下回る**ので信頼できない。普通株は優先株に劣後する。
* ERP は**短期国債の利回り**と**算術**平均で推定されており、どちらも ERP を**押し上げる**。

## ミニケース 2：Precision Irrigation

リスクの高い新興国市場にある非上場のソフトウェア会社を、上場しているソフトウェア同業他社と比較する。

| | Precision | 業界 |
| --- | --- | --- |
| 総負債 | 18.4 | 296.4 |
| 総資産 | 105.2 | 1,276.2 |
| EBITDA | 12.2 | 177.4 |
| 支払利息 | 1.6 | 23.5 |
| 税率 | 20% | 25% |
| ベータ | | 1.25 |

現地の 10 年 $r_f$ 5.41%。ERP 6%、SP 5%、IP 1%、SCRP 6%、CRP 2%。

**ステップ 1：合成格付からの負債コスト。**

$$
\begin{aligned}
IC&=\frac{12.2}{1.6}=7.63\\
D/E&=\frac{18.4}{105.2-18.4}=0.2120
\end{aligned}
$$

これは合成格付 **A**、スプレッド 1.46% にあたる。カントリー・リスクは負債にも適用される：

$$
\begin{aligned}
r_d&=5.41\%+1.46\%+\underbrace{2.00\%}_{CRP}\\
&=8.87\%\\
r_d(1-t)&=8.87\%\times 0.8=7.096\%
\end{aligned}
$$

**ステップ 2：プレミアム。**

* **規模プレミアムは 3–6% の範囲の上限近く**：Precision の資産は業界平均の 10 分の 1 未満である。
* **SCRP が高い要因**：無形資産が多く（47% 対 32%）現金が少ない（9% 対 14%）、売上の 70% が近隣の 5 顧客から（顧客と地域の集中）、後継者計画のない創業者 CEO（キーパーソン）。
* **SCRP が低い要因**：60% のサブスクリプション収益と低いレバレッジ（D/E 0.2120 対業界の 296.4/979.8 = 0.3025、IC 7.63 対 7.55）。

**ステップ 3：ベータ。** 業界のベータを**業界の**税率と D/E でアンレバーし、Precision のものでリレバーする：

$$
\begin{aligned}
\beta_{\text{asset}}&=\frac{1.25}{1+(1-0.25)(0.3025)}\\
&=1.019
\end{aligned}
$$

$$
\begin{aligned}
\beta_{\text{Precision}}&=1.019\\
&\quad\times[1+(1-0.20)(0.2120)]\\
&=1.19
\end{aligned}
$$

**ステップ 4：株主資本コスト**（%）。拡張 CAPM には IP と CRP を含み、ビルドアップ法は解答どおり IP を含めない。

$$
\begin{aligned}
r_e^{\text{expanded}}&=5.41+1.19(6)+5\\
&\quad+1+6+2\\
&=26.55\%\\
r_e^{\text{build-up}}&=5.41+6+5+6+2\\
&=24.41\%
\end{aligned}
$$

**ステップ 5：WACC**（$w_d=18.4/105.2=0.1749$、$w_e=0.8251$）：

$$
\begin{aligned}
WACC&=0.1749\times 7.096\%\\
&\quad+0.8251\times 24.41\%\\
&=21.38\%
\end{aligned}
$$

#### 試験の落とし穴

* アンレバーは**比較対象の**税率と D/E で、リレバーは**対象会社の**もので行う。
* 簿価データからの D/E は負債 ÷（資産 − 負債）であり、負債 ÷ 資産ではない。
* 普通株の資本コストが優先株のコストを下回るのは危険信号である。
* ケースでカントリー・リスクが負債と株式の両方に当てはまるとされていれば、CRP を**両方**に加える。

> [!NOTE]
>
> **教科書の誤植。**
>
> * Grinold–Kroner のシナリオ 1：解答の本文は「ERP の推定値は 3.6%」と書いているが、自身の計算では **5.0%** になる。
> * ミニケース 2：図表 19 は BB を「3 < IC < 1.4」と印刷している（3 < IC < 5 が正しい）。アンレバーの本文は「限界税率 20% を使って」と書いているが、式は正しく業界の 25% を使っている。見出しの数字が計算と合わない：拡張 CAPM「26.56%」（26.55%）、ビルドアップ法「25.41%」（24.41%。25.41% なら 1% の IP を含む）、WACC「21.13%」（24.41% を使えば 21.38%）。そこでの拡張 CAPM は、一般式には含まれない IP を含んでいる。問題で与えられた入力値に従うこと。
