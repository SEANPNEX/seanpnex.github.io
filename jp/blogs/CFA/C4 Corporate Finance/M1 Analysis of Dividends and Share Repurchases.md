# 配当と自社株買いの分析

企業が現金をどう還元するか（配当と自社株買い）、還元政策が重要でありうる理由に関する諸理論、自社株買いが EPS と簿価に与える影響、そして配当が安全かどうかの見分け方を扱う。

| 用語 | 意味 |
| --- | --- |
| **配当** | 取締役会が宣言する分配（欧州の多くでは株主の承認も必要だが、米国では不要）。社債の利息と違い、**裁量的**である |
| **権利落ち日** | 株式が配当の権利**なしで**取引される最初の日。株価はおよそ配当額だけ下がる |
| **還元政策** | 会社が現金を分配する方法：配当**と**自社株買い |
| **配当性向** | 普通株配当 ÷ 普通株主に帰属する純利益 |

配当はトータル・リターンの大きな部分を占める。1926 年から 2018 年まで、S&P 500 は配当を再投資すると年 10.0%、価格変動だけでは年 5.9% のリターンだった。

## 配当の形態

**現金配当**

* **普通配当**：決まったスケジュールで支払われる（米国とカナダは四半期、日本とオーストラリアは半期、ドイツは年 1 回）。企業は普通配当を維持または増やそうとし、一時的な問題で減らすのを避ける。予想外の増配は通常よいニュースである。
* **特別配当**：好調な年や一度きりの出来事の後に、普通配当に上乗せして、あるいは定期的に配当しない会社が支払う（例：Tencent Music の IPO 後の Tencent）。**景気循環的な**企業でよく見られ、少額の普通配当に好況年の特別配当を加える。
* **清算配当**：会社が解散する、事業の一部を売却して代金を分配する、あるいは利益剰余金の累計を超えて支払うときの配当。利益の分配ではなく、**資本の払戻し**である。

**株式配当、株式分割、株式併合**

* **株式配当**（無償交付）：現金の代わりに追加の株式を渡す。通常は発行済株式の 2–10%。
* **株式分割**：例えば 1 株を 2 株に。**株式併合**：例えば 20 株を 1 株に。

**例（AfriSage、特別配当）。** 方針は純利益の 35% 以上を普通配当とすること。2018 年の EPS は ZAR14.23、DPS は ZAR7.61 で、配当性向は 7.61/14.23 = **53.5%**（2017 年：10.68/12.65 = **84.4%**）。最低普通配当は 14.23 × 0.35 = **ZAR4.98** なので、特別配当は 7.61 − 4.98 = **ZAR2.63** である。

### 株主の富への影響

* **現金配当**：株価は配当だけ下がるが、他の条件が同じなら株主の富（株式 + 現金）は変わらない。
* **株式配当**：株数は増えるが富は同じ。取得原価の総額は変わらないので、**1 株あたり**の取得原価が下がる。1 株 US\$10 の 100 株は、5% の株式配当の後 105 株になり、1 株 US\$1,000/105 = **US\$9.52** となる。通常は課税されない。主張される利点：浮動株の増加、流動性の向上、「最適な」取引価格帯（米国ではしばしば US\$20–80）。
* **株式分割**：1 株あたりの数値はすべて比例して下がる。P/E、配当利回り、時価総額は変わらない。1 株を 2 株にする分割は、経済的には 100% の株式配当と同じで、会計処理だけが異なる。
* **株式併合**：株数が減り、株価が上がり、時価総額は変わらない。価格を売買しやすい水準に戻すために使う（上場の最低価格基準。機関投資家は US\$5 未満の株を避ける）。財務的困難の最中や後に最もよく見られる。

| | 株式配当 | 株式分割 |
| --- | --- | --- |
| 資本合計 | 変わらない | 変わらない |
| 資本の勘定 | 利益剰余金 → 払込資本（新株数 × 株価） | 変化なし |
| 典型的な規模 | 2–10% | 1 対 2、1 対 3 |

**例。**

* **3% の株式配当**（持株比率 10% の株主）：株数 1,000,000 → 1,030,000、EPS US\$1.00 → US\$0.97、株価（P/E 20）US\$20 → US\$19.42。株主の 100,000 株は 103,000 株になり、前後ともに **US\$2,000,000** の価値である。
* **1 対 2 の株式分割**：株数 4m → 8m、株価 €40 → €20、EPS €1.50 → €0.75、DPS €0.50 → €0.25。利回り **1.25%**、P/E **26.7** は前後で同じ。
* **Globus Maritime の 10 対 1 の株式併合**：US\$4.25 → **US\$42.50**。併合自体は富を失わせない。時価総額は変わらない。

### 財務比率への影響

**現金**配当は現金を外に出す。資産と資本が減るので、流動性比率は下がり、レバレッジ比率（D/A、D/E）は上がる。**株式**配当や分割は会社から何も出さない。総資産と資本は変わらず、株数、株価、EPS だけが変わる。

| | 現金配当の後 | 株式配当・分割の後 |
| --- | --- | --- |
| 資産（現金） | 下がる | 同じ |
| 資本 | 下がる | 同じ |
| 株価 | 下がる | 下がる |
| EPS | 同じ | 下がる |
| P/E | 下がる | 同じ |
| 流動性比率 | 下がる | 同じ |
| レバレッジ比率 | 上がる | 同じ |

**例（現金配当と株式配当）。** 現金 200、その他の流動資産 300、流動負債 250、総資産 1,000、負債 400、資本 600（US\$ 百万）。1 億株、1 株 US\$20。

| 比率 | 前 | US\$100m の現金配当後 | 5% の株式配当後 |
| --- | --- | --- | --- |
| 流動比率 | 500/250 = 2.00 | 400/250 = **1.60** | 2.00 |
| 現金比率 | 200/250 = 0.80 | 100/250 = **0.40** | 0.80 |
| 負債/資本 | 400/600 = 0.67 | 400/500 = **0.80** | 0.67 |
| 負債/資産 | 400/1,000 = 0.40 | 400/900 = **0.44** | 0.40 |

株式配当は 5m × US\$20 = US\$100m を利益剰余金から払込資本に移し、資本は 600 のままである。株価は 20/1.05 = US\$19.05 に下がり、時価総額（105m × 19.05 ≈ US\$2,000m）は変わらない。

> [!IMPORTANT]
> 会社から現金を出すのは**現金**配当だけである。株式配当、株式分割、株式併合は同じパイを違う大きさに切り分けるだけで、富、資本合計、流動性、レバレッジは変わらない（シグナル効果を除く）。

#### 試験の落とし穴

* 株式配当は資本の**勘定**を変えるが、資本の**合計**は変えない。株式分割はどの勘定も変えない。
* 株式配当で下がるのは**1 株あたり**の取得原価であり、取得原価の総額ではない。
* 利益剰余金の累計を超える配当はすべて清算配当（資本の払戻し）である。

## 配当政策の理論

配当政策は無関係だとする理論（Miller–Modigliani）と、関係があるとする理論がある。

| 理論 | 主張 | 増配が価値に与える影響 |
| --- | --- | --- |
| **MM の無関連命題** | 完全市場。投資家は「自家製」配当を作れる | なし |
| **手中の鳥** | 今日の配当は将来の利得よりリスクが小さい | 株主資本コスト低下 → 株価 ↑ |
| **税金の議論** | 配当はキャピタル・ゲインより重く課税される | 課税される投資家は低い還元や自社株買いを好む → 株価 ↓ |

### Miller–Modigliani（1961）

MM は**税金なし、取引コストなし、情報の対称性**、そして所与の資本予算と資本構成を仮定する。すると配当の決定は投資や資金調達の決定から独立する。

* A\$1 の配当前に A\$20 の株は、権利落ち後に A\$19 で取引される。保有者はどちらでも A\$20 を持っている。
* 配当は自社株買いと同じである。10,000 株、FCF A\$10,000、将来キャッシュフローの現在価値 A\$190,000 → 株価 **A\$20**。10,000/20 = **500** 株を買い戻すと、1 株 190,000/9,500 = **A\$20** になる。
* **自家製配当**：配当が支払われなくても、A\$1,000 が欲しい 1,000 株の保有者は A\$20 で **50** 株を売ればよい。

MM が無関係だというのは配当**政策**であり、配当そのものではない。現実の摩擦がこの議論を崩す。発行コスト（調達額の 4–10% のことが多い）、投資家の取引コスト、税金である。

### 手中の鳥と税金

* **手中の鳥**：今日の配当は不確実な利得より価値があるので、配当を支払う会社の株主資本コストは低い。MM の反論：配当を支払っても将来キャッシュフローのリスクは変わらない。
* **税金**：配当がキャピタル・ゲインより重く課税される場合、課税される投資家は低い還元や自社株買いを好む（極端な場合は無配）。米国では 2012 年以降、適格配当と長期キャピタル・ゲインの最高税率は 20% である。中国本土では株式のキャピタル・ゲイン税はなく、配当には保有期間 1 か月未満、1 か月から 1 年、1 年超に応じて 20%、10%、0% が課される。

### シグナリング

経営者は投資家より多くを知っているので、配当は情報を伝える。

* 現金によるシグナルは**まねるのにコストがかかる**ので信頼できる。キャッシュフローが増えていない会社は増配を続けられない（借入により一時的にできるだけ）。
* **初配や増配** → プラス：将来の利益成長、発表時の超過リターン。**減配や無配** → マイナス。ストレス下で配当を維持することは、問題が一時的であることを示す。
* 例外：現金が再投資される場合や、減配が慎重に見える場合、減配がプラスになることもある（Telstra 2017 年、BT 2018 年は株価 +6.9%）。初配は自信の表れとも、成熟の表れともなりうる（eBay 2019 年）。
* 一貫して増配する企業は、ニッチな地位、変動の小さい利益、高い ROA、低い負債を持つ傾向がある。

**例。** Oracle の 2009 年の初配（営業キャッシュフロー US\$80 億に対して年約 US\$10 億）は、景気後退を乗り切れる兆候と受け止められた。見通しの悪い会社が見栄えのために増配すると、後で減配するか、コストの高い資金を調達しなければならない。

### エージェンシー・コスト

* **経営者と株主**：配当はフリーキャッシュフローを経営者から取り上げる。そうしなければ経営者は NPV がマイナスのプロジェクトに過大投資するかもしれない（帝国建設）。これが Jensen の**フリーキャッシュフロー仮説**である。過大投資のリスクが大きいところほど、市場は配当の変化に強く反応する。
* **株主と債権者**：多額の配当は富を株主に移し、デフォルト・リスクを高め、過少投資につながりうる。社債の財務制限条項は累積の分配に上限を設け、カバレッジやレバレッジの制限を定める。

**例。** 配当性向が約 35% の無借金の競合 2 社のうち、ガバナンスが弱く（CEO が会長を兼務）、よいプロジェクトが少ない方が、**過大投資**を抑えるためにより多く払うよう求められる。公益企業は高配当を払ってから株式を発行する。コストはかかるが、株式市場が経営者と規制当局を監視することになる。

> [!IMPORTANT]
> 配当は経営者と株主の間のエージェンシー・コスト（過大投資）を**減らす**が、株主と債権者の対立（過少投資、デフォルト・リスク）を**強める**。取り違えないこと。

#### 試験の落とし穴

* MM は税金なし、取引コストなし、情報の対称性を仮定する。投資家が配当を好むとは仮定しない。
* 配当がキャピタル・ゲインより重く課税されるとき、税金の議論は**低い**還元を支持する。
* 減配は通常マイナスだが、常にそうとは限らない。

理論上、還元を決めるのは再投資の機会であるべきだ。若く成長の速い会社はあまり払わず、成熟した会社は多く払う。還元が価値に影響するかどうかの実証結果は決定的でないので、アナリストは少なくとも、会社の方針がその機会と法的・財務的環境に合っているかを確認すべきである。

## 実務で配当政策に影響する要因

市場が不完全になると、投資、資金調達、配当の決定はもはや独立ではない。

| 要因 | 還元への影響 |
| --- | --- |
| **投資機会** | 利益の上がるプロジェクトが多い → 還元は**低い**（内部資金の方が安い）。変化の速い業界（テクノロジー）はあまり払わず、機会の少ない会社（公益企業）は多く払う |
| **将来利益の変動性** | 利益の変動が大きい → 増配は小さく、頻度も低い |
| **財務の柔軟性** | 現金が必要 → 配当を下げるか、自社株買い（コミットメントなし） |
| **税金** | [税務上の考慮事項](#tax-considerations)を参照 |
| **発行コスト** | 新株は内部留保より高くつくので、株式発行が必要になる配当は避ける。小さな会社ほど影響が大きい |
| **契約上・法律上の制約** | 強制配当（ブラジル）、資本の毀損に関する規則（米国、カナダ）、社債の財務制限条項、優先株配当（累積未払分が先） |

調査によれば、経営者は**長期的に持続可能な利益**に基づいて目標配当性向を定め、水準より**変化**を重視し、撤回しなければならないかもしれない増配を避ける。これが**配当の平準化**である。Skanska は 2019 年、柔軟性を保つために 30% の「予防的」減配を行った。株価は 9% 下落したが、2 か月以内に発表前の水準を 7% 上回った。

**例。**

* **Boar's Head**：営業キャッシュフロー £5 億に対し、NPV がプラスのプロジェクトは £8 億で、負債はすでに平均を上回っている → **初配はしない**。配当を払うためだけに株式を発行することはしない。
* **Makinasi Appliances** は、損失の見込み、売上の減少、US\$5,000 万の社債発行、格下げの中で、四半期配当を US\$1.60 から US\$0.70 に減らす。主な要因は**利益の変動性**と**財務の柔軟性**で、発行コストも加わる。

## 税務上の考慮事項 {#tax-considerations}

### 二重課税

企業の利益は会社で課税され、配当として支払われるときに株主でもう一度課税される。

$$
\begin{aligned}
Div_{net} ={}& EBT\times \text{payout}\\
&\times(1-t_{c})(1-t_{i})
\end{aligned}
$$

$$
t_{\text{eff}} = 1-(1-t_{c})(1-t_{i})
$$

ここで $t_c$ は法人税率、$t_i$ は個人の配当税率、$t_{\text{eff}}$ は実効税率である。例えば、税引前 US\$100 に法人税 35% がかかると、払える額は 65 になる。15% の個人の税金が 9.75 で、残りは 55.25。実効税率は (35 + 9.75)/100 = **44.75%** である。

### インピュテーション方式

分配された利益は**株主の**税率で 1 回だけ課税される（オーストラリア、ニュージーランド）。株主はすでに支払われた法人税について**フランキング・クレジット**を受け取るので、実効税率は $t_i$ だけになる。

$$
Div_{net} = EBT\times \text{payout}\times(1-t_{i})
$$

例えば、税引前 A\$100 に法人税 30%、70 を分配：税率 15% の株主の納税額は 15 − 30 = **(15)** で還付、税率 47% の株主は 47 − 30 = **17**。実効税率は **15%** と **47%** である。

### 分割税率方式

配当として支払われる利益には留保利益より**低い**法人税率がかかり、その後通常の所得として再び課税される。二重課税であることに変わりはないが、$t_{c,\text{dist}}<t_{c,\text{retained}}$ である。

$$
t_{\text{eff}} = t_{c,\text{dist}}+(1-t_{c,\text{dist}})\,t_{i}
$$

例えば、分配する利益に 20%（留保利益は 35%）が課され、100 あたり 80 の配当が残る。株主の税率が 35% なら、0.65 × 80 = **€52** が残る。実効税率 = 20% + 0.35 × 80% = **48%**。

**例（同じ前提での 3 つの方式）。** 税引前 €100、全額分配、法人税率 30%、株主の配当税率 40%。

| 方式 | 法人税 | 配当 | 個人の税 | 投資家の手取り | 実効税率 |
| --- | --- | --- | --- | --- | --- |
| 二重課税 | 30 | 70 | 0.40 × 70 = 28 | 42 | **58%** |
| インピュテーション | 30 | 70 | 0.40 × 100 − 30 のクレジット = 10 | 60 | **40%** |
| 分割税率（分配 20% / 留保 30%） | 20 | 80 | 0.40 × 80 = 32 | 48 | **52%** |

### 株主の選好

* 投資家は配当の税**率**が低いことを望む。還元を高くしたいか低くしたいかは、配当とキャピタル・ゲインの税率の比較による。
* キャピタル・ゲイン税は売却まで**繰り延べ**られるが、配当の税は再投資しても受け取った時点で課される。死亡時の取得価額の引き上げ（米国、オーストラリア）もキャピタル・ゲインに有利である。
* **非課税**の投資家（年金基金、基金）はどちらでもよい。高配当株は非課税口座に置かれることがある。
* 国際投資家は外国の源泉徴収税にも直面する（通常は租税条約により自国で税額控除できる）。

#### 試験の落とし穴

* 二重課税：個人の税は**法人税控除後**の配当にかかる。
* インピュテーション：実効税率は株主の税率である。税率の低い投資家は**還付**を受けられる。
* 分割税率：分配される利益には**低い方**の法人税率を使う。

## 配当の支払政策

### 安定配当政策

**最も一般的**な政策：配当は長期的に持続可能な利益に従い、短期の変動を無視する（例えば Gruppo Hera は DPS を着実に増やしたが、配当性向は約 52% から 125% の間で変動した）。Lintner（1956）は、企業が持続可能な利益に対して**目標配当性向**を定め、配当の**変化**を気にかけ、極端な場合にしか減配しないことを見いだした。**目標配当性向調整モデル**：

$$
E(Div) = Div_{t-1}+\Delta Div
$$

$$
\Delta Div=\frac{E(EPS)\times \text{Target}-Div_{t-1}}{N}
$$

ここで Target は目標配当性向、$N$ は配当が目標に移るまでの年数なので、調整係数は $1/N$ である。

**例。**

* $Div_{t-1}$ = US\$0.40、目標 50%、係数 0.2、EPS が US\$1.50 に上昇：増加額 = (0.75 − 0.40) × 0.2 = **US\$0.07** → US\$0.47。翌年 EPS が US\$1.34 に低下：(0.67 − 0.47) × 0.2 = **US\$0.04** → US\$0.51。目標を下回っているので、配当はなお増える。
* **Luna Inc.**：$Div_{t-1}$ = US\$0.40、予想 EPS US\$2.80、目標 30%、4 年：0.40 + (0.84 − 0.40)/4 = **US\$0.51**。配当性向は 20% から 0.51/2.80 = **18.2%** に下がる。

### 一定配当性向政策

利益の一定割合を払う：$Div = \text{Payout ratio}\times NI$。配当が利益とともに変動するので、あまり使われない。

**例（Pampas Fertilizer）。** 四半期ごとに固定の ARS1.50 から、四半期利益の 25% に切り替えた。例えば 2019 年第 4 四半期の EPS 9.32 → 9.32 × 0.25 = ARS2.33。

**例（同じ利益、2 つの政策）。** 前年 EPS US\$2.00、DPS US\$0.80。今後 3 年の EPS は US\$3.00、US\$2.60、US\$3.40。配当性向または目標は 40%、調整係数は 0.5。

| 年 | EPS | 一定配当性向 | 安定配当（目標調整） | 安定配当の配当性向 |
| --- | --- | --- | --- | --- |
| 1 | 3.00 | 1.20 | 0.80 + (1.20 − 0.80) × 0.5 = **1.00** | 33.3% |
| 2 | 2.60 | 1.04 | 1.00 + (1.04 − 1.00) × 0.5 = **1.02** | 39.2% |
| 3 | 3.40 | 1.36 | 1.02 + (1.36 − 1.02) × 0.5 = **1.19** | 35.0% |

一定配当性向の配当は 2 年目に下がるが、安定配当は EPS が下がっても毎年増える。

| | 安定配当 | 一定配当性向 |
| --- | --- | --- |
| 基準 | 長期的に持続可能な利益 | 当期の利益 |
| 配当の変動 | 小さい | 大きい |
| 配当性向 | 変動する | 一定 |
| 実務での使用 | **最も一般的** | まれ |

#### 試験の落とし穴

* 調整係数は**差**（目標 − 前期の配当）に掛け、それを前期の配当に加える。係数 = **1/年数**。
* 目標が前期の配当を下回れば式は減配を示すが、実務では会社は配当の維持を好む。

### 世界的な傾向

* 多くの先進国市場（米国、カナダ、EU、英国、日本）で、**配当を支払う企業の割合**は長期的に低下している。米国の指数には欧州の指数より配当企業が少ない。
* 配当の**総額**と配当性向は概して上昇している。配当は、より少数の、より大きく、より収益性が高く、成長機会の少ない企業に集中している。アジア太平洋の配当は 2009 年から 2019 年に 3 倍になった。
* **自社株買い**は増えている。米国では 1980 年代前半から、英国と欧州では 1990 年代前半から、アジア（中国、日本）では 2010 年代後半から。
* ガバナンスと開示の改善（IFRS、投資家保護）→ 初配は**減り**、還元も控えめになる。シグナルやエージェンシーの抑制手段としての配当の役割が小さくなるからである。

## 自社株買い

**自社株買い**とは、会社が自社の株式を買い戻すことである。会社が保有する株式は**自己株式**（再発行できる。消却した株式は消滅する）で、配当も議決権もなく、EPS の計算から除かれる。

| | 現金配当 | 自社株買い |
| --- | --- | --- |
| コミットメント | 宣言すると会社は**拘束される** | 承認しても**拘束されない** |
| 分配 | すべての株主に**比例的** | 売却した株主だけが現金を得る |
| 継続の期待 | あり（普通配当） | 一般にない |

多くの市場は米国より自社株買いを制限している（株主の承認、しばしば 10% の上限）。米国の自社株買いは SEC 規則 10b-18（1982 年）の後に増えた。

### 自社株買いの方法

* **市場買付**：市場で株式を買う。時期と量が柔軟。
* **固定価格の公開買付**：一定数の株式を一定価格（通常はプレミアム付き）で買い付ける。応募超過なら按分して買う。
* **ダッチ・オークション**：株主が価格を提示し、会社は目標株数を買える**最低**価格を見つけ、受け入れたすべての提示に同じ清算価格を支払う。
* **相対取引**：特定の大株主から買う。しばしばプレミアム付き（売り手が流動性を必要としていればディスカウント）。

| 方法 | コスト | 柔軟性 | 速さ |
| --- | --- | --- | --- |
| **市場買付**（最も一般的。米国とカナダ以外ではほぼ唯一の方法） | タイミングがよければ低い | **最も高い**：完了の義務がない | 遅い |
| **固定価格の公開買付** | 高い（プレミアム。プラスのシグナルになりうる） | 低い | **最も速い** |
| **ダッチ・オークション** | 通常は固定価格の公開買付より**低い** | 低い | 速い。通常は固定価格よりやや遅い |
| **相対取引**（大株主の排除、アクティビストの阻止、グリーンメール） | プレミアムは残る株主から**富を移転する** | 該当なし | 該当なし |

**例（BCII、C\$37 で 5m 株）。** C\$40 の固定価格の公開買付のコストは 5m × 40 = **C\$200m**、C\$38 で清算されるダッチ・オークションのコストは **C\$190m** で、**C\$10m** の節約になる。

### EPS への影響

$$
EPS_{\text{after}} = \frac{E - C}{N_{\text{after}}}
$$

ここで $E$ は自社株買い前の利益、$C$ は使った資金の税引後コスト（新規借入の利息、または現金で得られなくなる受取利息）、$N_{\text{after}}$ は自社株買い後の発行済株式数である。

* **余剰現金で行う**：資産と資本が減るので、レバレッジが上がる。EPS が上がるのは、その現金が資本コストを稼げていなかった場合（遊休現金など）だけである。
* **借入で行う**：負債が増え、資本が減るので、レバレッジはさらに上がる。**益回り（E/P）が税引後負債コストを上回れば EPS は上がり**、そうでなければ下がる。$E/P = 1/(P/E)$ に注意。

**例。**

* **Takemiya**（余剰現金の利回りはほぼ 0）：10m 株、NI ¥100m、株価 ¥120。¥240m の現金で ¥140 で買い付ける → 約 1.7m 株、残りは 8.3m 株。EPS は ¥10.00 から 100/8.3 ≈ **¥12.00** に上がる（+20%、端数処理前は ¥12.07）。
* **Selamat**（借入）：MYR12m を借りて MYR60 で買い付ける → 200,000 株。利益 MYR6.6m、株数 2.2m → 2.0m、EPS MYR3、E/P 5%。税引後コスト 5% なら (6.6 − 0.6)/2 = **MYR3.00** で変わらず。6% なら (6.6 − 0.72)/2 = **MYR2.94** で下がる。
* **利息を生む余剰現金**：NI US\$50m、10m 株、EPS US\$5.00、株価 US\$50 → E/P 10%。税引後 4% を稼ぐ US\$100m の現金で 2m 株を買うと、利息 4 を失う。NI 46、EPS 46/8 = **US\$5.75**（上昇）。現金が 10% を稼いでいたら 40/8 = **US\$5.00**（不変）、12% なら 38/8 = **US\$4.75**（低下）。つまり E/P の判定は現金にも当てはまる。失う税引後リターンが E/P を下回れば EPS は上がる。

> [!IMPORTANT]
> **EPS の上昇 ≠ 株主の富の増加。** 同じ現金を配当として払うこともでき、キャピタル・ゲインは受け取らなかった配当を置き換えているだけかもしれない。レバレッジの上昇は要求リターンも高める。

### 1 株あたり純資産への影響

$$
BVPS_{\text{after}} = \frac{\text{Book equity} - \text{Buyback}}{N - N_{\text{bought}}}
$$

買付価格が現在の BVPS を上回れば BVPS は**下がり**、等しければ変わらず、下回れば**上がる**。

**例（US\$20 で US\$5m の自社株買い、2 社とも 10m 株）。** 250,000 株を買い、残りは 9.75m 株。A 社（簿価資本 US\$100m、BVPS 10）：(100 − 5)/9.75 = **US\$9.74** で低下。B 社（簿価資本 US\$300m、BVPS 30）：(300 − 5)/9.75 = **US\$30.26** で上昇。

#### 試験の落とし穴

* **税引後**の負債コストを **E/P** と比べる。税引前の金利や P/E と比べない。
* 自社株買い**後**の株数を使い、買う株数は**買付価格**（プレミアムを含む）から求める。
* ダッチ・オークション：受け入れられたすべての応募者が**同じ**清算価格を受け取る。
* 市場買付 = 最も柔軟、固定価格の公開買付 = 最も速い、ダッチ・オークションは通常固定価格の公開買付より安い。

### 配当と自社株買いの価値は同等

他の条件（同じ**税金**と同じ**情報内容**）が同じなら、自社株買いは株主の富への影響において**同額**の現金配当と同等である。

**例（Rohit Chemical、10m 株、1 株 Rs200、Rs500m を分配）。**

* 1 株 Rs50 の特別配当：権利落ち後の株価 = (2,000m − 500m)/10m = **Rs150**、富 = 50 + 150 = **Rs200**。
* 自社株買い：500m/200 = 2.5m 株、株価 = 1,500m/7.5m = **Rs200**。売っても売らなくても富は **Rs200**。

**例（AfriCitrus、プレミアム付きの自社株買い）。** 10m 株、1 株 ZAR200。1 人の株主から ZAR250 で ZAR500m 分を買う → 2m 株。新株価 = 1,500m/8m = **ZAR187.50**。他の株主は 1 株あたり **ZAR12.50** を失い、それが売り手に移る。

## 配当と自社株買いの比較

自社株買いの発表の後には、発表時と、その後 2 年間（5 年とする研究もある）にプラスの超過リターンが続く。株価が割安なときに経営者が買うことと整合的である。

| 自社株買いの理由 | 説明 |
| --- | --- |
| **税制上の利点** | 配当がキャピタル・ゲインより重く課税される場合。税率が同じでも、キャピタル・ゲイン税は繰り延べられる |
| **株価の下支え / シグナル** | 株価が割安に見えるときに経営陣が買える。反対の見方：**よい投資機会がない**ことを示しうる |
| **柔軟性** | 継続の期待がなく、完了の義務もない。株主は売るかどうかを選べる |
| **オプションによる希薄化の相殺** | オプション行使時に発行した株式を買い戻す |
| **レバレッジの引き上げ** | 借入による自社株買いは、現金による場合よりレバレッジを高める |

EPS を上げることは弱い理由である。要求リターンはレバレッジとともに上がり、株数が減ってもフリーキャッシュフローの総額は変わらない。

**例（Deira Oasis、AED 百万）。** 負債 30、資本 70。AED7m の自社株買い。

| | 前 | すべて現金 | すべて借入 |
| --- | --- | --- | --- |
| 負債 | 30（30%） | 30（32%） | 37（37%） |
| 資本 | 70（70%） | 63（68%） | 63（63%） |
| 合計 | 100 | 93 | 100 |

現金で行えば EPS は上がるので、資本は AED63m を超える価値になりそうだ。税引後コストが E/P を上回る借入で行えば EPS は下がるので、資本の価値は AED63m を下回る。格下げされれば負債の価値も 37 を下回るので、新しいウェイトは不確実である。

**その他の例。**

* **ITOCHU**（2018–19 年）は、ROE 13% 以上を達成するため、34,121,400 株を平均 ¥1,993（¥680 億）で買い戻した。
* 自社株買いは**景気順応的**で、特別配当の代わりになる。Russell 1000：2007 年は配当 US\$2,860 億に対し自社株買い US\$6,800 億。2008 年第 4 四半期から 2009 年第 3 四半期は US\$2,620 億対 US\$2,230 億で、自社株買いの方がはるかに大きく削られた。
* **Shenzhen Medical Devices** は 3 年間の自社株買いの後、¥0.40 の初配を行う（配当性向 0.40/3.20 = **12.5%**、目標 25%）。初配は将来の**高い**成長と結びついているので、「もはや成長企業ではない」と読むのは誤りであり、2% の株式配当は富を変えない。方針は目標配当性向調整を伴う**安定配当**である。

#### 試験の落とし穴

* キャピタル・ゲインの税率が配当の税率を**下回る**とき、株主は自社株買いを好む。
* 市場価格での自社株買いでは株価は変わらない。現金配当は株価を配当分だけ下げる。1 人の株主からのプレミアム付きの買付は富を移転する。
* 自社株買いは割安（プラス）のシグナルにも、機会の欠如（マイナス）のシグナルにもなりうる。

## 配当の安全性

| 比率 | 式 |
| --- | --- |
| 配当性向 | 配当 ÷ 純利益 |
| 配当カバレッジ | 純利益 ÷ 配当 |
| FCFE カバレッジ | FCFE ÷ (配当 + 自社株買い) |

$$
\begin{aligned}
FCFE ={}& CFO - FCInv\\
&+ \text{Net borrowing}
\end{aligned}
$$

* 配当性向が高い（カバレッジが低い）ほど減配のリスクは高い。大規模な成熟企業は **40–60%** の配当性向、つまり約 **1.7×–2.5×** のカバレッジを目標にすることが多い。カバレッジが **1.0×** に近いと、落ち込みが一時的でない限り配当は危うい。
* 配当の原資は純利益ではなく FCFE であり、自社株買いも還元に数える。

| FCFE カバレッジ | 意味 |
| --- | --- |
| = 1 | 利用可能な現金をすべて払っている |
| ≫ 1 | 流動性を積み上げている |
| ≪ 1 | **持続不可能**：現金を取り崩している。株式発行か設備投資の削減が必要になる |

**例（Mature European SA）。** NI €100m、配当 €40m → 配当性向 **40%**、カバレッジ **2.5×**。

**例（Lygon Resources、A\$ 百万）。**

| | 2015 | 2016 | 2017 | 2018 |
| --- | --- | --- | --- | --- |
| 純利益 | 540 | 458 | 399 | 341 |
| CFO | 837 | 824 | 679 | 628 |
| FCInv | 554 | 417 | 296 | 327 |
| 純借入 | (120) | (39) | 79 | (7) |
| 配当 | 121 | 256 | 277 | 323 |
| 自社株買い | 0 | 105 | 277 | 0 |
| 配当性向 | 22.4% | 55.9% | 69.4% | 94.7% |
| カバレッジ | 4.46× | 1.79× | 1.44× | 1.06× |
| FCFE | 163 | 368 | 462 | 294 |
| FCFE/(配当 + 自社株買い) | 1.35× | 1.02× | 0.83× | 0.91× |

カバレッジは 1.06× に下がり、FCFE カバレッジは 2017–2018 年に 1 を下回った（2017 年は純借入がプラスだったにもかかわらず）→ 自社株買いをやめ、**減配**を検討する。

配当を維持できないかもしれない**警告サイン**：

* 配当性向が高く（カバレッジが 1× に近い）悪化しており、同業他社や自社の過去と比べて高い
* FCFE カバレッジが 1 未満。還元を**借入**や**生産的な設備投資の削減**で賄っている
* 平均を上回るレバレッジ
* 自社の過去と比べて非常に高い配当利回り（StarHub は 2019 年の減配前に 9.4%）。高利回りはお買い得ではなく警告であり、市場価格がすでに減配の予想を示しているかもしれない
* 過去の減配の記録（安定または増加する配当の記録はプラス）

#### 試験の落とし穴

* カバレッジ = NI/配当で、配当性向の逆数である。
* FCFE カバレッジの分母には**自社株買い**を含める。純借入は加算する（マイナス = 返済）。
* 純借入がプラスなら FCFE は増えるが、還元の持続可能な原資ではない。

> [!NOTE]
>
> **教科書の誤植。** Rohit Chemical の解答で、会社を一度「WCII」と呼んでいる（RCII の意味）。ITOCHU の図表は平均価格を ¥1,997 の意味で「1.997」と印刷している。分割税率の図表は「€100 あたり」と書かれているが、税引前 €200（留保 €100、分配 €100）から始まっている。48% は配当に回した €100 あたりの値である。
