# 配当

## 配当と配当政策の概念

配当の分類：

* 現金配当：株主に現金を分配する
  * 普通配当
  * 特別配当・追加配当：株価が割高なとき
  * 清算配当：破産時
* 株式配当
* 株式分割（例：1 株を 2 株に分割）
  * 株式併合（例：20 株を 1 株に併合）

配当が株主の富に与える影響

* 現金：株価は配当額だけ下がるが、株主の富は変わらない
* 株式：株数が変わるだけで、富には影響しない

配当が財務比率に与える影響

* 現金：
  * 貸借対照表の資産と資本が減る
  * 現金が減るので流動性比率が下がる
  * 財務レバレッジ比率（D/A、D/E）が上がる
* 株式：
  * 資産と資本には影響せず、株数が増える
  * 株価と EPS が下がる

|                           | 現金配当後 | 株式配当・株式分割後 |
| ------------------------- | -------------------- | ----------------------------- |
| 資産（現金）             | 減少                | 変わらない                      |
| 資本                    | 減少                | 変わらない                      |
| 株価                     | 下落                | 下落                         |
| EPS                       | 変わらない             | 低下                         |
| PER                       | 低下                | 変わらない                      |
| 流動性比率          | 低下                | 変わらない                      |
| 財務レバレッジ比率 | 上昇               | 変わらない                      |

## 配当政策

MM 理論は配当は無関係だと主張する。一方、「手中の鳥」理論、税金に関する議論、情報シグナリング、エージェンシー・コストの理論は配当が重要だとする。

* 情報シグナリング：配当は会社についての情報（よいものも悪いものも）を伝える
* エージェンシー・コスト：
  * 配当によって、経営者が過剰投資して歯止めがきかなくなるためのフリー・キャッシュフローが減る
  * 配当は会社の負債のデフォルト・リスクを高める

### 税金の考慮

#### 二重課税制度

法人の税引前利益は法人段階で課税され、課税対象の株主に配当として分配されると株主段階で再び課税される。
$$
Div = EBT\times \text{payout\%}(1-t_{corporate})(1-t_{individual\ div})
$$
したがって実効税率 = $t_{corporate}+(1-t_{corporate})t_{individual\ div}$。

#### インピュテーション方式

配当として分配された利益が、株主の税率で 1 回だけ課税されるようにする。
$$
Div = EBT\times \text{payout\%}(1-t_{individual\ div})
$$
実効税率は $t_{indiviaul \ div}$ だけである。

#### 分割税率方式

配当として分配される法人利益には、内部留保される利益より低い法人税率が適用される。
$$
Div = EBT\times \text{payout\%}(1-t_{corporate})(1-t_{individual\ div})
$$
したがって実効税率 = $t_{corporate}+(1-t_{corporate})t_{individual\ div}$。

### 配当支払政策

#### 安定配当政策

$$
E(Div) = Div_{t-1}+(E(NI)\times r_{div}-Div_{t-1})\times \text{Adjustment Factor}
$$

ここで調整係数は $\frac{1}{N}$、$N$ は配当の調整にかける年数である。

#### 配当性向一定政策

常に一定の配当性向で配当を支払う
$$
Div = r_{div}\times NI
$$
配当が利益とともに変動してしまうため、この方法はめったに使われない。

## 自社株買いとその影響

**自社株買い：** 会社が自社の株式を買い戻す取引。買い戻した株式は**自己株式（金庫株）**と呼ばれ、配当、議決権、EPS の計算の対象外になる。

買い戻しの方法は 3 つ：

* 市場での買付け：時期と数量に柔軟性がある
* 公開買付け
  * 固定価格による公開買付け：決まった数の株式を決まった価格で買う。通常は市場価格にプレミアムを上乗せする
  * ダッチ・オークション：オークションで最低価格を決める
* 相対取引：通常は市場価格にプレミアムを上乗せする

EPS への影響：

* 余剰資金で買い戻す場合
  * 資産と資本が減り、レバレッジ比率（D/A、D/E）が上がる
  * EPS は上がる
* 借入で買い戻す場合
  * 負債が増え資本が減り、レバレッジ比率が上がる（現金で買い戻すより大きく）
  * 益回り（E/P）> 税引後負債コストなら EPS は上がり、そうでなければ下がる

1 株当たり純資産への影響：

>[!note]
>
>BVPS = 資本の簿価 / 発行済株式数

* 買い戻し価格 > 元の BVPS なら低下する
* 買い戻し価格 = BVPS なら変わらない
* それ以外なら上昇する

> [!note]
>
> いくつかの比率
>
> * 配当性向 = $\frac{div}{NI}$。
> * 配当カバレッジ・レシオ = $\frac{NI}{div}$
> * FCFE カバレッジ・レシオ = $\frac{FCFE}{div+\text{shares repurchase}}$
> * 減配の警告サイン：
>   * 株式市場の外部指標が悪い
>   * 配当利回りが極端に高い。
