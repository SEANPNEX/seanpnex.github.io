# 投資分析における環境・社会・ガバナンス（ESG）の考慮

所有構造がコーポレート・ガバナンスをどう形づくるか、会社のガバナンスをどう評価するか、そして ESG のリスクと機会をどう特定し、株式と信用の分析に組み込むかを扱う。概念中心の単元で、覚えるべき式はない。

| 用語 | 意味 |
| --- | --- |
| **支配株主** | 支配権を行使できる個人または集団（一族、他の会社、国家）。株式の**過半数**（> 50%）を持つ場合**も少数**（< 50%）の場合もある |
| **プリンシパル・エージェント問題** | 経営者が会社の資源を株主のためではなく自分の利益のために使う |
| **プリンシパル・プリンシパル問題** | 支配株主が少数株主を犠牲にして資源を得る |
| **議決権の上限** | 大口保有の議決権に対する法的な制限（戦略的企業の外国支配を防ぐために政府がよく使う） |
| **役員の兼任（インターロッキング）** | 同じ人々が複数の会社の取締役会に就いている（ラテンアメリカで一般的） |
| **内部者** | 株主でもある経営者や取締役 |
| **株主アクティビズム** | 株主が会社に特定の行動をとらせるために使う戦略 |
| **ESG インテグレーション** | 証券・業界の分析**とポートフォリオ構築**において、定性的・定量的な ESG 要因を使うこと |
| **座礁資産** | 規制や需要の変化などで陳腐化したり採算がとれなくなったりした資産 |
| **グリーンウォッシング** | グリーンボンドの調達資金が実際には環境に有益なプロジェクトに使われないリスク |

## 所有構造

* **分散所有**：株主が多く、単独で支配できる者はいない。
* **集中所有**：1 人の株主または集団（支配株主）が支配権を行使できる。
* **ハイブリッド**：その中間。

> [!IMPORTANT]
> 決まった割合の線引きはない。所有だけでは誰が会社を支配しているかわからないことがある。支配株主は、以下の仕組みを通じて株式の**過半数でも少数でも**持ちうる。（テキストで唯一出てくる「25%」は英国の説明で、英国では 25% 以上を持つ株主がいる会社は少ない。）

集中所有の方がはるかに一般的で、OECD（2017）が調査した 47 の法域のうち **38** がそうである。

| 分類 | 法域 | 備考 |
| --- | --- | --- |
| **分散** | オーストラリア、アイルランド、英国、米国 | オーストラリア：株式の多くは金融機関が保有。米国の上場企業に支配株主がいることはまれ |
| **ハイブリッド** | カナダ、ドイツ、日本、オランダ、スイス | 例：ドイツでは多くの会社が強く支配されているが、上場株式は広く保有されている |
| **集中** | 残りの 38（例：中国、フランス、インド、ブラジル、韓国） | 国家：中国、ノルウェー、スウェーデン。一族：ブラジル、メキシコ、ポルトガル、韓国。企業グループ：インド、ロシア |

**支配が所有を上回る仕組み：**

* **水平的所有**：事業上の利害を共有する会社（主要な顧客や仕入先）が互いに株式を持ち合う。戦略的提携や長期的な関係を支える。
* **垂直的（ピラミッド型）所有**：ある会社やグループが 2 つ以上の持株会社を支配し、その持株会社が事業会社を支配する。
* **種類株式（デュアル・クラス）**：ある種類の株式は優越的な（または唯一の）議決権を持ち、他の種類は議決権が劣るかない。ピラミッドと組み合わせると、頂点のグループは自らに優越的議決権株式を与え、比較的少ない持株で事業会社を支配できる。

### 所有構造ごとの対立

| 所有 | 議決権 | 力関係 | 主な対立 |
| --- | --- | --- | --- |
| 分散 | 分散 | 株主が弱く、**経営者が強い** | **プリンシパル・エージェント** |
| 集中 | 集中 | **株主が強く**、経営者が弱い | **プリンシパル・プリンシパル** |
| 分散 | 集中 | 支配株主が**過半数を持たない**（種類株式、ピラミッドによる） | **プリンシパル・プリンシパル** |
| 集中 | 分散 | **議決権の上限**から生じる | （テキストでは命名されていない） |

> [!IMPORTANT]
> 支配株主はプリンシパル・エージェント問題を**減らす**（取締役会を支配し、経営者を任命し、監視する動機を持つ）が、プリンシパル・プリンシパル問題を**生み出す**。

**例（A 社）。** 経営者が約 30% を所有し、他の株主はいずれも 1% 以下、1 株 1 議決権。分散所有で議決権も分散 → 株主が弱く経営者が強い → **プリンシパル・エージェント**のリスク。

### 影響力のある株主

| 株主 | 役割と懸念 |
| --- | --- |
| **銀行** | 欧州とアジアで一般的。貸し手**であり**株主でもある。不利な条件での多額の借入を会社に促し、他の株主を犠牲にすることがある |
| **一族** | ラテンアメリカで支配的で、アジアと欧州ではそれほどでもない。役員の兼任を伴うことが多い。**+** プリンシパル・エージェント問題が少ない。**−** 透明性が低い、経営者の説明責任が弱い、少数株主の権利を軽視する、優秀な経営者を集めにくい |
| **国有企業** | 戦略的な部門、必要資本が民間の能力を超える場合、国家が一定の価格や基準で製品を提供したい場合（電力、医療）。上場した国有企業（**混合所有**）は市場の監視を受けにくく（暗黙の国家による倒産保証）、株主を犠牲にして公共政策を追求することがある |
| **機関投資家** | 投資信託、年金基金、保険会社、ヘッジファンド。判断する資源と専門性がある。分散市場では支配できるほど大きいことはまれだが、取締役会と経営者に説明責任を果たさせることでよいガバナンスを促す |
| **企業グループ** | 水平・垂直の構造で所有に見合わない支配を得る。株式の持ち合いは株式の譲渡を制限し、外部者を締め出す。少数株主に不利な**関連当事者取引**のリスクが高い（例：Samsung、三和、Grupo Carso） |
| **プライベート・エクイティ** | ベンチャー・キャピタル（初期段階、監督）と LBO ファンド（成熟企業の過半数支配）。企業行動規範や業績連動報酬をもたらすことがある |
| **外国人投資家** | 新興市場で国内投資家より多く保有すると影響力を持つ。規制の厳しい法域の投資家は透明性の向上を求めることがある。より厳しい市場への重複上場は、現地の少数株主の利益になりうる |
| **内部者** | 持株が大きい → 株主との利害の一致と長期志向。ただし大きな持株は自分たちの利益を守る力も与えうる |

### ガバナンスへの影響

* **独立取締役**：会社と重要な関係（雇用、所有、報酬）を持たない取締役。分散所有の法域で経営者の監視を強めるために生まれ、エンロンなどの不祥事の後にその割合が高まった。米国は、監査、指名、報酬の各委員会をすべて独立取締役で構成することを求めている。集中所有の法域の多くでは指名・報酬委員会は義務ではなく、独立取締役の役割は狭い。OECD 諸国は、最低人数（通常 1–3 人）か最低比率（通常 20% から 50% 超）を求めるか推奨している。
* **取締役会の構造**：
  * **一層制**：業務執行取締役と非業務執行取締役からなる単一の取締役会。最も一般的な構造。
  * **二層制**：監査役会が執行役会を監督する。アルゼンチン、ドイツ、ロシアなどでは義務、ブラジルやフランスでは任意。監査役会は帳簿を調べ、年次報告書を審査し、監査人を監督し、経営陣の報酬を決めるか影響を与える。ドイツではステークホルダーの代表（銀行、労働者）が含まれる。
* **特別な議決の仕組み**：少数株主が取締役の指名・選任に参加するのを助ける（例：ブラジル、インド、ポルトガル、トルコ、イタリア、イスラエル、英国）。英国では、支配株主のいるプレミアム上場企業は、独立取締役の選任について全株主**と**非支配株主の**両方**の承認を得なければならない。
* **ガバナンス・コード、法律、上場規則**：各国のコードは**コンプライ・オア・エクスプレイン**で運用される。日本はさらに進んでおり、社外取締役のいない会社は、選任が適切でない理由を説明しなければならない。国のコードがない場合は、会社法（例：チリ）や取引所の上場規則（例：インド）が適用される。
* **スチュワードシップ・コード**：投資家に権利の行使とエンゲージメントを促す、主に任意のコード。英国のスチュワードシップ・コードの下では、機関投資家は投資先企業を監視しなければならず、英国の資産運用会社はコンプライ・オア・エクスプレインの声明を公表しなければならない。

> [!IMPORTANT]
> 集中所有の下ではプリンシパル・エージェント問題は一般に**小さい**。そのため、そこでは独立取締役の役割が狭い。

## コーポレート・ガバナンスの評価

有効なガバナンスは、高い収益性と ROE の成長、信用へのアクセスの改善、高く持続可能な配当、長期的によい株価パフォーマンス、そして**低い資本コスト**をもたらしうる。有効でないガバナンスは、評判の毀損、競争力の低下、弱い、あるいは不安定な株価、低い収益性、**高い資本コスト**をもたらす。

ガバナンスは数値化しにくい。まず開示された方針（企業倫理、贈収賄と汚職、内部通報者の保護、関連当事者取引を含む）から始め、次に経営陣と対話し、必要ならアクティビズムを使う。実務では、アナリストは**リスク・プレミアム（資本コスト）や信用スプレッド**を調整してガバナンスを反映する。

### 取締役会の方針と慣行

| 分野 | 見るべき点 |
| --- | --- |
| **CEO の兼任** | CEO が取締役会議長を兼ねる → 取締役会の監督が損なわれうる。議長が独立していなければ、**筆頭独立取締役**を置くことがある |
| **取締役会の独立性** | 独立取締役がいない、あるいは少数にとどまるのは**マイナス**：経営陣が自己の利益のために行動しうる → 認識されるリスクが高まる |
| **委員会** | 監査、ガバナンス、報酬、指名、リスク、コンプライアンス。主要な委員会が独立しているか確認する。独立していない、あるいは業務執行のメンバーは、報酬（報酬委員会）、経営者の選任（指名委員会）、報告の誠実性（監査委員会）で利益相反を生む |
| **スキルと経験** | スキルが偏りすぎていても、多様でも中核事業と無関係でも、どちらも不十分でありうる。資源やESG リスクの高い業種では、取締役会に環境、気候、社会の専門家が含まれるのが普通 |
| **在任期間** | **10 年**を超えると長い。**+** 事業と経営陣の実績を深く知っている。**−** 独立性を弱めうる（経営陣に近すぎる）し、変化に抵抗しうる |
| **構成** | 取締役の人数と多様性（職業、文化・地理的背景、性別、年齢、在任期間）。人数が多すぎる、あるいは多様性が乏しすぎると統治の効果が下がりうる |
| **取締役会の評価** | 自己評価または外部評価。職務、リーダーシップ、構造（委員会を含む）、取締役会と経営陣の関係を対象とする。株主、規制当局、その他のステークホルダー向けのことがある |

**役員報酬。** 透明性、短期・長期のインセンティブの基準、会社の戦略との結びつき、CEO と平均的な従業員の報酬格差を見る。過大な報酬（しばしば CEO 報酬 ÷ 平均的な従業員の報酬）は KPI と照らして判断する。インセンティブは企業価値を高めているか。

* **セイ・オン・ペイ**：**株主**が報酬について投票したり意見を述べたりできる。
* **クローバック**：修正再表示、不正行為、法令違反、リスク管理の失敗が明らかになった場合、会社は**支給済みの報酬を取り戻せる**。

**議決権。** **単純議決**（1 株 1 議決権）と**種類株式**の対比。後者では創業者や経営者が一般株主より議決権の多い株式を持ち、少数株主との潜在的な対立がある。

**例（Style、イタリアの衣料品小売業者）。** 取締役 11 人。議長（Leila Donato）は CEO ではない。独立取締役は 2 人。独立でない取締役 6 人のうち 4 人は Donato 一族で、いずれも在任 20 年以上。女性 5 人、年齢は 35–75 歳。

| プラス | マイナス |
| --- | --- |
| CEO の兼任がない | 独立取締役は 2 人だけ。一族には議長が含まれる |
| 年齢と性別の多様性 | 一族の在任期間は典型的な 10 年を大きく超える |

**例（日本の Sumiyoshi 銀行グループ、国内同業他社との比較）。**

| 要因 | 同業他社 | Sumiyoshi |
| --- | --- | --- |
| 取締役会の形態 / 人数 | 二層制 / 13 | 二層制 / 14 |
| CEO の兼任 | あり | あり |
| 独立した議長 | あり | **なし** |
| 取締役会の独立性 | 47% | **36%** |
| 女性取締役 | 17% | **7%** |
| 長期在任（> 10 年） | 0% | **14%** |
| 委員会 | 5（ガバナンスを含む） | 4（ガバナンス委員会なし） |
| 業界の経営経験を持つ独立取締役 | 67% | **20%** |
| インセンティブ指標の開示 | なし | なし |
| セイ・オン・ペイ | あり | **なし** |
| 所有 / 議決 | 単独の大株主なし、単純議決 | 同じ |

Sumiyoshi は取締役会の構成で後れをとっている。アナリストはガバナンスの代理指標として信用リスクも使う。不良債権 / 総貸出金の比率が**同業他社より 50 bp 高い**ことは、同業他社より高い**株式リスク・プレミアム**と広い**信用スプレッド**を正当化しうる。

> [!IMPORTANT]
> CEO と議長の分離はプラスだが、それがすべてではない。独立性の低さ、長い在任期間、一族や内部者の支配があれば、取締役会はなお弱くなりうる（Style）。

## ESG 要因の特定

最大の課題は、**目的適合的で、比較可能で、意思決定に有用な**情報を得ることである。ESG データは主に公開書類とサステナビリティ報告書（独立した保証を受けている場合もいない場合もある）から得られる。ESG 開示の多くは**任意**で**一貫性がない**が、時とともに増えてきた。

**重要性（マテリアリティ）。** ESG の問題は、プラスであれマイナスであれ、会社の事業、財務業績、証券の評価に影響すると予想されるなら重要である。会社は、投資家が重要と考えるマイナスの情報を軽く扱う一方で、プラスだが重要でない情報を「重要」と呼ぶことがある。

**投資期間。** 問題が重要かどうかは期間にもよる。

* 債券は満期がさまざまなので、期間は**信用アナリスト**にとって特に重要である。
* 規制の変更や石油流出などの論争の後、問題の期間は長期から短期に（あるいはその逆に）変わりうる。
* 例えば、ある製造業者が将来のより厳しい環境規制に直面する。短期の投資家は目先の利益への影響は小さいと見るが、長期の投資家は高額な工場の改修や罰金を予想する。

**業界ごとの関連要因。** ガバナンスのベスト・プラクティスは会社間でかなり共通している（地域による違いはある）。環境と社会の要因には**世界共通のベスト・プラクティスはなく**、関連性は業界による。エネルギー会社は**環境**要因に、銀行は**社会**要因（データ・セキュリティ、プライバシー、顧客満足）にさらされやすく、どちらもガバナンスにさらされる。

**ESG 要因を特定する 3 つの方法**（単独または組み合わせ）：

| 方法 | 内容 | 例 |
| --- | --- | --- |
| **独自の手法** | アナリストや会社自身の判断とツール。会社、ニュース、業界・環境団体、労働組織、専門家、政府の情報を使う | 年次報告書、サステナビリティ報告書、委任状説明書、10-K。CDL の気候シナリオ開示 |
| **ESG データ提供会社** | ベンダーが公開情報を ESG スコアとランキング（業界内の相対評価が多い）に変換し、アナリストの主観的評価も加える | MSCI、Sustainalytics |
| **非営利のイニシアチブと報告フレームワーク** | ESG の問題に関するデータ、知見、ツール | IIRC（標準化された開示フレームワーク）、GRI（業界別のサステナビリティ報告基準）、SASB（統一的なサステナビリティ会計基準。**マテリアリティ・マップ**）、2DII、Access to Nutrition Index |

**例（City Developments Limited、CDL）。** TCFD と IPCC に沿った気候シナリオ計画で、2°C と 1.5°C の温暖化について 2030 年のシナリオを示している。

| 種類 | 項目 |
| --- | --- |
| 移行リスク | 政策リスク（炭素税、より厳しい建築基準。優先度高）、水の安全保障、廃棄物の責任、保険料の上昇や付保不能な資産 |
| 物理的リスク | より頻繁で深刻な洪水や熱波 → 座礁資産 |
| 機会 | 消費者のアクティビズム、世界的な低炭素成長への移行（優先度高）、シンガポールのグリーン・ファイナンス |

開示は最小限のものから何ページにもわたるものまであり、比較を難しくしている。例えば GRI の耐久消費財と家庭用品・パーソナルケア製品のトピックには、環境面（原材料の調達、包装、プラスチックと化学物質、製品のエネルギー効率）、社会面（移民労働者、製品の安全性、表示、電子廃棄物）、その他（役員報酬、統治機関の性別構成、仕入先の審査）がある。

## ESG インテグレーション

ESG インテグレーションは、機会を見いだし、下方リスクを減らすことを目指す。

| | 株式 | 債券（信用） |
| --- | --- | --- |
| 目的 | **機会を見いだし**、下方リスクを減らす | 主に**下方リスクを減らす**（最良の場合でも額面での償還） |
| 手法 | 財務数値と比率の予測、評価の入力値（例：**割引率**）の調整、感応度・シナリオ分析 | 社内の信用評価、比率の予測、相対的な信用順位付け。相対価値、**スプレッド**、**デュレーション**、感応度・シナリオ分析 |
| 例 | ホテル：従業員の離職率が高いので営業費用を引き上げる。菓子メーカー：主要原料を持続可能なものに切り替えたので割引率を**下げる** | 玩具メーカー：訴訟が信用比率、キャッシュフロー、流動性を損ない、スプレッドが拡大しうる。石炭会社：座礁資産のリスクは **1 年**債より **10 年**債にはるかに大きく効く |

> [!IMPORTANT]
> 株式と信用で特定と統合のプロセスは似ているが、**重要な要因とその含意は異なり**、信用（と CDS）への影響は**満期**によって異なりうる。

### グリーンボンド

**グリーンボンド**は、環境や気候に便益のあるプロジェクトに資金を供給する。調達資金は特定のグリーン・プロジェクトに充てられる。

* 最初のものは欧州投資銀行の Climate Awareness Bond で、**2007 年**に発行された。
* 発行体は主幹事とともに「グリーン」のラベルを決め、適格基準と資金使途を開示しなければならず、独立したレビューを依頼することもある。**グリーンボンド原則**（2014 年。任意。ICMA が管理）がこれを導く。指数提供会社、格付会社、Climate Bonds Initiative には独自の手法があり、欧州委員会も基準を策定している。
* 発行体にとっては、追加の監視・報告コストがかかるが、投資家層が広がり、発行時の利回りが下がる可能性がある。
* 形態：普通社債、プロジェクト債、MBS/ABS、地方債（例：カリフォルニア州が 2014 年に発行した US\$3 億のグリーン一般財源債。他の GO 債と同じく一般会計で裏付けられる）。
* 他の条件が同じなら、発行体の通常の債券と**格付も評価も同じ**である。資金使途が違うだけで、債券保有者の遡求権は同じである。
* リスクが低いからではなく、**需要のために**プレミアム（より狭いスプレッド）で取引されることがある。
* リスク：**グリーンウォッシング**（グリーンという特徴に払いすぎる、あるいは環境上の運用方針を満たさない債券を持つ）と**流動性**（保有者の多くは満期保有する）。

> [!IMPORTANT]
> グリーンボンドの信用リスクは発行体の信用リスクである。スプレッドが狭いのは**需要**を反映したもので、デフォルト・リスクが低いからではない。

## ESG のリスクと機会の評価

インテグレーションのプロセス：

1. 会社とその業界にとって**重要な** ESG 要因を特定する。
2. それを時系列で、予測の中で、同業他社と比べて評価する。
3. 財務諸表とバリュエーションを調整する。

| どこで | 典型的な ESG 調整 |
| --- | --- |
| 損益計算書 / キャッシュフロー | 売上高、営業費用と営業外費用、利益率、利益、設備投資 |
| 貸借対照表 | **減損資産**の見積り |
| 株式のバリュエーション | 資本コスト / **割引率**、株価倍率、ターミナル・バリュー |
| 債券のバリュエーション | **信用スプレッド**または CDS |

*Guidance and Case Studies for ESG Integration: Equities and Fixed Income*（2018）のフレームワークは、リサーチ（定性・定量）、証券の評価、ポートフォリオ構築、資産配分、シナリオ分析、リスク管理を対象とする。

テキストの 3 つのケースはそれぞれ 1 つの柱に焦点を当てている。考え方は他の業界にも当てはまる。

| ケース | 柱 | 主要な指標 | 財務上の調整 | バリュエーションへの影響 |
| --- | --- | --- | --- | --- |
| **Frizzle Drinks**（米国の飲料） | 環境 | **水使用原単位** = 製品 1 リットルあたりの水のリットル数（同業他社比較のため売上高 US\$100 万あたりで基準化） | 2009 年から 2021 年に 27% 低下し、2025 年までにさらに 13% の削減が目標。2022 年予想の COGS/売上高は 40%（同業他社 42%）で、水使用の減少によりさらに 1% 下げる → 売上総利益率が上がる | 利益の増加 → 株式の公正価値が上がる。債券と CDS にとっては営業キャッシュフローの改善。ESG リスクの低下が**すでにスプレッドに織り込まれているか**を確認する |
| **Well Pharma**（欧州の製薬） | 社会 | **製品の品質**：論争、規制当局の警告書、リコール、罰金、認証を受けた工場の割合（例：ISO 9001） | 同業他社で最悪の記録（警告書 15 通、品質の論争 5 件）。翌年の売上高 −2%、COGS/売上高 +1.3%、営業外費用は営業利益の +4.5%。扱いは問題が**繰り返し起きるか一度きりか**による | 株主**にも**債券保有者にも利益とキャッシュフローの減少。ブランド価値の減損の可能性 |
| **Sumiyoshi**（日本の銀行） | ガバナンス | 同業他社と比べた取締役会の構成。ガバナンスの代理指標としての**不良債権 / 総貸出金** | 不良債権比率が同業他社より 50 bp 高い | 株式リスク・プレミアムの上昇。信用スプレッドの拡大 |

Well Pharma の品質問題が財務にどう波及するか：

| 要因 | 財務への影響 |
| --- | --- |
| 製品品質の論争 | ブランドの毀損 → 売上の減少 |
| 規制当局の警告書 | コンプライアンス費用の増加 |
| 製品リコール | 売上の喪失、リコール費用 |
| 規制上の罰金 | 返品や訴訟に対する引当金 |
| 認証を受けた工場の割合が低い | 品質問題、リコール、費用のリスクが高い |
