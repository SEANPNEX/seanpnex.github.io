# コモディティ

コモディティのセクターとそのライフサイクル、コモディティの評価が株式や債券とどう違うか、誰がコモディティ先物を取引するか、現物と先物の関係（コンタンゴとバックワーデーション）、先物リターンの 3 つの理論、フル担保の先物リターンの構成要素、コモディティ・スワップ、そして指数の構成が指数リターンをどう左右するか。（2026 年のタイトル：*Introduction to Commodities and Commodity Derivatives*。）

| 用語 | 意味 |
| --- | --- |
| **ベーシス** | 現物価格 − 先物価格 |
| **カレンダー・スプレッド** | 期近の先物価格 − 期先の先物価格（同じコモディティ） |
| **バックワーデーション** | 現物が先物より高い（または期近が期先より高い）：ベーシスとカレンダー・スプレッドがプラス |
| **コンタンゴ** | 現物が先物より低い（または期近が期先より低い）：ベーシスとカレンダー・スプレッドがマイナス |
| **コンビニエンス・イールド** | 供給の途絶に備えて現物在庫を持つことの便益。**在庫が乏しいときに高い** |
| **ロール・リターン** | 満期を迎える限月を手仕舞い、より先の限月を建てることで生じる損益 |
| **担保リターン** | 先物ポジションの担保として持つ現金や短期国債の利息 |
| **フル担保** | 担保 = 先物の想定元本。レバレッジなし |

## コモディティの基礎

### セクター

ブルームバーグ・コモディティ指数は、コモディティを 6 つのセクターに分ける。

* **エネルギー**：原油、天然ガス、石炭、石油製品（ガソリン、暖房油）。
* **産業用（ベース）メタル**：銅、アルミニウム、ニッケル、亜鉛、鉛、スズ、鉄。
* **貴金属**：金、銀、プラチナ（価値の保存手段であり、産業用途もある）。
* **穀物**：トウモロコシ、大豆、小麦、コメ（食料、飼料、エタノールなどのバイオ燃料）。
* **ソフト**（換金作物）：綿花、ココア、砂糖、コーヒー。
* **畜産物**：豚、牛、羊、家禽。

ファンダメンタル分析では、各セクターを**ストック**（潜在的な需給：油田、農地、飼養頭数、製錬能力）と**フロー**（そのストックがどう使われるか：天候、パイプライン、疫病、政策、GDP 成長）でとらえ、さらにタイミング（季節、物流、ショック）と資金の流れ（センチメント、金利、補助金）を考える。

| 主な影響要因 | エネルギー | ベースメタル | 貴金属 | 穀物 | ソフト | 畜産物 |
| --- | --- | --- | --- | --- | --- | --- |
| GDP の規模と成長 | ✓ | ✓ | ✓ | | ✓ | ✓ |
| 天候 | ✓ | | | ✓ | ✓ | ✓ |
| 消費者の嗜好 | | | | ✓ | ✓ | ✓ |
| 消費者の所得 | | | | | ✓ | ✓ |
| 人口増加 | | | | ✓ | | |
| バイオ燃料による代替 | | | | ✓ | ✓ | |
| 疫病 | | | | ✓ | ✓ | ✓ |
| 金融政策、マネーサプライ | | | ✓ | | | |
| 地政学 | ✓ | | ✓ | | | |
| 産業・環境政策、インフラ | ✓ | ✓ | | | | |

> [!IMPORTANT]
> 試験の頻出事項：産業活動は**銅**を動かす（天然ガスは主に天候、ソフトは主に所得で動く）。貴金属は保管が容易なので、短期の天候の影響が**最も小さい**。

### ライフサイクル

* 生産のライフサイクルは、保管、天候、政治的・経済的な出来事の変化を反映し、**増幅する**。
* ライフサイクルが**短い**と外部の出来事にかなり早く適応できる。**長い**と需給の反応の速さが制限される。
* 農産物と畜産物には明確な季節があり、地域（北半球と南半球）によって異なる。エネルギーと金属は**一年中**採掘される。その季節性は主に製品の需要（夏のガソリン、冬の暖房油）から生じる。

| セクター | ライフサイクルの要点 |
| --- | --- |
| **エネルギー** | 天然ガスは採掘後ほぼすぐに使える（夏のガスは冬に向けて貯蔵されることが多い）。原油は**精製**（「クラッキング」）されるまで役に立たない。製油所とパイプラインは非常に高価で、パイプラインは紛争で寸断されることが多い |
| **金属** | 最も**柔軟な**ライフサイクル。鉱石と金属は何か月、何年も劣化せずに保管できる。製錬の規模の経済が大きいので、供給が需要を上回っても減産しにくい。新しい生産能力は需要が落ちたちょうどそのときに稼働することが多い |
| **畜産物** | 家禽は数週間、豚は約 6 か月、牛は数年で成熟する（フィーダー・キャトル → フィードロットでライブ・キャトルに）。米国の畜産物は、屠畜後の肉が傷むので、歴史的に**最も輸出志向が弱い**（冷凍がこれを変えつつある） |
| **穀物** | 作付け → 生育 → さや・穂の形成 → 収穫。サイロで一年中保管され、カビや害虫のリスクがある |
| **ソフト** | たとえばコーヒーは赤道付近のどこかで一年中収穫される。ロブスタはロンドン、アラビカはニューヨークで取引され、焙煎前の「生」豆として保税倉庫に受け渡される |

### 株式・債券との評価の違い

| | 株式と債券 | コモディティ |
| --- | --- | --- |
| 性質 | 金融資産：経済的産出に対する請求権 | ほぼ常に**実物**資産（例外：電力、天候） |
| キャッシュフロー | 配当、クーポン | **ない**。現物を持つと保管と輸送の**コストがかかる** |
| 評価 | 期待キャッシュフローの現在価値 | **需給**と予想ボラティリティから価格を予測 |
| 投資家の主な手段 | 証券を保有 | 主に期限のある**デリバティブ**（先物、スワップ） |

保管と輸送のコストがフォワード・カーブを形づくる。保管コストが高い → 先物価格は満期とともに上がる。現在の需要が強いと現物が先物を上回ることもある。受け渡しができない参加者がいる場合、裁定は現物と先物の差を一定の水準ではなく、ある**範囲**内に保つだけである。

### 市場参加者

* **ヘッジャー**は自らのコモディティ・エクスポージャーをヘッジするために取引する。ヘッジ＝ロング、投機＝ショートというわけではない。スナック・メーカーはトウモロコシを**ロング**してヘッジし、金鉱会社は金を**ショート**してヘッジする。一貫操業の石油会社がロングで投機し、CTA がショートすることもある。
* **トレーダーと投資家**：
  * **情報を持つ投資家**（指数投資家や機関投資家を含むヘッジャーと投機家）は、情報面で優位にあると考えている。
  * **流動性供給者**は、生産者と消費者が同時に市場にいないときに参入する。期待利益と引き換えに、実質的に**ヘッジャーに保険を提供**している。
  * 保管設備（倉庫、サイロ、フィードロット）を持つ**裁定取引者**は、現物（と保管・資金調達コスト）と先物価格の間のミスプライシングを利用する。
* **取引所**（と清算機関）はルールを定め、インフラを提供する：CME と ICE（米国）、B3（ブラジル）、LME（産業用金属、HKEX 傘下）、大連、上海、東京。
* **アナリスト**はポジションを持たない（研究者、商品開発者、政策立案者、ブローカー）。
* **規制当局**：米国は CFTC（監視の多くを NFA に委任）。ほかの多くの国では単一の規制当局（例：中国証券監督管理委員会）。EU では ESMA と MiFID II。IOSCO が国際的な調整を行う。

> [!NOTE]
> 先物市場は**ネット・ゼロ**（ロング = ショート）で、投資家がネット・ロングである株式・債券市場とは違う。先物のショートは株式のショートより簡単である。借りる必要がなく、配当を払い戻す必要もなく、証拠金もロングと同じである。

## 現物価格と先物価格

* **現物価格**は、特定の場所で現物を受け渡しする現在の価格で、非常に**ローカル**である。
* **先物価格**は、標準的な数量と品質を将来の日に受け渡すために今日合意する価格で、グローバルまたは地域的で、標準化され公開されている。
* **ベーシス** = 現物 − 先物、**カレンダー・スプレッド** = 期近の先物 − 期先の先物。**バックワーデーション**（現物または期近が先物または期先より高い）ではベーシスとスプレッドがプラス、**コンタンゴ**ではマイナス。
* たとえば WTI が 7 月限 USD65.50、12 月限 USD64.00 → カレンダー・スプレッド **+USD1.50**（バックワーデーション）。リーン・ホッグが 7 月限 95¢、8 月限 96¢ → スプレッド **−1¢**（コンタンゴ）。
* カーブは、特にストレス時や構造変化の下で、コンタンゴとバックワーデーションの間で入れ替わりうる。

**決済。**

* **現金決済**は投機家と裁定取引者を呼び込み、ヘッジャーが受け渡しなしで価格リスクを移転できるようにした。
* **現物決済**では先物が現物に収束する。現金決済の市場は（取引コストのため）完全には収束しないことがある。
* 品質と品種が重要である。ロブスタはアラビカの契約に対して受け渡せず、産地や倉庫の場所によってプレミアムやディスカウントを適用する契約もある。

## 先物リターンの理論

### 保険理論

ケインズの**ノーマル・バックワーデーション**：

* 生産者はもともと現物をロングしているので、収入を確定するために**先物を売る**。
* 生産者が売り続けることで先物は現物を**下回る**。その割引は、価格の保険を提供する投機家への支払である。
* したがってカーブは**バックワーデーション**で、先物価格が現物に向かって上がるにつれて、ロングの投機家はプラスの超過リターンを得る。たとえば期近が 76.75¢ のときに 10 月限の綿花を 74.50¢ で買う → ポンドあたり +2.25¢、× 50,000 ポンド = 1 枚あたり USD1,125（期近の価格が変わらなければ）。
* 実証的な裏付けは弱い。Kolb（1992）は「ノーマル・バックワーデーションはノーマルではない」と結論づけた。バックワーデーションが確実にプラスのリターンをもたらすわけでも、コンタンゴが確実にマイナスのリターンをもたらすわけでもない。

### ヘッジ圧力仮説

生産者（先物の売り）も消費者（先物の買い）もヘッジする。

| ヘッジ圧力 | カーブ |
| --- | --- |
| 生産者 = 消費者 | **フラット**：ヘッジの需要が相殺され、投機家を引きつけるための割引は不要 |
| 生産者 > 消費者 | **バックワーデーション**（ケインズと同じ）：投機家は割引があるときだけロングする |
| 消費者 > 生産者 | **コンタンゴ**：買い手が先物を買い上げ、投機家にショートさせる |

限界：生産者の価格エクスポージャーは、分散した消費者より集中していることが多い。両者が投機することもある（例：1993 年のメタルゲゼルシャフト）。ヘッジ圧力の測定は非常に難しい。

### 貯蔵理論

Kaldor（1939）：在庫の水準がカーブの形を決める。

$$
\begin{aligned}
\text{Futures price}={}&\text{Spot price}\\
&+\text{Storage costs}\\
&-\text{Convenience yield}
\end{aligned}
$$

* 日常的に貯蔵されるコモディティ（供給が優勢）→ 保管コストが優勢 → **コンタンゴ**。
* ジャスト・イン・タイムで在庫が少ない（需要が優勢）→ コンビニエンス・イールドが優勢 → **バックワーデーション**。
* コンビニエンス・イールドは**在庫が豊富なときに低く**、**在庫が減ると上がる**。たとえば 2011 年のリビアでは、期近の原油のコンビニエンス・イールドが急上昇した一方、期先はほとんど動かなかった → バックワーデーション。

> [!IMPORTANT]
> 保険理論はバックワーデーションだけを予測する。ヘッジ圧力はフラット、バックワーデーション、**または**コンタンゴを予測する。貯蔵理論は保管コストとコンビニエンス・イールドの大小で決まる。実際には保管コストとコンビニエンス・イールドは観察できないか変動が大きいので、3 つとも判断が必要である。

## 先物リターンの構成要素

**フル担保**のコモディティ先物ポジションのトータル・リターン：

$$
\begin{aligned}
\text{Total return}={}&\text{Price return}\\
&+\text{Roll return}\\
&+\text{Collateral return}
\end{aligned}
$$

指数ではこれに**リバランス・リターン**が加わる。

* **価格リターン**（スポット・イールド）：先物価格の変化で、通常は期近限月：

$$
\text{Price return}=\frac{P_{\text{now}}-P_{\text{before}}}{P_{\text{before}}}
$$

* **ロール・リターン**（ロール・イールド）：期近の限月を手仕舞い、より先の限月を建てることから生じる。単独で獲得することはできず、会計上の計算である。

$$
\text{Roll return}=\frac{F_{\text{near}}-F_{\text{far}}}{F_{\text{near}}}\times\%\text{ rolled}
$$

* **担保リターン**（担保イールド）：ポジションを裏付ける現金や債券の利息。指数では担保 = 想定元本（レバレッジなし）で、通常は短期国債。長期の予測では、期間の合う国債を使う。

#### 例：S&P GSCI における WTI のロール

S&P GSCI は 5 日間にわたり、毎日ポジションの 20% ずつをロールする。

| 限月 | 価格 |
| --- | ---: |
| 期近（3 月限） | USD52.64 |
| 期先（4 月限） | USD53.00 |

**ステップ 1。グロスのロール・リターン。**

$$
\begin{aligned}
\text{Gross}&=\frac{52.64-53.00}{52.64}\\
&=-0.68\%
\end{aligned}
$$

**ステップ 2。ロール比率で調整する。**

$$
\text{Net}=-0.68\%\times 20\%=-0.13\%
$$

期先のほうが高い（コンタンゴ）ため、各日のロールでは **0.13% のコスト**がかかる。

#### 例：バックワーデーションにおけるトータル・リターン

| 入力 | 値 |
| --- | ---: |
| 期近限月 | USD80.00 |
| 期先限月 | USD78.40 |
| ロール比率 | 100% |
| 年間の価格リターン | +4% |
| 担保（フル担保、短期国債） | 3% |

**ステップ 1。ロール・リターン。**

$$
\begin{aligned}
\text{Roll}&=\frac{80.00-78.40}{80.00}\times 100\%\\
&=2.0\%
\end{aligned}
$$

**ステップ 2。トータル・リターン。**

$$
\begin{aligned}
\text{Total}&=4\%+2\%+3\%\\
&=9\%
\end{aligned}
$$

期先のほうが安い（バックワーデーション）ため、ロールが 2% **上乗せ**され、トータル・リターンは **9%** となる。

#### 例：同じエクスポージャーを保つロール

USD10,000 のロング・ポジションで、期近限月は USD4.00、期先限月は USD2.50 である。

$$
\begin{aligned}
\text{Near sold}&=\frac{10{,}000}{4.00}=2{,}500\\
\text{Far bought}&=\frac{10{,}000}{2.50}=4{,}000
\end{aligned}
$$

期先のほうが安い（バックワーデーション）ため、USD10,000 のエクスポージャーを保つには**より多くの**枚数（2,500 枚に対して 4,000 枚）が必要になる。

| カーブ | 期先と期近 | 同じエクスポージャーを保つには | ロール・リターン |
| --- | --- | --- | --- |
| **バックワーデーション** | 期先が安い | 期先を**多く**買う（例：£110 を £10 で → 11 枚、£9 で → 約 12 枚） | **プラス** |
| **コンタンゴ** | 期先が高い | 期先を**少なく**買う（例：£108 を £9 で → 12 枚、£10 で → 約 11 枚） | **マイナス** |

**S&P GSCI、1970 年 1 月 – 2019 年 3 月：**

| | トータル | スポット | ロール | 担保 |
| --- | --- | --- | --- | --- |
| 年率リターン | 6.8% | 3.0% | −1.3% | 5.0% |
| リスク（標準偏差） | 19.8% | 19.8% | 4.2% | 1.1% |
| トータルとの相関 | | 0.97 | −0.11 | −0.14 |

* トータル・リターンのボラティリティは、ほぼすべて**価格**リターンから来ている。
* 長期的には担保リターンの寄与が最も大きく、ロール・リターンは足を引っ張った。（構成要素の合計は 6.8% ではなく 6.7% になる。トータルは幾何的に複利計算されるからである。）

### 実務でのロール・リターン

* コンタンゴ、バックワーデーション、ロール・リターンは需給の予想を反映しており、どちらの状態も無期限には**続かない**。
* ロール・リターンと価格リターンの相関は約 **3%** にすぎない。ロール・リターンは価格リターンを確実には予測しない。
* Ilmanen（2011）はロール・リターンはおおむねリスク・プレミアムだと論じたが、彼が調べたコモディティの約 40% は、ロール・リターンがマイナス**かつ**トータル・リターンがプラスだった。
* サンプルの平均年率ロール・リターンは、すべてのセクターで**マイナス**だった：全体 −1.3%、エネルギー −1.5%、産業用金属 −1.3%、農産物 −4.5%、畜産物 −1.1%、貴金属 −5.1%、ソフト −5.5%。
  * 貯蔵されるコモディティ（金属、穀物、畜産物、ソフト。金は無期限に保管される）はコンタンゴになりやすい → ロールはマイナス。
  * 平均ロールがプラスになる統計的な可能性があったのは**エネルギー**（リアルタイムで消費される）だけで、それも 2010 年以降は薄れている（米国のシェール、中国が最大の輸入国に、OPEC+）。
* ロール・リターンは**単一の期間**では大きな意味を持ちうるが、長期的には価格リターンに比べて**控えめ**だった。**セクター**に大きく依存するので、セクターのウェイトがポートフォリオのロール・リターンを左右する。

## コモディティ・スワップ

**コモディティ・スワップ**は、コモディティの参照価格や指数（多くは一連の先物）に基づいて、複数の日に支払を交換する。多数の先物を管理せずにリスクを移転でき、**カスタマイズ**できる（特定の等級やブレンド、時間とともに変わる数量、受渡しの柔軟性のある現金決済）。ディーラーは先物でヘッジしたり、別のディーラーと相殺したり、現物を買ったり、エクスポージャーをそのまま持ったりする。

| スワップ | 支払を決めるもの | 典型的な利用者 |
| --- | --- | --- |
| **エクセス・リターン・スワップ** | 原資産の先物価格の変化（多くは固定水準との比較）× 想定元本 | ヘッジャー（例：製油所） |
| **トータル・リターン・スワップ** | 指数水準の変化：先物価格の変化**に加えて**担保の利息。買い手は手数料を払う | コモディティのロング・エクスポージャーを求める機関（分散、インフレ・ヘッジ、ALM） |
| **ベーシス・スワップ** | 関連はあるが完全には相関しない 2 つの価格の差（流動的なものとそうでないもの、例：ブレントとメキシコ湾岸の重質原油） | 流動性の低い等級の利用者 |
| **バリアンス・スワップ** | 実現分散と固定分散。実現が固定を上回れば買い手が受け取る（上限付きが多い） | ボラティリティのトレーダー |
| **ボラティリティ・スワップ** | 実現ボラティリティと予想ボラティリティ。実現が予想を下回れば売り手が利益 | ボラティリティのトレーダー |

$$
\begin{aligned}
\text{TRS payment}&=\text{Notional}\\
&\quad\times\text{Index return}\\
\text{Call-style ERS}&=\max(0,\ P-\text{Strike})
\end{aligned}
$$

ここで TRS はトータル・リターン・スワップ、ERS は一連のコール・オプションとして組成されたエクセス・リターン・スワップである（各決済日における 1 単位あたりのペイオフ）。

#### 例：製油所のエクセス・リターン・スワップ

製油所が、1 月から 9 月の各月末に原油価格が 1 バレル USD70 を超える分を受け取るスワップを、1 バレルあたり USD25 のプレミアムでロングする。

| 月 | 価格 | ペイオフ |
| --- | ---: | ---: |
| 1 月 | 70 | 0 |
| 2 月 | 75 | 5 |
| 3 月 | 71 | 1 |
| 4 月 | 66 | 0 |
| 5 月 | 65 | 0 |
| 6 月 | 63 | 0 |
| 7 月 | 66 | 0 |
| 8 月 | 72 | 2 |
| 9 月 | 78 | 8 |

**ステップ 1。ネットの結果。**

$$
\begin{aligned}
\text{Payoffs}&=5+1+2+8=16\\
\text{Net}&=16-25=-9
\end{aligned}
$$

製油所は **1 バレルあたり USD9**（月あたり約 USD1）の損失を出したが、価格の急騰から守られ、コストを前もって把握できた。

#### 例：トータル・リターン・スワップ

想定元本 USD1 億、毎月リセット。

| 指数の動き | 支払 |
| --- | --- |
| +3% | ディーラーがマネジャーに $0.03\times 100\text{m}=$ **USD300 万**を払う |
| −2% | マネジャーがディーラーに $0.02\times 100\text{m}=$ **USD200 万**を払う |

支払は満期まで繰り延べず、毎月行う。

## コモディティ指数

指数は、ベンチマーク、マクロ・予測の指標、投資商品の基礎として使われる。次の点で異なる。

* **幅**：コモディティとセクターの数。
* **ウェイト**とその決め方。
* **ロールの方法**：ロール・リターンを直接左右する。
* **リバランス**の方法と頻度：リバランス・リターンを左右する。
* **ガバナンス**：ルールに基づくか委員会が選ぶか。資産価格、指数提供者、商品提供者の独立性。

| 2019 年 4 月時点 | S&P GSCI | BCOM | DBLCI | TR/CC CRB | RICI |
| --- | --- | --- | --- | --- | --- |
| 開始 | 1991 | 1998 | 2003 | 2005（現行版） | 1998 |
| コモディティ数 | 24 | 23 | 14 | 19 | 38 |
| ウェイト | *生産量* | 生産量**と流動性** | 固定 | 固定 | 固定 |
| ロール | 最も流動性の高い期近限月、毎月 | 期近から次限月または 2 番目の限月へ | **ロール・リターンを最適化** | 期近から次限月へ | 期近から次限月へ |
| リバランス | 年 1 回 | 年 1 回 | 年 1 回 | **毎月** | **毎月** |
| 個人向けファンド | あり | あり | あり | 一部の地域で、ほかに関連指数の ETF | あり |

* **S&P GSCI**：世界の生産額でウェイト付け（時価総額加重に似る）→ 集中している。エネルギーは歴史的に最大約 80%。
* **BCOM**：委員会が選定。セクターの上限 33%、単一コモディティの下限 2% → エネルギーは約 30% だが、天然ガスのウェイトが高い（約 9%、GSCI では約 3%）。天然ガスのロール・コストは重かった（年約 19%）。
* **DBLCI**：畜産物を含まない。12 か月以内で**バックワーデーションが最大またはコンタンゴが最小**の限月にロールする（能動的なロールの判断）。
* **TR/CC CRB**：最初の投資可能な指数（CRB、1978 年）を継承。委員会が段階的な固定ウェイトを設定する。
* **RICI**：最も幅広い（38、木材、オーツ麦、ゴムを含む）。一部の契約は米ドル以外の通貨建てで、通貨エクスポージャーが加わる。

**リバランス。** 頻繁なリバランス（CRB、RICI）は**平均回帰する**市場では有利（高値で売り、安値で買う）だが、**トレンドのある**市場では不利。生産量加重の指数（GSCI、BCOM）は価格とともにウェイトが動くのでリバランスが少なく、トレンド相場では固定ウェイトで頻繁にリバランスする指数を上回ることがある。

> [!IMPORTANT]
>
> * 生産量加重の指数は、均等加重の指数よりエネルギーに**敏感**である。
> * 通常バックワーデーションにある限月を持つ指数はリターンが高くなりやすく（ロールがプラス）、コンタンゴの多い指数は見劣りする。
> * 多くの取引所に投資しても分散効果はほとんどない。コモディティ市場は世界的に相関が高い。主要指数どうしの相関は高く（70% 超）、株式や債券との相関は約 0% だった。どの指数の方法論も圧倒的に優れているわけではない。
