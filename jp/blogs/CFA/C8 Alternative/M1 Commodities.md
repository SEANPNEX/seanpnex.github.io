### コモディティのライフサイクル

* コモディティの生産のライフサイクルは、需給を動かす在庫、天候、政治・経済の出来事の変化を反映し、増幅する。
* ライフサイクルが短ければ外部の出来事に比較的すばやく対応できる。長ければ、一般に市場の反応力は限られる。
* 農産物と畜産には、地域ごとにはっきりした季節と成長サイクルがある。エネルギーと金属は 1 年中採掘される。

### 主な市場参加者

* **ヘッジャー**は、コモディティに関わるエクスポージャーをヘッジするために取引する
* **スペキュレーター**は情報面で優位に立ち、ヘッジャーを上回る成果を狙う。利益と引き換えに、市場に流動性と価格発見を提供する
* **アービトラージャー**は、現物と先物の価格のずれを利用しようとする
* **取引所**（清算機関）は取引ルールを定め、取引インフラを提供する
* **アナリスト**は市場参加者ではなく、取引所の情報を使って調査や政策立案を行い、市場参加を促す
* **規制当局**は市場を監視する。

### コモディティ指数を区別する主な特徴

* カバー範囲の広さ（コモディティとセクターの数）
* 各コモディティに割り当てる相対的なウェイト
* 契約を期先の限月に乗り換えるロールの方法
* ウェイトのリバランスの方法と頻度
* 指数のガバナンス

## 先物リターンの理論

**直物と先物の価格**

* ベーシスは直物価格と先物価格の差
* カレンダー・スプレッドは、期近と期先の契約の先物価格の差。
* **バックワーデーション**は、直物価格が先物価格を上回る（$S>F$）、あるいは期近の先物価格が期先の先物価格より高い状態。逆の状態が**コンタンゴ**（$S<F$）。

**決済**

* 差金決済では、スペキュレーターやアービトラージャーがより多く参加できる
* 現物受渡しでは先物価格と直物価格の収束が保証されるが、差金決済の市場では収束しないこともある。
* 直物価格は地域性が強く現物の受渡しと結びついているため、ヘッジや投機の余地が限られる。

### 保険理論

この理論では、**バックワーデーション**だけがありうる

* コモディティの生産者はもともと現物のロングを抱えているので、販売価格をヘッジして収入を予測しやすくするために先物を売る
* 生産者が先物を売り続けて先物価格を押し下げるので、先物カーブは通常バックワーデーションになる
* 価格リスクを引き受けるスペキュレーターへの報酬として、先物価格は現在の直物価格より低くなければならない。

### ヘッジ圧力仮説

売り手も買い手も市場にポジションをもつので、$S=F$ が通常の状態である。売り手の力が強ければ $S>F$、そうでなければ $S<F$

### 貯蔵理論

$$
\text{Future price}=\text{Spot price}+\text{Storage costs}-\text{Convenience yield}
$$



* コンタンゴ：貯蔵コストがコンビニエンス・イールドより大きい
* バックワーデーション：コンビニエンス・イールドが貯蔵コストより大きい

## 先物リターンの構成要素

先物リターンは 3 つの部分からなる

* 価格リターン

$$
\text{Price return}=\frac{\text{current}-\text{previous}}{\text{previous}}
$$

* 担保リターン：ポジション維持に使う現金から得られるリターン（金利）

* ロール・リターン：契約の乗り換えから生じるリターン

$$
\text{Roll return}=\frac{\text{Near term closing price}-\text{Farther term future closing price} }{\text{Near term closing price}}\times \text{Percentage of position being rolled}
$$

>[!note]
>
>* ロール・イールドは、一般にバックワーデーションではプラス、コンタンゴではマイナス
>* ロール・リターンは単一期間のリターンには大きく影響するが、全体として見ると価格リターンに比べて影響は小さい
>* 分散投資によってロール・リターンへの依存を減らせる

| **バックワーデーション**               | **コンタンゴ**                    |
| ------------------------------- | ------------------------------- |
| 直物 ≥ 先物                  | 直物 < 先物                  |
| ベーシス ≥ 0                       | ベーシス < 0                       |
| 期近 ≥ 期先         | 期近 < 期先         |
| カレンダー・スプレッド ≥ 0             | カレンダー・スプレッド < 0             |
| **ロール・イールド ≥ 0** *（プラス）* | **ロール・イールド < 0** *（マイナス）* |
