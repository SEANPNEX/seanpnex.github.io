# 公開取引される不動産証券

上場不動産証券の種類（REIT、REOC、MBS）、1 株あたり NAV を使う理由と、現金 NOI からの推定方法、FFO と AFFO、NAV、P/FFO、P/AFFO、配当割引モデルや DCF による REIT 株の評価、そして公開と非公開の不動産の比較。（2026 年のタイトル：*Investments in Real Estate through Publicly Traded Securities*。）

| 用語 | 意味 |
| --- | --- |
| **NAVPS** | （資産の時価 − 負債の時価）÷ 株式数 |
| **現金 NOI** | 非現金（定額法）賃料を除いた NOI |
| **非現金賃料** | 収益として計上した定額法（契約上の平均）賃料 − 実際に受け取った現金賃料 |
| **FFO** | 純利益 + 減価償却 + 償却 − 不動産売却の純利益 |
| **AFFO**（FAD、CAD） | FFO − 非現金賃料 − 経常的な（維持型の）資本的支出とリース費用 |
| **TRS** | 課税対象の REIT 子会社で、適格でない事業に使う |

## 上場不動産証券の種類

* **REIT** は、収益を生む不動産を保有し、資金を供給し、（限られた範囲で）開発する。課税所得の **90%–100%** を分配しなければならない。配当は損金算入できる（または REIT は単純に非課税）ので、実質的に法人所得税はかからない。**エクイティ REIT** は物件を保有し、**モーゲージ REIT** は不動産ローンを実行したり投資したりする。
* **REOC** は普通の**課税対象の**不動産会社である。REIT 制度のない国にある、主に**売却目的**で物件を開発する、ほかの適格でないサービス（仲介、第三者の物件管理）を提供する、といった場合、その事業は REIT ではなく REOC になる。
* **MBS** はモーゲージ・プールに対する証券化された請求権である：CMBS（商業用。約 100 件のローンから 1 件の大口ローンまで）と RMBS（住宅用。数千件のローン）。不動産**デット**証券（特に RMBS）の時価は、上場不動産エクイティをはるかに上回る。
* 非公開の形態もある（私募 REIT と REOC、私的なモーゲージとデット）。

### REIT のルール

多くの国で、REIT は次を満たさなければならない。

* 本来なら課税される利益の **90%–100%** を分配する。
* 資産の少なくとも **75%** を不動産に投資する。
* 収入の少なくとも **75%** を賃料またはモーゲージ利息から得る。

ほかにありうるルール：最低株主数と集中の制限（米国では株主 100 人以上、**5/50 ルール**：5 人以下の保有者が 50% 超を保有してはならない）、賃料以外の収入、開発、レバレッジの制限。

* 米国の REIT の多くは**自己運用・自己助言型**である（利益相反が少ない）。**外部運用型**の REIT はアドバイザーに報酬を払う。報酬が資産ベースなら、アドバイザーは資産を増やしたがり、関連サービスを押し付けるかもしれない。
* 北米では REIT が主流（上場不動産エクイティの 98%）。税制の違いから、欧州（59%）とアジア太平洋（51%）では REOC のほうが一般的である。

| REIT の長所（非公開の不動産と比べて） | 短所 |
| --- | --- |
| 流動性 | 内部留保がない：成長には外部資本を調達し続けなければならない |
| 透明性 | 上場企業としての規制コスト |
| 分散した物件保有（種類、地域、テナントの信用） | 分散効果は小さい：株価は部分的に株式市場に連動する |
| 質の高いポートフォリオ | 資産の種類が限られる：適格でない事業は課税される **TRS** に入れる |
| 専門的な運用（規模の経済） | |
| 安定しうる収入（毎月の場合もある） | |
| 税の効率性（課税は 1 回） | |

## 評価

3 つの手法：資産価値（NAV）、価格倍率（P/FFO、P/AFFO、EV/EBITDA）、割引キャッシュフロー（DDM または DCF）。

### 純資産価値

* **BVPS** は減価償却後の取得原価を使い、**NAVPS** は時価を使う。REIT と REOC に関係するのは NAVPS である。
* NAVPS は**欧州とアジア**での**主要な**評価指標である。米国のアナリストは P/FFO をより多く使う。
* NAV は本源的価値の最大の部分である。資産以外からの収入（手数料）、不動産以外の資産（現金）、偶発債務、経営陣が生む価値も反映すべきである。
* 価格が NAVPS を下回れば割安、上回れば割高を示唆する。ただし正当な理由（経営陣、レバレッジ、ガバナンス、予想される出来事）がある場合は別である。NAV を下回る REIT や高レバレッジの REIT は増資が難しい。NAV を下回る価格での株式発行は**希薄化**をもたらす。
* **会計**：IFRS では、投資不動産に**公正価値モデル**（変動は純利益に計上）か**原価モデル**（公正価値を開示）を使える。US GAAP では、多くの保有者が取得原価を使う。これは長期保有で値上がりした資産を過小評価し、減価償却を過大にしうるので、簿価を市場の推定値に置き換える必要がある。

$$
NAVPS=\frac{\text{Assets}-\text{Liabilities}}{\text{Shares}}
$$

資産と負債は時価で評価する。

**手順：**

1. NOI（総賃料 − 空室・未回収損失 − 運営費用。利息、税、減価償却、償却の前）から始める。**非現金賃料**を除き、期中の取得について 1 年分を加える → プロフォーマの**現金 NOI**。1 年分成長させる → 今後 12 か月の現金 NOI。
2. その NOI を還元して稼働中の不動産を評価する：価値 = $NOI_1$ ÷ キャップ・レート。キャップ・レートは類似の取引から求める。
3. ほかの有形資産を簿価で加える：現金、売掛金、前払いその他の資産、**開発用の保有土地**（土地は評価が難しいので通常は簿価）→ **総資産価値**。のれん、繰延資金調達コスト、繰延税金資産は除く。
4. 負債（時価と大きく違うなら時価）とその他の負債を差し引く。ただし**繰延税金負債は差し引かない**（会計上の引当であり、経済的な負債ではない）。
5. 発行済株式数で割る。

NAV は**税引前**の価値である。会社やその資産がどう売却されるか分からないので、清算時の税は無視する。

#### 例：現金 NOI からの NAVPS

USD 千。キャップ・レートは 7.00%、発行済株式数は 55,689 株である。

**ステップ 1。今後 12 か月の現金 NOI。**

| | 金額 |
| --- | ---: |
| 直近 12 か月の NOI | 270,432 |
| 控除：非現金賃料 | (7,667) |
| 加算：取得の通年効果 | 4,534 |
| プロフォーマの現金 NOI（直近 12 か月） | 267,299 |
| 加算：今後 12 か月の成長（1.5%） | 4,009 |
| **今後 12 か月の現金 NOI** | **271,308** |

**ステップ 2。稼働中の不動産の価値。**

$$
\begin{aligned}
\text{Real estate}&=\frac{271{,}308}{0.07}\\
&=3{,}875{,}829
\end{aligned}
$$

**ステップ 3。総資産価値。** 現金 65,554、開発用土地 34,566、売掛金 45,667、前払いその他の資産 23,456（合計 169,243）を加える。

$$
\begin{aligned}
GAV&=3{,}875{,}829+169{,}243\\
&=4{,}045{,}072
\end{aligned}
$$

**ステップ 4。NAV。** 負債合計 1,010,988 とその他の負債 119,886（合計 1,130,874）を差し引く。

$$
\begin{aligned}
NAV&=4{,}045{,}072-1{,}130{,}874\\
&=2{,}914{,}198
\end{aligned}
$$

**ステップ 5。NAVPS。**

$$
NAVPS=\frac{2{,}914{,}198}{55{,}689}=52.33
$$

NAVPS は **USD52.33** である。

#### 例：NAVPS と簿価

| 入力 | 値 |
| --- | ---: |
| NOI | USD115m |
| キャップ・レート | 7% |
| 資本の簿価 | USD1,005m |
| 負債の時価 | USD505m |
| 株式数 | 100m |

$$
\begin{aligned}
\text{Property}&=\frac{115}{0.07}=1{,}642.9\\
NAV&=1{,}642.9-505=1{,}137.9\\
NAVPS&=\frac{1{,}137.9}{100}=11.38
\end{aligned}
$$

NAVPS は **USD11.38** であり、1 株あたり簿価の USD10.05 でも、負債控除前の USD16.43 でもない。

> [!IMPORTANT]
> キャップ・レートが高い → 物件価値が低い → **NAV が低い**。NOI の成長が速い → NAV が高い。繰延税金負債は NAV を**減らさない**。簿価で計上された古い土地は、現在の価値に評価し直せる。

NAV は、(1) キャップ・レートと NOI、(2) 平方フィートまたは 1 戸あたりの価値、(3) IFRS で開示される鑑定価値（アナリストが同意しなければ調整）から推定できる。

**NAV の限界：**

* キャップ・レートと平方フィートあたりの価値は非公開市場の取引から来ており、私的な買い手の割引率は REIT 投資家と異なるかもしれない。
* NAV は**私的な買い手**にとっての価値を反映する。株式投資家は収入と資産価値の短期的な変化に注目し、鑑定ベースの NAV は遅れる。
* REIT は NAV に対して **25%** を超えるプレミアムやディスカウントで取引されたことがある。
* NAV は REIT を継続企業ではなく**静的な資産のプール**として扱う。経営陣が価値を生んだり壊したりする力を無視している（より強いチームなら 10% のプレミアムを正当化できる）。
* 不動産市場の流動性が低い（取引が少ない）場合や REIT が数百の物件を保有する場合、NAV は**主観的**になる。大規模なポートフォリオにはプレミアムやディスカウントがありうる。土地、独特な物件、サービス事業、ジョイント・ベンチャーは評価が難しい。

経営陣が価値を生むなら、REIT は NAV に対してプレミアムで取引される**べき**である。日々の流動性により、要求リターンは非公開市場より低くなり、公開市場は平均以上の運用者を引きつける。実務では NAV は**相対的に**使われることが多い。プレミアムが最も小さい REIT を買う（またはディスカウントが最も小さい REIT を売る）、あるいは株価から**インプライド・キャップ・レート**を逆算して類似のポートフォリオを比べる。

### 価格倍率

P/FFO と P/AFFO（頻度は低いが EV/EBITDA も）は相対評価に使われ、通常は来期の予想を使って、過去、同じ物件タイプの同業他社、またはすべての REIT と比べる。

**ファンズ・フロム・オペレーション：**

$$
\begin{aligned}
FFO={}&\text{Net income}+\text{Depreciation}\\
&+\text{Amortization}\\
&-\text{Gains on property sales}
\end{aligned}
$$

より完全な（Nareit の）定義：GAAP 純利益 + 物件売却損（− 売却益）+ 不動産の減価償却と償却 + 不動産の減損と評価減。

* 減価償却を足し戻すのは、不動産は価値を保つか上がる傾向があり、会計上の減価償却が経済的実態を反映しないからである。
* 減価償却した物件の売却損益は持続的な収入ではない。
* 足し戻す償却には、リース仲介手数料、テナントの内装工事とその補助が含まれる。
* FFO はキャッシュフローでは**ない**。キャッシュフローを維持するのに必要な資本的支出と財務キャッシュフローを無視している。
* **米国**で最も一般的な指標で（アジア太平洋でも増えている）、データ提供会社から容易に入手できる。

**調整後ファンズ・フロム・オペレーション：**

$$
\begin{aligned}
AFFO={}&FFO-\text{Non-cash rent}\\
&-\text{Recurring capex}
\end{aligned}
$$

* ここでの経常的な資本的支出にはリース費用が含まれる。
* 非現金（定額法）賃料を差し引く。賃料が段階的に上がるリースでは、初期の数年は計上賃料が現金賃料を上回る。
* 経常的な維持の資本的支出とリース費用（リース仲介手数料、テナントの内装補助）を差し引く。
* AFFO（分配可能資金 **FAD**、分配可能現金 **CAD** とも呼ぶ）は、FFO より**経済的な利益**と**配当支払能力**をよく表す。ただしより主観的で（資本的支出は不規則）、方法もまちまちで、データ提供会社は一般に AFFO の予想を**集計していない**。

#### 例：Office Equity REIT の FFO と AFFO

SGD 千。株式数は 55,689 株である。

| 入力 | 金額 |
| --- | ---: |
| 純利益 | 160,638 |
| 減価償却と償却 | 76,100 |
| 償却対象の不動産の売却損 | 25,000 |
| 非現金（定額法）賃料 | 21,103 |
| 経常的な維持の資本的支出とリース仲介手数料 | 55,765 |

**ステップ 1。FFO。** 売却損を足し戻す（経常的ではないため）。

$$
\begin{aligned}
FFO&=160{,}638+76{,}100\\
&\quad+25{,}000=261{,}738\\
\text{Per share}&=\frac{261{,}738}{55{,}689}=4.70
\end{aligned}
$$

**ステップ 2。AFFO。**

$$
\begin{aligned}
AFFO&=261{,}738-21{,}103\\
&\quad-55{,}765=184{,}870\\
\text{Per share}&=\frac{184{,}870}{55{,}689}=3.32
\end{aligned}
$$

1 株あたり FFO は **SGD4.70**、AFFO は **SGD3.32** である。

#### 例：AFFO からの P/FFO

| 入力 | USD |
| --- | ---: |
| AFFO | 4,000,000 |
| 1 株あたり AFFO | 5.00 |
| 非現金賃料 | 215,000 |
| 経常的な資本的支出 | 700,000 |
| 株価 | 80 |

**ステップ 1。株式数。** $4{,}000{,}000/5.00=800{,}000$。

**ステップ 2。FFO。** AFFO の調整を逆算する（減価償却はすでに FFO に含まれているので足し戻さない）。

$$
\begin{aligned}
FFO&=4{,}000{,}000+215{,}000\\
&\quad+700{,}000=4{,}915{,}000\\
\text{Per share}&=\frac{4{,}915{,}000}{800{,}000}=6.14
\end{aligned}
$$

**ステップ 3。倍率。**

$$
P/FFO=\frac{80}{6.14}=13.0\times
$$

P/FFO は **13.0×** である。

**P/FFO、P/AFFO、EV/EBITDA の違いを生むもの：**

1. **FFO や AFFO の期待成長** → 倍率が高い（開発の成功、ニューヨークやロンドンのような供給の限られた一等地の市場、経営陣、リースの構造）。
2. **不動産のリスク**（種類、品質、築年数、リース、立地）：集合住宅はホテルより高い倍率で取引される。若く手入れの行き届いたポートフォリオは、資本的支出の必要な古いものより高い。
3. **資本構成と資本へのアクセス**：レバレッジが高い → 要求リターンが高い → 倍率が**低い**。株式の需給悪化（オーバーハング）を招くこともある。

> [!IMPORTANT]
> FFO と AFFO は**レバレッジ後**（利息控除後）なので、ほかの条件が同じなら、レバレッジの高い REIT ほど P/FFO は低い。EV/EBITDA はレバレッジの影響を受けず、EBITDA/EV はキャップ・レート（NOI ÷ 価値）に近い。P/FFO は REIT 版の P/E、P/AFFO は手早いキャッシュフロー倍率である。

| P/FFO と P/AFFO の長所 | 短所 |
| --- | --- |
| 広く受け入れられた利益倍率なので、REIT をほかの投資と比べられる | 収入を生まない資産（開発用の保有土地、空きビル、開発プロジェクト）、十分に使われていない資産、市場より低い賃料の価値をとらえない |
| FFO の予想は容易に入手できる | P/FFO は経常的な資本的支出を無視する。P/AFFO は含めるが、AFFO の予想はばらつきが大きい |
| 成長やレバレッジと組み合わせて、より深く比較できる | 一時的な項目や新しい収益認識ルールが計算と比較を複雑にする |

### 配当割引モデルと DCF モデル

REIT は収入の大部分を分配するので、配当割引モデルや DCF モデルが適している。**2 段階または 3 段階**の DDM（短期、中期、長期の成長）を使う。DCF では中期のキャッシュフロー予想と、過去のキャッシュフロー倍率から求めたターミナル・バリューを使う。

$$
\begin{aligned}
V_0={}&\sum_{t=1}^{n}\frac{D_t}{(1+r)^t}+\frac{P_n}{(1+r)^n}\\
P_n={}&\frac{D_{n+1}}{r-g}
\end{aligned}
$$

#### 例：Baldwin REIT の 2 段階 DDM

| 入力 | 値 |
| --- | ---: |
| 無リスク金利 | 4% |
| ベータ | 0.9 |
| 株式リスク・プレミアム | 5% |
| $D_1$ / $D_2$ | 1.00 / 1.06 |
| 3 年目以降の成長率 | 5% |

**ステップ 1。要求リターン（CAPM）。**

$$
r=4\%+0.9\times 5\%=8.5\%
$$

**ステップ 2。2 年目末の株価。**

$$
\begin{aligned}
D_3&=1.06\times 1.05\approx 1.11\\
P_2&=\frac{1.11}{0.085-0.05}=31.71
\end{aligned}
$$

**ステップ 3。現在の価値。**

$$
\begin{aligned}
V_0&=\frac{1.00}{1.085}+\frac{1.06+31.71}{1.085^2}\\
&=0.92+27.84=28.76
\end{aligned}
$$

1 株あたりの価値は **USD28.76** である。

#### 例：REIT C の 3 段階 DDM

$r$ = 8%、$D_1$ = 4.00、2–3 年目は 4.5% 成長、その後は 4% 成長である。

**ステップ 1。配当。**

$$
\begin{aligned}
D_2&=4.00\times 1.045=4.18\\
D_3&=4.18\times 1.045=4.37\\
D_4&=4.37\times 1.04=4.54
\end{aligned}
$$

**ステップ 2。3 年目末の株価。**

$$
P_3=\frac{4.54}{0.08-0.04}=113.57
$$

（113.57 は丸めていない $D_4=4.543$ を用いている。）

**ステップ 3。現在の価値。**

$$
\begin{aligned}
V_0={}&\frac{4.00}{1.08}+\frac{4.18}{1.08^2}\\
&+\frac{4.37+113.57}{1.08^3}\\
={}&3.704+3.584+93.625\\
={}&100.91
\end{aligned}
$$

1 株あたりの価値は **USD100.91** である。

#### 例：P/FFO と P/AFFO からの評価

$$
\begin{aligned}
V&=\frac{FFO}{\text{Shares}}\times\text{Peer }P/FFO\\
V&=\frac{AFFO}{\text{Shares}}\times\text{Peer }P/AFFO
\end{aligned}
$$

**REIT B（P/FFO）。** 株式数 67,900 株に対する FFO は 290,612、サブセクターの倍率は 13.5× である。

$$
\begin{aligned}
FFO/\text{share}&=\frac{290{,}612}{67{,}900}=4.28\\
V&=4.28\times 13.5=57.78
\end{aligned}
$$

**REIT A（P/AFFO）。** 株式数 56,100 株に対して、FFO は 316,965、非現金賃料は 25,991、経常的な資本的支出は 63,769、倍率は 18.3× である。

$$
\begin{aligned}
AFFO&=316{,}965-25{,}991\\
&\quad-63{,}769=227{,}205\\
AFFO/\text{share}&=\frac{227{,}205}{56{,}100}=4.05\\
V&=4.05\times 18.3=74.12
\end{aligned}
$$

REIT B の価値は 1 株あたり **USD57.78**、REIT A は **USD74.12** である。

## ミニケース：Capitol Shopping Center REIT

Capitol Shopping Center REIT（CSC）は、ワシントン DC 周辺で、食料品店とドラッグストアをアンカーとするショッピング・センターを保有している（ディフェンシブなテナント、政府部門の雇用、新規供給を制限する厳しい用途規制）。

| 2 年目（USD 千） | |
| --- | --- |
| 純利益 | 124,454 |
| + 減価償却と償却 | 115,110 |
| **FFO**（1 株あたり 3.95） | **239,564** |
| − 非現金賃料（繰延未収賃料の変化） | (5,112) |
| − 経常的な資本的支出 | (20,006) |
| **AFFO**（1 株あたり 3.54） | **214,446** |
| 1 株あたり配当 2.80 → 配当性向は FFO の 70.9%、AFFO の 79.1% | |

* 同業他社と比べた貸借対照表：負債/総時価 40.5%（同業 47.1%）、インタレスト・カバレッジ 3.38×（2.35×）、純負債/EBITDA 5.01×（7.10×）→ より強い貸借対照表。
* 株価 USD69.85、3 年目の FFO 予想 4.23 → P/FFO **16.5×**。ショッピング・センター REIT は 14.5×（13.8% のプレミアム）。P/AFFO は 18.6× 対 16.1×。
* プレミアムは安定した成長と低いレバレッジに見合っているが、ファンダメンタルズが回復しても CSC の上値余地は小さいかもしれない。同業他社ほど落ち込まなかったからである。
* 手法によって価値は異なる。前提を見直し、最も信頼できる手法、中間値、または加重平均を使う。

> [!IMPORTANT]
>
> * 取引の少ない景気後退期には NAV の有用性は**下がり**（より主観的になる）、ディフェンシブな REIT の P/FFO は同業他社に比べて上がるかもしれない。
> * 開発用の保有土地は FFO を生まないが価値があるので、**高い**倍率を正当化する。
> * 要求されるゴーイングイン・キャップ・レートが高い → NAV は**低い**。
> * 長期の成長が低い（例：新規供給を多く認める用途規制）→ DDM の価値は低い。

## 公開と非公開の不動産

どちらも物件のファンダメンタルズへのエクスポージャー、潜在的なインフレ・ヘッジ、魅力的なリスク調整後リターン、ある程度の分散をもたらし、多くの機関が両方を保有している。上場不動産の流動性によって、短期的な見方を取ったり、公開と非公開の価値の間で裁定したりできる（株価が NAV を大きく下回れば非公開化、価値が高ければ IPO）。

| 非公開（直接）不動産の長所 | 公開不動産（エクイティ REIT と REOC）の長所 |
| --- | --- |
| 不動産のファンダメンタルズへの直接のエクスポージャー | 長期的に不動産のファンダメンタルズに連動 |
| 安定したリターン、低いボラティリティ | 流動性 |
| 物件のパフォーマンスがリターンを決める | 専門的な運用 |
| ほかの資産との相関が低い | 潜在的なインフレ・ヘッジ |
| 潜在的なインフレ・ヘッジ | 利害が強く一致する可能性 |
| コントロール（直接保有、分別勘定） | 税効率のよい仕組みで、二重課税がない（REIT のみ） |
| 潜在的な非流動性プレミアム | 分散したポートフォリオへのエクスポージャー |
| 幅広い戦略、少ない制約 | 多様なセクターへのアクセス（データセンター、医療オフィス、セルフ・ストレージ） |
| 税の優遇（加速償却。一部の市場では売却代金の再投資による課税の繰延） | 最低投資額と売買コストが低い |
| | 投資家に特別な資格が不要 |
| | 有限責任 |
| | 規制と投資家保護が多い。透明性が高い |

| 非公開不動産の短所 | 公開不動産の短所 |
| --- | --- |
| 流動性が低い。ファンドから抜けにくい。解約が殺到する | 非公開不動産よりボラティリティが高い |
| 報酬と費用が高い | 短期的には株式との相関が高い |
| 鑑定が市場の状況に遅れる | REIT の仕組みが事業を制限する |
| 投資家保護が少ない。透明性が低い | 株価が物件の価値を反映しないことがある（NAV に対するディスカウント） |
| 収益性より資産集めを重視する運用者もいる | 配当は高い所得税率で課税される |
| 最低投資額と資産要件が高い | 小さな会社には遵守コストが重すぎる |
| 高いリターンはレバレッジによることが多い | ガバナンスの悪さや利害の不一致がパフォーマンスを損ないうる |
| | 株式市場は高いレバレッジを嫌うことが多い |

> [!IMPORTANT]
>
> * 不動産の専門知識が最も必要なのは、**単一物件への直接**投資である。
> * 事業と財務の柔軟性が最も大きいのは **REOC**（配当や事業の制限がない）→ 最大の成長を目指すのに最適。流動性には REIT と REOC が最適。
> * 直接保有に対する REIT の長所は、ポートフォリオ全体ではなく**物件保有**の分散である。
