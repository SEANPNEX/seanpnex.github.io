# 上場不動産証券

## 上場不動産証券の種類

* REIT
* MBS
* REOC
* 株式

不動産投資信託（REIT）は税制上の優遇を受ける事業体で、一般に収益を生む不動産を保有・運営し、限られた範囲で開発も行う。**エクイティ REIT** と**モーゲージ REIT** がある。

不動産運営会社（REOC）は課税対象となる不動産保有会社である。不動産開発を大規模に手がけ、売却を目的とすることも多い。主なキャッシュフローは売却から得られる。

モーゲージ担保証券（MBS）は、資産を裏付けとする証券化された債務である。商業用 MBS と住宅用 MBS がある。

### REIT

REIT には次のことが求められる：

* 利益の 90% 以上を分配する
* 資産の 75% 以上を不動産に投資する
* 収入の 75% 以上を賃料収入またはモーゲージの利息から得る

米国の REIT の多くは自己運用型で、そうでない場合は外部の運用会社に運用報酬を支払う必要がある。

REIT 投資のメリット：

* 流動性
* 透明性
* 分散
* 質の高いポートフォリオ
* アクティブな運用
* 安定した収入
* 税効率

デメリット：

* 内部留保がない
* 規制
* ポートフォリオの分散効果が小さくなる
* 保有できる資産の種類が限られる



## 評価

### 純資産価値

資本の時価（MV）：$\text{MV of asset}-\text{MV-liabilities}$。これを発行済株式数で割ると 1 株当たり純資産価値（NAVPS）が得られる。REIT の株価と比べると市場の状況がわかる。

手順：

1. REIT や REOC が保有する物件の価値は、キャップレートで NOI を還元して推定する：$P=\frac{NOI_1}{\text{r-g}}$。キャップレート = $r-g$ は、市場の類似物件を参考にできる。

> [!Note]
>
> NOI は年率換算し、成長率を掛けて $NOI_1$ を求める必要がある

2. 現金、売掛金、前払費用、将来の開発用地の簿価を加えて、推定**総資産価値**を得る。のれんと繰延税金資産は除く
3. 負債とその他の債務を差し引く。繰延税金負債は除く。
4. 発行済株式数で割って **NAVPS** を得る

留意点：

* キャップレートが正確でない
* NAV は私募市場の買い手にとっての価値を反映している
* NAV は暗黙のうちに REIT を静的な資産プールとして扱っている
* 不動産市場の流動性が低いときや、REIT が多数の物件を保有しているとき、NAV の推定はかなり主観的になりうる。

### 相対評価（価格倍率）

相対評価では P/FFO や P/AFFO を使う

#### FFO

FFO（Funds From Operations）は一般に、純利益 + 物件売却損 - 物件売却益 + 減価償却費で計算する。

#### AFFO

FFO をもとに：

* 会計上の非現金の賃料調整を差し引く
* 経常的な維持更新投資とリース手数料を差し引く。

>[!note]
>
>AFFO は、分配可能資金（**FAD**）や分配可能キャッシュ（**CAD**）とも呼ばれる。



## 私募不動産投資と上場不動産投資の比較

### メリット

| **私募不動産**                     | **上場不動産**                                      |
| ------------------------------------------- | ----------------------------------------------------------- |
| 不動産のファンダメンタルズに直接投資できる | 長期的には不動産のファンダメンタルズに連動する          |
| 安定したリターン / 低いボラティリティ             | 流動性                                                   |
| インカムとキャピタル・ゲイン             | プロの運用を利用できる                           |
| 物件のパフォーマンスがリターンを決める         | インフレ・ヘッジになりうる                                   |
| ほかの資産クラスとの相関が低い   | 利害が強く一致する可能性                 |
| インフレ・ヘッジになりうる                   | 二重課税を避けられる税効率のよい仕組み（REIT のみ） |
| 支配権                                     | 分散されたポートフォリオに投資できる可能性            |

| **私募不動産**                                      | **上場不動産**                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 非流動性プレミアムを得られる可能性                        | 一般の株式投資以上の特別な投資家要件がない |
| 多様な戦略 / 制約が少ない                | 規制と投資家保護が手厚い                  |
| 税制上のメリット（例：加速償却、一部の市場では売却代金を別の不動産に再投資すれば課税を繰り延べられる） | データセンター、医療オフィス、トランクルームなど多様なセクターに投資できる |
|                                                              | 必要な投資額が小さい                                  |
|                                                              | 参入・退出のコストが低い                                         |
|                                                              | 有限責任                                            |
|                                                              | 透明性が高い                                            |

### デメリット

| **私募不動産**                                      | **上場不動産**                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 流動性が低い                                                | ボラティリティが高い（私募不動産と比べて）          |
| 退出が難しい                                            | 短期的には株式市場との相関が高い              |
| 報酬と費用が高い                                       | REIT の仕組みにより、できる事業が限られる                    |
| 鑑定評価は市場環境の変化に遅れることが多い | 株価が裏付けとなる物件の価値を反映しないことがある（NAV に対してディスカウントで取引される） |

| **私募不動産**                                      | **上場不動産**                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 投資家を保護する規制が少ない                       | 配当は高い経常所得の税率で課税される             |
| 収益性よりも資産の積み上げを重視する運用者もいる | 短期的には株式市場との相関が高い              |
| 最低投資額が高く、純資産の要件も高い     | 小さな会社には規制対応のコストが重すぎる |
| 透明性が低い                                             | ガバナンスの不備や利害の不一致が株価の足を引っ張りうる |
| 高いリターンはレバレッジによることが多い                         | 株式市場はレバレッジの高い会社を嫌う傾向がある   |
