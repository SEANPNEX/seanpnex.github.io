# Titres immobiliers cotés

## Types de titres immobiliers cotés

* REIT
* MBS
* REOC
* Actions

Les sociétés d’investissement immobilier cotées (REIT) sont des entités fiscalement avantagées qui, en général, détiennent, exploitent et — dans une mesure limitée — développent des immeubles de rapport. On distingue les **REIT de fonds propres** et les **REIT hypothécaires**.

Les sociétés d’exploitation immobilière (REOC) sont des sociétés foncières imposables. Elles se consacrent largement au développement immobilier, souvent en vue de vendre ; leurs flux proviennent principalement des ventes.

Les titres adossés à des créances hypothécaires (MBS) sont des dettes titrisées adossées à des actifs. On distingue les MBS commerciaux et résidentiels.

### REIT

Les REIT doivent :

* Distribuer au moins 90 % de leurs bénéfices
* Investir au moins 75 % de leurs actifs dans l’immobilier
* Tirer au moins 75 % de leurs revenus des loyers ou des intérêts hypothécaires

La plupart des REIT américaines sont autogérées ; sinon, elles doivent verser des frais de gestion à des gérants tiers.

Avantages d’un investissement en REIT :

* Liquidité
* Transparence
* Diversification
* Portefeuille de qualité
* Gestion active
* Revenus stables
* Efficacité fiscale

Inconvénients :

* Absence de bénéfices mis en réserve
* Réglementation
* Bénéfice de diversification du portefeuille réduit
* Types d’actifs détenus limités



## Valorisation

### Actif net réévalué

Valeur de marché (MV) des fonds propres : $\text{MV of asset}-\text{MV-liabilities}$ ; en divisant par le nombre d’actions en circulation, on obtient l’actif net réévalué par action (NAVPS). La comparaison avec le cours de la REIT renseigne sur la situation de marché.

Étapes :

1. La valeur des immeubles détenus par les REIT et REOC s’estime en capitalisant le NOI au taux de capitalisation : $P=\frac{NOI_1}{\text{r-g}}$, où le taux de capitalisation $= r-g$ peut être tiré d’immeubles comparables sur le marché.

> [!Note]
>
> Le NOI doit être annualisé et multiplié par le taux de croissance pour obtenir $NOI_1$

2. On ajoute la valeur comptable de la trésorerie, des créances, des charges constatées d’avance et des terrains destinés au développement pour obtenir la **valeur brute des actifs** estimée. Le goodwill et les impôts différés actifs sont exclus
3. On soustrait la dette et les autres passifs. Les impôts différés passifs sont exclus.
4. On divise par le nombre d’actions en circulation pour obtenir la **NAVPS**

Points d’attention :

* Le taux de capitalisation n’est pas précis
* L’ANR reflète la valeur pour un acheteur sur le marché privé
* L’ANR traite implicitement la REIT comme un portefeuille d’actifs statique
* Les estimations d’ANR peuvent devenir très subjectives lorsque le marché immobilier est illiquide et que la REIT détient de nombreux immeubles.

### Valorisation relative (multiples de prix)

On utilise P/FFO ou P/AFFO pour la valorisation relative

#### FFO

Les fonds provenant des opérations (FFO) se calculent en général ainsi : résultat net + pertes sur cessions d’immeubles - plus-values de cession + dotations aux amortissements.

#### AFFO

À partir des FFO :

* Retrancher les ajustements comptables de loyers sans effet de trésorerie
* Retrancher les dépenses d’investissement d’entretien récurrentes et les commissions de location.

>[!note]
>
>L’AFFO est aussi appelé fonds disponibles pour distribution (**FAD**) ou trésorerie disponible pour distribution (**CAD**).



## Comparaison de l’immobilier privé et de l’immobilier coté

### Avantages

| **Immobilier privé**                     | **Immobilier coté**                                      |
| ------------------------------------------- | ----------------------------------------------------------- |
| Exposition directe aux fondamentaux immobiliers | Suit les fondamentaux immobiliers à long terme          |
| Rendements stables / faible volatilité             | Liquidité                                                   |
| Revenus et plus-values             | Accès à une gestion professionnelle                           |
| Les rendements dépendent de la performance des immeubles         | Couverture potentielle contre l’inflation                                   |
| Faibles corrélations avec les autres classes d’actifs   | Alignement d’intérêts potentiellement fort                 |
| Couverture potentielle contre l’inflation                   | Structure fiscalement efficace évitant la double imposition (REIT uniquement) |
| Contrôle                                     | Possibilité d’exposition à des portefeuilles diversifiés            |

| **Immobilier privé**                                      | **Immobilier coté**                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| Possibilité de capter une prime d’illiquidité                        | Pas d’exigence particulière au-delà de l’investissement en actions |
| Grande variété de stratégies / peu de restrictions                | Réglementation et protection des investisseurs renforcées                  |
| Avantages fiscaux (par exemple amortissement accéléré ; dans certains marchés, report d’impôt lorsque le produit de cession est réinvesti dans l’immobilier) | Accès à des secteurs variés : centres de données, cabinets médicaux, garde-meubles |
|                                                              | Ticket d’entrée faible                                  |
|                                                              | Faibles coûts d’entrée et de sortie                                         |
|                                                              | Responsabilité limitée                                            |
|                                                              | Grande transparence                                            |

### Inconvénients

| **Immobilier privé**                                      | **Immobilier coté**                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| Faible liquidité                                                | Volatilité élevée (par rapport à l’immobilier privé)          |
| Sortie difficile                                            | Forte corrélation avec les actions à court terme              |
| Frais et charges élevés                                       | La structure de REIT limite les activités possibles                    |
| Les expertises sont souvent en retard sur l’évolution du marché | Le cours peut ne pas refléter la valeur des immeubles (décote sur l’ANR) |

| **Immobilier privé**                                      | **Immobilier coté**                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| Moins de réglementation protégeant les investisseurs                       | Dividendes imposés aux taux élevés de l’impôt sur le revenu             |
| Certains gérants privilégient la collecte d’actifs plutôt que la rentabilité | Forte corrélation avec les actions à court terme              |
| Tickets minimums élevés et exigences de patrimoine élevées     | Les coûts de conformité sont prohibitifs pour les petites sociétés |
| Faible transparence                                             | Une mauvaise gouvernance ou des intérêts mal alignés peuvent pénaliser le cours |
| Les rendements élevés proviennent souvent du levier                         | Les marchés actions pénalisent souvent les sociétés très endettées   |
