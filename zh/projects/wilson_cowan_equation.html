神经元群体何时开始振荡

对修正版 Wilson–Cowan 模型中极限环产生条件的解析与计算研究。

阅读完整报告 ↗
年份
2022
角色
数学分析与仿真
方法
微分方程 · 分岔分析 · Python

问题 ​

本项目用修正版 Wilson-Cowan 模型研究神经元群体的振荡行为，探讨极限环（代表振荡的神经活动）在什么条件下出现，兼顾理论分析与仿真结果。

目标 ​

  • 理解兴奋性与抑制性神经元群体如何相互作用而产生振荡。
  • 找出导致 Hopf 分岔和极限环的条件。
  • 用解析方法和计算仿真分析特殊情形与一般情形。

核心概念 ​

  • Wilson-Cowan 模型： 用非线性微分方程和 S 形响应函数描述兴奋性（E）与抑制性（I）神经元群体之间的相互作用。
  • 极限环： 振荡行为在相平面上表现为闭合轨道。
  • Hopf 分岔： 稳定平衡点失稳并出现极限环的临界条件。

Wilson-Cowan 模型方程 ​

dx(t)dt=−ax(t)+(1−rxx(t))S(wx(t)−by(t)+I(t))dy(t)dt=−dy(t)+(1−ryy(t))S(cx(t)−ey(t)+J(t))

其中：

  • ( x(t) ) 和 ( y(t) )：时刻 ( t ) 放电的兴奋性和抑制性细胞所占比例
  • ( S(\theta') = \frac{\theta'}{\sqrt{\theta'^2 + 1}} )：S 形响应函数

案例：无外部刺激（I = 0，J = 0） ​

  • 改变自兴奋系数 w，研究它的影响。
  • 结果：
    • 当 w > d 且 γ > 1（γ 为参数比）时出现振荡行为（极限环）。
    • 在该范围内，振荡周期随 w 增大而变长。
    • 已用 Mathematica 和 Python 仿真验证。

其他发现 ​

  • 当 J = 0 而 I 变化时：
    • 极限环只在特定的 I 区间内存在：I ∈ [-2.98, 2.98]。
  • 当 I = 0 而 J 变化时：
    • 极限环存在于 J ∈ [-7.22, 7.22]。
  • **自兴奋（w > 0）**是振荡行为的必要条件；w = 0 时不出现极限环。

结论 ​

修正后的 Wilson-Cowan 模型表明，皮层柱可以表现出内在的振荡行为。振荡及其周期对自兴奋和外部刺激十分敏感。这为理解神经元集群如何同步以处理感觉输入提供了一种机制上的解释。
