大数据项目 ​

大数据不仅指观测值数量庞大，也指那些因规模、速度、多样性或质量问题而难以用常规方式存储和分析的数据。在投资管理中，它的价值来自把原始数据转化为能改善决策的信息，而不只是来自规模本身。

数据的来源与形式 ​

常见来源包括：

  • 金融市场： 价格、报价、订单簿、成交量和交易记录。
  • 公司： 财务报表、业绩电话会、客户交易和运营记录。
  • 政府： 经济数据发布、监管文件、法院记录和公共登记信息。
  • 个人： 调查、评论、搜索和社交媒体活动，须遵守同意和隐私规则。
  • 传感器与联网设备： 卫星图像、地理位置、航运信号和物联网数据。

传统数据通常是为既定的商业或报告目的而产生的。另类数据则产生于这些常规渠道之外——例如停车场的卫星图像或匿名化的支付活动——并被重新用于投资分析。

形式组织方式例子
结构化固定的行、列和数据类型SQL 表、市场价格面板、CSV 文件
半结构化标签或键提供一定的组织JSON、XML、网站日志
非结构化没有预定义的表格结构文本、图像、音频和视频

四个 V ​

  • Volume（体量）： 数据量。
  • Velocity（速度）： 数据到达并需要处理的速率。
  • Variety（多样性）： 来源、格式和结构的多样程度。
  • Veracity（真实性）： 数据的准确性、可信度、一致性和可靠性。

有些框架还加上 value（价值），强调大型数据集只有在其带来的收益超过获取、处理、合规和模型风险成本时才有用。

IMPORTANT

数据更多并不会自动消除偏差。一个非常大但不具代表性的样本，可能对一个错误的量给出非常精确的估计。

大数据项目流程 ​

一个稳健的项目是迭代的，而不是单向的建模练习。

  1. 界定问题。 明确决策、目标输出、使用者、经济目标、约束条件和成功标准。
  2. 收集与整理数据。 确定来源、合法获取访问权限、记录数据来源，如计划使用监督学习则为观测值打标签。
  3. 准备与整理数据。 发现错误、清洗记录、整合来源，并把数值转换成可用的分析表。
  4. 探索数据。 汇总分布和关系，调查异常，并评估样本能否代表目标总体。
  5. 构建与选择特征。 创建有经济含义的预测变量，剔除无关或冗余的输入。
  6. 选择、训练与验证模型。 选择合适的方法，在不使用测试集的前提下调节超参数，并评估样本外表现。
  7. 部署与监控。 把输出接入决策流程，监控数据漂移和模型漂移，并制定上报和重新训练的规则。

在收集数据之前，分析师应能回答：

  • 输出会改变什么决策？
  • 在做预测的时点，目标变量是否可得？
  • 谁会使用结果，它如何进入业务流程？
  • 假阳性和假阴性的成本分别是什么？
  • 有哪些法律、隐私、许可和伦理方面的限制？

数据准备与整理 ​

数据准备检查原始数据，识别并缓解质量问题。数据整理则把清洗后的数据变换、合并、重塑成适合分析的形式。

常见的数据错误 ​

错误含义例子
不完整缺少必需的值部分公司没有行业代码
无效值违反规则或允许范围股数为负
不准确看似合理的值是错的价格的小数点位置记错
不一致相关字段相互矛盾币种代码是 USD，但数值以 EUR 计
不统一单位、格式或定义不同千与百万混用
重复同一经济观测值多次出现同一份文件从两个数据源导入
过时值已不再是最新的旧的总部地址

缺失数据不应机械处理。当缺失是系统性的时，删除不完整的行会使样本产生偏差。插补保留了观测值，但如果把填充值当作观测到的事实，就会低估不确定性。分析师应调查值为何缺失，必要时加入一个缺失指示变量。

结构化数据的变换 ​

典型操作包括：

  • 提取： 取出某个字段或子串，例如从日期中取出年份。
  • 筛选： 保留满足某条规则的观测值。
  • 选择： 保留相关的列或特征。
  • 聚合： 合并记录，例如把交易汇总为月度总额。
  • 转换： 改变单位、格式或数据类型。
  • 连接： 用实体标识符和日期把不同来源合并起来。
  • 缩尾或稳健变换： 限制极端观测值的影响，并记录所用规则。

两种常见的缩放变换是：

最小–最大归一化把特征映射到指定区间，通常为 [0,1]：

xi∗=xi−xminxmax−xmin.

标准化使均值为零、标准差为一：

zi=xi−μσ.

xmin、xmax、μ 和 σ 只能在训练集上估计，然后再把这些值应用到验证、测试和实时数据上。否则信息会在样本之间泄露。

WARNING

在金融领域，时点对齐至关重要。把今天重述后的基本面数据与历史价格连接，会造成前视偏差，因为修订后的信息在当时并不可得。发布时间戳和历史成分股名单必须反映投资者当时实际能够知道的信息。

准备文本数据 ​

文本项目遵循同样的总体流程，但需要专门的文本处理：

  1. 提出基于文本的目标，并定义输入和输出；
  2. 通过授权数据源、API 或许可范围内的网络爬取收集文档；
  3. 使用监督学习时，标注标签；
  4. 清洗、分词、规范化，并用数值表示文档；
  5. 探索词项并构建文本特征；
  6. 训练、验证、部署并监控模型。

清洗与分词 ​

清洗可能包括去除 HTML 标签、规范空白字符、解决编码问题，以及处理标点或数字。是否去除标点和数字取决于任务：在金融文本中，10%、$5bn 和问号都可能承载重要含义。

**分词（tokenization）**把文本切分为分析单元。一个词元可以是单词、子词、标点符号或其他符号；它不一定等同于一个单词。

规范化可以包括：

  • 当大小写不携带信息时，统一大小写；
  • 去除部分停用词，但保留 not 这类会影响含义的词；
  • 词干提取：用机械规则缩减词的屈折形式，可能产生并不存在的词；
  • 词形还原：结合语言上下文，把词映射到其词典原形。

这些步骤是选择，而不是普遍要求。现代语言模型通常保留词序、标点和停用词，并使用子词分词，而不是经典的词袋流程。

词袋与文档–词项矩阵 ​

**词袋（BOW）**表示记录每个词表中的词项在各文档中出现的频率。它是计数或权重组成的向量——而不只是一个集合——不过它忽略了词序和大部分上下文。

对于 D 篇文档和 V 个词项，文档–词项矩阵的维度为 D×V。元素 (d,t) 是词项 t 在文档 d 中的计数或权重。这个矩阵往往维度很高且稀疏。

词频与 TF–IDF ​

词频 TF(t,d) 衡量词项 t 在文档 d 中出现的频率，有时会除以该文档的词元总数。文档频率为

DF(t)=#{d:t∈d}.

当共有 N 篇文档时，逆文档频率可定义为

IDF(t)=log⁡(NDF(t)),

并且

TF-IDF(t,d)=TF(t,d)×IDF(t).

实际实现中常加入平滑以避免除以零。TF–IDF 降低几乎出现在每篇文档中的词项的权重，提高在某篇文档中频繁出现、但在整个语料中并不常见的词项的权重。

图中显示的是语料中的原始频率。词云也能表示频率，但对齐排列的行更便于近距离比较和读取精确数值。极为罕见的词元可能是错误或噪声，而极为常见的词元可能几乎没有区分度；不结合任务考虑，就不应删除任何一类。

数据探索与特征开发 ​

探索性数据分析 ​

探索性数据分析（EDA）在最终选择模型之前，用数值摘要和可视化来理解数据。

对于结构化数据，检查：

  • 集中趋势、离散程度、分位数、偏度、峰度和缺失情况；
  • 直方图、箱线图、密度图、散点图和相关热力图；
  • 单变量分布以及多变量关系；
  • 在不同时间、行业、市场或其他有经济意义的分组之间的稳定性。

高维数据可以借助 PCA 等降维技术来探索，参见 M6：主成分分析。

对于文本数据，可以考察文档长度、词表规模、词项和 n 元组的频率、共现、类别平衡、主题、情感及其随时间的变化。

特征选择 ​

特征选择保留有用的已有预测变量。可能的方法包括：

  • 相关系数或其他关联度量；
  • 检验分类特征与类别之间是否相关的卡方检验；
  • 特征与目标之间的互信息；
  • 基于模型的重要性或正则化；
  • 经济判断和稳定性分析。

对于离散变量 X 和 Y，互信息为

I(X;Y)=∑x,yp(x,y)log⁡(p(x,y)p(x)p(y)).

当变量相互独立时它为零；当知道其中一个能降低另一个的不确定性时它为正。互信息一般不以 1 为上限；其尺度取决于对数的底和变量的分布。

特征选择必须在训练或交叉验证过程内部进行。用全部数据选择特征，会把验证和测试观测值的信息泄露出去。

特征工程 ​

特征工程通过变换、分解或组合原始变量来创建预测变量。例子包括：

  • 把价格和每股收益转换为盈利收益率或市盈率；
  • 计算销售增长、杠杆、滚动波动率或相对于市场一致预期的意外；
  • 把时间戳转换为交易时段、星期几或财报季的指示变量；
  • 只用预测时点之前可得的信息构造滞后项。

文本特征工程可以包括：

  • 把数字替换为 <PERCENTAGE> 之类的类型化词元，或保留其大小；
  • 构造 going concern 这样的 n 元组，以保留有用的多词模式；
  • 命名实体识别，识别公司、人物、地点、货币或产品；
  • 词性标注；
  • 情感、不确定性、可读性或主题特征；
  • 由神经语言模型学到的稠密嵌入。

NOTE

一个特征可能在统计上有预测力，却在经济上无法使用：例如数据到得太晚、违反许可条款、无法在生产环境中复现，或通过泄露反映了目标本身。

模型选择、训练与评估 ​

方法的选择取决于学习目标、目标类型、数据形式、样本量、维度、非线性关系、可解释性需求、计算约束和错误成本。

  • 结构化表格数据可能适合惩罚回归、决策树、随机森林或神经网络。
  • 文本分类可以使用 BOW 或 TF–IDF 特征配合线性分类器，或使用学到的嵌入配合神经网络。
  • 主题发现和文档分组属于无监督任务。
  • 图像和音频通常需要专门的特征提取或深度学习架构。

具体的算法、样本划分、过拟合控制、交叉验证和表现度量见 M6：机器学习。

参数与超参数 ​

  • 参数从训练数据中学得，例如回归系数或神经网络的权重。
  • 超参数决定模型结构或训练过程，由分析师选择，通常借助验证数据或交叉验证。例子包括 LASSO 惩罚、近邻个数、树深和学习率。

调参是寻找能改善验证表现的超参数取值。在模型和超参数选定之前，最终的测试集应保持不动。

分类评估 ​

实际 / 预测阳性阴性
阳性真阳性（TP）假阴性（FN；第二类错误）
阴性假阳性（FP；第一类错误）真阴性（TN）
Precision=TPTP+FP,Recall=TPR=TPTP+FN,Accuracy=TP+TNTP+TN+FP+FN,F1=2Precision×RecallPrecision+Recall,FPR=FPFP+TN.

受试者工作特征（ROC）曲线描绘分类阈值变化时 TPR 相对于 FPR 的变化。曲线越靠近左上角、曲线下面积（AUC）越大，排序表现越好。说一条曲线"更凸"并不准确；应比较曲线是否占优以及 AUC。

在类别不平衡时，准确率可能具有误导性。应根据两类错误的经济成本来选择度量和阈值，而不是套用通用惯例。

对于连续预测，常见的度量包括 MAE、MSE 和均方根误差：

RMSE=1n∑i=1n(yi−y^i)2.

RMSE 对大误差的惩罚比 MAE 更重，且与目标变量的单位相同。

数据与模型治理 ​

一个技术上准确的模型，仍可能因治理薄弱而失败。稳健的流程会记录：

  • 数据来源、所有权、许可、同意和允许的用途；
  • 采集时间戳、修订以及时点可得性；
  • 变换、剔除、标签和带版本的数据集；
  • 访问控制、保留政策、隐私和网络安全；
  • 模型假设、验证结果、局限性和人工监督；
  • 生产环境中的表现、漂移、事故、重新训练和下线标准。

偏差与漂移 ​

  • 选择偏差： 观测到的样本不能代表目标总体。
  • 幸存者偏差： 遗漏了失败或退市的实体。
  • 前视偏差： 未来的或事后修订的信息进入了历史特征。
  • 标签偏差： 目标标签含有系统性的人为或流程错误。
  • 代理偏差： 一个看似中立的特征间接捕捉到了敏感或被禁止的特征。
  • 数据漂移： 输入的分布发生变化。
  • 概念漂移： 输入与目标之间的关系发生变化。

监控应同时跟踪预测表现和数据生成过程。稳定的平均准确率可能掩盖模型在某个重要子群体或市场状态中的表现恶化。

考试清单 ​

  • 区分结构化、半结构化和非结构化数据。
  • 解释体量、速度、多样性和真实性。
  • 区分数据准备、数据整理、数据探索、特征选择和特征工程。
  • 区分归一化与标准化，并在估计缩放参数时避免泄露。
  • 解释分词、词干提取、词形还原、BOW、文档–词项矩阵、n 元组和 TF–IDF。
  • 知道词元不一定是单词，BOW 存储计数或权重但丢失了顺序。
  • 把卡方和互信息理解为关联度量，而不据此断言因果。
  • 区分参数与超参数。
  • 让分类和回归的度量与分析目标相匹配。
  • 识别时点、隐私、许可、偏差、漂移和治理方面的风险。
