# 道德与职业准则


## 标准 I 专业素养
### 标准 I(A) 了解法律

> 会员及候选人必须了解并遵守对其职业活动具有管辖权的任何政府、监管机构、发照机构或专业协会的所有适用法律、法规和规章（包括 CFA 协会《道德规范与职业行为准则》）。当存在冲突时，会员及候选人必须遵守更严格的法律、法规或规章。会员及候选人不得在知情的情况下参与或协助任何违反此类法律、法规或规章的行为，且必须与该违规行为切割。

这一条标准包含三项职责：**了解**、**遵守更严格的规则**，以及**不得在知情的情况下协助——并与之切割**。

#### 你必须了解什么（以及无需了解什么）

- 了解**直接管辖**你职业活动以及保护客户权益的法律和法规。
- 你**无需**成为合规专家，也无需了解可能间接涉及你工作的每一项法律。
- 当规则发生变化时及时跟进——新产品、新渠道（社交媒体、应用程序）以及新的地方/区域/全球性要求均属此列。
- 遇到不确定情况时，使用公司的合规渠道；咨询法律顾问是值得推荐的做法，但如果有关行为仍然违反法律或《准则与标准》，**依赖法律顾问的意见并不能免除**你的责任。

#### 适用法律与《准则与标准》中更严格的一方

“适用法律”是指在具体案件事实中管辖会员或候选人行为的法律。“更严格”是指对投资者施加**更大限制**或要求采取**更具保护性行动**的规则。

| 情形 | 遵循 |
| --- | --- |
| 适用法律**比**《准则与标准》**更严格** | 适用法律 |
| 适用法律**较宽松**，或保持沉默 / 无证券法律 | 《准则与标准》 |
| 行为在当地法律下合法，但违反《准则与标准》 | 《准则与标准》（不得实施该行为） |

> [!IMPORTANT]
> 适用法律是**底线**，而非上限。如果当地法律允许《准则与标准》所禁止的行为（例如未披露的推荐费），你仍必须遵守《准则与标准》。

涉及多司法管辖区案件的速查表（NS = 无适用的证券法；LS = 比《准则与标准》宽松；MS = 比《准则与标准》严格）：

| 你的执业地点 / 适用哪部法律 | 职责 |
| --- | --- |
| 适用法律为 LS 或 NS | 遵守《准则与标准》 |
| 适用法律为 MS | 遵守该更严格的法律 |
| 本国法律规定“业务开展所在地的法律管辖”，且所在地为 LS/NS | 《准则与标准》 |
| 本国法律规定所在地法律管辖，且所在地为 MS | 该更严格的当地法律 |
| 法律选择条款指向**客户所在国** | 在该国法律与《准则与标准》之间取较严格者——通常即遵守两者中更严格的一方 |

#### 知情参与/协助——以及切割

- 你对你**知情**参与或协助的违规行为负有责任。该标准亦涵盖你**知道或应当知道**可能会促成违规的行为。
- 如果你有合理理由相信客户或雇主的活动属于非法或不道德行为：**与之切割**。
- 当直接沟通无效时的升级路径：
  1. 向主管或合规部门报告。
  2. 退出相关活动（从报告中撤下你的名字、拒绝该项任务、停止使用误导性材料、拒绝或终止服务该客户）。
  3. 在极端情况下，辞职。
- **在保持关联的同时不作为**，本身就可能被视为参与或协助。
- **鼓励**向 CFA 协会举报其他会员或候选人的违规行为；仅当适用法律**强制要求**时才须向监管机构报告（否则属于自行决定的内部举报/吹哨行为——应先寻求法律/合规建议）。

> [!WARNING]
> 在招揽业务时使用虚高的组合业绩、在发现招股说明书存在误导性内容后仍继续承销，或对伪装成“研究”费用的买流量（pay-for-flow）安排保持沉默，都是典型的协助/切割陷阱——即使问题并非由你制造。

#### 跨境产品与分销

如果你创设或维护产品或投资组合方案，必须了解**产品设立地**和**预期销售地**两个司法管辖区的法律。作出合理努力检查分销商是否也遵守分销国的规定。当多司法管辖区的复杂性引发疑问时，应咨询合规部门或外部法律顾问。

#### 建议程序（考试实用清单）

**个人**

- 保持信息更新（合规备忘录、CLE / 持续教育）。
- 定期审阅书面合规程序。
- 保存关键法规与规则的最新参考档案。
- 记录采取的切割步骤；敦促公司停止违规行为。
- 了解你协助开发或销售的产品在分销地区的法律规定。

**公司（鼓励采取）**

- 制定道德规范（例如以《资产管理人职业准则》为模板）。
- 为员工集中汇总适用法律信息。
- 建立报告涉嫌违规行为的书面规程。

#### 考试陷阱

- “法律顾问说这很难举证” ≠ 可以无视违规的许可。
- 母国持证人身份**不能**凌驾于**更严格**的东道国规则之上（例如当地禁止个人参与 IPO）。
- 当地内幕交易法律宽松，**不会**放宽标准 II(A) 的要求——必须遵守更严格的《准则与标准》规则。
- 新媒体（Facebook、X、即时通讯）同样必须遵守现行监管要求；不了解新规指引仍属于未履行“了解法律”的职责。


### 标准 I(B) 独立性与客观性

> 会员及候选人必须运用合理的谨慎与判断，在职业活动中实现并保持独立性与客观性。会员及候选人不得提供、索取或接受任何可以合理预期会损害自身或他人独立性与客观性的礼物、利益、报酬或对价。

客户必须获得**不受利益冲突或压力影响**的工作成果与专业意见。应避免实际丧失独立性/客观性，也应避免**被外界视为**会导致这种丧失的情形。投资建议必须以**清晰、明确**的语言陈述你的**真实**观点——不得为了取悦投行人员、发行人或销售团队而含糊其辞、淡化立场。

#### 礼物、利益与影响

| 来源 | 经验法则 |
| --- | --- |
| 寻求影响的**第三方**（发行人、经纪商、承销商、评级委托方、争取管理委托的基金经理） | 象征性/微薄的礼物和普通的商务招待或许可以接受；**奢华**礼物、招待、给个人账户的 IPO 配售，或任何可以合理预期会损害判断力的东西 → 拒绝。最佳实践：拒绝任何可能威胁独立性的东西。 |
| **客户**（已存在报酬关系） | 礼物 / “奖金”应视为**额外报酬**。尽可能在收受**之前**向雇主披露；否则事后立即披露。披露便于公司监控是否存在偏向该客户而损害其他客户的情况。 |

> [!IMPORTANT]
> 根据标准 I(B)，向基金经理提供**超额认购 IPO 的个人配售**是被禁止的——这属于客户无法获得的快速获利机会。

提供**或**索取可能损害独立性的礼物均违反标准 I(B)，包括并非由你个人直接受益的礼物（例如与聘用决定挂钩的慈善捐款或政治竞选捐款）。基金经理遴选/采购的双方均受约束：既不得购买影响力，也不得出售影响力。

#### 压力点（客观性容易失守的地方）

- **买方客户**向卖方分析师施压要求不要下调评级；报复性做法（向发行人告发该分析师）均属不当。
- **投资银行业务**施压要求对投行客户或潜在客户出具正面研究报告 → 设立防火墙、独立汇报线、投行部门对研究报告无否决权、薪酬**不**直接与投行业务挂钩；充分且具体地披露利益冲突。
- 担心**发行人/公司管理层**报复（切断电话会议或管理层调研渠道）不能成为出具偏颇评级的理由。
- **信用评级机构**——收费与结构设计带来的利益冲突；评级使用者应保持警觉，必要时需进行独立验证。
- **业绩计量**——拒绝将表现较差的账户从组合群（composite）中剔除，或掩盖投资授权偏离（mandate drift）的要求。
- **发行人付费研究**——仅在保持真正独立性、充分披露利益冲突并尽职调查的情况下允许；报酬必须是**与研究结论无关的固定费用**（不得有成功奖金、认股权证或股权激励）。
- **差旅资助**——最佳实践：由你本人或你所在公司支付商业交通与住宿费用。仅在没有商业交通选择时（例如偏远地产或矿区考察），才可接受发行人安排的适度交通。由参与竞标、之后又被你聘用的基金经理出资赞助的“实地调研”旅行，存在明显的观感与利益冲突风险。

#### 建议程序

- 制定政策确保关于公司客户的研究报告反映分析师的**无偏见**观点；建立保护研究独立性的薪酬制度。
- 若公司不允许发布负面观点，应设立**限制名单**——仅传播客观事实。
- 拜访发行人时自行支付商业交通与酒店费用；不要总是让同一家发行人接待。
- 设定象征性礼物的限额（单次及/或年度累计限额，结合当地商业习惯）；只要目的不是施加影响，普通商务招待可以接受。
- 员工参与 IPO 须事先批准/披露；严格限制私募配售；监控个人交易。
- 制定书面独立性政策：研究部门不得向投行或其他可能损害独立性的部门汇报。
- 指定高级管理人员负责道德与合规；建立清晰的内部报告渠道。

#### 案例题判断规则

1. 自问：这份礼物、费用、差旅或奖金是否**可以合理预期**会损害我的判断力——或在客户眼中看起来如此？
2. 第三方利诱 vs. 已披露的客户礼物——适用不同规则；客户礼物必须披露。
3. 发行人付费研究的固定费用 → 可以接受；与“吸引投资者”或正面基调挂钩的费用 → 违规。
4. 公司内部压力（销售部门有库存、投行项目、上司此前给出“买入”评级）→ 仍须出具**你自己的**独立结论，或拒绝接受受限制的任务；可考虑列入限制名单。
5. 聘用 / “付费换业务”（pay-to-play）——旨在赢得管理委托的政治捐款或奢华招待会损害对方的客观性，提供方同样违反标准 I(B)。

> [!TIP]
> 外部观感至关重要。即使由发行人支付的纯商务性质且适度的实地考察未必违反标准 I(B)，公司要求一律自费的政策更为稳妥。对于基金经理尽职调查差旅，应由你的雇主或养老金计划支付基本的交通与住宿费用。

> [!WARNING]
> 若服务费/尾随佣金（trailer）安排在未充分披露的情况下（或在基金业绩不佳后，因你需要该费用而）把你绑定在推销某一产品系列上，这属于独立性失守——通常还同时伴随标准 VI(A) 利益冲突披露问题。

### 标准 I(C) 不实陈述

> 会员及候选人不得在知情的情况下作出任何与投资分析、建议、行动或其他职业活动有关的不实陈述。

**不实陈述**是指任何不真实的陈述、对事实的遗漏，或其他虚假或误导性陈述。“知情”涵盖你已经知道**或应当知道**的情况——包括可能改变投资决策的遗漏。职业信誉建立在准确陈述的基础之上；虚假或误导性宣传会损害投资者利益与市场诚信。

#### 涵盖范围（不得作不实陈述的领域）

| 领域 | 经验法则 |
| --- | --- |
| **执业能力 / 资历** | 个人资格、公司能力、服务内容、过往业绩记录、投资产品特征——全部必须准确无误。 |
| **收益或本金保证** | **不得**对波动性投资保证特定回报或保本。产品本身内置的担保（或机构提供的损失保障）可以如实描述，但必须说明其限制条件（例如 FDIC 承保的存单仅在承保额度内受保障）。 |
| **第三方材料** | 信用评级、外部研究、客户推荐信、营销材料——如果你在业务中使用它们，**你**对其准确性负有共同责任。务必核实。 |
| **外部管理人** | 披露拟定用途；**不得**将外部管理人的做法说成是你自己的。 |
| **基准 / 组合群** | 使用具有可比性的基准；披露采用非标准参考指数的原因。不得挑选表现好的账户（cherry-picking）编入组合群。不得仅为获取更高估值而四处“比价”非流动性资产的估值报价。 |
| **模型 / 遗漏** | 不得故意遗漏会造成误导的模型输入参数；不得将模型输出结果当作客观事实陈述。 |
| **社交媒体** | 适用与传统客户沟通相同的诚实准则；表面上的匿名性不是挡箭牌。 |
| **网页** | 及时更新；保护网站完整性与安全性；充分披露，不得包含误导性内容。 |

#### 抄袭

未经**注明出处**而以实质相同的形式复制或使用他人材料违反标准 I(C)——无论是书面**还是**口头形式。典型陷阱包括：

- 将另一家公司的报告改头换面署上自己的名字
- 近乎逐字摘录而不注明来源
- 泛泛声称“知名分析师指出……”而不指明具体来源
- 使用他人的预测/统计数据却删去其前提与免责说明
- 未经注明来源或授权而使用他人的图表或专有模型/电子表格
- 将未注明来源的观点或预测拼凑在一起，伪装成原创内容

**允许的情况：** 公司可以继续使用已离职分析师制作的研究报告/模型（属于公司财产）；无需标注离职作者姓名。你**不得**将旧报告仅换上你自己的新个人名义重新发布。若你**不**声称自己是作者，可以分发第三方研究报告——但必须披露来源，让客户知道他们购买的是谁的专业成果。

#### 建议程序

- 了解公司的真实能力；使用公司批准的服务/资历表述；明确谁有权代表公司对外发言。
- 保留个人的资历与从业经历摘要。
- 在使用第三方材料前核实其真实能力。
- 监控网页内容的时效性与安全性。
- **防范抄袭规范：** 保留原始资料副本；引述原文时注明出处；转述或归纳他人观点时亦注明出处。

#### 考试陷阱

- 事后发现的无意笔误 → 及时更正并停止分发；若在作出时并非明知故犯，则**不**构成标准 I(C) 违规——但明知资历虚假仍反复使用 → 违规。
- 对只付息债券（IO strips）等结构化产品宣称“由政府担保”，而实际上仅底层抵押贷款（而非利息现金流或投资者本金经济结果）受担保 → 典型不实陈述。
- 将外部供应商的研究重新包装为“我们的研究成果” → 夸大并曲解了自身工作范围。
- 仅引用转述某项研究的报纸报道 → 应引用**原始实际**来源（如果依赖中间媒体的解读，则两者一并注明）。

#### 应用案例

**例 4 —— 抄袭（Cindy Grant）。** Grant 专攻加拿大矿业。她阅读了 Barton 撰写的详尽的 Jefferson Mining 研究报告，通过电话获取了新的钻探数据，将其加入 Barton 的分析中，并将整套材料作为**她自己的**报告发布。  
**要点：** 未经注明出处而大量复制另一位分析师的工作成果属于抄袭——即使你在其中加入了一个新的数据点。

**例 5 —— 对投资产品作不实陈述（Ricki Marks）。** Marks 向公共养老金客户出售纯付息（IO）抵押贷款剥离证券，声称其“由美国政府担保”。根据政策和法律，客户需要政府担保的证券。实际上，只有底层抵押贷款受到担保——IO 的利息现金流和投资者的经济收益并未得到担保；利率下降和提前还款可能摧毁其价值。  
**要点：** 复杂产品的准确标签至关重要。将“担保”的含义延伸到实际担保范围之外，构成标准 I(C) 违规。

### 标准 I(D) 不当行为

> 会员及候选人不得从事任何涉及不诚实、欺诈或欺骗的职业行为，也不得实施任何对其职业声誉、诚信或专业胜任能力产生不利影响的行为。

标准 I(A) 关注管辖职业活动的**适用法律**。标准 I(D) 范围更广：任何对**职业**诚信、声誉或胜任能力产生负面影响的行为——撒谎、作弊、偷窃或其他对职业活动产生不利影响的不诚实行为。《准则与标准》主要针对**职业生活**中的行为（CFA 协会总体上反对任何不道德的个人行为，但标准 I(D) 并非囊括一切私人过失的兜底条款）。

#### 哪些行为计入（哪些通常不计入）

| 行为 | 是否违反 I(D)？ |
| --- | --- |
| 与工作相关或损害职业可信度的不诚实、欺诈、欺骗行为 | 是 |
| 损害履行职责能力的行为（即使不违法，例如在作出投资决策时处于醉酒状态） | 是 |
| 跳过尽职调查、盲目依赖他人而辜负客户信任 | 可能构成（缺乏应有努力） |
| **不**涉及欺诈或欺骗性商业行为的个人破产 | 通常否 |
| 不影响职业声誉、诚信或胜任能力的非暴力抗命 / 抗议被捕 | 通常否 |
| 利用 CFA 协会纪律处分程序来解决与职业道德无关的个人/政治恩怨 | 滥用程序；并非 I(D) 的正当用途 |

#### 建议程序（鼓励公司采取）

- 制定公司道德规范：明确表明有损个人、公司或行业声誉的个人行为将不被容忍。
- 列出潜在违规行为及相应制裁措施（直至解雇）。
- 进行背景与推荐人核查，确保聘用人员品行端正且未被行业禁入。

#### 考试陷阱

- 职场欺诈（例如伪造保险报销单）→ 即使“与证券无关”，也违反标准 I(D)。
- 利用慈善或志愿者职务收取回扣 → 在标准 I(D) 下仍属欺诈/欺骗。
- 发现可能存在虚假报告却被告知“别管” → 按公司政策携带证据逐级上报；若内部渠道失效，考虑向监管机构报告（同时涉及标准 IV(A) / IV(C)）。

#### 应用案例

**例 1 —— 专业素养与胜任能力（Simon Sasserman）。** 一名信托主管每天午餐时大量饮酒；客户也看到了这种情况；午饭后他在醉酒状态下作出投资决策。同事们只敢在上午与他打交道。  
**要点：** 损害职业判断力并引发胜任能力质疑的酗酒行为违反标准 I(D)——它损害了他本人、雇主以及整个行业的声誉。

**例 4 —— 个人行动与诚信（Carmen Garcia）。** 一名社会责任投资（SRI）基金经理兼环保活动人士多次因在石化工厂进行非暴力非法闯入抗议而被捕。  
**要点：** 与个人信仰相关的非暴力公民抗命，若未对其职业声誉、诚信或胜任能力造成负面影响，通常**不**违反标准 I(D)。

### 标准 I(E) 专业胜任能力

> 会员及候选人必须具备并保持履行其职业职责所需的专业胜任能力。

该标准支持《道德规范》中关于以胜任能力和勤勉尽责态度行事、并**保持和提升**专业胜任能力的要求。胜任能力 = 胜任**该特定岗位**所需的充分的**知识、技能和能力**——而非单凭一次考试成绩或一张学位证书。“胜任”的具体要求取决于实际情形与职责；随着岗位变化，职责是随时间推移**达到并保持**相应的胜任能力。

| 要素 | 含义 |
| --- | --- |
| **知识（Knowledge）** | 应用于该职能的信息体系——以及应用的有效程度 |
| **技能（Skills）** | 完成任务与目标所需的岗位特定能力 |
| **能力（Abilities）** | 能够产生可观察职业成果的素质与态度 |

#### 核心经验法则

- **结果不佳 ≠ 不胜任。** 胜任的基金经理也可能亏损；胜任的分析师在充分研究后也可能预测失误。误导整个市场的隐蔽欺诈，未必证明尽职推荐人“不胜任”。
- **学历背景 ≠ 新领域的胜任能力。** 优秀的审计师未必准备好执行 GIPS 合规审查；通才型顾问可能缺乏遴选可持续投资管理人的专业技能。
- **执照/考试通过 ≠ 足够。** 通过销售牌照考试却不学习将要执行的公平原则，仍然违反标准 I(E)。
- **新岗位 / 新产品：** 在行动**之前**掌握所需能力（监管管理技能、ESG、加密货币等）。切勿为了追逐潮流或留住客户而将客户资金投入你不理解的产品。
- **持续教育（CE）重在精神，而非强制项目。** 学术会议、专业认证、雇主培训、自律自学、专家研讨小组——任何能让你保持专业水准的途径皆可。

#### 建议程序

- 持续职业发展 / CE；在有益时考取相关认证。
- 参加会议、研讨会、网络讲座；参加雇主培训；有计划地自学。
- 参与专家小组；在职责发生变化时有意识地培养新技能。

#### 考试陷阱

- 将某人提拔为研究总监或主管，却未培养其履新所需的**管理与合规**胜任能力。
- 在聘请专业人才并培训团队**之后**再将 ESG（或任何新分析维度）纳入报告 → 合规路径；毫无知识储备便强行套用 → 违规。
- 因社交媒体炒作而仓促投资陌生产品（如加密货币），却不了解其性质或适当性 → 违反标准 I(E)（通常还伴随适当性或勤勉尽责问题）。

#### 应用案例

**例 6 —— 理解新投资产品（Alex Halsey）。** 客户在看到快速上涨后强烈要求投资加密货币。Halsey 仅从报纸上有所耳闻，并不理解该资产或各类产品之间的差异，但为了不显得落伍或流失业务，仍为客户购买了一款大力推销的加密货币产品。  
**要点：** 知识有限且仓促将客户资金投入不熟悉的产品 = 未能以所需的专业胜任能力行事。

**例 5 —— 选择投资标的（Kwame Mifune）。** 经过全面研究（信用状况、财务数据、过往业绩）后，Mifune 向合适客户推荐了 Vouchsafe 的人寿保单。后来 CFO 隐瞒的欺诈行为导致该保险公司破产，保单变得一文不值。客户指责他不胜任。  
**要点：** 全面、恰当的研究却仍未能发现全行业普遍受骗的欺诈行为，其本身**并不**证明在标准 I(E) 下不胜任。不能单凭结果论英雄。

## 标准 II 资本市场诚信

### 标准 II(A) 重大非公开信息

> 掌握可能影响投资价值的重大非公开信息的会员及候选人，不得依据该信息采取行动或促使他人采取行动。

利用重大非公开信息（MNPI）进行交易——或诱导他人交易——会侵蚀市场信心。该禁令涵盖股票**以及**衍生品、基金和其他另类投资。若市场被视为存在选择性“内幕知情”而有失公平，所有人的资本形成都会受损。

#### 重大性与非公开性

| 测试 | 含义 |
| --- | --- |
| **重大（Material）** | 信息披露后很可能影响证券价格，**或者**理性投资者在作出投资决策前会希望知晓该信息——即它会显著改变现有信息的总体格局。考量因素：具体性、与公开信息的偏离程度、性质、**信息来源的可靠性**、价格影响的明确性、时间流逝。 |
| **非公开（Nonpublic）** | 尚未向市场公众普遍传播/开放获取。一旦真正广泛发布，无需等待反应最慢的读者——但仅向一屋子分析师或小型股东会议披露**不**构成公开传播。 |

**通常属于重大的信息：** 盈利数据；并购 / 要约收购 / 合资企业；资产质量变化；重大产品/专利/监管审批结果；重要客户/供应商变动；管理层或审计师变更；证券事件（违约、拆股、股息、发行）；破产；重大诉讼；能撼动市场的政府数据；大额未执行订单；第三方评级/推荐变动。

**来源可靠性很关键：** 公司内部人关于重大合同的事实陈述 → 很可能重大；竞争对手的猜测 → 通常不是。新药试验运营人员透露的试验结果 → 很可能重大；无关联专家基于经验的推断 → 通常不是。

**选择性披露：** 公司向少数分析师/投资者透露的消息在普遍公开之前仍属于非公开信息。仅为受青睐群体“解读”公开申报文件的业绩指引也可能构成 MNPI。在交易协议（并购、承销、评级、发行）下通过正当尽职调查获得的 MNPI，仅可用于**该项委托业务**——不得用于交易或向他人泄密（tipping）。

#### 马赛克理论（考试重点）

根据**马赛克理论**，分析师可以依据从以下两类信息中得出的结论提出建议：

1. **公开**信息，加上  
2. **非重大的非公开**信息  

……即使**该结论本身**如果是由公司内部人直接和盘托出，本会构成重大内幕信息。将公开事实与零散、非重大的非公开信息碎片（客户/供应商闲聊、设计师/零售商意见、用工情况、汇率看法等）拼合在一起，是核心的投研工作，**并不**违反标准 II(A)。

| 马赛克理论允许 | 违规 |
| --- | --- |
| 公开财报 + 实地探访工厂的观察 + 来自客户/竞争对手的非重大补充信息 → 预判盈利下滑并给出卖出评级 | 在公开前依据具体、可靠的内部消息（即将达成的交易、下周罢工、试验失败）进行交易 |
| 有记录可查的访谈与分析，支持评级调整 | 向他人（包括家人）泄露 MNPI，或在提前获悉某份能影响市场的**未公开**分析师建议后抢先交易 |
| 加深行业理解的专家网络访谈，**不涉及**保密的试验或公司结果 | 专家（或任何人）提供了重大的保密结果 → 公开前不得交易；你必须自行判断重大性——签署“不含 MNPI”声明书不能免责 |

**记录马赛克拼图过程。** 保存研究资料，证明结论源自公开信息 + 非重大的非公开信息[另见标准 V(C) 记录保存]。如果日后有人质疑你使用了 MNPI，完备的记录就是你的证据。

**分析师报告对他人而言可能是 MNPI：** 明星分析师尚未发布的评级建议对市场而言可能具有重大性。分析师可将该建议提供给**客户**（基于马赛克理论和公开投入的付费研究成果），而不必免费向全世界公开。提前获取该报告的**非客户**人士（如电视节目制作人）不得据此交易或泄密。

**社交媒体：** 需凭会员资格进入的群组并不会自动成为“公开渠道”。在将重大事项视为公开信息之前，务必通过真正的公开渠道（法定公告、新闻稿、开放网页）加以核实。若满足监管备案和标准 I(A) 要求，面向客户或公众全面发布的内容则是合规的。

#### 建议程序

- 如果你获取了 MNPI：推动**公开披露**；若无法公开，仅向指定合规官/主管报告——**不得**交易或调整投资建议；不得诱导内部人私下泄密。
- 公司合规措施：交易审查、建议审查、书面程序、跨部门监督。
- 公平披露文化（无论大中小券商、买方还是卖方均同等对待；不得封杀给出负面评级的分析师）。
- **防火墙：** 控制跨部门信息流动（最好通过合规/法务审批）；建立观察名单、限制名单、传闻名单；记录并严格执行；当持有 MNPI 时加强对自营交易的审查；物理隔离且跨墙人员不重叠；仅经合规批准方可“跨墙”；由单一权威机构统一认定信息是否重大及是否已公开。
- 个人交易限制；限制名单与观察名单的权衡（范围过宽的限制名单反而可能向市场泄露信号）。
- 持有 MNPI 时从事做市业务：保持**被动**（仅作为非主动客户订单的交易对手方）。风险套利业务：列入观察名单时最应**暂停**交易。
- 培训全体员工识别 MNPI 并按流程上报。

#### 考试陷阱

- 泄密链条：告诉一位经纪人，后者随即买入 → 泄密者与交易者均可能违规。
- 销售人员穿过办公区时无意听见投行部门讨论盈利暴跌 → 防火墙失效；据此交易的人违规，导致信息泄露的人也可能违规。
- 不可靠的流言（医生闲聊的收购八卦）→ 通常**不**重大 → 在完成其他尽职调查后交易或许合规。
- “我朋友是高管，不会违法” + 甜美的盈利耳语 → 你仍有义务避免利用 MNPI 交易；最终盈利还是亏损均无关紧要。
- 专家网络：允许用于行业学习；**不得**用于获取保密的试验或产品结果并据此交易。

#### 应用案例

**例 5 —— 运用马赛克理论（Jagdish Teja）。** 这位买方家具行业分析师研究了财务报表，实地走访了生产运营，并与设计师和零售商交流哪些款式畅销。虽然没有明确的买入标的，但他发现 Swan Furniture 昂贵的新款设计不受欢迎，而同行销售的传统款式却卖得很好。结合上述信息与损益表分析，Teja 得出 Swan 下季度盈利将大幅下滑的结论并发布卖出建议；基金经理们随之减仓。  
**要点：** 季度盈利数字属于重大非公开信息——但 Teja 基于公开信息加上**非重大**的非公开行业细节得出的**结论**，是典型的马赛克理论应用，**不**违反标准 II(A)。务必记录这些信息来源。

**例 3 —— 选择性披露（Elizabeth Levenson）。** 在受邀与某制造商财务总监会面的 10 大股东中，她得知员工将于下周五罢工并导致运营瘫痪。她想将评级从买入下调为卖出。  
**要点：** 在小范围群体中分享的重大信息依然属于**非公开信息**。在公司向全市场普遍公布之前，她不得据此采取行动。

### 标准 II(B) 市场操纵

> 会员及候选人不得从事旨在误导市场参与者而扭曲价格或人为夸大交易量的行为。

标准 II(B) 旨在维护市场诚信。市场操纵会降低市场信任、推高风险溢价，并且随着市场互联互通而产生跨境溢出效应。新产品和更快的通信渠道催生了更多扭曲价格或成交量的手段——该标准同时涵盖**基于信息**和**基于交易**的操纵计划。**意图**是核心检验标准：利用真实市场无效性的合法投资策略并不构成违规。

#### 两种形式

| 形式 | 表现形式 |
| --- | --- |
| **基于信息的操纵** | 散布虚假或误导性信息（或过度乐观的“独立”分析）以诱导交易——典型的**拉高出货（pump and dump）**：先吹高股价，再借人为制造的需求逢高卖出。 |
| **基于交易的操纵** | 你知道（或应当知道）会影响定价的交易：制造偏离公平市场的虚假成交量或价格信号，或控制主导性头寸以逼空/挤压相关衍生品或标的资产。 |

两者可同时并用（谣言**加**对倒交易）。是否获取个人利益**并非**必要条件——只要存在误导市场的意图即构成违规。

#### 哪些*不*属于标准 II(B)

- 基于对错误定价或市场无效性的真实判断而进行的交易。
- 流动性“启动注入”（例如交易所新产品上线时的做市成交协议），**前提是充分披露**，使市场参与者不会被误导而误判真实流动性。
- 具有合理依据且公平分发的诚实研究报告——即使观点激进——有别于为配合客户做空而刻意选择时机、制造轰动的投机性报告。

#### 考试陷阱

- 以股票或现金收取报酬的“独立”微盘股推广 → 违反 II(B)，且通常同时违反 V(A)（缺乏合理依据）和 VI(A)（未披露冲突）。
- 在多个基金或账户之间进行对倒交易以虚增成交量/价格便于退出 → 即使宣称“为了基金份额持有人利益”，仍违反 II(B)。
- 向一小部分动量交易者夸大盈利预期，企图迫使公司回应或引发短线拉升 → 违反 II(B)；选择性提前透露还触犯 III(B) 公平对待。
- 为伤害同事而在聊天室散布虚假谣言（无个人获利）→ 仍违反 II(B)。
- 为赢得评级或促成销售而篡改模型输入参数 → 属于标准 II(B) 下的信息操纵。

#### 应用案例

**例 7 —— 拉高出货（Steve Weinberg）。** 为推高 Moosehead & Belfast 股价，Weinberg 在投资者聊天室发帖谎称该铁路公司即将扩建以承接一笔大型木材运输合同。  
**要点：** 怀着误导意图散布**虚假**信息，属于典型的**基于信息**的标准 II(B) 违规。

**例 4 —— 基金间制造虚假成交量（Rajesh Sekar）。** Sekar 管理的股票型基金和平衡型基金均超配了流动性极差的 Digital Design。他在两只基金之间来回买卖 DD 以抬高成交量和价格，从而吸引外部买盘入场，使他能够在不减记账面价值的情况下削减超配头寸——他声称这是“为了基金持有人”，尽管产生了额外佣金。  
**要点：** 人为扭曲**成交量和价格**属于**基于交易**的标准 II(B) 违规，无论是否声称有利于客户。

## 标准 III 对客户的职责
### 标准 III(A) 忠诚、审慎与尽责

> 会员及候选人对客户负有忠诚义务，必须以合理的谨慎行事并运用审慎的判断。会员及候选人必须为客户的利益行事，并将客户利益置于雇主或自身利益之上。

客户利益**至高无上**。投资行动必须**完全为了**客户利益，并像你在类似情况下对待自身利益一样运用同样的审慎、判断与谨慎。**审慎（Prudence）** = 理性人士在同类职责中所具备的谨慎、技能与勤勉——在投资组合管理中，即遵循客户的投资参数并平衡风险与收益。标准 III(A) 是适用于每一位会员的**最低**基准，无论其职位头衔、当地法律或文化背景如何；它**不会**自动使每个人都成为法律意义上的受托人（fiduciary），也**不会**取代法律规定的更严格受托责任[参见标准 I(A)]。

#### 识别真正的投资客户（第一步）

履行忠诚义务的第一步是确定**谁是客户**。请审视你的角色和职责——不直接从事投资管理工作的会员同样拥有“客户”。

| 角色 | 忠诚义务的对象 |
| --- | --- |
| 个人资产管理人 | 该个人（容易识别） |
| **养老金计划或信托**管理人 | 该计划或信托的**受益人**——**而非**聘请管理人的人或机构 |
| 按**指数或既定授权**管理的基金经理 | 按**既定授权**进行投资；决策无需迎合任何单一投资者的需求与风险偏好 |
| 客户投资某只基金的投顾 | 仅对该顾问客户负责——基金经理不承担对该单一客户的直接义务 |
| 公司高管 | 公司的**公众股东** |
| 面向广大投资公众的研究人员 | 研究的独立性与客观性高于对单一组织的忠诚 |
| 仅负责执行的经纪商 | 在客户交易指令（数量、价格、时机）范围内实现最佳执行——**不**负有受托责任 |
| 律师事务所聘请的专家证人 | 如同独立研究分析师一样保持独立性与客观性；律所不得影响证词 |

> [!IMPORTANT]
> 养老金/信托资金：聘请你的人或发起人/受托机构**并非**客户——**最终受益人**（计划参与者）才是。动用计划资产去帮助发起人管理层（例如抵御恶意收购）或为自己公司争取更多业务，均违反标准 III(A)。

**混合角色**（执行交易加上在有限产品范围内提供建议，例如仅限本公司自营产品）：应在最初的客户协议中明确服务边界；随后在允许的产品范围内根据客户目标与风险承受能力作出推荐，不考虑公司或个人在交易中的利益。

会员在所有业务往来中都必须将客户义务放在首位，**并**努力避免一切实际或潜在的利益冲突。

#### 托管、管理文件与构建组合

- **托管（Custody）**（任何直接或间接接触客户资金的权限）→ 承担更高标准的责任。
- 严格依据**管辖文件**（信托契约、投资管理协议）管理资产——这些文件是界定你权力与职责的首要依据。违背管辖文件或适用法律行事可能触犯标准 III(A)。
- 管理人通常比客户更懂行，因此客户处于弱势地位：确保目标与业绩预期**切合实际且适当**，风险水平合适；策略应与客户的**长期**目标相匹配。
- 警惕公司或管理人的目标（推销产品、促成交易）与客户利益发生冲突；对于无法避免的冲突 → 进行清晰、如实的披露。
- 遵循客户**指引**：部分客户（慈善组织、养老金计划）限制资产类别或禁止特定证券；另一些客户则对**整体组合的风险与收益**设定标准。
- 在**整体投资组合**的背景下评估每一笔投资：该投资在组合中的定位、亏损风险与获利机会、税务影响、分散化程度、流动性、现金流以及所管理资产的总体回报要求。

> [!Note]
> **投资政策声明（IPS）** 是落实标准 III(A) 的操作文件：客户的目标、约束条件和指引均载明于此，忠诚意味着在 IPS 框架内行事（IPS 的具体内容归于标准 III(C)）。基金经理按照**基金的** IPS/投资授权（例 9 —— 识别客户，Miller 与 Spears）进行管理即履行了职责，而非迎合某一位单独投资者的需要。

#### 软佣金与客户经纪交易

**经纪佣金是客户的资产**——必须用于造福客户，而非管理人。

| 做法 | 经验法则 |
| --- | --- |
| **软美元 / 软佣金**（用客户佣金购买研究服务） | 支付高于正常水平的佣金去购买**并未给客户带来相应利益**的商品或服务 → 违反忠诚义务。 |
| **指定经纪交易**（客户指定将其经纪业务交给特定券商以换取服务于客户自身的商品/服务） | 不构成违反忠诚义务——因为这是客户自己的资产。但仍须力求**最佳价格与最佳执行**，获得客户确认相关商品/服务确实造福**账户受益人**，并向客户披露通过指定券商可能**无法**获得最佳执行。 |
| **最佳执行** | 在客户既定目标和约束范围内，力求最大化客户投资组合价值的交易过程。除非作为最终受益人的客户另有指令，否则必须履行。 |
| 将**其他**客户的交易导向某经纪商，作为其推荐业务的回报 | 仅当这些账户获得了最佳价格/执行**且**已向这些账户充分披露该做法时方为允许。 |

#### 代理投票权

- 代理投票权对客户具有**经济价值**；以知情、负责任的方式行使投票权是忠诚义务的组成部分，也是投资管理不可或缺的一环。
- 违规风险：未予投票、未考虑议题影响即草率投票，或在**非常规**公司治理议题（例如公司资本结构变更）上**盲目追随管理层**投票。
- 若**成本—收益**分析表明对每一项代理投票都行权并不符合客户利益，则可豁免逐一投票。
- 向客户**披露**代理投票政策。

#### 建议程序

**定期账户信息**（如果你控制客户资产）：**至少每季度**提供一份分项对账单（列明所持资金和证券、所有借记、贷记及交易明细）；披露资产存放地点以及资产转移的时间与去向；将客户资产与任何其他方（包括你自己）的资产**隔离存放**。

**客户批准：** 拿不准时，问自己如果你是客户会期待或要求什么；若仍有疑问，以**书面形式**披露相关事项并征得客户同意。

**公司政策**——应涵盖（并鼓励公司制定）以下要点：

- 遵守所有适用的法规、法律以及《准则与标准》。
- 在提供建议或采取行动**之前**，确定客户的投资目标（投资经验、风险/收益目标、财务约束）。
- 全面考量所有信息：(1) 客户需求与处境，(2) 该投资的基本特征，(3) 整体组合的基本特征。
- **分散投资**，除非与计划指引不一致或违背账户目标。
- 定期核查持仓是否符合管辖文件。
- 公平对待所有客户——交易分配与信息传播政策[参见标准 III(B)]。
- 披露所有实际和潜在利益冲突；让客户知晓**管理人报酬的所有形式**。
- 行使代理投票权：在大多数情况下，确定谁有权投票，并本着符合客户及最终受益人最佳利益的原则投票。
- 保守秘密[参见标准 III(E)]；除非作为最终受益人的客户另有指定，否则力求最佳执行。
- **将客户利益置于首位。**

#### 考试陷阱

- 养老金计划发起人的管理层要求你用计划资金买入本公司股票以击退收购 → 受益人才是客户；为此买入被高估的股票违反标准 III(A)。
- 将佣金业务导向收费高昂、且替你所在公司承担**租金/日常办公开支**的经纪商 → 客户未受益，也未实现最佳执行。
- 用客户佣金支付调研行程中顺便附加的**度假天数** → 不属于研究费用；绝不可用客户资产支付。
- 经纪商在你的**个人**交易中给予更优价格，于是你将信托账户的交易导向他 → 将个人利益置于客户之上。
- 为达标公司最低佣金指标而交易（**过度交易**），即使买入的证券本身合适 → 违反标准 III(A)。
- “为了避免利益冲突观感”而将**正常付费的家族账户**排除在合适的 IPO 之外 → 损害了该客户利益；违反标准 III(A)（只有当家族账户是在公司正常收费结构**之外**管理时，排除才是正确的）。
- 对威胁要撤资的客户隐瞒已发现的业绩报告错误 → 违规；如实纠正才是合规做法。

#### 应用案例

**例 1 —— 识别客户：计划参与者（Julian Wiley）。** First Country Bank 担任 Miller Company 养老金计划的受托人。Miller 管理层正在抵御 Newton 的恶意收购，说服 Wiley 为养老金计划买入 Miller 股票，并暗示今后会交给该银行更多账户。Wiley 明知该股被高估却依然买入；大额买盘推高了股价，Newton 撤回了收购要约。  
**要点：** 忠诚义务的对象是**计划参与者与受益人**。利用养老金计划来保住管理层职位、讨好发起人并赢取业务违反标准 III(A)；收购要约本应纯粹基于其自身投资价值来评估。

**例 2 —— 客户佣金做法（JNI）。** JNI 将大部分养老金客户的交易交给 Thompson, Inc. 执行——佣金高昂、研究与执行水平平平——只因两家公司的高管私交甚笃，且 Thompson 替 JNI 承担了房租等日常管理费用。  
**要点：** 将客户经纪佣金用于并不造福客户的服务，且未提供最佳价格与最佳执行，违背了忠诚义务。

**例 3 —— 经纪安排（Charlotte Everett）。** 客户 Crayton 指定将其所有交易交给 Scott Company，而 Scott 正在为 Everett 牵线新客户。为了获得更多推荐，Everett 在**其他**客户不知情的情况下也将他们的交易导向 Scott。  
**要点：** 新客户交易仅在能实现最佳价格/执行，或获得客户书面豁免声明的前提下，才可独家通过 Scott 执行。用其他客户的交易回报 Scott 必须同时满足最佳价格/执行**以及**向这些客户披露——未披露的转介路由违反标准 III(A)。

### 标准 III(B) 公平对待

> 会员及候选人在提供投资分析、提出投资建议、采取投资行动或从事其他职业活动时，必须公平、客观地对待所有客户。

适用于传播投资建议、对先前建议作出重大变更，以及采取投资行动（常规买入、新股发行、增发/二级发行）。面对多位客户时，偏袒可能体现在服务的**质量与时机**，或**投资机会的分配**上。标准 III(B) 要求的是**公平（fairly）**，而非**绝对平均（equally）**：你无法在同一秒钟触达所有客户，也并非每个机会都适合每一位客户。

#### 公平 vs. 平均

| 公平（必须做到） | 不要求 |
| --- | --- |
| 在信息传播或投资行动中不歧视任何客户 | 在完全相同的瞬间触达所有客户 |
| 每位客户都获得依据每项建议采取行动的**公平机会** | 把每一条建议发给每一位客户（按**适当性和已知兴趣**筛选发送对象是可以的） |
| 高级服务层级（通过更高费用或更多佣金付费获得）须**公开披露**且**向所有人开放** | 对所有收费层级提供完全相同的服务 |

> [!IMPORTANT]
> **差异化服务层级**在满足以下条件时是被允许的：(1) 不损害或负面影响其他客户，(2) 已向现有及潜在客户**披露**，以及 (3) **不进行选择性提供**。额外服务永远只能在公平传播**之后**提供，绝不可在此之前。

#### 投资建议 vs. 投资行动

| | 投资建议 | 投资行动 |
| --- | --- | --- |
| **适用对象** | 主要职责是为他人（公司内外）准备投资建议的会员 | 主要职责是运用内外部建议进行投资组合管理的会员 |
| **涵盖内容** | 关于买入、卖出或持有的任何意见——详细报告、简短更新、增删推荐名单、口头沟通 | 交易执行、大宗订单分配、新股发行、二级市场融资 |
| **职责** | 推动建立公平的信息传播体系；告知客户他们将收到的沟通类型 | **结合客户的目标与具体情况**公平对待所有客户；按公司大宗交易分配政策进行分配 |

向公司**外部**任何人分发的投资建议，均属于面向公众或客户广泛传播的沟通材料。

**传播重大变更：** 对已变更的建议，公平传播的义务可能比首次发布时**更为关键**。重大变更应当传达给**所有现有客户**，并特别关注已知曾**依据此前建议采取行动**或受其影响的客户。如果客户下达了一笔**与当前最新建议相反**的订单（因不知情建议已变更），应在受理订单前告知该客户。

#### IPO 与热门发行

- 根据公司分配政策，将新股发行分配给**所有适合该发行的客户**。
- **超额认购** → 按所有申购者的认购量以**整手（round-lot）**为基础按比例配售（避免产生零股）。
- 超额认购 → **放弃**为你本人及直系亲属分配份额，以腾出股份留给客户。
- 但与普通客户一样正常管理的家族账户**不应被排除在外**。
- **热门发行（Hot issue）** = 因需求旺盛而在二级市场上市首日即溢价交易的公开发行证券。必须进行**真诚的公开发行分配**；绝不可扣留热门发行股票谋取私利，或将其作为奖赏或诱饵。
- 向现有客户与潜在客户披露成文的分配程序。**客户同意永远无法凌驾于公平义务之上——明显不公平的分配依然是不公平的。**

部分成交的按比例分配验算（下述例 7）：申购需求为 $3 \times 10{,}000 + 2 \times 50{,}000 = 130{,}000$，实际获配 $55{,}000$：

$$
\text{按比例分配} = \frac{55{,}000}{130{,}000} \approx 42.3\% \;\Rightarrow\; 10{,}000 \times 42.3\% \approx 4{,}231 < 5{,}000 \text{ 最小交易单位}
$$

严格按比例分配会使小账户低于最小交易单位，因此教材认可一种让所有账户都至少获得最小交易单位的调整分配方式。

#### 建议程序

- **制定公司政策：** 鼓励为所有传播建议或采取投资行动的人员建立合规程序；若尚无制度，应建议制定；发现潜在不公平对待违规时向管理层报告。程序的形式化程度取决于公司规模及所涉证券类型——即使是只管理全权委托账户的个体执业者，也应具备**正式的书面**程序。
- 将首次发布的建议提供给所有表达过兴趣的客户；按**适当性与已知兴趣**而非受宠地位挑选接收人；常见做法是公司内部与客户**同步**沟通。
- **限制**提前知晓即将发布建议的人数。
- **缩短**从决策到发布的时间间隔：如果完整报告需要数周才能完成，可先发布简短摘要；尽量在同一天召开研究委员会与投资政策委员会会议；使用“快讯”（flash）更新。
- **发布前指引：** 禁止讨论或依据待发布的建议进行交易。
- **同步传播：** 合理安排发布时间，避免任何客户群体获得先发优势；在向全面发布时同步通知各分支机构；在适当情况下宣布员工交易禁令直至传播完成。仅在全面分发**之后**方可与个别客户跟进沟通。
- 保留**客户及其持仓清单**，以便在建议变更时通知持有人，并在卖出时公平对待所有持有人。
- **交易分配程序**——原则：大宗交易中优先顺序与分配价格的公平性；及时性与效率；准确记录。实务做法：对订单、修改及撤单进行记录并加盖时间戳；先到先得（为提高效率可合并下单）；制定关于成交价格和“部分成交”的政策；同一大宗订单中的所有账户享受**相同的价格与佣金**；部分成交按**订单规模比例**分配，且不得低于既定最小交易单位（如债券）；对于新股发行，提前收集认购意向、**按客户**（而非按基金经理）进行分配，并制定明确的计算分配方法。
- **披露**交易分配程序——披露一种不公平的方法并不能免除公平义务。
- 主管人员进行**系统性账户复核**（当在一个账户买入同时在另一个账户卖出时，双方原因均须记录在案）。
- **披露服务层级**（无论收费相同还是不同）；绝不选择性提供。

#### 考试陷阱

- 在全公司正式发布前，在午餐会上向最优质的客户提前透露待发布的建议 → 违反 III(B)。
- 集合基金总是优先成交、热门新股只给集合基金、非全权委托账户永远排在最后 → 不公平的优先顺序；即使披露了该政策也不能使其变得公平。
- 在看到哪几笔交易上涨**之后**再进行事后分配，以讨好威胁要离开的客户 → 违反 III(B)；应在执行前分配，或在执行后尽快按既定系统规则（如按比例）分配。
- 在报告中重复官方 EPS 数字，却私下只告诉大客户你预计业绩将超预期 → 违反 III(B)。
- 在报告发送给所有客户之前，先在公司的 X 账号上向粉丝发布“买入”摘要 → 选择性传播。
- 在其他账户中进行额外交易，让某个受偏袒的（家族关联）计划逃避分摊共同研究所需支付的佣金 → 违反 III(B)。

#### 应用案例

**例 1 —— 选择性披露（Bradley Ames）。** 在他撰写的一家小型场外交易公司买入报告尚在进行事实核查期间，Ames 在午餐时向几位最优质的客户透露了计划于下周初发送给公司所有客户的这项建议。  
**要点：** 让受偏袒的客户提前一周知晓投资建议，违反标准 III(B)。

**例 3 —— 公平对待与 IPO 分配（Dominic Morris）。** Arena, Ltd. 的 IPO（旨在收购一家室内美式足球特许经营球队）看起来是一只热门新股；Morris 私下为自己谈妥了期权。机构投资者超额认购了该次发行，他在削减机构大宗申购的同时，满足了包括自己在内的所有个人订单。  
**要点：** 自己不得拿任何股份，并应在所有客户之间**按比例配售**。他私下获得的期权还必须向公司和客户披露[标准 VI(A)]。

**例 6 —— 向特定客户提供额外服务（Jenpin Weng）。** Weng 通过电子邮件向所有客户发送了一项新建议，随后打电话给他的三位最大机构客户详细讨论。  
**要点：** **不违规**——面向所有客户的全面传播在先；额外服务（他们大概支付了更高的费用或在他这里托管了更多资产）在后。如果他先打电话给他们，就会违反标准 III(B)。

**例 7 —— 最小交易单位分配（Lynn Hampton）。** 五位客户想认购一只超额认购的新发债券（三家各 US\$10,000，两家各 US\$50,000；最小交易单位为 US\$5,000）。她总共获配 US\$55,000，于是为每个小账户分配 US\$5,000，为每个大账户分配 US\$20,000。  
**要点：** **不违规**——由于存在最小交易单位的限制，这并非严格按比例分配，但每位客户都至少获得了最小交易单位，从而确保日后都能有效卖出。

### 标准 III(C) 适当性

> 1. 当会员及候选人与客户存在顾问关系时，必须：
>    a. 在作出任何投资建议或采取任何投资行动之前，对客户或潜在客户的投资经验、风险与收益目标以及财务约束进行合理调查，并定期重新评估和更新这些信息。
>    b. 在作出投资建议或采取投资行动之前，确定某项投资适合客户的财务状况，并与客户书面的目标、授权和约束条件相一致。
>    c. 在客户整体投资组合的背景下判断投资的适当性。
> 2. 当会员及候选人负责按照特定授权、策略或风格管理投资组合时，必须仅作出或采取与该组合既定目标和约束条件相一致的投资建议或投资行动。

适用于处于**顾问关系**中的会员：在提出建议或采取行动前，应考虑客户的需求、处境和目标。审查客户的知识水平、投资经验和财务状况——评估该投资的风险与客户约束条件的匹配度、对组合分散化的影响，以及客户是否具备承担该风险的财务能力。适当性应当仅反映**审慎人士**会采取的行动。恰当的适当性评估并**不**保证投资不会贬值。仅负责执行交易的人员和卖方分析师可能没有机会对最终客户进行适当性判断。

#### 制定投资政策声明（IPS）

在关系建立之初收集以下信息：财务状况、相关个人资料（年龄、职业）、对风险的态度、投资目标——并将其写入**书面 IPS**。

| IPS 组成部分 | 内容 |
| --- | --- |
| **客户识别** | 客户类型与性质；是否存在独立受益人；你所管理的资产占客户总资产的大致比例 |
| **目标 —— 收益** | 收益（收入）、本金增值、购买力保值 |
| **目标 —— 风险** | 风险承受能力（适当性、价值稳定性） |
| **约束条件** | 流动性需求；预期现金流（追加/提取）；可投资资金（资产、负债、承诺）；**时间期限**；**税务**考量；**监管与法律**环境；投资者偏好、禁止事项、特殊处境与**独特**需求；代理投票职责与指引 |
| **业绩基准** | 业绩计量基准 |

IPS 还应说明各方的角色与职责，以及**定期审阅与评估的时间表**。在形成长期资本市场预期之后，协助制定战略资产配置（写入 IPS 正文、附录或单独文件）。

> [!Note]
> 记忆口诀（作者自拟，非教材原文）——目标 **R**eturn 与 **R**isk（收益与风险）；约束 **TTLLU**：**T**ime horizon（时间期限）、**T**ax（税务）、**L**iquidity（流动性）、**L**egal/regulatory（法律/监管）、**U**nique circumstances（独特处境）。

#### 风险画像与更新 IPS

- **风险承受能力**是最重要的适当性因素之一；考虑快速变化的市场环境，并**事先**分析和量化策略风险。
- **衍生品 / 合成工具：** 关注内在的**杠杆**以及有限的**流动性**——两者均直接关系到适当性。
- **至少每年**更新一次 IPS，并在对具体建议或决策作出重大调整**之前**更新。
- 值得关注的变化：个人方面——受抚养人情况、税务身份、健康状况、流动性需求、风险承受能力、组合之外的财富、收入满足日常支出的能力；机构方面——未足额拨备的养老金负债、储蓄计划的提取权限、基金会的派发要求。
- 只有在客户披露**完整投资组合**时，适当性评估效果才最佳；若客户隐瞒了部分信息，分析便仅基于其实际提供的信息。

#### 分散化与整体投资组合

- 保持一定程度的合理分散是常态，对于负有法定受托责任的人而言尤其如此。
- 一项本身高风险的投资，在**整体投资组合的背景下**，或者当客户目标本身包含投机时，可能是适当的。
- 你仅需根据客户**实际提供**的信息和标准承担适当性责任。

#### 非主动征询的交易请求（Unsolicited trade requests）

此类请求可能反映客户自身的偏见或职业经验。如果你明知该交易**不适当**，应在与客户**讨论**你的顾虑之前暂缓执行。

| 情形 | 行动 |
| --- | --- |
| 对组合**影响极小**（交易规模小，风险变化有限） | 向客户说明该交易如何偏离 IPS；遵循公司关于客户批准不适当交易的政策。最低限度应让客户**确认**已进行过该讨论，并接受使其不适当的条件。 |
| 对组合有**重大影响** | 借此机会**更新 IPS** |
| 客户拒绝更新 IPS 但仍坚持交易 | 评估你的服务范围：部分公司允许在新的**非管理账户（unmanaged account）**中执行该交易；若无替代方案，则决定是否**继续**维持顾问关系 |

#### 按指数或特定授权管理

- 基金经理必须**严格按照既定授权**进行投资（例如，大盘收益型基金不应重仓投资投机性小盘股或初创公司）。
- 他们**不**负责判断该基金是否适合每一位具体投资者——该职责仅属于存在**顾问**关系的会员。

#### 建议程序

- **投资政策声明：** 将每位客户的需求、处境与目标写入书面 IPS（内容如上）。
- **定期更新：** 定期审视目标与约束条件；定期将客户约束条件与资本市场预期进行比对（任一方变化都可能改变资产配置）。**年度审阅**是合理的常规做法，除非业务原因或重大市场变化要求更频繁地审阅；如因客观条件受阻未能完成，应**记录**尝试开展审阅的努力。
- **适当性测试政策：** 鼓励公司制定相关政策；不要只看回报潜力，还要考察 (1) 对组合**分散化**的影响，(2) 投资风险与客户**评估风险承受能力**的匹配度，(3) 与既定**投资策略**的契合度。

#### 考试陷阱

- 对薪资相近但财富规模与投资目标迥异的两位客户采用同样激进的资产配置 → 对不符合的那位客户违反标准 III(C)。
- 客户获得大额遗产 → **必须**更新 IPS；其承担风险的能力（以及可能的意愿）已经改变。
- 在**高收益**基金中买入零股息股票 → 违反投资授权，除非授权文件或基金披露文件允许。
- 即使在要求高流动性资产的 IPS 中只配置极小比例带有**锁定期**的私募股权 → 同时违反标准 III(C) **与**标准 III(A)。
- 仅凭**最低费率**挑选次级管理人，而未使其策略匹配客户的风险画像 → 可能违反标准 III(C)（客户要求国际分散化投资时，正是更新 IPS 的信号）。
- 为追逐季度奖金而在长期养老金账户中高频交易高贝塔股票 → 违反标准 III(C)。
- 没有制定 IPS、来者不拒地将每一位新客户都塞进朋友的对冲基金产品 → 违反标准 III(C)；投资顾问绝非单纯的销售代理。

#### 应用案例

**例 1 —— 投资适当性：风险画像（Caleb Smith）。** Larry Robertson（60 岁，资产雄厚，风险承受能力高得多）和 Gabriel Lanai（40 岁，希望为子女教育获取稳健低波动回报）薪资相近。Smith 将**两人**组合的 20% 都投入了零分红的高科技小盘股。  
**要点：** 对 Robertson 或许合适，对 Lanai **绝对不合适**——将一位客户的策略直接套用到处境与目标完全不同的另一位客户身上，违反标准 III(C)。

**例 4 —— 遵循投资授权（Louis Perkowski）。** 他为自己管理的**高收益**共同基金买入了一只被低估、零股息的金融服务股。  
**要点：** 除非符合投资授权或基金披露的可投资范围，否则无论该股票多么具吸引力，偏离授权买入均违反标准 III(C)(2)。

**例 5 —— IPS 要求与限制（Max Gubler）。** 某保险子公司的 IPS 仅允许投资高流动性资产（大盘股；AA 级及以上的政府、超国家机构及期限不超过五年的公司债）。Gubler 将 4% 的资金投入了一只带有三年锁定期及阶梯退出的种子期私募股权基金，尽管总权益仓位仍远低于上限。  
**要点：** 带有锁定期的非流动性资产超出了 IPS 的流动性要求及可接受资产类别——无论规模多小，均同时违反**标准 III(A) 和标准 III(C)**。管理人还应当在 IPS 条文之外充分了解客户的业务实质。

### 标准 III(D) 业绩陈述

> 在沟通投资业绩信息时，会员及候选人必须作出合理努力，确保信息公平、准确且完整。

涵盖**任何**可能歪曲业绩记录的做法——无论是业绩**陈述**还是业绩**计量**，无论是**过往**业绩还是**合理预期**业绩——针对个人账户、组合群，或是分析师及公司的过往成果。这并不仅限于独立账户管理人：集合基金以及宣传自身推荐准确率的研究分析师同样受其约束。绝不可陈述或暗示客户未来将获得过去曾经实现的回报。

#### 简明业绩陈述

| 允许 | 要求 |
| --- | --- |
| 简短的业绩摘要 | **依请求可提供**详细的支持信息 |
| 因篇幅限制省略部分细节 | 最佳实践：注明该信息属于**有限披露（limited）** |

#### 建议程序

- **采用 GIPS 标准**——是满足标准 III(D) 的最佳方式；鼓励公司全面遵守 GIPS。
- **未采用 GIPS 时：**
  - 考量受众的专业知识与成熟度；
  - 展示类似投资组合的**加权组合群（weighted composite）**，而非单一代表性账户；
  - 纳入**已终止账户**，并列明其终止时间；
  - 充分披露：**模拟（模型）**结果、**前任职机构**的业绩记录、**扣除费用前/后**或**税后**口径；
  - 保存用于计算业绩的数据与原始记录。

#### 考试陷阱

- 当组合群并非按资产加权时仍宣称符合 GIPS → 仅凭**虚假宣称**即违反标准 III(D)，即使并未篡改具体数据。
- 展示在**前一家公司**取得的业绩记录，仅在披露业绩来源地及你在其中的具体角色时方为允许。
- 未加标明地挑出时间加权收益率或资金加权收益率中较高者予以展示 → 违反标准 III(D)。
- 在未告知客户的情况下更换归因方法或更改月末结算日期以美化业绩 → 违反标准 III(D)。
- “你可以预期每年稳定获得 25% 的回报” → 同时违反标准 III(D) **与**标准 I(C)（构成保证）。

#### 应用案例

**例 1 —— 业绩计算与时间跨度（Kyle Taylor）。** Taylor 的宣传册承诺“每年稳定 25% 的复利增长”，理由是普通信托基金去年顺应市场上涨了 25%。但该基金从未在超过一年的时间里达到过这一平均水平，且全部信托账户五年平均回报仅为 5%。  
**要点：** 违反标准 III(D)——他应当说明 25% 仅是单年表现，并纳入所有账户类别。该承诺同时也违反**标准 I(C)**。

**例 2 —— 业绩计算与资产加权（Anna Judd）。** Judd 分发了一份宣称符合 GIPS 的业绩报告，但其中的组合群并未按资产规模加权。  
**要点：** 违规在于**虚假宣称符合 GIPS**——宣称符合 GIPS 意味着必须满足其全部要求与披露规范。

**例 3 —— 业绩陈述与前基金/前雇主（Aaron McCoy）。** Mastermind 公司的广告展示了 McCoy 在 G&P Financial 任职期间创造的六年股票投资业绩，却未说明该业绩是在 G&P 取得的。  
**要点：** 违反标准 III(D)。只有在充分披露业绩取得地点及他本人具体职责的前提下，才可展示前雇主时期的业绩记录。

**例 4 —— 业绩陈述与模拟结果（Jed Davis）。** Davis 利用 1996–2003 年的数据回测了他的选基模型，并在未注明为模拟结果的情况下将该业绩用于广告宣传。  
**要点：** 模拟结果必须清晰标明，并披露其数据来源——否则违反标准 III(D)。

### 标准 III(E) 保密义务

> 会员及候选人必须对现客户、前客户及潜在客户的信息保密，除非：
> 1. 该信息涉及客户的非法活动；
> 2. 法律要求披露；或
> 3. 该客户或潜在客户允许披露该信息。

当你 (1) 因具备处理客户部分商业或个人事务的**特殊能力**而获取信息，且 (2) 该信息产生于或相关于该部分业务时，本标准适用。如果法律要求披露或信息涉及客户的非法活动，你可能有义务向主管当局报告。

#### 指引要点

| 要点 | 核心内容 |
| --- | --- |
| **客户身份状态** | 同样涵盖**前客户**——关系结束后保密义务依然延续；若客户明确授权披露，须按授权范围执行 |
| **遵守法律** | 法律要求披露 → 予以披露。法律要求保密，**即使涉及非法活动** → 不得披露。跨部门隔离限制也可能限制公司内部的信息流转。若有疑问 → 咨询合规或法律顾问 |
| **电子信息与安全** | 防范意外泄密；无需成为 IT 专家，但要熟知雇主的安全政策；鼓励对**全体**员工（包括前台接待员和非投资人员）开展定期培训 |
| **CFA 协会 PCP** | 向职业行为项目（PCP）提供客户信息**不**构成违规；应将 PCP 视为你自身的延伸 |

#### 建议程序

- 最简单、最稳妥的做法：仅向**同样服务该客户的获授权同事**披露客户信息。
- 在保密范围之外披露信息（且不涉非法行为）前，自问：该信息是在何种**情境**下披露的，是否与工作相关？它是否属于有助于**改善对客户服务**的背景信息？
- 遵守公司的电子通信与存储规程；若无规程，应推动制定。
- **与客户沟通：** 确保公司支持的渠道能防止意外分发，定期审视隐私保护措施，并告知客户哪些沟通方式适合传递机密信息。

#### 考试陷阱

- 出于善意（帮助慈善机构筹款）并不能成为泄密的借口 → 违反标准 III(E)。
- 怀疑存在非法活动 ≠ 立刻公之于众：报告主管 → 与客户沟通纠正 → 咨询法律顾问；随后可能须依法披露（并辞职）。
- 客户自己在经适当警示的社交媒体群组里泄露个人详细信息 → **不**构成你的违规；应及时将其删除。

#### 应用案例

**例 1 —— 掌握机密信息（Sarah Connor）。** City Medical Center 的受托人向 Connor 提供了关于翻修与扩建需求的内部报告。当地商人 Thomas Kasey 在决定向何处捐款前向她打听该建筑规划。  
**要点：** 该信息属于合作关系范围内的机密信息——她必须拒绝透露。

**例 2 —— 披露机密信息（Lynn Moody）。** 一位客户告诉 Moody，出于税务原因她计划向慈善机构捐赠约 US\$50,000；身兼 Home for Indigent Widows 财务主管的 Moody 随即通知 HIW 去向该客户募捐这一数额。  
**要点：** 无论初衷多么善良，均违反标准 III(E)。

**例 3 —— 披露可能的非法活动（Casey Samuel）。** 政府官员要求查阅 Garcia 的养老金记录；Samuel 早已发现该计划可能被收取了过高且不当的费用，法律顾问认为 Garcia 很可能违反了税法和受托责任法。  
**要点：** 她应向主管报告并尝试与 Garcia 一同纠正；若纠正失败，寻求法律建议。她可能有义务向当局披露并辞职。

**例 5 —— 意外披露机密信息（Lynn Moody）。** Moody 管理着一个经合规批准的客户群组页面，并在页面上警示所有发帖均为公开可见。一名客户自行发布了高度私密的信息；她随即安排将其删除。  
**要点：** **不违规**——她已采取合理预防措施并迅速处置；该事件提示应加强培训和风险提示。

## 标准 IV 对雇主的职责
### 标准 IV(A) 忠诚

> 在与雇佣相关的事务中，会员及候选人必须为雇主的利益行事，不得剥夺雇主享有其技能与能力的权利、泄露机密信息或以其他方式对雇主造成损害。

保护所在公司：不得从事任何会损害公司利益、剥夺公司利润或剥夺公司享有你技能与能力的行为，并且只要公司政策不与法律或《准则与标准》相冲突，便须遵守。客户利益永远排在雇主**之前**。标准 IV(A) **并非**要求把雇主置于重要个人及家庭义务之上的一刀切规则——当个人事务经常干扰工作时，应与雇主沟通平衡之道。

#### 雇主责任与独立执业

- 雇主本身**不受**《准则与标准》约束，但不应制定与之冲突的政策；高级管理层应当避免设置诱发不道德行为的激励机制。鼓励向雇主提供一份《准则与标准》副本。
- 仅当你向雇主通知了**服务类型**、**预期持续时间**及**报酬情况**，并就**所有条款**取得**同意**后，方可开展有偿**独立执业**。
- “执业” = 雇主目前有偿提供的任何服务。**准备**竞争 ≠ **开展**独立执业。

#### 离职与离开雇主

| 允许 | 违规（尤其是组合出现时） |
| --- | --- |
| 利用业余时间筹备竞争性业务 | 盗用**商业秘密** |
| 离职后：运用自身技能、经验以及对客户姓名的简单记忆 | 滥用**机密信息** |
| 离职后：在无竞业禁止协议的情况下，通过**公开信息**联系前客户 | 在雇佣关系结束前**招揽**雇主的客户 |
| 遵循行业协议的既定程序带走协议允许的信息（例如美国《经纪人招募协议》Protocol for Broker Recruiting） | **自我交易**；盗用**客户或客户名单** |

> [!IMPORTANT]
> 在辞职正式生效之前，必须继续以雇主的最佳利益行事。未经雇主**书面**许可，不得带走任何记录或文件——**即使是你自己创建的**；删除或归还存放在家中或个人设备上的公司记录。

#### 社交媒体、内部举报（吹哨）与雇佣性质

- **社交媒体：** 遵守公司政策，尤其是在离职时。公司批准设立的业务账号属于**公司财产**。最佳实践：将个人账号与职业账号分开。
- **内部举报（吹哨）：** 违背雇主利益行事（如违抗指令、复制记录）**仅**在旨在保护客户或市场诚信时才具备正当性——绝不能为了个人私利。
- **雇佣性质：** 属于雇员还是独立承包商，取决于雇主的**控制程度**（工作时间、工作地点、办公设施、费用报销、是否服务其他雇主或客户）。独立承包商的职责遵循其合同约定。

#### 建议程序

- **竞业政策：** 了解对外部服务的所有限制；签署竞业禁止协议前确保条款清晰。
- **离职政策：** 辞职流程、如何通知客户与员工、社交媒体更新、研究与账户移交，以及允许带走哪些客户信息。
- **事件报告程序：** 熟知内部举报（吹哨）政策；鼓励设立保密、匿名的举报机制。
- **雇员分类：** 区分兼职、全职与独立承包商，明确各自适用的政策。

#### 考试陷阱

- 带走**你自己搭建的**记录（模型、电子表格）→ 仍违反标准 IV(A)。
- **无薪实习生**同样属于雇员（以经验与知识作为报酬）。
- 在业余时间注册一家竞争公司且不进行招揽 → 属于筹备工作，**不**构成违规。
- 离职前参与投标一份当前雇主也在竞标的 RFP（征求建议书）→ 违反标准 IV(A)，除非雇主与 RFP 发起方双方均同意。
- 将公司设密码保护的研究报告发在公开的个人博客上 → 违反标准 IV(A)。

> [!Note]
> 记忆口诀（作者自拟，非教材原文）——**只筹备，不竞争；离职只带走大脑，不带走文件。**

#### 应用案例

**例 1 —— 招揽前客户（Samuel Magee）。** 在从 Trust Assets 辞职前，Magee 邀请四个大客户和几名潜在客户随他转投 Fiduciary Management。  
**要点：** 在仍在职期间招揽现有客户和潜在客户违反标准 IV(A)。

**例 2 —— 前雇主的文件与档案（James Hightower）。** 准备离开 Jason Investment 自立门户的 Hightower 计划复制客户名单、账户对账单、营销演示文稿、推荐名单、配置与选股模型，以及他自己编写的分析师电子表格。  
**要点：** 以上全部属于雇主财产——未经同意带走其中任何一项，即便是他自己编写的材料，也违反标准 IV(A)。

**例 5 —— 已完成过往成果的所有权（Emma Madeline）。** 一名在 Murdoch and Lowell 工作的无薪实习生在加入 McMillan 前复制了她参与开发的 GIPS 软件。  
**要点：** 她属于雇员（以工作经验作为报酬）且使用了公司资源——复制该软件违反标准 IV(A)。

**例 10 —— 招揽前客户（Shawna McQuillen）。** 在没有竞业禁止协议的情况下，她未带走任何记录、清空了电脑，并在离职后通过公开记录查找到前客户的电话号码进行联系。  
**要点：** **不违规**——使用公开信息、无竞业协议、未动用前雇主的任何记录。

### 标准 IV(B) 额外报酬安排

> 会员及候选人不得接受与雇主利益相竞争、或可以合理预期会与雇主利益产生冲突的礼物、利益、报酬或对价，除非获得所有相关方的书面同意。

在向第三方提供与受雇工作相关的服务，或提供任何可能与雇主利益冲突的服务并收取报酬或其他利益**之前**，必须取得雇主许可。本条涵盖来自客户的**直接**报酬以及来自第三方的**间接**报酬或利益。此类安排可能影响忠诚度与客观性；披露便于雇主评估你的动机以及你服务的**真实成本**。

#### 核心规则

| 规则 | 细节 |
| --- | --- |
| **书面同意** | 任何可留存记录的形式均符合要求（例如可检索的电子邮件） |
| **非货币利益** | 同样计入——例如因担任董事而获得的免费会籍 |
| **兼职雇员** | 应在入职时讨论竞业服务限制；标准 IV(B) 适用于当时界定的限制范围 |

#### 建议程序

- 就任何超出雇主所付薪酬的拟议报酬，**立即**向主管及合规官提交**书面报告**。
- 由**提供报酬的一方确认**具体细节，包括来自客户的业绩激励安排。
- 列明具体**条款**：报酬性质、大致金额及持续时间。

#### 考试陷阱

- 客户提供的挂钩业绩的奖金（若回报率 ≥ 15% 则赠送免费度假）→ 必须书面披露并取得同意。
- “又不是给钱”不能作为借口——非货币性质的董事会福利同样需要披露。
- 事先取得批准，随后参加公司会议，并在事后如实披露计划外的晚餐 → **不**违规。

#### 应用案例

**例 1 —— 通知客户奖金报酬（Geoff Whitman）。** 客户 Carol Cochran 提出，只要她的投资组合税前回报率至少达到 15%，就免费让 Whitman 夫妇在她位于摩纳哥的公寓度假一周；他在未告知雇主的情况下欣然前往。  
**要点：** 违反标准 IV(B)——这种附条件的额外安排可能使他偏袒 Cochran 的账户而忽视其他客户；他必须获得雇主的书面同意。

**例 2 —— 通知外部报酬（Terry Jones）。** Jones 因担任 Exercise Unlimited 董事会成员而获得不限次数的家庭会员卡，他为合适客户买入该公司股票，却因自己未领取现金报酬而未予披露。  
**要点：** 违反标准 IV(B)——非货币报酬与现金董事袍金一样会制造利益冲突。

**例 3 —— 外部报酬的事先批准（Jonathan Hollis）。** 在发布买入报告后，ABC Oil 邀请 Hollis 与 CEO 会面并提供公司专机接送。他事先征得公司批准，婉拒了专机接送，赴约出席并参加了一场高档晚宴，事后如实报告了包括晚宴在内的全部情况。  
**要点：** **不违规**——事先审批、拒绝专机接待以及事后全面披露，使公司能够评估对其客观性的任何潜在影响。

### 标准 IV(C) 主管人员的职责

> 会员及候选人必须作出合理努力，确保受其监督或管辖的任何人员遵守适用的法律、法规、规章以及《准则与标准》。

任何对他人拥有控制权或影响力的人员——无论这些下属是否为会员或候选人——都负有监督职责，并需要深入掌握《准则与标准》。何谓“合理努力”取决于下属人数及所从事工作的性质；监督职责可以**授权委派**，但你必须指导被授权人如何预防和发现违规行为。最低限度上，必须通过**有效的合规体系**作出合理努力以**预防和发现**违规——并且超越条文规定：开展定期培训并设置奖励道德行为的激励机制。

#### 监督体系

- 合规程序必须经过**建立、成文、传达与执行**，并加以监控和强制落实。“充分（Adequate）” = 符合行业标准、监管规定、《准则与标准》以及公司自身情况。
- 程序必须在违规发生**之前**就已建立，瞄准最容易滋生不当行为的业务活动，并与公司的规模和业务性质相匹配。
- 对全公司政策没有决定权？仍应与上级合作推动建立道德规范、合规程序、培训、道德激励及最佳实践标准（GIPS、《资产管理人职业准则》）。
- 体系不充分 → 告知高级管理层并提出改进建议；若明确无法履行有效监督职责，应**以书面形式拒绝承担监督责任**，直至合理的程序建立为止。

> [!IMPORTANT]
> 一旦获悉可能存在违规行为：**立即**调查其波及范围。仅听信员工的口头保证、向上级汇报了事，或仅仅口头警告该员工均**远远不够**。在调查结果出来之前，必须限制或加强对该员工活动的监控。

#### 监督包括“发现”

| 情形 | 是否违反 IV(C)？ |
| --- | --- |
| 已制定并严格执行合理程序，但仍发生个别违规漏网 | 可能**不**违规 |
| 违规行为接连不断发生 | 可能表明程序**不充分** |
| 你知道或应当知道程序**未被遵守** | 违规 |

#### 建议程序

- **道德规范：** 鼓励制定一份与详细合规手册**分开**的道德规范，采用通俗语言撰写，并与客户分享。
- **充分的合规程序：** 量身定制、清晰的书面合规手册；易于理解；配备拥有明确职权与资源的合规官；明确的监督层级；制衡机制；涵盖范围；有记录的监控与测试；允许的行为界定；违规报告与惩戒措施。
- **到位之后：** 广泛分发、定期更新、持续教育、定期提醒、将职业操守纳入绩效考核、复核员工行为、严格执行。
- **违规发生后：** 迅速响应、彻底调查、在结论出炉前加强监督或限制涉事人员权限、复盘完善程序。
- **教育与培训：** 结合道德规范定期开展。
- **激励结构：** 将奖励与客户利益及成果**如何达成**相挂钩，而非仅仅看为公司创造了多少收入。

#### 考试陷阱

- 向同事透露即将作出的评级调整，却没有任何程序阻止他们据此抢先交易 → **主管人员**违反标准 IV(C)。
- 未经复核便转发下属（基于并购传闻撰写的）投资建议 → 违反标准 IV(C)。
- 薪酬部分与交易佣金挂钩的合规主管对可疑成交量视而不见 → 违反标准 IV(C)；务必警惕自身利益冲突。
- 主管人员敷衍、打发员工提出的问题顾虑 → 违反标准 IV(C)；必须认真审查。

#### 应用案例

**例 1 —— 监督研究活动（Jane Mattock）。** Mattock 口头告诉 H&V 高管她准备把 Timber Products 从买入调降为卖出；向她汇报的 Frampton 随即为其本人及全权委托客户卖出该股，其他人也在报告发布前向机构客户通风报信。  
**要点：** 违反标准 IV(C)——她需要建立程序来预防并发现他人利用及传播尚未发布的评级变更。

**例 2 —— 监督研究活动（Deion Miller）。** Miller 在休假前未作复核，便将 Georgia Ginn 基于并购传闻撰写的 Excelsior 买入备忘录直接转交给了基金经理。  
**要点：** 违反标准 IV(C)——他既未检查是否存在合理依据，也未核查是否涉及重大非公开信息。

**例 3 —— 监督交易活动（Roberta Ann Mason）。** 见习生 David Edwards 允许一名客户用即时转售 Highland 股票的利润来支付买入款项；薪酬部分与交易佣金挂钩的合规主管 Mason 看到了交易量却无所作为。  
**要点：** 违反标准 IV(C)——主管人员必须对自身利益与监督职责之间的冲突保持高度警觉。

**例 5 —— 承担监督责任（Meredith Rasmussen）。** 一只对冲基金的报告业绩忽略了一次剧烈的市场暴跌；交易主管和合规官却让 Rasmussen 别多问。  
**要点：** **主管人员**因驳回她的合理质疑而违反标准 IV(C)——他们必须认真核查并培育合乎道德的企业文化。（她的内部举报行为归属标准 IV(A) 管辖。）

## 标准 V 投资分析、建议与行动
### 标准 V(A) 勤勉与合理依据

> 会员及候选人必须：
> 1. 在进行投资分析、提出投资建议和采取投资行动时保持勤勉、独立和彻底。
> 2. 为任何投资分析、建议或行动提供适当研究和调查所支持的合理且充分的依据。

所需的勤勉程度取决于**投资理念**、你在决策流程中的**角色**，以及雇主提供的**支持与资源**。合理依据是在各种资源（公司财报、第三方研究、定量模型）之间取得与具体证券或决策相匹配的**平衡**。具备合理依据并**不**能消除下行风险：你只能基于当时已知的信息作出判断。

#### 二手研究与第三方研究

| 类型 | 含义 |
| --- | --- |
| **二手研究（Secondary research）** | 由**你所在公司内部**的其他人完成的研究 |
| **第三方研究（Third-party research）** | 由**公司外部**（券商、银行、独立研究机构）完成的研究 |

- 只有在作出**合理且勤勉的努力**判断其可靠性之后，方可依赖此类研究。如果你怀疑来源缺乏可靠依据 → **不得**依赖。
- 可靠性检验维度：**假设条件**、分析的**严谨性**、**日期/时效性**，以及**客观性与独立性**。
- 互联网信息来源（个人博客、信息聚合网站、社交媒体）需要比老牌研究机构**更严格**的核查。
- 除非有理由怀疑，否则可以善意依赖公司自身对外部研究供应商的尽职调查。检查公司是否制定了及时、一致地复核获批研究提供商的政策；若无，应推动建立。

#### 定量研究与模型

- **模型使用者**无需精通每一项技术细节，但必须理解模型的**假设条件与局限性**，以及输出结果如何应用于决策；在将模型纳入决策流程**之前**测试其输出。
- 分析应当涵盖**广泛的情景假设**，包括极端乐观与极端悲观的情景——剔除负面结果可能歪曲真实价值。
- 新模型的**开发者**必须展现出比使用者**更高水准的勤勉**：精通技术细节、在分发前彻底测试，并核查数据的**来源与时间跨度**——历史数据库可能未能同时覆盖上行与下行周期，因此必须测试可观测数据范围**之外**的情景。

#### 外部管理人与次级管理人

像尽调单只基金和证券一样勤勉地评估外部管理人。你所在公司应当建立**标准化评估维度**，包括：
- 管理人的**道德规范**；
- 其**合规与内部控制**程序；
- **公开披露回报**信息的质量；
- 其**投资流程**及对既定策略的遵循情况。

#### 团队研究与集体决策

团队报告反映的是**集体共识**，未必等于你个人的观点。如果你认为该共识拥有**合理且充分的依据**，且保持了独立与客观，即使你个人持有异议，也**无需**从报告中撤出署名。你也可以请求将自己的名字移除。

#### 建议程序

- 制定政策，确保研究报告、信用评级与投资建议均有充分依据，并在对外分发**之前**由**监督分析师**或**复核委员会**审阅。
- 为分析师、监督分析师和复核委员会制定详尽的书面尽职调查指引。
- 建立衡量研究质量、建议依据及长期准确率的**可量化指标**（可与薪酬挂钩，并一贯执行）。
- 为所有计算机模型制定书面的最低**情景测试**标准（情景广度、长期准确性、现金流对输入参数的敏感度）。
- 设定评估**外部提供商**的可量化标准，并规定复核频率。
- 制定评估**外部管理人**的标准化准则，并规定资产配置复核频率。

#### 考试陷阱

- 因时间紧迫而按公司规模估算交易定价“以后再补理由” → 违反标准 V(A)；只承接自己有能力保质完成的工作。
- 将**最乐观**情景当作**基准情景**来展示 → 违反标准 V(A)；应当给出多种情景及其概率分布。
- 仅凭**最低费率**，或仅凭**历史业绩 + 宣称符合 GIPS** 就选定次级管理人 → 违反标准 V(A)。
- 对模型各模块分别做了测试，却从未测试过**整合后的整体模型** → 违反标准 V(A)。
- 经过勤勉研究后作出的推荐随后亏损 60% → **不**违规；尽职调查 ≠ 保证盈利。
- 从不亲自交易的模型开发者，依然要为模型给出的建议承担责任。

#### 应用案例

**例 2 —— 充分的情景测试（Babu Dhaliwal）。** 为证明 Feggans Resources 增发定价的合理性，Dhaliwal 让管理层按最理想情景预测最大产量，随后直接将这些数字作为基准情景向券商路演推介。  
**要点：** 违反标准 V(A)——他应当提供一系列产量情景及其对应概率。

**例 5 —— 团队研究意见（Evelyn Mastakis）。** 固定收益委员会多数成员修改了她关于抵押贷款利率的报告，预测利率将更大幅度上升。  
**要点：** 只要她确信该流程产生了合理且充分的依据，即使报告不再反映她的个人观点，也**无需**撤下自己的名字。

**例 7 —— 遴选次级管理人的尽职调查（Paul Ostrowski）。** 他使用 CFA 协会的范本 RFP 发出问卷，收到七份回复后直接选择了收费最低的那家公司。  
**要点：** 可能违反标准 V(A)——遴选必须全面审查服务能力、历史业绩与成本结构。

**例 11 —— 定量模型的使用（Espacia Liakos）。** Hellenica 的建模团队将一项大宗商品波动率策略的部分模块外包；每个模块单独验证都通过了，但从未作为一个整体进行测试，结果策略在波动率飙升时彻底失效。  
**要点：** 违反标准 V(A)——她必须理解整个模型并测试各模块之间的交互作用，而不仅仅是逐个单独验证。

**例 12 —— 尽职调查成功但投资失败（Alton Newbury）。** 在分析完 Top Shelf 的业绩记录、核心团队、费率与风险画像后，他将其推荐给一位激进型客户；一周后该投资大跌 60%。  
**要点：** **不违规**——具备合理依据并不能保证不存在下行风险。

### 标准 V(B) 与客户及潜在客户的沟通

> 会员及候选人必须：
> 1. 向客户及潜在客户披露所提供服务的性质，以及与这些服务相关的客户成本信息。
> 2. 向客户及潜在客户披露其用于分析投资、选择证券和构建投资组合的基本形式与一般原则，并必须及时披露任何可能对这些流程产生重大影响的变更。
> 3. 向客户及潜在客户披露与投资流程相关的重大局限性与风险。
> 4. 运用合理判断识别对其投资分析、建议或行动至关重要的因素，并将这些因素纳入与客户及潜在客户的沟通中。
> 5. 在陈述投资分析与建议时区分事实与观点。

清晰、频繁且全面的沟通让客户明白你如何为他们行事，并能作出充分知情的决策。沟通涵盖**任何**形式——书面报告、面对面交流、电话、媒体广播、互联网、社交媒体——从短短一个词的“买入”到长达百页的深度报告均在其列。

#### 服务性质与成本

| 要点 | 核心细节 |
| --- | --- |
| **披露内容** | **将会提供和不会提供**的服务，以及客户预计承担的成本——合理程度的细节即可，**无需**精确到每一美元 |
| **持续义务** | 服务或成本发生变化 → 及时通知所有受影响的客户 |
| **涵盖范围** | 与服务相关的**全部**成本，包括关联方、相关实体及第三方收取的费用 |
| **客户成熟度** | 不能因为客户经验丰富就跳过披露；可以**因人制宜**调整披露方式 |
| **适用人员** | 通常仅限**面向客户**的会员 |
| **形式** | 由你酌情决定，只要恰当、准确、及时且完整；最佳实践 = **书面形式** |

#### 投资流程与沟通形式

- 说明决策流程，包括产生**正面和负面**影响的因素，并及时向客户通报**变更**，尤其是新出现的重大风险与局限性。
- 告知客户所聘用的任何**外部管理人/顾问**的专业领域。
- 精简版推荐（例如推荐股票池）→ 告知客户可以随时获取更多信息与分析依据。
- 新技术/社交媒体 → 确保沟通方式能让所有客户获得公平对待。

#### 风险与局限性

- 披露分析中的**重大**风险与局限性。**杠杆**通常属于重大风险；市场相关风险及**复杂金融工具**的风险亦然；其他还可能包括交易对手风险、国家风险、行业风险、特定证券风险及信用风险。
- 报告重大限制因素，例如**流动性**（能否按时以合理成本卖出）以及**策略容量**（超过该规模后新增资金会损害回报）。
- 按**事前（ex ante）**标准评判——即依据你行动时已知的信息。事后发生的一次性亏损本身并不意味着违反标准 V(B)；若根本未意识到某项风险，则可能指向**标准 V(A)** 的问题。

#### 报告呈现

- 纳入对分析至关重要的要素，使读者能够**理解并质询**你的推理过程；若你认为某些领域不重要而予以省略，须说明报告研究范围的局限性。
- 定量投资建议需要提供随时可得的参考资料并保持方法论一致；方法论发生变更时务必**重点标出**。

> [!IMPORTANT]
> **事实 vs. 观点。** 盈利预测、股息展望和未来目标价都是受未来环境影响的**观点**——务必明确标注。在定量分析中，将事实与**统计推断**区分开来，并说明预测的已知局限性。与客户探讨模型假设，并谨慎宣传模型的准确性：模型的输出是估计值，而非确定无疑的事实。

#### 建议程序

- 判断应纳入哪些因素须逐案权衡，而非机械核对清单。
- 鼓励公司建立严谨的方法论，在研究报告发布前进行审阅。
- 保留研究性质的相关记录，以便客户询问时能够提供报告中未列出的因素。

#### 考试陷阱

- 未告知客户便更改收费计算方法 → 违反标准 V(B)，**即使变更后费用下降**。
- 仅向潜在客户通报投资授权变更（提高市值上限、加入非美国股票），却未通知**现有**客户 → 违反标准 V(B)。
- 切换至新的估值模型，或将选股权限移交给投资委员会，均属于流程的重大变更 → 必须披露。
- “基于公司拥有 50 万盎司黄金的**事实**”——估算储量属于**观点** → 违反标准 V(B)。
- 因担心“模糊卖点”而在营销材料中隐去策略容量限制 → 违反标准 V(B)，即使当前规模远未触及上限。

#### 应用案例

**例 3 —— 披露收费计算方法的变更（Marc Maalouf）。** 他所在的公司悄悄将计费基数从日均余额改为期末市值，并开始将现金纳入计费基数。  
**要点：** 公司可以更改计费方法，但必须告知客户——未经披露擅自更改，即使最终费用降低也属不当。

**例 5 —— 将观点当作事实陈述（Richard Dox）。** 根据岩心样本，Dox 估算 Boisy Bay Minerals 拥有超过 50 万盎司黄金，并在报告中写道：“基于公司拥有 50 万盎司待开采黄金的事实，我给出强烈买入建议。”  
**要点：** 违反标准 V(B)——储量估算是一种定量的**观点**，而非客观事实。

**例 7 —— 通知基金投资授权变更（May & Associates）。** 这家小盘股管理公司的首席投资官将选股的市值上限从 US\$2.5 亿提高到 US\$5 亿，却只更新了发给潜在客户的营销资料。  
**要点：** 必须同时通知**现有**客户——部分客户在多管理人组合中正是将 May 作为小盘股专家来配置的。

**例 15 —— 通知风险与局限性（Yuri Yakovlev）。** 他管理的非流动性小盘股策略在规模超过约 US\$1 亿后可能运作困难；市场总监 Alan Wellard 在募资材料中省略了这一容量限制，而 Yakovlev 因基金当前规模只有 US\$1,200 万也未提出异议。  
**要点：** 双方均未能披露一项重大局限性；他们必须向客户充分说明或重新检视适当性。

### 标准 V(C) 记录保存

> 会员及候选人必须建立并保存适当的记录，以支持其投资分析、建议、行动以及其他与客户和潜在客户之间的投资相关沟通。

保存能够支持你研究**范围**和行动**理由**的记录——不仅针对买入/卖出决策，也包括**决定维持不变**的复核过程。具体需要保存哪些记录取决于你的职责。纸质或电子形式均可。

#### 指引要点

| 要点 | 核心内容 |
| --- | --- |
| **记录示例** | 公司调研纪要、公司新闻稿/演示文稿、模型输入与输出、组合风险分析、外部管理人遴选标准、客户 IPS 会议纪要、外部研究报告 |
| **新媒体记录** | 媒介形式无关紧要——保存电子邮件、短信、博客文章及社交媒体帖子；公司或监管政策可能滞后，因此个人需承担更多责任 |
| **归属公司财产** | 记录属于公司财产；仅在获得**明确同意**后方可带走原件或副本至新雇主。在新公司应通过**公开来源或标的公司**重新建立支持材料，而不能凭记忆或使用原公司档案 |
| **当地要求** | 遵守监管机构与公司规定；若无明确规定，至少保存 **7 年** |

#### 建议程序

- 记录保存总体上属于**公司**职责，但你必须将支持当前投资沟通的研究笔记与文档（电子或纸质）妥善归档。

#### 考试陷阱

- 带走你自己搭建的模型背后的支持记录副本 → 违反标准 V(C)。
- 在支持记录无法获取时仍直接沿用老东家的旧报告 → 必须先重新建立支持记录。
- 报告中使用的二手研究或第三方研究也必须一并保存。

#### 应用案例

**例 1 —— 记录保存与 IPS 目标及建议（Nikolas Lindstrom）。** 在科技股连续三年亏损后，一位客户投诉组合中 35% 的科技股配置；而 IPS 设定的基准中原本就包含 35% 的科技股权重。  
**要点：** 基准权重记录、IPS 文件、给客户的解释以及定期 IPS 更新记录共同证明他遵守了标准 V(C)。

**例 2 —— 记录保存与研究流程（Malcolm Young）。** 他的奢侈品零售报告参考了管理层访谈、实地走访、客户调研以及其他分析师的研究。  
**要点：** 他必须记录并保存上述全部材料，包括二手或第三方研究——否则违反标准 V(C)。

**例 3 —— 记录属于公司而非个人财产（Martin Blank）。** Blank 被竞争对手挖角后，带走了支持他在 GPIM 期间所建模型的记录副本。  
**要点：** 违反标准 V(C)——那些记录属于 GPIM；他必须在新公司重新建立支持记录。

## 标准 VI 利益冲突
### 标准 VI(A) 避免或披露冲突

> 会员及候选人必须避免或充分、公平地披露所有可以合理预期会损害其独立性与客观性，或妨碍其各自对客户、潜在客户和雇主履行职责的事项。会员及候选人必须确保此类披露醒目、使用通俗易懂的语言，并有效传达相关信息。

利益冲突是指任何可以合理预期会损害独立性与客观性，或引发偏颇质疑的事项——可能发生在客户、雇主与你自身利益之间。常见诱因：奖励短期表现的激励与奖金结构。**最佳实践是避免**实际或表面上的利益冲突；当无法合理避免时，必须进行**清晰且完整的披露**。披露的频率与方式由你自行决定；当冲突发生重大变化时（例如奖金从按年度利润考核改为按季度利润考核），必须更新披露，且宜从严把握、宁可多披露勿漏披露。

#### 向雇主披露

- 向雇主提供足够信息以便其**评估影响**。及时报告：所分析或推荐股票的持股情况、外部董事席位，以及财务或其他压力。
- 遵守雇主旨在防范哪怕只是**表面**利益冲突的限制规定（如个人交易、外部兼任董事）。
- 避免可能妨碍清晰判断或全心履职的冲突；若无法避免，应如实报告。

#### 向客户披露

- **必须始终**避免或披露的事项：与发行人的关系——担任董事或顾问、投行业务、承销与财务关系、经纪自营商**做市**活动，以及重大的**实益所有权**。
- **实益所有权（Beneficial ownership）** = 直接或间接的经济利益，或对证券行使投票权或处置权的权力。
- 还应披露收费安排、次级顾问协议、非标准收费结构，以及公司因推荐而获益的安排（例如共同基金服务费返还）。

#### 跨部门、持股与董事身份冲突

| 来源 | 核心要点 |
| --- | --- |
| **跨部门冲突** | 来自发行人、投行或市场营销部门要求覆盖或推荐某只股票的压力；券商发起的风险投资合伙企业 → 解决或披露 |
| **股票所有权** | **最常见**的冲突；一刀切禁止持股固然可行但可能过于严苛——必须披露你在所推荐标的中的任何实益所有权 |
| **董事会成员 / 董事** | 三重冲突：(1) 对客户的职责 vs. 对公司股东的职责；(2) 作为报酬获得的证券或期权；(3) 接触**重大非公开信息** → 使用**防火墙**将董事与投资决策隔离开来 |

#### 建议程序

- 教材未对标准 VI(A) 单独列示“建议程序”——参见标准 VI(B)。

#### 考试陷阱

- 自己持有该股票却未作披露而直接推荐 → 违反标准 VI(A)；最佳实践是将该股票的研究覆盖移交给另一位分析师。
- 新设定的**季度**奖金制度诱使基金经理买入高贝塔股票，背离长期 IPS → 必须向客户披露薪酬安排的这一变化。
- 因推销某只股票而从股票推广方处收取额外报酬 → 必须向客户和雇主披露；最佳实践 = 拒绝。
- 在未告知雇主双方关系的情况下聘用朋友的公司 → 违反标准 VI(A)。

#### 应用案例

**例 1 —— 利益冲突与业务关系（Henry Weiss）。** Williamsburg 20 年来包揽了 Jimco 的全部并购业务，且公司高管在 Jimco 子公司董事会任职；Weiss 正在撰写一篇关于 Jimco 的研究报告。  
**要点：** 他必须在报告中披露 Williamsburg 与 Jimco 的这一特殊关系。

**例 3 —— 利益冲突与个人持股（Karl Fargmon）。** 在他发布 Kincaid Printing 的买入报告后，他的妻子继承了价值 US\$300 万的 Kincaid 股票；随后公司要求他撰写跟踪报告。  
**要点：** 最低限度须向雇主并在报告中披露；最佳实践是交由另一位分析师撰写。

**例 5 —— 利益冲突与薪酬安排（Sarah Snead）。** 她所在的公司推出了按季度同业相对排名发放的奖金；她于是为长期养老金账户买入高贝塔股票，这似乎违背了它们的 IPS。  
**要点：** 违反标准 VI(A)——她未能向客户披露这一与客户目标相冲突的新薪酬安排。

**例 6 —— 利益冲突与薪酬安排（Kevin Carter）。** Badger Company 的一位股票推广方为鼓励他向客户推销 Badger 股票而向他支付额外报酬；他既未告诉客户也未告诉雇主。  
**要点：** 违反标准 VI(A)；最低限度须披露——最佳实践是拒绝该提议。

### 标准 VI(B) 交易优先顺序

> 客户和雇主的投资交易必须优先于会员或候选人作为实益所有人的投资交易。

优先顺序：**客户 → 雇主 → 个人**。只要满足以下条件，个人投资并不违背道德：(1) 客户利益**未受损**，(2) 你**未从客户交易中谋取私利**，且 (3) 你**遵守**相关监管规定。当你需要作出与自己投资建议相反的个人交易时（如支付学费、购房首付、追加保证金），同样适用这三项检验标准。与客户共同投资未必总是产生冲突，但个人头寸绝不能损害客户投资。

#### 非公开信息与实益所有权

- 不得向任何人透露有关待执行交易或尚未发布研究的非公开信息，只要你对相关证券拥有**实益所有权**，或者该信息对其他人而言属于**重大**信息。
- 仅在客户和雇主获得充足机会采取行动**之后**，方可在拥有实益所有权的账户中交易。
- 个人账户包括你自己的账户、**家庭**账户（配偶、子女、直系亲属）以及享有经济利益的账户（信托、退休账户）。
- 本身就是**付费客户**的家庭成员应与任何其他客户同等对待——不得优待，**也不得歧视或不利对待**；如果你拥有实益所有权，仍可能适用事前审批与交易申报要求。

#### 建议程序

| 程序 | 核心要点 |
| --- | --- |
| **限制参与股票 IPO** | 双重冲突：看似抢占属于客户的热门机会；看似对未来决策的利益输送。应避免参与；即使不存在冲突，参与 IPO 也须**事先审批** |
| **限制私募配售** | **严格限制**加主管审查；可能被作为业务往来的回报，日后一旦上市又会诱使分析师推荐该股票 |
| **静默期 / 限制期** | 在客户交易前设置禁售期，以杜绝**抢先交易（front-running）**；至少所有参与投资决策流程的人员均受同一期限约束。大公司 → 实质上相当于禁止交易；小公司 → 主要用于防止抢先交易 |
| **报告要求** | (1) 在**入职时及至少每年一次**保密申报实益持股情况；(2) 所有个人交易的**复本成交确认单**及对账单；(3) 拟议交易的**事先审批（preclearance）** |
| **披露相关政策** | 向投资者充分披露个人投资政策——提供切实有用的细节，**而非模板套话** |

#### 考试陷阱

- 压住一份投资建议不发，以便自己先买入 → 违反标准 VI(B)。
- 为**配偶**账户买入稀缺的热门新股，而基金却一股未得 → 违反标准 VI(B)；基金优先。
- 为了避免显得偏袒，把父母的客户账户排在**最后**分配 IPO 股份 → 同样违反标准 VI(B)。
- 在内部广播刚结束几分钟、书面报告尚未送达客户前就为公司自营账户交易 → 违反标准 VI(B)。
- 员工从未提交个人交易申报表 → 该员工违反标准 VI(B)；其**主管**违反标准 IV(C)。

#### 应用案例

**例 1 —— 个人交易（Marlon Long）。** Long 没有向雇主推荐某只股票，因为他想先自己买入。  
**要点：** 违反标准 VI(B)——他抢在雇主之前利用了自身的研究成果。

**例 2 —— 为家庭成员账户交易（Carol Baker）。** 她让经纪商为丈夫的账户买入稀缺的热门新股；她管理的基金和客户通常一股都拿不到。  
**要点：** 违反标准 VI(B)——必须优先为基金买入，并向雇主披露丈夫的账户。

**例 3 —— 平等对待家庭账户（Erin Toffler）。** 她在满足了所有其他合适客户之后，才把 IPO 股份分给父母的退休账户。  
**要点：** 违反标准 VI(B)——正常付费的父母理应与任何其他客户享有同等待遇。

**例 5 —— 在报告传播前交易（Denise Wilson / Ellen Riley）。** 在 Wilson 结束负面的闭路电视内部广播七分钟后，赶在报告送达客户之前，交易主管 Riley 平掉了看涨期权多头并建立了看跌期权仓位。  
**要点：** Riley 违反标准 VI(B)——公司在客户有机会依据该建议采取行动之前抢先交易。

### 标准 VI(C) 推荐费

> 会员及候选人必须酌情向雇主、客户及潜在客户披露因推荐产品或服务而从他人处收受或向他人支付的任何报酬、对价或利益。

披露使客户和雇主能够判断：(1) 推荐中是否存在任何**偏颇**，以及 (2) 服务的**全部成本**。本条同时适用于你**收取**的费用以及你向为你引荐客户的介绍人**支付**的费用。

#### 披露内容

| 项目 | 细节 |
| --- | --- |
| **何时** | 在客户签署任何正式服务协议**之前** |
| **性质** | 固定金额或百分比、一次性或持续性、与业绩挂钩、研究服务或其他非现金利益 |
| **价值** | **估算的美元价值** |
| **对价形式** | 所有形式的费用——现金、**软美元**或实物/服务折抵 |

#### 建议程序

- 鼓励雇主制定推荐费程序；雇主可完全禁止推荐费，否则应建立审批流程。
- 向客户通知经批准的推荐计划；**至少每季度**向雇主更新相关报酬的金额与性质。

#### 考试陷阱

- 以**研究服务和交易佣金**而非现金支付推荐费 → 仍须披露。
- 同一家银行内部不同部门之间的**内部**推荐费同样计入——推荐时须书面披露。
- 将佣金导向朋友的经纪商以换取客户推荐，却未告知雇主 → 违反标准 VI(C)。
- 取得雇主批准 + 在制定 IPS 时向客户披露 → **不**违规。

#### 应用案例

**例 1 —— 披露推荐安排与外部关联方（Willard White）。** Brady Securities 将免税账户推荐给 Lewis Brothers，以换取研究服务、市场评论以及全部股票交易佣金；White 接手了由 Brady 的 Harold Hill 推荐来的 Maxwell Inc. 利润分享计划，却未披露这一安排。  
**要点：** 违反标准 VI(C)——以服务和佣金形式支付的推荐费同样必须披露。

**例 2 —— 披露跨部门推荐安排（James Handley）。** 他因向 Central Trust Bank 的其他部门推荐客户而获得报酬，却未告知客户。  
**要点：** 违反标准 VI(C)——内部推荐费也在约束之列；必须书面披露其性质和价值。

**例 3 —— 披露推荐安排并告知公司（Katherine Roberts）。** 她将 Katama 的交易佣金导向同学所在的一家缺乏竞争力的券商 Naushon，而 Naushon 则回馈给她高净值客户推荐。  
**要点：** 因未通知雇主而违反标准 VI(C)。

**例 4 —— 披露推荐安排与外部组织（Alex Burl）。** 经主管批准，他将学校家长推荐客户所得费用的一部分捐赠给孩子就读的学校，并在建立 IPS 时向客户说明了这一安排。  
**要点：** **不违规**——已事先获得雇主批准并向客户充分披露。

## 标准 VII 作为 CFA 协会会员或 CFA 候选人的责任
### 标准 VII(A) 作为 CFA 协会项目参与者的行为

> 会员及候选人不得从事任何损害 CFA 协会声誉或诚信、CFA 持证资格声誉或诚信，或 CFA 协会项目完整性、有效性或安全性的行为。

旨在保护公众对于特许资格体现**真才实学与道德操守**的信心，涵盖**所有** CFA 协会项目（如 CIPM、Investment Foundations）。受约束的行为包括：
- 在任何考试中提供或接受协助（**作弊**）；
- 违反项目规则、规章与考场政策；
- 向候选人或公众泄露**保密的**项目或考试信息；
- 无视或企图规避考试安全措施；
- 不当利用与 CFA 协会的关联谋取个人或职业目的；
- 在**职业行为声明（PCS）**或持续教育项目中作虚假陈述。

#### 保密考试内容

| 可以讨论 | **不得**披露 |
| --- | --- |
| 在学习小组或与他人讨论非保密信息及教材内容 | 考题的**具体细节** |
| 考试难度感受、个人自我发挥评价 | 考过或**未考到**的**宽泛主题领域及公式** |
| 对 CFA 协会、其政策或倡导立场的意见与不同看法 | 夹带具体考试内容信息的观点表达 |

在 CFA 协会正式公布之前，所有考试内容均处于保密状态。CFA 协会会对博客、论坛和社交网络进行巡查监控。

#### 其他项目限制与志愿者

- 违反任何考试政策（**计算器**政策、**个人物品**政策、**考生誓言**）均违反标准 VII(A)。
- 参与命题、考务或阅卷的会员志愿者不得泄露或打听：考题或备选考题、**评议讨论**或**评分**信息。同样的诚信要求适用于 CFA 协会的所有其他项目。

> [!IMPORTANT]
> **考生誓言（Candidate Pledge）：** 考前我未提供亦未接受考试内容；考中我将不会这样做；考后我不会披露考试的**任何部分**，也不会带走考试材料。包括答题内容在内的所有考试材料均归 CFA 协会所有。违规后果 → 成绩作废，并可能被暂停或终止候选人资格。

#### 考试陷阱

- “考了好多衍生品——我数了有 18 道！完全没考 IPO 分配” → 违反标准 VII(A)；只说考试很难是可以的。
- 在论坛开帖一起还原并推算最难考题的答案 → 违反标准 VII(A)。
- 把最难的考题发给考培机构 → 违反标准 VII(A)；考培机构中身为会员或候选人的员工同样违规。
- 利用地方协会志愿者身份来宣传自己的客户 → 违反标准 VII(A)。
- 把 GIPS 执行委员会委员身份包装成客户优势来推销 → 违反标准 VII(A)；仅客观陈述该职务是可以的。

#### 应用案例

**例 2 —— 将书面材料带入考场（Loren Sullivan）。** 他在参加二级考试前把公式写在手心；被监考官发现。  
**要点：** 违反标准 VII(A)、项目规则以及考生誓言。

**例 3 —— 考试时间结束后继续作答（John Davis）。** 在听到“立即停笔”指令以及此后两次警告后，他仍然继续填涂答题卡圆圈。  
**要点：** 违反标准 VII(A)——企图获取不公平优势且无视监考官指令。

**例 4 —— 分享考试内容（Annabelle Rossi）。** 她在博客上写道二级考试很难，她数到有 18 道衍生品题目，且没有考 IPO 分配问题。  
**要点：** 评价难度和自我表现是可以的；透露**考了什么和没考什么**违反标准 VII(A)。

**例 7 —— 讨论阅卷标准与结果（Wesley Whitcomb）。** 阅卷结束后，他告诉身为考生的同事自己批改了哪道题、评分标准答案是什么，以及几乎没几个人考得好。  
**要点：** 违反标准 VII(A) 及阅卷人协议。

### 标准 VII(B) 对 CFA 协会、CFA 持证资格及 CFA 项目的提及

> 在提及 CFA 协会、CFA 协会会员资格、CFA 持证资格或 CFA 项目候选人身份时，会员及候选人不得歪曲或夸大 CFA 协会会员资格、持有 CFA 持证资格或参加 CFA 项目的含义或影响。

不得作出与持证资格挂钩的承诺或保证，也不得有任何暗示**卓越投资业绩**的表述。客观陈述持证的益处、对道德规范的承诺或项目本身的严谨性是可以的；关于相对优势的说法若明确作为**个人观点**表述则可以——否则需要事实依据。本条适用于所有形式：信笺抬头、名片、个人简介、名录、广告、宣传册、简历以及口头陈述。

#### 会员资格、持证资格与候选人身份

| 身份 | 规则 |
| --- | --- |
| **会员（Member）** | 每年提交**职业行为声明（PCS）**并缴纳**会费**以保持活跃状态。失效 → 不得以活跃会员自居；可以说自己过去曾是会员 |
| **持证人（Charterholder）** | 完成全部项目并通过所需工作经验审核，且须持续满足会员要求。失效 → **丧失**使用 CFA 称号的权利；可以说“曾是 CFA 持证人” |
| **网络形象** | 不得将 CFA 称号关联到化名或匿名网络账号上 |
| **候选人（Candidate）** | 报名申请获批**且**已注册参加某次考试，或已参加考试正等待成绩。已注册但缺考 → 在重新报名参考前不属于活跃候选人 |

> [!IMPORTANT]
> 候选人**绝不可**陈述或暗示存在**部分持证资格**（如“CFA, Level II”）或**预期完成日期**（如“CFA, Expected 2011”）。连续三年一次性通过全部级别考试可以作为**客观事实**陈述；由此暗示具备卓越能力则违反标准 VII(B)。

#### 正确 vs. 不当提及示例（教材图表 Exhibit 3）

| 正确 | 不当 |
| --- | --- |
| “完成 CFA 项目提升了我的投资组合管理技能。” | “CFA 持证人能够取得更好的投资业绩。” |
| “John Smith 连续三年通过了 CFA 项目的全部三级考试。” | “John Smith 连续三次尝试便通过了全部三级 CFA 考试，跻身顶尖精英之列。” |
| “CFA 持证资格获得全球认可，证明持证人成功完成了一项严谨而全面的学习项目……” | “作为一名 CFA 持证人，我是管理客户投资最有资格的人选。” |
| “CFA 持证资格带来的公信力以及 CFA 项目培养的技能，是我未来职业发展的关键资产。” | “作为一名 CFA 持证人，Jane White 在交易执行方面提供最佳价值。” |
| “我报名参加 CFA 项目是为了获取全球投资管理行业最高水准的资质认证。” | “注册成为 CFA 项目候选人可确保一个人在债券估值方面变得更出色。” |
| “我已通过 CFA 项目一级考试。” | “CFA, Level II” |
| “我是 2010 年 CFA 项目三级候选人。” | “CFA, Expected 2011” |
| “我已通过 CFA 项目全部三个级别，待完成所需工作经验后或有资格获授 CFA 特许资格。” | “John Smith，特许资格待批（Charter Pending）” |

#### 建议程序

- 向公司的**法务、合规、公关及市场营销**部门提供关于标准 VII(B) 的书面资料。
- 鼓励建立由合规等中心权威部门审定的 CFA 提及**标准模板**。

#### 考试陷阱

- “所有合伙人均一次性通过考试”是可以的——将其与基金**业绩**挂钩 → 违反标准 VII(B)。
- 停止提交 PCS 和缴纳会费后仍在名片上印“CFA” → 违反标准 VII(B)；退休会员必须先申请**退休（retired）**会员资格。
- 名片上 CFA 与 PhD 的排列顺序取决于个人偏好——两个头衔之间用**逗号**分隔。
- 博客作者署名“Expert CFA” → 违反标准 VII(B)；网络署名必须使用持证人的真实全名。

#### 应用案例

**例 1 —— 连续年份通过考试（AZ Investment Advisors）。** 一则广告宣称公司所有合伙人均为首次参考即通过考试的持证人，并将此与旗下基金的卓越业绩联系起来。  
**要点：** 客观事实可以陈述，但将其与业绩或卓越能力挂钩违反标准 VII(B)。

**例 2 —— 使用 CFA 称号的权利（Louis Vasseur）。** 在外出旅行两年、未提交 PCS 也未缴纳会费后，他在名片姓名后印上了“CFA”。  
**要点：** 违反标准 VII(B)——在重新激活会员资格前，他使用该称号的权利已被暂停。

**例 3 —— “退休”CFA 协会会员身份（James Simpson）。** 退休后不再提交声明也不再缴费，但他继续在个人名片上保留“CFA”。  
**要点：** 违反标准 VII(B)——他必须申请退休会员身份（享受减免会费）才能继续使用该称号。

**例 6 —— 使用虚假名称（Barry Glass / “Expert CFA”）。** Glass 将一个由“Expert CFA”运营的博客中的因子纳入其基金模型。  
**要点：** “Expert CFA”违反标准 VII(B)——网络上提及 CFA 资格必须使用真实全名；Glass 违反标准 V(A)。
