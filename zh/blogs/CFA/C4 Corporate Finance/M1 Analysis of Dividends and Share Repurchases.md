# 股利与股票回购分析

公司如何派发现金（股利和回购）、关于派现政策为何可能重要的各种理论、回购对 EPS 和账面价值的影响，以及如何判断股利是否安全。

| 术语 | 含义 |
| --- | --- |
| **股利** | 由董事会宣告的分配（在欧洲大部分地区还需股东批准，美国不需要）。与债券利息不同，它是**可自主决定的** |
| **除息日** | 股票开始**不再**附带股利权利交易的第一天；股价大约下跌一个股利 |
| **派现政策** | 公司分配现金的方式：股利**和**股票回购 |
| **股利支付率** | 普通股股利 ÷ 归属于普通股股东的净利润 |

股利是总回报的重要组成部分：1926 年至 2018 年，标普 500 在股利再投资的情况下年回报 10.0%，而仅价格变动的回报为 5.9%。

## 股利的形式

**现金股利**

* **常规股利**：按计划支付（美国和加拿大按季度，日本和澳大利亚按半年，德国按年）。公司努力维持或提高常规股利，避免因暂时性问题而削减；意外的提高通常是好消息。
* **特别（额外）股利**：在常规股利之外支付，或由不定期派息的公司在业绩强劲的年份或一次性事件后支付（如腾讯在腾讯音乐 IPO 后）。在**周期性**公司中很常见：较小的常规股利加上好年景时的额外股利。
* **清算股利**：公司清盘、出售部分业务并派发所得款项，或派发超过累计留存收益的金额时支付。它是**资本返还**，而不是盈利的分配。

**股票股利、拆股与并股**

* **股票股利**（红股）：以额外股份代替现金，通常为流通股的 2–10%。
* **拆股**：如 1 拆 2。**并股**：如 20 并 1。

**例子（AfriSage，额外股利）。** 其政策是普通股利至少为净利润的 35%。2018 年 EPS 为 ZAR14.23，DPS 为 ZAR7.61，支付率为 7.61/14.23 = **53.5%**（2017 年：10.68/12.65 = **84.4%**）。最低普通股利为 14.23 × 0.35 = **ZAR4.98**，因此额外股利为 7.61 − 4.98 = **ZAR2.63**。

### 对股东财富的影响

* **现金股利**：股价下跌一个股利，但在其他条件不变时，股东的财富（股票 + 现金）不变。
* **股票股利**：股数更多，财富相同。总成本基础不变，因此**每股**成本下降：100 股、每股 US\$10，在 5% 的股票股利后变为 105 股，每股 US\$1,000/105 = **US\$9.52**。通常不征税。声称的好处：更大的流通量、更好的流动性，以及处于"最佳"交易区间的价格（在美国常为 US\$20–80）。
* **拆股**：所有每股数据按比例下降；P/E、股息率和市值不变。1 拆 2 在经济上等同于 100% 的股票股利；只有会计处理不同。
* **并股**：股数更少，价格更高，市值不变。用于把价格拉回可交易的区间（上市最低价要求；机构回避低于 US\$5 的股票）；最常见于财务困境中或之后。

| | 股票股利 | 拆股 |
| --- | --- | --- |
| 总权益 | 不变 | 不变 |
| 权益账户 | 留存收益 → 投入资本（新股数 × 价格） | 不变 |
| 典型规模 | 2–10% | 1 拆 2、1 拆 3 |

**例子。**

* **3% 的股票股利**，对持股 10% 的股东：股数 1,000,000 → 1,030,000；EPS US\$1.00 → US\$0.97；股价（P/E 20）US\$20 → US\$19.42。该股东的 100,000 股变为 103,000 股，前后价值都是 **US\$2,000,000**。
* **1 拆 2**：股数 4m → 8m；股价 €40 → €20；EPS €1.50 → €0.75；DPS €0.50 → €0.25。前后股息率都是 **1.25%**，P/E 都是 **26.7**。
* **Globus Maritime 10 并 1**：US\$4.25 → **US\$42.50**。并股本身不会毁灭财富：市值不变。

### 对财务比率的影响

**现金**股利会把现金拿走：资产和权益下降，因此流动性比率下降，杠杆比率（D/A、D/E）上升。**股票**股利或拆股不会把任何东西移出公司：总资产和权益不变；只有股数、股价和 EPS 改变。

| | 现金股利之后 | 股票股利 / 拆股之后 |
| --- | --- | --- |
| 资产（现金） | 降低 | 不变 |
| 权益 | 降低 | 不变 |
| 股价 | 降低 | 降低 |
| EPS | 不变 | 降低 |
| P/E | 降低 | 不变 |
| 流动性比率 | 降低 | 不变 |
| 杠杆比率 | 升高 | 不变 |

**例子（现金股利与股票股利）。** 现金 200，其他流动资产 300，流动负债 250，总资产 1,000，债务 400，权益 600（US\$ 百万）；1 亿股，每股 US\$20。

| 比率 | 之前 | US\$100m 现金股利之后 | 5% 股票股利之后 |
| --- | --- | --- | --- |
| 流动比率 | 500/250 = 2.00 | 400/250 = **1.60** | 2.00 |
| 现金比率 | 200/250 = 0.80 | 100/250 = **0.40** | 0.80 |
| 债务/权益 | 400/600 = 0.67 | 400/500 = **0.80** | 0.67 |
| 债务/资产 | 400/1,000 = 0.40 | 400/900 = **0.44** | 0.40 |

股票股利把 5m × US\$20 = US\$100m 从留存收益转到投入资本；权益仍为 600。股价跌至 20/1.05 = US\$19.05，市值（105m × 19.05 ≈ US\$2,000m）不变。

> [!IMPORTANT]
> 只有**现金**股利会把现金拿出公司。股票股利、拆股和并股只是把同一块饼切成不同的块：财富、总权益、流动性和杠杆都不变（不考虑信号作用）。

#### 考试陷阱

* 股票股利改变权益**账户**，但不改变**总**权益；拆股不改变任何账户。
* 股票股利降低的是**每股**成本基础，而不是总成本基础。
* 任何超过累计留存收益的股利都是清算股利（资本返还）。

## 股利政策理论

一种理论认为股利政策无关紧要（Miller–Modigliani）；其他理论则认为它重要。

| 理论 | 主张 | 提高股利对价值的影响 |
| --- | --- | --- |
| **MM 无关论** | 完美市场；投资者可以"自制"股利 | 无 |
| **一鸟在手** | 今天的股利比未来的收益风险更小 | 股权成本降低 → 股价 ↑ |
| **税收观点** | 股利的税负高于资本利得 | 应税投资者偏好低派现或回购 → 股价 ↓ |

### Miller–Modigliani（1961）

MM 假设**没有税收、没有交易成本、信息对称**，并且资本预算和资本结构既定。这时股利决策独立于投资和融资决策：

* 在派发 A\$1 股利之前价格为 A\$20 的股票，除息后为 A\$19：持有人无论如何都拥有 A\$20。
* 股利等同于回购。10,000 股；FCF A\$10,000；未来现金流现值 A\$190,000 → 股价 **A\$20**。回购 10,000/20 = **500** 股后，每股为 190,000/9,500 = **A\$20**。
* **自制股利**：如果不派发股利，持有 1,000 股、想要 A\$1,000 的股东以 A\$20 卖出 **50** 股即可。

MM 说的是股利**政策**无关，而不是股利本身无关。现实中的摩擦破坏了这一论证：发行成本（常为所筹资本的 4–10%）、投资者的交易成本和税收。

### 一鸟在手与税收

* **一鸟在手**：今天的股利比不确定的收益更有价值，因此派息公司的股权成本更低。MM 的回应：派发股利并不改变未来现金流的风险。
* **税收**：在股利税负高于资本利得的地方，应税投资者偏好低派现或回购（极端情况下不派股利）。在美国，自 2012 年起，合格股利和长期资本利得的最高税率为 20%。在中国内地，股票没有资本利得税，股利按持股期限不足 1 个月、1 个月至 1 年、超过 1 年分别按 20%、10% 或 0% 征税。

### 信号作用

管理层比投资者知道得更多，因此股利传递信息。

* 现金信号是可信的，因为它**难以模仿**：现金流没有增长的公司无法持续提高股利（除非借钱，且只能短期）。
* **首次派息或提高股利** → 正面：未来盈利增长，公告时有超额回报。**削减或取消** → 负面。在压力下维持股利，表明问题是暂时的。
* 例外：如果现金被再投资或削减显得审慎，削减也可能是正面的（Telstra 2017 年；BT 2018 年，股价 +6.9%）。首次派息可能传递信心，也可能表明公司已成熟（eBay 2019 年）。
* 持续提高股利的公司往往具有细分市场地位、盈利波动较小、ROA 高且负债低。

**例子。** Oracle 在 2009 年首次派息（每年约 US\$10 亿，相对于 US\$80 亿的经营现金流），被解读为它能够渡过经济低迷的迹象。一家前景不佳的公司为了好看而提高股利，之后必须削减，或者筹集昂贵的资本。

### 代理成本

* **管理层与股东**：股利把自由现金流从管理层手中拿走，否则管理层可能过度投资于 NPV 为负的项目（帝国建造）：即 Jensen 的**自由现金流假说**。过度投资风险越大的地方，市场对股利变化的反应越大。
* **股东与债权人**：大额股利把财富转移给股东并提高违约风险，可能导致投资不足。债券契约会限制累计分配，并设定保障或杠杆限制。

**例子。** 在两家支付率约 35% 的全股权竞争对手中，治理较弱（CEO 兼任董事长）、好项目较少的那家会被要求多派现，以遏制**过度投资**。公用事业公司派发高股利，然后发行股票：成本高，但股票市场随后会监督管理层和监管者。

> [!IMPORTANT]
> 股利**降低**管理层–股东代理成本（过度投资），但**加剧**股东–债权人冲突（投资不足、违约风险）。不要把二者弄反。

#### 考试陷阱

* MM 假设没有税收、没有交易成本且信息对称；它们并不假设投资者偏好股利。
* 当股利税负高于资本利得时，税收观点支持**低**派现。
* 削减股利通常是负面的，但并非总是如此。

理论上，再投资机会应当决定派现：年轻、快速增长的公司派得少，成熟公司派得多。关于派现是否影响价值的证据并无定论，因此分析师至少应检查公司的政策是否与其机会及法律和财务环境相符。

## 实践中影响股利政策的因素

一旦市场不完美，投资、融资和股利决策就不再相互独立。

| 因素 | 对派现的影响 |
| --- | --- |
| **投资机会** | 盈利项目越多 → 派现越**低**（内部资金更便宜）。变化快的行业（科技）派得少；机会少的公司（公用事业）派得多 |
| **未来盈利的波动性** | 盈利波动越大 → 提高股利的幅度越小、频率越低 |
| **财务灵活性** | 需要现金 → 降低股利，或采用回购（无承诺） |
| **税收** | 见[税收考虑](#tax-considerations) |
| **发行成本** | 新股权比留存收益更贵，因此避免需要发行股票才能支付的股利；对小公司影响更大 |
| **合同与法律限制** | 强制股利（巴西）、资本减损规则（美国、加拿大）、债券契约、优先股股利（累积拖欠的优先） |

调查显示，管理层根据**长期可持续盈利**设定目标支付率，关注**变化**而不是水平，并避免可能不得不撤回的提高：即**股利平滑**。Skanska 在 2019 年为保持灵活性进行了 30% 的"预防性"削减；其股价下跌 9%，然后在两个月内升至比公告前高 7% 的水平。

**例子。**

* **Boar's Head**：经营现金流 £5 亿，而 NPV 为正的项目需要 £8 亿，且负债已高于平均水平 → **不首次派息**：它不会仅仅为了派息而发行股票。
* **Makinasi Appliances** 在预期亏损、销售下滑、发行 US\$5,000 万债券和评级下调的情况下，把季度股利从 US\$1.60 削减到 US\$0.70。主要因素：**盈利波动性**和**财务灵活性**，以及发行成本。

## 税收考虑 {#tax-considerations}

### 双重征税

公司盈利先在公司层面征税，作为股利派发时又在股东层面征税：

$$
\begin{aligned}
Div_{net} ={}& EBT\times \text{payout}\\
&\times(1-t_{c})(1-t_{i})
\end{aligned}
$$

$$
t_{\text{eff}} = 1-(1-t_{c})(1-t_{i})
$$

其中 $t_c$ 是公司税率，$t_i$ 是个人的股利税率，$t_{\text{eff}}$ 是有效税率。例如，US\$100 税前利润按 35% 的公司税率纳税后剩 65 可派发；按 15% 的个人税率纳税 9.75，剩 55.25。有效税率为 (35 + 9.75)/100 = **44.75%**。

### 股利归集抵免

已分配的利润只按**股东的**税率征税一次（澳大利亚、新西兰）。股东就公司已缴税款获得**抵免额（franking credit）**，因此有效税率就是 $t_i$：

$$
Div_{net} = EBT\times \text{payout}\times(1-t_{i})
$$

例如，A\$100 税前利润按 30% 的公司税率纳税，派发 70：税率 15% 的股东应缴 15 − 30 = **(15)**，即退税；税率 47% 的股东应缴 47 − 30 = **17**。有效税率分别为 **15%** 和 **47%**。

### 分率制

作为股利派发的盈利按比留存盈利**更低**的公司税率征税，然后作为普通收入再次征税：仍是双重征税，但 $t_{c,\text{dist}}<t_{c,\text{retained}}$：

$$
t_{\text{eff}} = t_{c,\text{dist}}+(1-t_{c,\text{dist}})\,t_{i}
$$

例如，派发的盈利按 20% 征税（留存按 35%），每 100 剩下 80 的股利；股东税率 35%，剩 0.65 × 80 = **€52**。有效税率 = 20% + 0.35 × 80% = **48%**。

**例子（相同输入下的三种制度）。** 税前 €100，全部派发；公司税率 30%；股东的股利税率 40%。

| 制度 | 公司税 | 股利 | 个人税 | 投资者所得 | 有效税率 |
| --- | --- | --- | --- | --- | --- |
| 双重征税 | 30 | 70 | 0.40 × 70 = 28 | 42 | **58%** |
| 归集抵免 | 30 | 70 | 0.40 × 100 − 30 抵免 = 10 | 60 | **40%** |
| 分率制（派发 20% / 留存 30%） | 20 | 80 | 0.40 × 80 = 32 | 48 | **52%** |

### 股东偏好

* 投资者希望股利的税**率**更低；他们偏好更高还是更低的**派现**，取决于股利税率与资本利得税率的对比。
* 资本利得税可以**递延**到出售时缴纳；股利税在收到时就要缴纳，即使再投资也一样。死亡时的计税基础提升（美国、澳大利亚）也有利于资本利得。
* **免税**投资者（养老基金、捐赠基金）无所谓；高派现股票可能放在免税账户中。
* 全球投资者还面临外国预扣税（根据税收协定，通常可在本国抵免）。

#### 考试陷阱

* 双重征税：个人税适用于**公司税后**的股利。
* 归集抵免：有效税率就是股东的税率；低税率档的投资者可以获得**退税**。
* 分率制：对已分配的盈利使用**较低**的公司税率。

## 股利支付政策

### 稳定股利政策

**最常见**的政策：股利跟随长期可持续盈利，忽略短期波动（如 Gruppo Hera 稳步提高 DPS，而其支付率在约 52% 到 125% 之间波动）。Lintner（1956）发现，公司根据可持续盈利设定**目标支付率**，关心股利的**变化**，只有在极端情况下才削减。**目标支付率调整模型**：

$$
E(Div) = Div_{t-1}+\Delta Div
$$

$$
\Delta Div=\frac{E(EPS)\times \text{Target}-Div_{t-1}}{N}
$$

其中 Target 是目标支付率，$N$ 是股利调整到目标所需的年数，因此调整因子为 $1/N$。

**例子。**

* $Div_{t-1}$ = US\$0.40，目标 50%，因子 0.2，EPS 升至 US\$1.50：增加 = (0.75 − 0.40) × 0.2 = **US\$0.07** → US\$0.47。下一年 EPS 降到 US\$1.34：(0.67 − 0.47) × 0.2 = **US\$0.04** → US\$0.51。股利仍然上升，因为它低于目标。
* **Luna Inc.**：$Div_{t-1}$ = US\$0.40，预期 EPS US\$2.80，目标 30%，4 年：0.40 + (0.84 − 0.40)/4 = **US\$0.51**。支付率从 20% 降至 0.51/2.80 = **18.2%**。

### 固定支付率政策

派发固定比例的盈利：$Div = \text{Payout ratio}\times NI$。这种政策很少使用，因为股利会随盈利波动。

**例子（Pampas Fertilizer）。** 它从每季度固定 ARS1.50 改为季度盈利的 25%：如 2019 年第四季度 EPS 9.32 → 9.32 × 0.25 = ARS2.33。

**例子（相同盈利，两种政策）。** 去年 EPS US\$2.00，DPS US\$0.80；未来三年 EPS 为 US\$3.00、US\$2.60、US\$3.40；支付率或目标为 40%；调整因子 0.5。

| 年份 | EPS | 固定支付率 | 稳定（目标调整） | 稳定政策支付率 |
| --- | --- | --- | --- | --- |
| 1 | 3.00 | 1.20 | 0.80 + (1.20 − 0.80) × 0.5 = **1.00** | 33.3% |
| 2 | 2.60 | 1.04 | 1.00 + (1.04 − 1.00) × 0.5 = **1.02** | 39.2% |
| 3 | 3.40 | 1.36 | 1.02 + (1.36 − 1.02) × 0.5 = **1.19** | 35.0% |

固定支付率的股利在第 2 年下降；稳定股利每年都上升，即使 EPS 下降也是如此。

| | 稳定股利 | 固定支付率 |
| --- | --- | --- |
| 依据 | 长期可持续盈利 | 当期盈利 |
| 股利波动性 | 低 | 高 |
| 支付率 | 变化 | 固定 |
| 实践中的使用 | **最常见** | 很少 |

#### 考试陷阱

* 把调整因子乘以**差距**（目标 − 上一期股利），再加到上一期股利上。因子 = **1/年数**。
* 如果目标低于上一期股利，公式会削减股利，但实践中公司更愿意维持股利。

### 全球趋势

* 在大多数发达市场（美国、加拿大、欧盟、英国、日本），**派息公司的比例**长期下降；美国指数中的派息公司少于欧洲指数。
* **总**股利和支付率总体上升：股利集中在数量更少、规模更大、盈利更强、增长机会更少的公司。亚太地区的股利在 2009 年至 2019 年间增至三倍。
* **回购**在增加：美国自 1980 年代初，英国和欧洲自 1990 年代初，亚洲（中国、日本）在 2010 年代后期。
* 更好的治理和披露（IFRS、投资者保护）→ 首次派息**更少**、派现不那么慷慨，因为股利作为信号和代理控制手段的作用减弱。

## 股票回购

**股票回购**是公司买回自己的股票。公司持有的股票是**库存股**（可以再发行；注销的股票则退出）；它们没有股利和投票权，并被排除在 EPS 之外。

| | 现金股利 | 股票回购 |
| --- | --- | --- |
| 承诺 | 宣告即**承诺**公司 | 授权**不**构成承诺 |
| 分配 | 对所有持有人**按比例** | 只有卖出者得到现金 |
| 预期会持续 | 是（常规） | 一般不会 |

许多市场对回购的限制比美国多（需股东批准，常有 10% 的上限）。美国的回购在 SEC 规则 10b-18（1982 年）之后增长。

### 回购方式

* **公开市场**：在市场上买入股票；时间和数量灵活。
* **固定价格要约收购**：以固定价格（通常有溢价）收购固定数量的股票；若超额认购，则按比例购买。
* **荷兰式拍卖**：股东报价；公司找到能买到目标股数的**最低**价格，并对所有被接受的报价支付同一个出清价格。
* **直接协商**：从特定大股东处购买，常有溢价（若卖方需要流动性也可能折价）。

| 方式 | 成本 | 灵活性 | 速度 |
| --- | --- | --- | --- |
| **公开市场**（最常见；在美国和加拿大以外几乎是唯一方式） | 时机好则成本低 | **最高**：没有完成的义务 | 慢 |
| **固定价格要约** | 较高（溢价；可能是正面信号） | 低 | **最快** |
| **荷兰式拍卖** | 通常**低于**固定价格要约 | 低 | 快，通常比固定价格稍慢 |
| **直接协商**（清除大股东、阻止激进投资者、绿票讹诈） | 溢价会从剩余持有人那里**转移财富** | 不适用 | 不适用 |

**例子（BCII，以 C\$37 计 5m 股）。** 以 C\$40 进行固定价格要约，成本为 5m × 40 = **C\$200m**；以 C\$38 出清的荷兰式拍卖成本为 **C\$190m**，节省 **C\$10m**。

### 对 EPS 的影响

$$
EPS_{\text{after}} = \frac{E - C}{N_{\text{after}}}
$$

其中 $E$ 是回购前的盈利，$C$ 是所用资金的税后成本（新债务的利息，或现金放弃的利息收入），$N_{\text{after}}$ 是回购后的流通股数。

* **用富余现金回购**：资产和权益下降，杠杆上升。只有当这些现金原本赚不到其资本成本时（如闲置现金），EPS 才会上升。
* **用债务回购**：债务上升、权益下降，杠杆上升得更多。**如果盈利收益率（E/P）高于税后债务成本，EPS 上升**，否则下降。注意 $E/P = 1/(P/E)$。

**例子。**

* **Takemiya**（富余现金收益约为 0）：10m 股，NI ¥100m，股价 ¥120；用 ¥240m 现金以 ¥140 买入 → 约 1.7m 股，剩 8.3m 股。EPS 从 ¥10.00 升至 100/8.3 ≈ **¥12.00**（+20%；未四舍五入为 ¥12.07）。
* **Selamat**（债务）：借 MYR12m 以 MYR60 买入 → 200,000 股。盈利 MYR6.6m；股数 2.2m → 2.0m；EPS MYR3；E/P 5%。税后成本为 5% 时：(6.6 − 0.6)/2 = **MYR3.00**，不变。为 6% 时：(6.6 − 0.72)/2 = **MYR2.94**，下降。
* **有利息收入的富余现金**：NI US\$50m，10m 股，EPS US\$5.00，股价 US\$50 → E/P 10%。动用税后收益 4% 的 US\$100m 现金买入 2m 股，损失 4 的利息：NI 46，EPS 46/8 = **US\$5.75**（上升）。若现金收益为 10%：40/8 = **US\$5.00**（不变）；12% 时：38/8 = **US\$4.75**（下降）。所以 E/P 检验对现金同样适用：当放弃的税后回报低于 E/P 时，EPS 上升。

> [!IMPORTANT]
> **EPS 更高 ≠ 股东财富更多。** 同样的现金也可以作为股利派发，任何资本利得可能只是替代了放弃的股利。更高的杠杆也会提高要求回报率。

### 对每股账面价值的影响

$$
BVPS_{\text{after}} = \frac{\text{Book equity} - \text{Buyback}}{N - N_{\text{bought}}}
$$

如果回购价格高于当前 BVPS，BVPS **下降**；相等时不变；低于时**上升**。

**例子（以 US\$20 回购 US\$5m，两家公司各 10m 股）。** 买入 250,000 股，剩 9.75m 股。公司 A（账面权益 US\$100m，BVPS 10）：(100 − 5)/9.75 = **US\$9.74**，下降。公司 B（账面权益 US\$300m，BVPS 30）：(300 − 5)/9.75 = **US\$30.26**，上升。

#### 考试陷阱

* 把**税后**债务成本与 **E/P** 比较，而不是与税前利率或 P/E 比较。
* 使用回购**之后**的股数，并根据**回购价格**（包括任何溢价）计算回购的股数。
* 荷兰式拍卖：每个被接受的报价者都获得**相同**的出清价格。
* 公开市场 = 最灵活；固定价格要约 = 最快；荷兰式拍卖通常比固定价格要约便宜。

### 股利与回购在价值上等价

在其他条件不变（相同的**税收**和相同的**信息含量**）时，回购对股东财富的影响等同于**相同金额**的现金股利。

**例子（Rohit Chemical，10m 股，每股 Rs200，分配 Rs500m）。**

* 每股 Rs50 的特别股利：除息价 = (2,000m − 500m)/10m = **Rs150**；财富 = 50 + 150 = **Rs200**。
* 回购：500m/200 = 2.5m 股；股价 = 1,500m/7.5m = **Rs200**；无论是否卖出，财富都是 **Rs200**。

**例子（AfriCitrus，溢价回购）。** 10m 股，每股 ZAR200；以 ZAR250 从一位持有人处买入 ZAR500m 的股票 → 2m 股。新股价 = 1,500m/8m = **ZAR187.50**：其他持有人每股损失 **ZAR12.50**，转移给了卖方。

## 股利与股票回购的比较

回购公告之后会出现正的超额回报，在公告时以及之后两年（一些研究说五年），这与管理层在股票被低估时买入相一致。

| 回购的理由 | 解释 |
| --- | --- |
| **税收优势** | 在股利税负高于资本利得的地方；即使税率相同，资本利得税也可以递延 |
| **支撑股价 / 信号** | 管理层可以在股票看起来被低估时买入。反方观点：可能表明**缺乏好的投资机会** |
| **灵活性** | 不被预期持续，也没有完成的义务；股东自行选择是否卖出 |
| **抵消期权带来的稀释** | 买回期权行权时发行的股票 |
| **提高杠杆** | 债务融资的回购比现金融资的回购更能提高杠杆 |

提高 EPS 是一个弱理由：要求回报率随杠杆上升，而股数减少并不改变总自由现金流。

**例子（Deira Oasis，AED 百万）。** 债务 30，权益 70；回购 AED7m。

| | 之前 | 全部用现金 | 全部用债务 |
| --- | --- | --- | --- |
| 债务 | 30（30%） | 30（32%） | 37（37%） |
| 权益 | 70（70%） | 63（68%） | 63（63%） |
| 合计 | 100 | 93 | 100 |

用现金回购时 EPS 上升，因此权益的价值很可能高于 AED63m。用税后成本高于 E/P 的债务回购时 EPS 下降，因此权益价值低于 AED63m；若评级下调，债务价值也会降到 37 以下，因此新的权重并不确定。

**其他例子。**

* **ITOCHU**（2018–19 年）以平均 ¥1,993（共 ¥680 亿）回购 34,121,400 股，以使 ROE 达到至少 13%。
* 回购是**顺周期**的，并且替代了特别股利。Russell 1000：2007 年股利 US\$2,860 亿，回购 US\$6,800 亿；2008 年第四季度至 2009 年第三季度为 US\$2,620 亿对 US\$2,230 亿：回购削减得多得多。
* **Shenzhen Medical Devices** 在三年回购之后首次派发 ¥0.40 的股利（支付率 0.40/3.20 = **12.5%**，目标 25%）。首次派息与**更高**的未来增长相关，因此把它解读为"我们不再是成长型公司"是错误的，而 2% 的股票股利不会改变财富。这一政策是采用目标支付率调整的**稳定股利**。

#### 考试陷阱

* 当资本利得税率**低于**股利税率时，股东偏好回购。
* 按市价回购，股价不变；现金股利使股价下降一个股利；从一位持有人处溢价回购会转移财富。
* 回购可能传递低估信号（正面），也可能传递缺乏机会的信号（负面）。

## 股利安全性

| 比率 | 公式 |
| --- | --- |
| 支付率 | 股利 ÷ 净利润 |
| 股利保障倍数 | 净利润 ÷ 股利 |
| FCFE 保障倍数 | FCFE ÷ (股利 + 股票回购) |

$$
\begin{aligned}
FCFE ={}& CFO - FCInv\\
&+ \text{Net borrowing}
\end{aligned}
$$

* 支付率越高（保障倍数越低），削减的风险越高。大型成熟公司常以 **40–60%** 的支付率为目标，即约 **1.7×–2.5×** 的保障倍数。保障倍数接近 **1.0×** 时股利岌岌可危，除非下降是一次性的。
* 为股利提供资金的是 FCFE 而不是净利润，并且回购也算作派现：

| FCFE 保障倍数 | 含义 |
| --- | --- |
| = 1 | 派发了全部可用现金 |
| ≫ 1 | 在积累流动性 |
| ≪ 1 | **不可持续**：在消耗现金；将需要股权融资或削减资本支出 |

**例子（Mature European SA）。** NI €100m，股利 €40m → 支付率 **40%**，保障倍数 **2.5×**。

**例子（Lygon Resources，A\$ 百万）。**

| | 2015 | 2016 | 2017 | 2018 |
| --- | --- | --- | --- | --- |
| 净利润 | 540 | 458 | 399 | 341 |
| CFO | 837 | 824 | 679 | 628 |
| FCInv | 554 | 417 | 296 | 327 |
| 净借款 | (120) | (39) | 79 | (7) |
| 股利 | 121 | 256 | 277 | 323 |
| 回购 | 0 | 105 | 277 | 0 |
| 支付率 | 22.4% | 55.9% | 69.4% | 94.7% |
| 保障倍数 | 4.46× | 1.79× | 1.44× | 1.06× |
| FCFE | 163 | 368 | 462 | 294 |
| FCFE/(股利 + 回购) | 1.35× | 1.02× | 0.83× | 0.91× |

保障倍数降至 1.06×，FCFE 保障倍数在 2017–2018 年低于 1（即使 2017 年净借款为正）→ 停止回购，并考虑**削减股利**。

公司可能无法维持股利的**警示信号**：

* 支付率高（保障倍数接近 1×）且在恶化，并且相对于同行或自身历史偏高
* FCFE 保障倍数低于 1；派现靠**借款**或**削减生产性资本支出**来支撑
* 杠杆高于平均水平
* 股息率相对于自身历史非常高（StarHub 在 2019 年削减前为 9.4%）：高股息率是警告，而不是便宜货；市场价格可能已经在预示削减
* 有过削减股利的记录（股利稳定或上升的记录是加分项）

#### 考试陷阱

* 保障倍数 = NI/股利，是支付率的倒数。
* FCFE 保障倍数的分母包含**回购**；净借款要加上（负数 = 偿还）。
* 正的净借款会提高 FCFE，但它不是可持续的派现来源。

>
> **教材笔误。** Rohit Chemical 的解答中有一处把公司称为"WCII"（应为 RCII）。ITOCHU 的表格把平均价格印为"1.997"，实为 ¥1,997。分率制的表格标注为"每 €100"，但从 €200 税前利润开始（€100 留存，€100 分配）；48% 是按分配给股利的每 €100 计算的。
