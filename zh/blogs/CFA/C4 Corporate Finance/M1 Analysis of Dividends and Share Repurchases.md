# 股利

## 股利与股利政策的概念

股利的分类：

* 现金股利：向股东分配现金
  * 常规股利
  * 特别/额外股利：股价被高估时
  * 清算股利：破产时
* 股票股利
* 股票分割（例如 1 拆 2）
  * 反向股票分割（例如 20 并 1）

股利对股东财富的影响

* 现金：股价会下跌相当于股利的金额，但股东的财富不变
* 股票：只改变股数，不影响财富

股利对财务比率的影响

* 现金：
  * 减少资产负债表中的资产和权益
  * 现金减少，流动性比率下降
  * 财务杠杆比率（D/A、D/E）上升
* 股票：
  * 不影响资产和权益，股数增加
  * 股价和每股收益下降

|                           | 发放现金股利后 | 发放股票股利/拆股后 |
| ------------------------- | -------------------- | ----------------------------- |
| 资产（现金）             | 降低                | 不变                      |
| 权益                    | 降低                | 不变                      |
| 股价                     | 降低                | 降低                         |
| 每股收益                       | 不变             | 降低                         |
| 市盈率                       | 降低                | 不变                      |
| 流动性比率          | 降低                | 不变                      |
| 财务杠杆比率 | 升高               | 不变                      |

## 股利政策

MM 理论认为股利无关紧要。"一鸟在手"理论、税收理论、信息信号理论和代理成本理论则认为股利是重要的。

* 信息信号：股利传递了关于公司的信息（正面或负面）
* 代理成本：
  * 股利减少了管理层可用于过度投资、失去约束的自由现金流
  * 股利会提高公司债务的违约风险

### 税收考虑

#### 双重征税制度

公司的税前利润先在公司层面征税，如果以股利形式分配给需纳税的股东，在股东层面还要再征一次税。
$$
Div = EBT\times \text{payout\%}(1-t_{corporate})(1-t_{individual\ div})
$$
于是有效税率 = $t_{corporate}+(1-t_{corporate})t_{individual\ div}$。

#### 股利归集抵免制度

确保作为股利分配的利润只按股东的税率征税一次。
$$
Div = EBT\times \text{payout\%}(1-t_{individual\ div})
$$
有效税率就是 $t_{indiviaul \ div}$。

#### 分率税制

作为股利分配的公司利润，在公司层面适用的税率低于留存利润。
$$
Div = EBT\times \text{payout\%}(1-t_{corporate})(1-t_{individual\ div})
$$
于是有效税率 = $t_{corporate}+(1-t_{corporate})t_{individual\ div}$。

### 股利支付政策

#### 稳定股利政策

$$
E(Div) = Div_{t-1}+(E(NI)\times r_{div}-Div_{t-1})\times \text{Adjustment Factor}
$$

其中调整系数为 $\frac{1}{N}$，$N$ 是完成股利调整所需的年数。

#### 固定股利支付率政策

始终按固定的支付率发放股利
$$
Div = r_{div}\times NI
$$
这种方法很少使用，因为股利会随盈利波动。

## 股票回购及其影响

**股票回购：** 公司买回自己股票的交易。回购的股票称为**库存股**，不参与分红、投票，也不计入每股收益的计算。

回购方式有 3 种：

* 在市场上购买：时间和数量都很灵活
* 要约收购
  * 固定价格要约：以固定价格买入固定数量的股票，通常高于市价
  * 荷兰式拍卖：通过拍卖确定最低价格
* 直接协商：通常高于市价

对每股收益的影响：

* 用多余现金回购
  * 资产和权益下降，杠杆比率（D/A、D/E）上升
  * 每股收益上升
* 举债回购
  * 负债增加、权益下降，杠杆比率上升（幅度大于用现金回购）
  * 如果盈利收益率（E/P）> 税后债务成本，每股收益上升，否则下降

对每股账面价值的影响：

>[!note]
>
>BVPS = 权益账面价值 / 流通股数

* 如果回购价格 > 原 BVPS，则下降
* 如果回购价格 = BVPS，则不变
* 否则上升

> [!note]
>
> 一些比率
>
> * 股利支付率 = $\frac{div}{NI}$。
> * 股利保障倍数 = $\frac{NI}{div}$
> * FCFE 保障倍数 = $\frac{FCFE}{div+\text{shares repurchase}}$
> * 削减股利的预警信号：
>   * 外部股市指标负面
>   * 股息率极高。
