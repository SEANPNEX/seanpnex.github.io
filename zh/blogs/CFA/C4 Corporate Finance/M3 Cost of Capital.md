# 资本成本

什么决定公司的资本成本；如何估计交易债务、非交易债务、银行贷款和租赁的债务成本；如何估计股权风险溢价；以及如何估计上市公司、私营公司和跨国公司的股权要求回报率。两个小案例把这些内容串起来。（2026 年标题：*Cost of Capital: Advanced Topics*。）

| 术语 | 含义 |
| --- | --- |
| **债务成本** | 发行人的税后成本，基于债务投资者要求的回报 |
| **股权成本**（$r_e$） | 股权投资者要求的回报；**无法观察**，因此必须估计 |
| **ERP** | 股票的预期回报减去无风险基准利率 |
| **合成信用评级** | 债务没有评级时，根据基本面（利息保障倍数、D/E）推断的评级 |
| **矩阵定价** | 根据评级、期限和票息相近的交易债券估计收益率 |
| **RIIL** | 租赁内含利率 |
| **IBR** | 增量借款利率：同期限担保贷款的利率 |
| **SP / IP / SCRP** | 规模溢价 / 行业风险溢价 / 公司特定风险溢价 |
| **CRP** | 国家风险溢价 |

## 加权平均资本成本（WACC）

$$
WACC=w_dr_d(1-t)+w_pr_p+w_er_e
$$

其中 $t$ 是**边际**税率，权重（非负，加总为 1）是**目标**资本结构。

* $r_d=r_f+\text{credit spread}$（税前）。
* $r_e=r_f+\beta\times ERP$（CAPM，实践中最常用的模型）：$\beta$ 是股票对市场的敏感度；ERP 是投资者因持有股票而非无风险资产所要求的补偿。
* 优先股有约定股利，对普通股有优先求偿权，因此通常 $r_d < r_p < r_e$。

WACC 难以估计，因为每个组成部分都有多种估计方法，没有唯一正确的一种；**长期目标**资本结构可能不同于当前结构；**边际**税率可能不同于平均税率或有效税率。

**例子（含优先股和利息扣除上限的 WACC）。** 目标权重：债务 30%，优先股 10%，普通股 60%。税前 $r_d$ 6%，$r_p$ 7%，$r_e$ 11%；边际税率 25%。

* 利息可扣除：0.30 × 6% × 0.75 + 0.10 × 7% + 0.60 × 11% = 1.35% + 0.70% + 6.60% = **8.65%**。
* 已达到利息扣除上限（新债务没有税收利益）：0.30 × 6% + 0.70% + 6.60% = **9.10%**。

## 什么决定资本成本

| **自上而下（外部）** | **自下而上（公司特定）** |
| --- | --- |
| 资本可得性 | 收入、盈利和现金流的波动性 |
| 市场状况 | 资产性质和流动性 |
| 法律和监管环境、国家风险 | 财务实力、盈利能力和杠杆 |
| 税收管辖区 | 证券特征 |

自上而下的因素是系统性的，体现在**无风险利率和 ERP** 中；自下而上的因素是公司特定的，体现在**信用利差和 beta** 中。

### 自上而下的因素

* **资本可得性**：可得资本越多 → 成本**越低**。发达市场有更深的资本市场、稳定的货币、产权保护和法治。在公司债市场不发达的地方，公司依赖银行贷款或**影子银行**（不作为银行受监管的贷款人）。
* **市场状况**：通胀更高（$r_f$ 更高）→ **更高**；衰退（利差和 ERP 扩大）→ **更高**；扩张（利差收窄）→ **更低**，公司借得更多。低利率、窄利差、低利率和汇率波动以及可预测、透明的货币政策都会降低资本成本。
* **法律和监管**：更强的投资者保护（常见于**普通法**）和成熟的监管 → **更低**；薄弱的制度（常见于大陆法）→ 更高。在受监管的行业（公用事业、金融），监管者会影响资本结构、派现和定价。
* **税收**：更高的边际税率 → 税后债务成本**更低**（税盾更大），**但前提是**利息可以扣除且公司有应税收入。

### 自下而上的因素

| 因素 | 资本成本 |
| --- | --- |
| 销售更稳定（如经常性或订阅收入） | 更低 |
| 收入更集中 | 更高 |
| 盈利更可预测 | 更低 |
| 经营杠杆和财务杠杆更高 | 更高 |
| ESG 风险更高 | 更高 |
| 资产更具可替代性、更有形 | 更低 |
| 资产流动性更好 | 更低 |
| 盈利能力、现金流、利息保障倍数、流动性更高 | 更低 |
| 杠杆更高（债务/EBITDA、D/E） | 更高 |

* **ESG 风险**（未缓解的碳足迹、员工安全、治理薄弱、反收购条款）会提高资本成本。或者，分析师也可以调整**现金流预测**而不是折现率。
* **抵押品**：有形资产可以抵押，这会降低**债务**成本，但可能提高**股权**成本（债权人有优先求偿权）。

**证券特征：**

| 证券 | 特征 | 资本成本 |
| --- | --- | --- |
| 债务 | 可赎回 | 更高 |
| | 可回售 | 更低 |
| | 可转换 | 更低 |
| 优先股 | 累积 | 更低 |
| 普通股 | 现金流或投票权较弱 | 更高 |

* **赎回权**对发行人有利，因此投资者在发行时要求更高的收益率（如果之后利率下降、债券被再融资，成本可能下降）。
* **回售权**或**转换权**对投资者有利，因此发行时收益率更低，但之后成本可能上升（回售后以更高利率再融资；转换后的稀释）。
* **累积**优先股：未付的股利必须在任何普通股股利之前支付，因此投资者接受比非累积优先股更低的回报。

**例子（两个国家）。** A 国：利差宽、利率波动和通胀高、资本可得性低、税率 15%。B 国：利差窄、波动和通胀低、可得性高、税率 25% → **B 国**的资本成本更低。如果利息可扣除且公司有应税收入，把 A 国的税率从 15% 提高到 25% 会降低税后债务成本。

**例子（两家公司）。** 公司 1 与公司 2：现金和证券 20% 对 17%；无形资产 10% 对 24%；PP&E 46% 对 29%；净债务/EBITDA 2.1 对 2.5；利息保障倍数 12.6 对 7.9；经营杠杆低；前五大客户 15% 对 27%；**可回售**债务（公司 2 的是可赎回的）→ 在每一项上，**公司 1** 的资本成本都更低。

#### 考试陷阱

* 更高的税率只通过债务税盾**降低** WACC；如果不能扣除或没有应税收入，就没有影响。
* 赎回特征 → 发行时成本**更高**；回售和转换 → **更低**。
* 抵押品降低债务成本，但可能提高股权成本。

## 债务成本

方法取决于债务的类型（交易、非交易、银行、租赁）、流动性、是否有评级以及币种。

* **交易债务**：公司**普通**（不含期权）债务的 YTM，通常取最长期限；如果较短期债券流动性更好，其 YTM 可能更可靠。YTM 就是发行类似新债的当前成本。
* **非交易债务**（大多数私营公司、部分上市公司）：没有报价的 YTM，或者 YTM 包含很大的**流动性溢价**。
  * **有评级**：使用**矩阵定价**，依据期限和评级相近的其他公司债券。
  * **无评级**：根据基本面（利息保障倍数、杠杆）估计**合成信用评级**，然后使用该评级和期限债券的 YTM，或用 $r_f$ 加该评级的利差。
  * 发行人的评级可能不同于单个债券的评级（抵押、优先级、可转换性）。

**合成评级表（Brunswix Firm）：**

| 评级 | 利息保障倍数（IC） | D/E |
| --- | --- | --- |
| AAA | IC > 10 | D/E < 35% |
| AA | 8 < IC < 10 | 35% < D/E < 40% |
| A | 5 < IC < 8 | 40% < D/E < 42% |
| BBB | 3 < IC < 5 | 42% < D/E < 44% |
| BB | 2 < IC < 3 | 44% < D/E < 50% |
| B | 1.4 < IC < 2 | 50% < D/E < 60% |
| CCC | 1.0 < IC < 1.4 | 60% < D/E < 70% |
| CC | 0.6 < IC < 1.0 | 70% < D/E < 80% |
| C | 0.3 < IC < 0.6 | 80% < D/E < 100% |
| D | IC < 0.3 | D/E > 100% |

**例子（Gamma 公司）。** IC 1.5 → **B**；D/E 43% → **BBB**。两个比率相互矛盾，因此要运用判断并观察其**趋势**（例如 IC 上升可能支持 BB）。

* **银行贷款**：如果自那以后市场状况和公司风险没有重大变化，使用最近一次借款的利率。贷款可以是固定或浮动利率，可以全额、部分或不摊还。**摊还**贷款通常比到期一次还本的贷款成本低，因为本金在期限内逐步偿还（违约风险更低）。
* **租赁**：**融资租赁**类似摊还的担保贷款，因此通常比无担保借款便宜（经营租赁费用化）。根据 IFRS 16 / ASC 842，**租赁内含利率**（RIIL）满足：

$$
\begin{aligned}
&\text{PV of lease payments}\\
&+\text{PV of residual value to lessor}\\
&=\text{Fair value of the asset}\\
&+\text{Lessor's direct initial costs}
\end{aligned}
$$

  * 如果残值和出租人成本未知，使用**增量借款利率**（IBR）；如果 IBR 也未知，使用非交易债务的方法。大多数上市承租人会披露其租赁利率。
  * 如果融资租赁在税务上视同购买，利息可以扣除 → 使用税后利率。

**例子（G&S Airlines 租赁）。** 15 年，每年付款 €9.0m，飞机公允价值 €100m，出租人直接成本 €5m，残值 €10m。净现金流：$t=0$ 时 −105，每年 +9，第 15 年 +19。

* N = 15，PV = −105，PMT = 9，FV = 10 → **RIIL = 4.08%**。
* 比无担保的 IBR（6%）和股权（11%，且有稀释）便宜；避免了所有权风险，但**提高杠杆**。

* **国际**：债务成本应以**现金流的币种**计。对较不成熟的市场，根据反映经济状况、政治风险、汇率风险以及证券市场发展和监管的**国家风险评级（CRR）**加上国家风险溢价：CRP = 该国评级类别的中位利率 − 基准国家的利率。主权风险（政府债务违约）只是国家风险的**一部分**，国家风险还包括政治稳定、经济竞争力和人类发展。

**例子（国家风险溢价）。** 基准国家 A（评级 1），中位利率 4.0% → CRP 0%。C 国（评级 2），4.5% → CRP **0.5%**。D 国（评级 8），15.5% → CRP **11.5%**。

* **利息扣除限制**：如果公司已经达到上限，**不要**对新债务成本做税收调整（没有进一步的税收利益）。

#### 考试陷阱

* 使用**新**债务的**边际**成本，而不是旧债务的票息。
* 对于交易稀少的债券，根据流动性好的债券矩阵定价得到的收益率会低估真实成本：为非流动性稍加一点。
* 计算 RIIL 需要付款额、残值、资产公允价值、出租人直接成本和租赁期限。

## 股权风险溢价（ERP）

有两大类方法：**历史法**（事后）和**前瞻法**（事前）。两者都在使用，都有估计误差。

### 历史法

ERP 是样本期内宽基股票指数回报与政府债务回报之差的均值：

$$
ERP = \overline{r_m-r_f}
$$

它假设回报是**平稳的**，市场是合理**有效的**，平均回报是长期预期回报的无偏估计。四个选择决定结果：

**1. 股票指数**：通常是宽基、市值加权的指数（标普 500、Russell 3000、MSCI EAFE、All Ordinaries、上证综指）。

**2. 时间段**：

| 时间段 | 优点 | 缺点 |
| --- | --- | --- |
| 较长（通常**更受青睐**） | 波动率变化的影响较小；标准误更低 | 可能不能代表**当前**市场 |
| 较短 | 代表当前环境 | 噪音更多（可能只覆盖周期的一部分，或一次冲击） |

近期一连串的强劲回报会抬高历史均值，因此可能**高估**前瞻 ERP。

**3. 均值**：

| 均值 | 优点 | 缺点 |
| --- | --- | --- |
| **算术** | 简单；使用所有观测值；与单期模型（CAPM、多因素）一致 | 对极端值敏感；高估预期期末财富 |
| **几何**（通常**更受青睐**） | 使用所有观测值；离群值权重较小；估计预期期末财富 | |

算术均值总是不小于几何均值，因此算术 ERP **更高**。

**4. 无风险代理**：

| 代理 | 优点 | 缺点 |
| --- | --- | --- |
| 长期政府债券 YTM（业界惯例） | 更接近股票的无限久期 | 并非完全无风险（票息再投资未知） |
| 政府短期国库券利率 | 完全无风险（零息，回报事先已知） | 久期远短于股票 |

在正常向上倾斜的收益率曲线下，以短期国库券为基础的 ERP 比以长期债券为基础的 ERP **更高**。

**局限。** ERP 会随时间变化（永久性的变化会使长期历史失去代表性），**幸存者偏差**会抬高历史估计（失败的公司退出指数，回填的指数历史也是如此）。

**例子（Smith 与 Müller）。** Smith：Russell 3000，35 年，30 年期国债，算术均值：12.96% − 6.25% = **6.71%**。Müller：标普 500，65 年，3 个月期国库券，几何均值：11.23% − 3.11% = **8.12%**。两者都可能有效：他们做了不同的选择。

### 前瞻法

前瞻性估计只使用对驱动未来现金流的变量的预期，因此较少受非平稳性和数据偏差的影响。

**调查。** 询问人们（常为专家）的预期。调查显示，发展中市场的 ERP 远高于发达市场，答案往往跟随近期市场回报。

**股利折现模型。** 根据 Gordon 增长模型，$r_e=D_1/V_0+g$。如果 P/E 不变，使盈利、股利和价格以相同速度增长：

$$
ERP= E\left(\frac{D_1}{V_0}\right)+E(g)-r_f
$$

* 如果预期 P/E 会变化，要做相应调整（除非 P/E 上升，价格不可能比盈利增长得快）。
* 一些分析师把指数**回购**加到收益率中（总派现），然后考虑回购如何改变增长。
* 对于快速增长的经济体，使用**三阶段**（快速增长、过渡、成熟），求解使所有阶段的现值等于指数水平的折现率，然后减去 $r_f$。

**例子（FTSE 100）。** 股息率 1.94%，增长率 5.0%，英国国债收益率 1.63% → ERP = 1.94 + 5.0 − 1.63 = **5.31%**。预测的范围从 1.5 + 4 − 2.5 = **3%** 到 3.5 + 6 − 1.5 = **8%**（可用于模拟）。

**宏观经济模型（Grinold–Kroner，2001）。**

$$
\begin{aligned}
ERP ={}& DY+\Delta\left(\tfrac{P}{E}\right)+i+g-\Delta S\\
&-E(r_f)
\end{aligned}
$$

| 项 | 含义 | 常用代理 |
| --- | --- | --- |
| $DY$ | 股息率 | 指数股息率 |
| $\Delta(P/E)$ | 预期重新定价 | 分析师对高估或低估的看法（通常为 0） |
| $i$ | 预期通胀 | 名义收益率 − 实际（通胀挂钩）收益率，期限相近 |
| $g$ | 实际盈利增长 | 实际 GDP 增长 |
| $\Delta S$ | 流通股数的预期变化百分比 | 取决于市场和时期；除非给定，通常为 0 |

* $DY+\Delta(P/E)$ 是收益和重新定价回报；$i+g-\Delta S$ 是每股名义盈利增长。净**回购**使 $\Delta S$ 为负，从而**增加**回报；稀释则减少回报。
* 预期通胀，来自期限相近的名义收益率和通胀挂钩（TIPS）收益率：

$$
\begin{aligned}
i&=\frac{1+YTM_{\text{nominal}}}{1+YTM_{\text{TIPS}}}-1\\
&\approx YTM_{\text{nominal}}-YTM_{\text{TIPS}}
\end{aligned}
$$

* 在上市股票占**经济比重较大**的地方（发达市场）更可靠；在股票市场较小的地方（许多发展中国家）不适用。

**例子。**

* 10 年期国债 2.3%，TIPS 0.66% → $i$ = 1.023/1.0066 − 1 = **1.6%**。
* 情景 1：$r_f$ 2.5，$i$ 1.6，$g$ 3，$\Delta(P/E)$ 0，DY 2.2，$\Delta S$ −0.7 → {2.2 + 0 + [1.6 + 3.0 − (−0.7)]} − 2.5 = **5.0%**。
* 情景 2：$r_f$ 3，$i$ 3，$g$ 2，$\Delta(P/E)$ 1，DY 2，$\Delta S$ 0 → {2.0 + 1.0 + [3.0 + 2.0 − 0]} − 3.0 = **5.0%**。
* 预期通胀上升：对 ERP **没有影响**（$i$ 和 $r_f$ 同步上升）。预期收益下降：ERP **下降**。
* 同一市场，两种方法：历史法 9.96 − 3.15 = **6.81%**；Grinold–Kroner {1.8 − 1.2 + (1.9 + 2.7 − 0)} − 0.96 = **4.24%**。

**前瞻性估计的局限：**

* **调查**：抽样和回答偏差；行为偏差（**近因**、**确认**偏差）。
* **DDM**：假设 P/E 不变；当盈利、股利和价格以不同速度增长时需要调整。
* **宏观模型**：宏观数据有误差；预测中有行为偏差。

**例子（只有 20 年历史的新市场）。** 指数回报在推出前用幸存成分股回填了 4 年 → **向上**的幸存者偏差。一场压低回报、且不会再发生的 5 年边境冲突 → 历史 ERP **向下**偏差。倒挂的曲线（短期利率 9%，10 年期 7%）：基于短期利率的要求回报率**向上**偏差。Grinold–Kroner 中 $i$ = 4%（长期），$g$ = 4%，$\Delta(P/E)$ = 1%，DY 1%，$r_f$ = 7%（10 年期）→ {1 + 1 + [4 + 4 + 0]} − 7 = **3.0%**；因此平均风险的股票至少要求 7% + 2% 到 3% = **9% 或以上**。

#### 考试陷阱

* Grinold–Kroner：使用**长期**通胀预测和**长期**债券收益率；回购（$-\Delta S$）增加回报，稀释减少回报。
* 基于国库券和算术均值的 ERP 比基于长期债券和几何均值的 ERP **更高**。
* 幸存者偏差使历史 ERP **偏高**；样本中一次性的危机使其**偏低**。

## 股权成本

| 情形 | 模型 |
| --- | --- |
| 上市公司 | DDM、债券收益率加风险溢价（BYPRP）、CAPM、Fama–French |
| 私营公司 | 扩展 CAPM、累加法 |
| 国际 | 国家利差模型、全球 CAPM、国际 CAPM |

### 股利折现模型

对于股利稳定、可预测的上市公司：

* **Gordon 增长**：$r_e=\dfrac{D_1}{P_0}+g$
* **多年预测**：求解 IRR，$P_0 = \sum_{t=1}^n \dfrac{D_t}{(1+r_e)^t}+\dfrac{P_n}{(1+r_e)^n}$

**例子。**

* 公司 X：$P_0$ €40，$D_1$ €1.04，$g$ 4% → 1.04/40 + 0.04 = **6.6%**。
* 多年：$P_0$ USD40；股利 1.00、1.25、1.35、1.50；$P_4$ USD45 → 现金流 −40、1、1.25、1.35、46.5 → IRR = **6.015%**。
* $D_0$ USD2.50，$P_0$ USD50，$g$ 5% → 2.625/50 + 0.05 = **10.25%**。更高的 $g$ 提高 $r_e$（$D_1$ 和 $g$ 都上升）；更低的价格提高 $r_e$。
* 优先股（永续年金，$g$ = 0）：$r_p = D/P$。

### 债券收益率加风险溢价（BYPRP）

$$
r_e =r_d+RP
$$

其中 $r_d$ 通常是公司**长期**债务的 YTM，$RP$ 常为股票指数回报与公司债指数回报之差的历史平均值。

* 债务成本是天然的出发点：股权投资者要求的回报高于公司的债权人。
* 溢价相当任意，并且可能随时间不稳定。
* 它需要有交易的债务；如果有几只特征不同的债券，没有规则规定用哪一个收益率（常见做法：长期债券）。

**例子。** 债券收益率 4.3% + 历史溢价 6.1% = **10.40%**。

### CAPM

$$
r_e = r_f+\hat\beta\,(ERP)
$$

Beta 来自**市场模型**，即股票超额回报对市场超额回报的回归：

$$
(r_{i,t}-r_{f,t}) = b_0 + b_1(r_{m,t}-r_{f,t}) + \varepsilon_t
$$

检查指数、估计期（数据足够与数据过旧）以及 $r_f$ 代理：在向上倾斜的曲线下，国库券利率给出的 $r_e$ 明显**低于**长期债券收益率给出的。非上市公司可以使用**去杠杆再加杠杆的同行 beta**（见小案例 2）。

### Fama–French 模型

$$
\begin{aligned}
r_e = r_f &+\beta_1ERP + \beta_2 SMB\\
&+ \beta_3 HML+ \beta_4 RMW\\
&+ \beta_5 CMA
\end{aligned}
$$

三因素模型只使用前三个因素。

* **SMB**（小减大）：规模溢价
* **HML**（高账面市值比减低）：价值溢价
* **RMW**（稳健减疲弱）：盈利能力溢价
* **CMA**（保守减激进）：投资溢价

Beta 来自公司超额回报对各因素的回归。多因素模型中的市场 beta **不同于** CAPM 的 beta，不同模型给出不同答案。当曲线向上倾斜时，回归中使用短期 $r_f$ 可能低估 $r_f$。

**例子。**

* 五因素：3.82% + 1.2(6.5%) + 0.10(1.8%) − 0.20(4.0%) + 0.5(2.0%) + 0.2(1.0%) = **12.2%**。
* 含截距的三因素：$r_e - r_f$ = 0.003 + 1.2(0.05) − 0.4(0.01) + 0.2(0.04) = 0.067 → $r_e$ = **8.7%**（$r_f$ 为 2%）。
* CAPM 与三因素（$r_f$ 6%，市场 10%）：CAPM 6% + 0.8(4%) = **9.2%**；三因素 6% + 0.01 + 0.75(4%) + 0.15(5%) + 0.05(2%) = **10.85%**。SMB 和 HML 增加了 0.85%。

### 私营公司

**扩展 CAPM：**

$$
r_e = r_f +\beta_{\text{peer}}(ERP)+SP+SCRP
$$

* $\beta_{\text{peer}}$：同一行业上市公司同行组的 beta。
* **规模溢价（SP）**：与规模负相关；基于市值最小的十分位，即平均风险的**微型股**回报。对于健康的小公司，历史 SP 可能需要**下调**（小盘股样本包括衰落、陷入困境的公司）。
* **公司特定风险溢价（SCRP）**：地理、关键人物以及其他难以分散的风险。

步骤：（1）找到同行 beta；（2）计算 CAPM 的 $r_e$；（3）判断是否需要规模和公司溢价；（4）加上它们。

| SCRP：定性因素 | SCRP：定量因素 |
| --- | --- |
| 行业、竞争地位、管理层经验 | 财务杠杆和经营杠杆 |
| 客户、供应商和地域集中度 | 现金流和盈利的波动性 |
| 治理、资产类型（有形与无形） | 盈利可预测性、定价能力 |

私营公司也**缺乏流动性**，但流动性不足通常作为价值上的**缺乏市场流通性折扣**来处理，而不是作为 $r_e$ 中的溢价。

**累加法：**

$$
r_e=r_f+ERP+SP+IP+SCRP
$$

这里的 ERP **未经 beta 调整**（隐含 beta 为 1）：$r_f$ + ERP 是平均风险**大盘股**的要求回报。加上 SP 得到微型股回报；然后加上**行业风险溢价**（IP，针对风险更高的行业）和 SCRP。在没有可比上市公司或其可比性存疑时很有用。

### 跨国公司

新兴股票市场的**国家利差模型**：

$$
ERP = ERP_{\text{developed}} + \lambda\times CRP
$$

其中 $\lambda$ 是公司对当地国家的敞口。**CRP** 补偿投资新兴市场的额外风险（经济状况、征收、政治风险）。其基本形式是**主权收益率利差**：以发达市场货币计价的新兴市场政府债券收益率，减去期限相近的发达市场政府债券收益率。**债券**利差未必适合**股票**溢价，因此 Damodaran 对其进行缩放：

$$
CRP = \text{Sovereign spread}\times \frac{\sigma_{\text{equity}}}{\sigma_{\text{bond}}}
$$

其中 $\sigma_{\text{equity}}$ 和 $\sigma_{\text{bond}}$ 是当地股票和债券市场的波动率。这需要两者的回报历史。

**例子（Makinassi）。** 总部在 X 国（利差 1.5%）；Y 国（占销售的 40%）利差为 3.2%，$\sigma_E$ 4.0%，$\sigma_B$ 2.5%。相关利差为 3.2 − 1.5 = 1.7%；CRP = 1.7% × 4.0/2.5 = 2.72%；乘以 40% 的敞口 = 加到 $r_e$ 上的 **1.088%**。

**全球 CAPM。** 单一因素：以全球市场指数作为 $r_m$，假设各国之间没有显著的风险差异。问题：新兴市场与发达市场回报的相关性低，会得出很低甚至**为负**的 beta。如果当地数据可靠，加入本国指数因素会有帮助。

**国际 CAPM。**

$$
\begin{aligned}
E(r_e)={}&r_f+\beta_G\left[E(r_{gm})-r_f\right]\\
&+\beta_c\left[E(r_c)-r_f\right]
\end{aligned}
$$

* $r_{gm}$：全球指数（MSCI ACWI、FTSE All-World）；与全球经济联系较少的公司 $\beta_G$ 较低。
* $r_c$：**财富加权**的外币指数（预期汇率变化加上该国的 $r_f$）；$\beta_c$ 取决于现金流对汇率的敏感程度（进口、出口、投资）。

**选择方法。** 对于只在**发达**国家经营的业务，全球或国际 CAPM 是合理的。对于在**发展中**国家的业务则不那么明确；主权利差 CRP 可能可行，但它依赖于历史利率。

#### 考试陷阱

* 多年 DDM：用 $(1+r_e)^t$ 折现**每个** $D_t$，并把 $P_n$ 计入最后一年的现金流。
* BYPRP 把溢价加到公司**自己的**债券收益率上，而不是 $r_f$。
* 累加法使用**不含** beta 的 ERP；扩展 CAPM 使用**同行** beta。
* 私营公司的流动性不足 → 估值折扣（DLOM），而不是额外溢价。
* 国家利差模型：把 CRP 乘以公司的**敞口** $\lambda$；Damodaran 用 $\sigma_{\text{equity}}/\sigma_{\text{bond}}$（> 1）缩放利差。

## 小案例 1：Gretna Engines

一家上市小盘发动机制造商：周期性、固定成本高、资产主要是存货和 PP&E。资本：债务 20%（票息 7%，7 年，BBB，交易稀少），优先股 15%（股利 7%，面值 1,000，价格 980，可按面值赎回），普通股 65%。它计划发行无担保债务来赎回优先股。

* **资本成本为何高**：收入和盈利具有周期性和波动性；资产缺乏流动性；经营杠杆高。
* **以矩阵定价估计债务成本**（四只流动性好的 BBB 债券，半年付息）：

| 债券 | 票息 | 期限 | 价格 | YTM |
| --- | --- | --- | --- | --- |
| 1 | 5% | 4 | 99.50 | 5.140% |
| 2 | 7% | 4 | 106.46 | 5.191% |
| 3 | 6% | 8 | 100.00 | 6.000% |
| 4 | 8% | 8 | 112.42 | 6.021% |

  4 年期平均为 **5.166%**，8 年期平均为 **6.011%**，每年递增 (6.011 − 5.166)/4 = 0.211% → 5 年 5.377%，6 年 5.588%，7 年 **5.799% ≈ 5.8%**。Gretna 交易稀少，意味着其真实收益率略高。
* **优先股成本**：70/980 = **7.14%**。
* 用债务替换优先股后（债务 35%，股权 65%），新债务的成本将高于 5.8%、低于 7.14%。在价格为 980 时按面值赎回，意味着 $r_f$ 低和/或利差窄，即时机好。要进一步降低成本，可以发行**有担保**、**可回售**或**可转换**的债务。
* **股权成本**：CAPM 2.1% + 0.91 × 5.5% = **7.11%**；五因素 2.1% + 0.95(5.5) + 0.45(1.8) + 0.14(3.9) − 0.19(3.1) + 0.30(3.7) = **9.20%**；BYPRP 5.8% + 6.2% = **12.0%**。
* CAPM 的 7.11% **低于**优先股成本 7.14%，因此不可信：普通股次于优先股。
* ERP 是用**国库券利率**和**算术**均值估计的，两者都会使它**偏高**。

## 小案例 2：Precision Irrigation

一家位于风险较高的新兴市场的私营软件公司，与上市软件同行进行比较。

| | Precision | 行业 |
| --- | --- | --- |
| 总债务 | 18.4 | 296.4 |
| 总资产 | 105.2 | 1,276.2 |
| EBITDA | 12.2 | 177.4 |
| 利息 | 1.6 | 23.5 |
| 税率 | 20% | 25% |
| Beta | | 1.25 |

当地 10 年期 $r_f$ 5.41%；ERP 6%，SP 5%，IP 1%，SCRP 6%，CRP 2%。

* **债务成本**：IC = 12.2/1.6 = **7.63**；D/E = 18.4/(105.2 − 18.4) = **0.2120** → 合成评级 **A**，利差 1.46%。$r_d$ = 5.41 + 1.46 + 2.00（CRP）= **8.87%**；税后为 8.87% × 0.8 = **7.096%**。
* **规模溢价接近 3–6% 区间的上端**：Precision 的资产不到行业平均水平的十分之一。
* **SCRP**：因无形资产更多（47% 对 32%）和现金更少（9% 对 14%）而**更高**；70% 的收入来自附近的五个客户（客户和地域集中）；创始人兼 CEO 没有继任计划（关键人物）。因 60% 的订阅收入和更低的杠杆（D/E 0.2120 对 0.3025；IC 7.63 对 7.55）而**更低**。
* **Beta**：用**行业的**税率和 D/E 对行业 beta 去杠杆，然后用 Precision 的数据再加杠杆：

$$
\begin{aligned}
\beta_{\text{asset}}&=\frac{1.25}{1+(1-0.25)(0.3025)}\\
&=1.019
\end{aligned}
$$

$$
\begin{aligned}
\beta_{\text{Precision}}&=1.019\\
&\quad\times[1+(1-0.20)(0.2120)]\\
&=1.19
\end{aligned}
$$

* **扩展 CAPM**（包括 IP 和 CRP）：5.41 + 1.19(6) + 5 + 1 + 6 + 2 = **26.55%**。
* **累加法**（按解答中的计算，不含 IP）：5.41 + 6 + 5 + 6 + 2 = **24.41%**。
* **WACC**，$w_d$ = 18.4/105.2 = 0.1749，$w_e$ = 0.8251：0.1749 × 8.87% × 0.8 + 0.8251 × 24.41% = **21.38%**。

#### 考试陷阱

* 用**可比公司的**税率和 D/E 去杠杆；用**目标公司的**再加杠杆。
* 根据账面数据计算的 D/E 是债务 ÷（资产 − 债务），而不是债务 ÷ 资产。
* 普通股成本低于优先股成本是一个危险信号。
* 当案例说明国家风险同时适用于债务和股权时，要把 CRP **同时**加到两者上。

> [!NOTE]
>
> **教材笔误。**
>
> * Grinold–Kroner 情景 1：解答文字说"ERP 估计为 3.6%"，但其自身的计算得出 **5.0%**。
> * 小案例 2：表 19 把 BB 印为"3 < IC < 1.4"（应为 3 < IC < 5）。去杠杆的文字说"使用 20% 的边际税率"，但公式正确地使用了行业的 25%。主要数字与计算不符：扩展 CAPM"26.56%"（应为 26.55%），累加法"25.41%"（应为 24.41%；25.41% 会包含 1% 的 IP），WACC"21.13%"（应为 21.38%，使用 24.41%）。那里的扩展 CAPM 包含了 IP，尽管一般公式并不包含；按题目给出的输入计算即可。
