# 资本成本

**加权平均资本成本（WACC）**：
$$
WACC=w_dr_d(1-t)+w_pr_p+w_er_e
$$
其中 $t$ 是税率。

* $r_d=r_f+\text{spread}$
* $r_e=r_f+(ERP+IRP)$
  * ERP：股权风险溢价
  * IRP：特质风险溢价

## 影响资本成本的因素

| **自上而下，外部因素**                            | **自下而上，公司特有因素**                 |
| ------------------------------------------------- | ----------------------------------------------- |
| 资本可得性                              | 收入、盈利和现金流的波动性      |
| 市场环境                                 | 资产性质和流动性                      |
| 法律与监管因素、国家风险 | 财务实力、盈利能力和杠杆 |
| 税收管辖区                                  | 证券条款                               |

* 资本可得性高：更低
* 市场环境
  * 通胀：更高
  * 衰退：更高
  * 扩张：更低
  * 利率或汇率波动较低：更低
* 法律与监管：更完善，更低
* 边际所得税率更高：更低（看公式，税盾效应更大）

* 收入、盈利和现金流的波动性：

| 因素                                  | **资本成本** |
| --------------------------------------- | ------------------- |
| 销售更稳定               | 更低               |
| 收入更集中            | 更高              |
| 盈利更可预测          | 更低               |
| 经营杠杆和财务杠杆更高 | 更高              |
| ESG 风险更高                         | 更高              |

* 资产性质和流动性

| 因素                                | **资本成本** |
| ------------------------------------- | ------------------- |
| 可替代、有形资产占比更高 | 更低               |
| 流动资产占比更高             | 更低               |

* 财务实力

| 因素                              | **资本成本** |
| ----------------------------------- | ------------------- |
| 盈利能力更强                | 更低               |
| 现金流创造能力更强         | 更低               |
| 利息保障倍数、流动性更高 | 更低               |
| 杠杆比率更高              | 更高              |

* 证券条款

|                     | **条款**                      | **资本成本** |
| ------------------- | -------------------------------- | ------------------- |
| **债务**            | 可赎回                      | 更高              |
|                     | 可回售                       | 更低               |
|                     | 可转换                   | 更低               |
| **优先股** | 累积                       | 更低               |
| **普通股**    | 现金流/投票权次级 | 更高              |

## 债务成本

* 有交易的债务：到期收益率（YTM）
* 无交易的债务：参考信用评级相同、期限相近的债券收益率。没有信用评级时：使用合成信用评级。

**合成信用评级示例**

| **评级** | **利息保障倍数** | **D/E**          |
| ---------------- | --------------------------- | ---------------- |
| AAA              | IC > 10 倍               | D/E < 35%        |
| AA               | 8 < IC < 10                 | 35% < D/E < 40%  |
| A                | 5 < IC < 8                  | 40% < D/E < 42%  |
| BBB              | 3 < IC < 5                  | 42% < D/E < 44%  |
| BB               | 2 < IC < 3                  | 44% < D/E < 50%  |
| B                | 1.4 < IC < 2                | 50% < D/E < 60%  |
| CCC              | 1.0 < IC < 1.4              | 60% < D/E < 70%  |
| CC               | 0.6 < IC < 1.0              | 70% < D/E < 80%  |
| C                | 0.3 < IC < 0.6              | 80% < D/E < 100% |
| D                | IC < 0.3                    | D/E > 100%       |

* 银行贷款：最新的利率。

> [!note]
>
> 分期摊还贷款的债务成本通常低于非摊还贷款

* 租赁

  * 租赁内含利率（RIIL）

  满足以下等式（以融资租赁为例）
  $$
  \text{PV of lease payment}+\text{PV of residual value to lessor}=\text{Fair value of leasedn asset}+\text{Lessor's direct initial cost}
  $$
  

  * 增量借款利率（IBR）：同期限抵押贷款的利率

## 股权风险溢价（ERP）

### 历史法

$$
ERP = r_m-r_f
$$

可以对历史数据取多种平均值来估计未来的 ERP。

**关键假设**：

* 收益率是平稳的
* 市场相对有效
* 长期来看，平均收益应是预期收益的无偏估计

**关键决策**：

* 选择股票指数
  * 通常选用覆盖面广的市值加权指数
* 选择时间区间

| 时间区间         | **优点**                                   | **缺点**                                            |
| ------------------- | ------------------------------------------------ | ------------------------------------------------------------ |
| 较长区间  | 波动率的起伏影响较小           | *不能*代表*当前市场*                 |
| 较短区间 | 能代表当前的市场环境 | 更可能带来*更多噪声*（只覆盖经济周期的一部分或某个动荡时期） |

* 选择平均值类型

|                     | **优点**                                               | **缺点**                                            |
| ------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **算术平均** | • 计算*简单*  <br> • 考虑全部观测值    | • 对*极端*值敏感  <br> • 高估财富的预期终值 |
| **几何平均**  | • 考虑全部观测值  <br> • *降低异常值的权重* <br> • 估计财富的预期终值 |                                                              |

* 选择无风险利率的代理变量

|                      | **优点**                                  | **缺点**                              |
| -------------------- | ----------------------------------------------- | ---------------------------------------------- |
| 政府债券到期收益率  | 与股票的无限久期*更匹配* | *并非*完全无风险的收益            |
| 政府短期国库券利率 | 对无风险利率的*精确*估计          | 与股票的无限久期*不太匹配* |

**局限**：

* ERP 可能随时间变化
* 幸存者偏差往往会高估 ERP 的历史估计值

### 前瞻法

* 基于调查的估计
* 股利折现模型
* 宏观经济建模

#### 基于调查

* 通过询问人们的预期来评估预期
* 估计值往往对近期市场收益很敏感

#### 股利折现模型（DDM）

由戈登增长模型，假设市盈率不变，盈利、股利和价格以相同速度增长。
$$
ERP= E(\frac{D_1}{V_0})+E(g)-r_f
$$

#### 宏观经济模型

$$
ERP = [DY+\Delta(\frac{P}{E})+i+g-\Delta S]-E(r_f)
$$

> [!note]
>
> 与经济学中的**增长公式**类似，其中 $\Delta S$ 是回购 + 相对活力的净变化。思路完全相同，只是记号不同。

| **因素**           |                       |                              | **符号**    |
| --------------------- | --------------------- | ---------------------------- | ------------- |
| 股息率        |                       |                              | $DY$          |
| 预期资本利得 | 预期重新定价    |                              | $\Delta(P/E)$ |
|                       | 每股收益增长 | 预期通胀           | $i$           |
|                       |                       | 实际经济增长         | $g$           |
|                       |                       | 流通股数的变化 | $\Delta S$    |

> [!note]
>
> 预期通胀 $i$ 可以用 $YTM_{treasury\ bond}-YTM_{TIPS}$ 来估计

#### 局限

* 调查
  * 抽样偏差与回应偏差
  * 行为偏差
* DDM
  * 假设过于严格
* 宏观经济模型
  * 宏观数据带来的建模误差
  * 行为偏差

## 股权成本

模型

* DDM
* 债券收益率加风险溢价法（BYPRP）
* CAPM
* Fama-French

### DDM

* 要求：公开交易，股利稳定且可预测
* 戈登增长模型：
  * $r_e=\frac{D_1}{P_0}+g$
* 多年期财务预测：
  * $P_0 = (\sum_{t=1}^n \frac{D_1}{(1+r_e)})+\frac{P_n}{(1+r_e)^n}$，用内部收益率（IRR）的方法求 $r_e$。

### BYPRP

$$
r_e =r_d+RP
$$

其中 $RP$ 可以用股票市场指数与公司债指数之间收益的历史平均差来估计。

* 估计债务成本为债权投资者要求的回报提供了一个起点
* $RP$ 的确定相对主观
* 要求公司有交易中的债务
* 如果公司有多只条款不同的交易中债务，很难选择。

### CAPM

$$
r_e = r_f+\beta(ERP)
$$

### Fama-French 模型

$$
r_e = r_f +\beta_1ERP + \beta_2 SMB + \beta_3 HML + \beta_4 RMW + \beta_5 CMA
$$

* SMB：小盘减大盘，规模溢价
* HML：高（账面市值比）减低，价值溢价
* RMW：稳健减疲弱，盈利能力溢价
* CMA：保守减激进，投资溢价

### 扩展 CAPM

$$
r_e = r_f +\beta_{\text{peer}}(ERP)+SP+SCRP
$$

* $\beta_{\text{peer}}$：行业 $\beta$，取自同行业上市公司的可比组
* SP：规模溢价
* SCRP：公司特有风险溢价

### 累加法

$$
r_e=r_f+ERP+SP+IP+SCRP
$$

>[!note]
>
>找不到行业 $\beta$ 时，假设 $\beta=1$。

* IP：行业风险溢价

### 国家风险溢价（CRP）

**CRP** 是投资者因投资新兴市场承担额外风险而要求的溢价
$$
CRP = \text{Sovereign yield spread}\times \frac{\sigma_{\text{equity}}}{\sigma_{\text{bond}}}
$$

* 主权收益率利差：新兴市场债券收益率减去发达市场政府债券收益率。
* $\sigma_{\text{equity}}$：当地股票市场的波动率
* $\sigma_{\text{bond}}$：当地债券市场的波动率

### 全球 CAPM

* 单因子：以全球市场指数作为 $r_m$
* 假设各国之间没有显著的风险差异

### 国际 CAPM

$$
E(r_e)=r_f+\beta_G(E(r_{gm})-r_f)+\beta_c(E(r_c)-r_f)
$$

* $r_{gm}$：全球指数
* $r_c$：外币指数
