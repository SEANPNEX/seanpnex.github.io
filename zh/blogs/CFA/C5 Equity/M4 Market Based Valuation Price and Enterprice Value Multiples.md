# 基于市场的估值：价格乘数与企业价值乘数

用乘数为股票估值，可以与相似资产比较（可比法），也可以从预测的基本面推导出乘数（合理乘数）。涵盖 P/E、P/B、P/S、价格/现金流、股息率和 EV 乘数，然后是跨境比较、动量指标以及如何对乘数取平均。

## 两种方法

| | 可比法 | 基于预测基本面的方法 |
| --- | --- | --- |
| 思路 | 从相似资产（可比公司，"参照公司"）的乘数得出价值 | 从公司自身的 DCF 或剩余收益模型推导出乘数 |
| 依据 | **一价定律**：相似资产以相似价格出售 | 价值 = 未来现金流的现值，由盈利能力、增长和风险驱动 |
| 结论 | **相对**价值（可比公司本身可能定价错误） | 绝对（内在）价值 |

* **合理乘数**是乘数的公允值，可由任一方法得出。合理值 > 实际值 → 低估。
* 使用同行的**中位数**以限制离群值。例如，同行 P/B 中位数 2.2 × BVPS \$23 = \$50.60；剩余收益价值 \$46 意味着合理 P/B 为 46/23 = **2.0**。

**例子（最简单的比较）。** A 的 EPS 为 \$1.50；竞争对手 B 的 P/E 为 22。在 \$37.50 时，A 的 P/E 为 25 > 22 → A 相对于 B **被高估**；按 B 的 P/E，A 值 1.50 × 22 = **\$33**。

## 市盈率

| 理由 | 缺点 |
| --- | --- |
| 盈利能力是价值的主要驱动因素 | EPS 可能为零、为负或极小 → P/E 无意义 |
| 使用最广、认可度最高的乘数 | 难以区分经常性盈利和暂时性盈利 |
| P/E 的差异与长期回报相关 | 管理层的自由裁量可能扭曲 EPS，损害可比性 |

### 历史 P/E 与预期 P/E

* **历史 P/E** = 价格 ÷ 过去四个季度的 EPS（TTM）。
* **预期（前瞻）P/E** = 价格 ÷ 下一年的预期 EPS：未来四个季度、未来十二个月（NTM）或下一个财年（FY1、FY2）。对每家公司使用**相同的定义**。盈利上升时，预期 P/E 低于历史 P/E。
* 有预测数据，或在重大收购或杠杆变化之后，更倾向于使用预期 P/E；盈利不可预测时使用历史 P/E。
* **NTM EPS** 是各财年估计的时间加权组合，例如 (10/12) × FY1 + (2/12) × FY2。

**例子。**

* **IBM**，价格 \$137.90：FY1 EPS \$13.91 → **9.9**；FY2 EPS \$14.17 → **9.7**。
* **Selene Gaming**（EPS 波动大），2020 年 8 月 9 日价格 \$12.20：

| 定义 | EPS | P/E |
| --- | --- | --- |
| 未来四个季度（−0.10 − 0.50 + 0.70 + 0.80） | 0.90 | **13.6** |
| NTM：(5/12)(−0.50) + (7/12)(1.50) | 0.67 | **18.2** |
| FY2020 | (0.50) | −24.4 → 无意义 |
| FY2021 | 1.50 | **8.1** |

盈利如此波动且顺周期时，要对其进行正常化。

### 调整 EPS

1. **稀释**：比较时优先使用稀释 EPS。例如西门子：基本 €7.12，稀释 €7.01，价格 €95.94 → P/E 13.47 对 **13.69**。
2. **非经常性项目** → **基础**（核心、持续）盈利。公司报告的"核心 EPS"是没有规则的非 IFRS/非 GAAP 指标：要用自己的判断。仅凭利润表上的分类是不够的。
3. **经济周期** → **正常化**（周期中点）EPS。周期性公司的 P/E 在周期底部高、在顶部低（**Molodovsky 效应**）。
4. **可比性**：调整会计差异（如 LIFO 与 FIFO）。

**例子（Evergreen，非经常性项目）。** 价格 £50.11。报告的 TTM EPS £4.52 → P/E **11.1**；公司的核心 EPS £6.01 → **8.3**；分析师的看法（只有法律准备是非经常性的；摊销和反复出现的重组是持续性的）得出 EPS £4.60 → **10.9**。

| 正常化方法 | 正常化 EPS | 说明 |
| --- | --- | --- |
| 历史平均 EPS | 最近一个完整周期的平均 EPS | 忽略公司**规模**的变化 |
| 平均 ROE | 周期内平均 ROE × **当前** BVPS | 反映规模；通常更受青睐 |

长期 ROA × 总资产，或长期 ROE × 权益，也可以使用（在公司报告亏损时有用）。

**例子（Zenlandia Chemical）。** 价格 \$18.21；2014–20 年 EPS：0.74、0.63、0.61、0.54、1.07、0.88、1.08；平均 ROE 22.6%；当前 BVPS \$4.82。

* 平均 EPS = \$0.79 → P/E = **23.1**。
* 平均 ROE：0.226 × 4.82 = \$1.09 → P/E = **16.7**。BVPS 增长了 61%，因此 ROE 方法反映了规模更大的公司，公司看起来更便宜。

**盈利为负或极小。** 把 P/E 报告为无意义（NM）。使用正常化或预期 EPS，或按**盈利收益率**（E/P）排序：价格永远不会为负，因此排序保持一致，而且 E/P 受离群值影响较小。例如特斯拉 EPS 为 −7.72，P/E 为 NM，E/P 为 −2.51%。

| 价格比率 | 倒数 | 说明 |
| --- | --- | --- |
| P/E | E/P（盈利收益率） | 两者都常用 |
| P/B | B/P（账面市值比） | 账面价值很少为负；研究中偏好 B/M |
| P/S | S/P | 很少使用 |
| P/CF | CF/P（现金流收益率） | 两者都常用 |
| P/D | D/P（股息率） | D/P 远为常见（对不派息公司 P/D 无定义） |

### 合理 P/E 与预测 P/E

根据 Gordon 增长模型：

$$
\frac{P_0}{E_1}=\frac{1-b}{r-g}
$$

$$
\frac{P_0}{E_0}=\frac{(1-b)(1+g)}{r-g}
$$

在任何 DCF 模型中，合理 P/E 都随 $r$（风险）下降，随 $g$ 上升。对于更复杂的模型，合理 P/E = DCF 价值 ÷ EPS。

**例子。**

* **BP**：留存率 40%，$g$ 3.5%，$r$ 7.6% → $P_0/E_1$ = 0.60/0.041 = **14.6**。
* **丰田**：FCFE 价值 ¥6,980，FY2020 EPS ¥720 → 合理预期 P/E **9.7**，而市场为 6,688/720 = 9.3 → 约低估 4%。

**预测 P/E** 来自对基本面（支付率、beta、增长）的横截面回归。例如，预测 P/E = 12.12 + 2.25(0.45) − 0.20(0.9) + 14.43(0.08) = **14.1**，低于实际的 18 → **高估**。局限：回归只对其样本和时期有效；系数和解释力随时间变化；**多重共线性**使单个系数难以解释。

### 比较 P/E

任何乘数的步骤：（1）选择并计算乘数；（2）选择可比公司并计算**基准**（中位数或均值）；（3）应用基准，必要时按基本面调整；（4）检查差异是否可以由基本面解释。

* 基准：同行组、行业或板块、股票指数，或股票**自身的历史**。
* 可比公司从最窄的 GICS（子行业）或 ICB（子板块）分组开始，然后按规模和所服务的市场筛选。
* 其他条件相同时：**增长越高 → 合理 P/E 越高；风险越高 → 合理 P/E 越低**。

**例子（Verizon 与同行）。** 历史 P/E：AT&T 13.20，Comcast 16.23，CenturyLink NM，中国电信 13.14，Charter 70.67，Verizon 15.03，Windstream 19.01。均值（不含 CenturyLink）24.55 被 Charter 扭曲，因此使用**中位数 15.03**。Verizon 处于中位数 → 估值合理；AT&T、中国电信和 CenturyLink 看起来被低估。还要检查现金流：电信公司有大量非现金费用。

**PEG 比率** = P/E ÷ 预期 EPS 增长率（以百分数表示）。越低越有吸引力；有人认为低于 1 就有吸引力。局限：它假设 P/E 与增长之间是**线性**关系，并忽略了**风险**以及增长能持续多久。

**例子（电信，结合基本面）。** CenturyLink：预期 P/E 8.89，增长 8.52%，PEG 1.04（低 P/E 公司中最低）→ 相对低估。AT&T：预期 EPS \$3.63 × 同行中位数 11.99，上调到 13.0（盈利能力更强、风险低于平均）= **\$47.19**，而价格为 \$33.98 → 低估。

**行业和市场比较。** 较大的组别能抵消个别的错误定价，但相似度较低。市值加权的指数 P/E 由最大的股票主导，因此对中盘股使用**中位数**。

**例子（与标普 500 比较）。** 指数 P/E 21.8。股票 A：P/E 15.2，历史上为指数的 80%（→ 17.4）。股票 C：P/E 15.2，历史上为 105%（→ 22.9）→ **C 被低估**。股票 B：P/E 30，而历史为 120%（26.2）→ 偏贵。这假设历史关系仍然成立。

**市场层面的模型。**

* **美联储模型**：当市场的预期 E/P 低于 10 年期国债收益率时，市场被高估；合理 P/E = 1 ÷ 国债收益率。例如收益率 2.72% → 合理 P/E 36.8，而历史 P/E 为 18.9。批评：它忽略了 ERP 和增长，对通胀处理不当，在低利率时呈非线性，对利率的小幅变化非常敏感。
* **Yardeni 模型**：盈利收益率 = CBY − b × LTEG + 残差，因此

$$
\frac{P}{E}=\frac{1}{CBY-b\times LTEG}
$$

  其中 CBY 是 A 级公司债收益率，LTEG 是一致预期的 5 年盈利增长率，$b$ 历史上为 0.10（后来为 0.10、0.20、0.25）。CBY 越高 → P/E 越低；增长越高 → P/E 越高。

**股票自身的历史。** 合理价格 = 自身历史 P/E 基准 × 最近（或正常化）的 EPS。如果业务组合、杠杆、利率或通胀发生了变化，这种方法就会失效。

**例子（本田）。** 五年 P/E 为 6.9、10.0、10.9、10.8、9.7：中位数 **10.0**，均值 9.7。EPS ¥381.93 → 合理价格 ¥3,819（中位数）或 ¥3,704（均值）。最近的价格约 ¥2,817–2,837，低约 24–26% → 可能被低估。

**通胀与 P/E。** 在没有实际增长、全部派现、成本通胀 $I$ 的传导率为 λ、实际要求回报率 $\rho=r-I$ 时：

$$
\frac{P_0}{E_1}=\frac{1}{\rho+(1-\lambda)I}
$$

完全传导（λ = 1）时，P/E = 1/ρ；完全不传导（λ = 0）时为 1/$r$。在不完全传导时，**通胀越高 → P/E 越低**；在相同通胀下，**传导越多 → P/E 越高**。例如 ρ = 3%：λ = 75% 时，$I$ = 6% → **22.2**，$I$ = 2% → **28.6**；$I$ = 6% 时，λ = 90% → **27.8**，λ = 70% → **20.8**。

### 用乘数计算终值

$$
V_n=\text{Trailing P/E}\times E_n
$$

$$
V_n=\text{Forward P/E}\times E_{n+1}
$$

* **基于基本面**的终值乘数是把 GGM 改写成乘数（对 $r$、支付率和 $g$ 敏感）。
* **基于可比公司**的乘数（行业 P/E 的中位数或平均值、股票自身过去的 P/E）以市场数据为依据，但会把任何市场错误定价带入终值。

**例子（石油勘探公司）。** $r$ 10%，成熟期支付率 45%，行业 ROE 13%，$E_3$ \$3.00，行业 P/E 14.3。

* 可比法：14.3 × 3.00 = **\$42.90**。
* GGM：$D_3$ = 1.35，$g$ = 0.55 × 13% = 7.15% → $V_3$ = 1.35(1.0715)/(0.10 − 0.0715) = **\$50.76**（高 18.3%）。

## 市净率

| 理由 | 缺点 |
| --- | --- |
| EPS 不为正时，账面价值通常仍为正 | 忽略了不在资产负债表上的价值：人力资本、声誉、内部创造的品牌和研发 |
| BVPS 比 EPS 更稳定 | 当资产密集度或商业模式不同时会产生误导 |
| 适合以流动资产为主的公司（银行、保险公司、投资公司） | 会计：历史成本与公允价值、通胀、技术、资产年龄 |
| 适合预期不会持续经营的公司 | **股票回购**扭曲历史比较 |
| P/B 的差异与长期回报相关 | |

* 例如，五年间高露洁的 P/E 上升了 5.5%，但其 P/B 上升了 125.9%，主要是因为高于账面价值的回购减少了其账面价值（\$24.8 亿 → \$15.3 亿）。
* 银行的 P/B 因商业模式而异（花旗 0.69，富国 1.21，美国合众银行 1.63）。

$$
BVPS=\frac{\text{Equity}-\text{Preferred}}{\text{Common shares}}
$$

优先股包括任何拖欠的优先股股利。

**例子（TD 银行）。** 2018 年 BVPS = (80,040 − 5,000)/1,830.4 = **CAD41.00**（2017 年：38.23；2016 年：37.58）；价格 CAD73.03 → **P/B 1.78**。

**调整**：使用**有形账面价值**（至少剔除商誉；专利等可分离的无形资产可以保留）；把 LIFO 转换为 FIFO；纳入表外项目；重述为公允价值。

**例子（巴克莱，2012 年）。** 价格 £2.4239；稀释股数 12,614m；权益 £62,957m；商誉和无形资产 £7,915m；金融资产的公允价值比账面价值低 £17,333m，负债的公允价值低 £399m。

* BVPS £4.9910 → P/B **0.49**；有形 BVPS £4.3636 → **0.56**。
* 调整后 BVPS = (62,957 − 7,915 − 17,333 + 399)/12,614 = £3.0211 → **0.80**。

**合理 P/B**（GGM，$g$ = $b$ × ROE，基于 $B_0$）：

$$
\frac{P_0}{B_0}=\frac{ROE-g}{r-g}
$$

$$
\frac{P_0}{B_0}=1+\frac{PV(RI)}{B_0}
$$

其中 $PV(RI)$ 是预期剩余收益的现值。

* 例如 ROE 12%，$r$ 10%，$g$ 7% → (0.12 − 0.07)/(0.10 − 0.07) = **1.67**。
* P/B 由**相对于 $r$ 的 ROE** 驱动：若 ROE = $r$，P/B = 1；若 $g$ = 0，P/B = ROE/$r$。在 P/B 相同时，ROE 较高的股票更便宜。

**例子（券商）。** E\*TRADE 的 P/B 为 0.65，不到嘉信（2.31）或 TD Ameritrade（2.53）的 30%，也不到其自身均值（1.14）的 60%。但其较低的账面价值和收入预测增长（1.5%、−1.0%）以及较高的 beta（1.65）可以解释这一点。

## 市销率

| 理由 | 缺点 |
| --- | --- |
| 销售额更难操纵 | 没有利润或现金的销售增长不等于价值 |
| 即使 EPS 不为正，销售额也为正 | P/S 把价格（融资之后）与**融资之前**的流量进行比较；应使用 EV/销售额 |
| 比 P/E 更稳定 | 忽略成本结构的差异 |
| 适合成熟、周期性和亏损的公司 | 收入确认仍可能使其失真 |
| P/S 的差异与长期回报相关 | |

P/S = P/E × 净利润率。

**例子（Stora Enso）。** 销售额 €10,486m，约 788.5m 股 → 每股销售额 €13.30；价格 €10.34 → **P/S 0.778**。

收入确认的危险信号：互联网公司之间的广告**易货**交易（1998–2000 年）、**开票持有**销售（Diebold：与 SEC 达成 \$2,500 万的和解）、**总额与净额**收入（Groupon 的重述使其销售额减少了一半以上）。如果怀疑存在操纵，使用更高的风险溢价（更低的合理 P/S），或回避该股票。

**合理 P/S：**

$$
\frac{P_0}{S_1}=\frac{(E_1/S_1)(1-b)}{r-g}
$$

$$
\frac{P_0}{S_0}=\frac{(E_0/S_0)(1-b)(1+g)}{r-g}
$$

它随利润率上升，既直接上升，也通过增长上升：$g=b\times PM\times\frac{Sales}{TA}\times\frac{TA}{Equity}$。

**例子。**

* **Getinge**：$r$ 9%，预测利润率 9%，支付率 35%，$g$ 7% → $P_0/S_1$ = 0.09 × 0.35/0.02 = **1.575**。以 2019 年每股销售额 SEK94.3 计，价值为 **SEK148.52**，高于 SEK133.70 的价格 → 低估。
* **可比公司**：Getinge 的 P/S 为 1.54，是最低的（CMD 3.96，NEO 8.79），因此看起来最便宜。但其利润率（−2.49%）、杠杆和 EV/收入（1.88）更接近 CMD，而不是 NEO（利润率 14.53%），因此 CMD 是更好的可比公司。

## 价格/现金流

| 理由 | 缺点 |
| --- | --- |
| 现金流比盈利更难操纵 | CF = EPS + 非现金费用，忽略了非现金收入和营运资本变化 |
| 比 P/E 更稳定 | 理论偏好 FCFE，而它波动更大、常为负 |
| 避免会计稳健性程度的差异 | CFO 可以被管理（应收款证券化、外包应付款） |
| P/CF 的差异与长期回报相关 | IFRS 和 US GAAP 对利息和股利的分类不同 |

| 现金流指标 | 说明 |
| --- | --- |
| **CF** = EPS + 折旧、摊销、折耗 | 简单的近似 |
| **CFO**（来自现金流量表） | 调整非经常性项目和 IFRS/GAAP 差异 |
| **FCFE** | 与理论联系最紧密；波动大（资本支出的时间），因此使用平均值或 DCF 价值 |
| **EBITDA** | 利息之前 → 与 **EV** 搭配，而不是价格 |

**例子。**

* **折旧方法**：现金流相同，但 A 使用直线法（EPS 稳定在 \$10），B 使用加速折旧（EPS 每年增长 29%，7.50 → 12.50）；两者的 CF 都是每股 \$15。EPS 增长可能是会计造成的假象。
* **飞利浦**：EPS €1.41 + 每股 D&A €1.17 = CF €2.58；价格 €36.31 → **P/CF 14.1**。
* **高露洁，合理乘数**：FCFE₀ \$2.66，CF \$3.26，$r$ 7.4%，$g$ 3.2% → $V_0$ = 1.032(2.66)/0.042 = **\$65.36**；合理 P/CF = 65.36/3.26 = **20.05**；P/FCFE = **24.57**。
* **两家公司**：A 的 P/CF 为 9.8，B 为 11.4，但 A 的增长预测高 280 个基点，且其 FCFE 为正（B 为负）→ A 相对低估。

## 股息率

* **理由**：是总回报的一个组成部分，而且风险较小。
* **缺点**：只是回报的一部分；**股利替代盈利**（现在派发会降低未来增长，尽管支付率可能与未来盈利能力相关）；"更安全"的论点假设市场对风险定价错误。
* **历史股息率** = 股利率（最近一次季度股利 × 4，或对半年派息不均的公司取最近一年的合计）÷ 价格。**预期股息率** = 下一年的预测股利 ÷ 价格。

**例子（BCE、BT）。** BCE：4 × 0.58 = \$2.32 ÷ \$39.53 = **5.87%**。BT（半年派息不均）：\$0.976/\$15.20 = **6.42%**。

**合理股息率**（GGM）：

$$
\frac{D_0}{P_0}=\frac{r-g}{1+g}
$$

增长越高 → 股息率越低（高股息率筛选偏向价值型）；$r$ 越高 → 股息率越高。检查股利的**安全性**：支付率、利息保障倍数、净债务/EBITDA。

**例子（公用事业）。** Duke 的股息率为 4.24%，但支付率为 89%（股利有风险）；PPL 的股息率为 5.37%，但增长只有 0.60%；Portland General 的股息率 2.76% 加上 5.20% 的增长 ≈ **7.96%** 的预期回报，且没有明显的负面因素 → 应重点关注它。

## 企业价值乘数

$$
\begin{aligned}
EV={}&\text{Equity}+\text{Preferred}\\
&+\text{Minority interest}+\text{Debt}\\
&-\text{Cash and ST investments}
\end{aligned}
$$

（全部按市值）。减去现金是因为收购方会得到它：EV 是净购买价格。使用债务的市值；如果没有，使用账面价值或矩阵定价的价值。**总投入资本**（TIC）= 权益 + 债务，**不**减去现金。

| EV/EBITDA 的理由 | 缺点 |
| --- | --- |
| 对**杠杆**不同的公司比 P/E 更好（EBITDA 在利息之前） | 营运资本增长时高估 CFO；忽略收入确认的影响 |
| 控制了 D&A 的差异 → 资本密集型公司（有线电视、钢铁） | FCFF 与价值的联系更好；只有当 D&A ≈ 资本支出时，EBITDA 才反映资本支出 |
| EPS 为负时，EBITDA 常为正 | |

EV 乘数采用**控制权**视角，对杠杆的敏感度低于价格乘数。

**例子（高露洁 EV/EBITDA，\$m）。** 市值 863 × \$66.48 = 57,372；债务（长期债务 6,354 + 当期部分 0 + 其他非流动负债 2,269）= 8,623；非控制性权益 299；现金 726 → **EV 65,034**。EBITDA = NI 2,400 + 利息 143 + 税 906 + D&A 511 = **3,960** → **EV/EBITDA 16.6**。

* 有优先股时，EBITDA 从归属于优先股和普通股股东**双方**的净利润开始计算。
* 合理 EV/EBITDA 随预期 **FCFF 增长**和 **ROIC**（税后营业利润 ÷ 投入资本）上升，随 **WACC** 下降。
* EV/EBITDA 低于同行 → 相对低估（是若干输入之一）。

**例子（家居用品）。** EV/EBITDA：高露洁 16.9，金佰利 14.7，Clorox 17.6，Church & Dwight 22.5（TIC/EBITDA 的排序相同；只有当现金持有量差异很大时排序才可能不同）。高露洁比 Clorox 和 Church & Dwight 便宜（它的增长比 Church & Dwight 慢），比金佰利贵（利润率 14.8% 对 9.8%）。

**其他 EV 分母**，从净利润构建：

| 指标 | 利息 | 税 | 折旧 | 摊销 | 其他 |
| --- | --- | --- | --- | --- | --- |
| FCFF | +（税后） | | + | + | − WCInv − FCInv |
| EBITDA | + | + | + | + | |
| EBITA | + | + | | + | 摊销大而折旧不大时 |
| EBIT | + | + | | | 两者都不大时 |

行业特定指标包括 EV/EBITDAR（航空公司）、EV/用户数和 EV/储量。**EV/销售额**修正了 P/S 对资本结构不同公司的错配：例如 Stora Enso 的权益 €8,154m + 债务 €2,970m − 现金 €1,130m = **€9,994m** → EV/销售额 = **0.953**。

## 合理乘数：汇总

| 乘数 | 合理值（基于 GGM） | 随之上升 | 随之下降 |
| --- | --- | --- | --- |
| 预期 P/E | $(1-b)/(r-g)$ | $g$、支付率 | $r$ |
| 历史 P/E | $(1-b)(1+g)/(r-g)$ | $g$、支付率 | $r$ |
| P/B | $(ROE-g)/(r-g)$ | ROE − $r$ | $r$ |
| 预期 P/S | $PM_1(1-b)/(r-g)$ | 利润率、$g$ | $r$ |
| 历史 P/S | $PM_0(1-b)(1+g)/(r-g)$ | 利润率、$g$ | $r$ |
| D/P | $(r-g)/(1+g)$ | $r$ | $g$ |
| P/CF、P/FCFE | DCF 价值 ÷ CF | $g$ | $r$ |
| EV/EBITDA | （定性） | FCFF 增长、ROIC | WACC |

## 跨境比较

差异来自会计准则、文化、经济、风险和增长机会；同一行业的 P/E 以及整个市场的 P/E 在各国之间差异很大。

把 IFRS 调节为 US GAAP 的典型影响（Harris 和 Muller）：

| 类别 | 盈利 | 权益 |
| --- | --- | --- |
| 商誉 | − | + |
| 递延所得税 | + | + |
| 外汇调整 | + | − |
| 研发成本 | − | − |
| 养老金费用 | − | + |
| 有形资产重估 | + | − |
| 其他 | − | − |

最常见的调整是养老金；金额最大的是商誉。**P/CFO 和 P/FCFE 受会计差异的影响最小**；P/B、P/E 和 EBITDA 乘数**受影响最大**。通胀和传导率的差异也会扭曲 P/E。

## 动量指标

| 指标 | 定义 |
| --- | --- |
| 意外盈利（盈利意外） | $UE_t=EPS_t-E(EPS_t)$；意外百分比 = UE ÷ 预期 EPS |
| 标准化盈利意外 | UE ÷ **分析师预测**的标准差（其离散度） |
| 标准化意外盈利 | $SUE_t=\dfrac{EPS_t-E(EPS_t)}{\sigma[EPS_t-E(EPS_t)]}$，使用**过去意外**的标准差（如 20 个季度） |
| 相对强弱 | 股票在一段时期内的复合回报（价格动量），或股票 ÷ 指数，常在起点标准化为 1.0 |

依据：正的意外之后可能出现持续的超额回报，回报可能表现出持续或反转。注意事项：数据挖掘和后见之明偏差，以及技术规则一旦被广泛使用往往就会失效。动量可以提示价格**何时**会向内在价值收敛。

**例子。**

* **BP 的标准化盈利意外**：一致预期 \$3.26，最高估计 \$3.74，预测的标准差 \$0.29 → (3.74 − 3.26)/0.29 = **1.66**。
* **SUE**：意外 \$0.05，过去意外的标准差 \$0.20 → SUE 0.25；标准差 \$0.07 时 → 0.71。埃克森美孚，2013 年 9 月：(1.79 − 1.77)/0.1250 = **0.16**。大众的意外百分比更大，但埃克森美孚的 SUE 波动更大（标准差更小），因此"准确性"取决于所用的指标。
* **相对标普 500 的相对强弱**（2018 年 3 月 = 1.0）：到 2019 年 8 月，TLT **1.067**（比指数 +6.7%），FEU **0.847**（−15.3%），EEM **0.743**（−25.7%）。2018 年 12 月，EEM 的相对强弱从 0.852 升至 0.872，而 FEU 从 0.909 降至 0.885。

## 对乘数取平均

$$
X_H=\frac{n}{\sum_{i=1}^{n}1/X_i}
$$

$$
X_{WH}=\frac{1}{\sum_{i=1}^{n}w_i/X_i}
$$

* 以市值为权重的**加权调和平均**是投资组合真正的总体乘数（指数提供商使用）。
* 调和平均低于算术平均（除非所有值都相等）。它给高乘数较小的权重，因此减少了**大**离群值的影响，但可能放大**小**离群值的影响（它以零为下界）。
* **中位数**在两个方向上都限制离群值。

**例子（两只股票的组合）。** 市值 €715m、盈利 €71.5m（P/E 10），以及市值 €585m、盈利 €29.25m（P/E 20）。组合 P/E = 1,300/100.75 = **12.90**。

| 指标 | 计算 | P/E |
| --- | --- | --- |
| 算术平均 | (10 + 20)/2 | 15.00 |
| 加权平均 | 0.55(10) + 0.45(20) | 14.50 |
| 调和平均 | 1/[0.5(0.1) + 0.5(0.05)] | 13.33 |
| **加权调和平均** | 1/[0.55(0.1) + 0.45(0.05)] | **12.90** |

**例子（电信 P/E）。** 包括 Charter 的 70.67：算术平均 25.30，中位数 15.23，调和平均 17.70（更接近中位数）。不含离群值：16.43、15.03、15.39。

**使用多个指标。** 分析师把 DCF 价值与乘数（P/E、EV/EBITDA、股息率）结合使用。在回测中，要注意**前视偏差**（使用了当时尚未公布的数据）。

**筛选**按标准缩小股票范围。局限：无法控制 EPS 等输入的计算方式，也没有定性因素。

**例子（Larsen 的筛选）。** P/E < 20，P/B < 2，PEG < 1，股息率 ≥ 3%，市值 > \$100 亿 → 10 只股票。她是**大盘价值**投资者，不使用动量指标。局限：没有盈利能力或风险标准（低 P/E 可能反映低盈利能力或高风险）、数据库输入未经调整、没有定性因素。
