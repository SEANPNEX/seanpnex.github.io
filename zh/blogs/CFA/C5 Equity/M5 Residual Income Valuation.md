# 剩余收益估值

**剩余收益**（RI）是净利润减去股权成本费用：在**所有**资本都得到补偿之后剩下的利润。RI 模型把股票的价值估计为其账面价值加上预期未来剩余收益的现值。涵盖 RI、EVA 和 MVA；一般、单阶段和多阶段 RI 模型；RI 与 P/B、股利模型和自由现金流模型的关系；以及该模型所需的会计调整。

## 剩余收益、EVA 与 MVA

净利润已经扣除了**债务**成本（利息），但没有扣除**股权**成本，因此正的净利润仍可能毁灭价值。

$$
RI=NI-r_e\times\text{Equity capital}
$$

从所有资本提供者的角度看：RI = NOPAT − 总资本费用（以金额表示的 WACC）=（ROIC − 有效资本费用率）× 期初资本。当债务的边际成本等于其当前成本，且资本权重为**账面**权重时，两种视角一致。

**例子（Axis Manufacturing）。** 资产 €200 万，50% 由债务（税前 7%）融资，50% 由股权（12%）融资；EBIT €200,000；税率 30%。

* NI = (200,000 − 70,000) × 0.7 = €91,000；股权费用 0.12 × 1,000,000 = €120,000 → **RI = −€29,000**。
* 资本视角：NOPAT €140,000 − (120,000 + 0.07 × 0.7 × 1,000,000 = 169,000) = **−€29,000**；ROIC 为 7%，而资本费用率为 8.45%。
* 估值：100,000 股，账面价值 €10；每股每年毁灭价值 €0.29 → 现值 0.29/0.12 = €2.42 → 价格 ≈ **€7.58**（E/P = 0.91/7.5833 = 12%），P/B 0.7583。RI 为负 → P/B 低于 1。

**经济增加值**（Stern Stewart 的商业版本）：

$$
EVA=NOPAT-(C\%\times TC)
$$

其中 $C\%$ 是资本成本，TC 是总资本。典型的调整：把研发资本化并摊销（把净研发加回 NOPAT）；对回报延迟的战略性投资暂停计算资本费用；使用现金税（剔除递延所得税）；把 LIFO 储备加入资本，并把其增加额加入 NOPAT；把经营租赁视为资本租赁；调整非经常性项目。

**市场增加值：**

$$
\begin{aligned}
MVA={}&\text{Market value of the company}\\
&-\text{Book value of total capital}
\end{aligned}
$$

长期为正的经济利润 → 市场价值高于资本的账面价值。研究结果不一：增加值指标与回报的相关性略高于 ROA 或 ROE，但在预测业绩方面并不优于盈利增长。

**用途。** RI 模型用于为个股和指数（如道琼斯）估值。商业版本主要用于**衡量内部业绩**和设定**高管薪酬**，而不是为股权估值。其他名称：经济利润、异常盈利、折现异常盈利模型、Edwards–Bell–Ohlson 模型，在美国税务估值中称为**超额收益法**。

## 一般 RI 模型

$$
V_0=B_0+\sum_{t=1}^{\infty}\frac{RI_t}{(1+r)^t}
$$

$$
\begin{aligned}
V_0&=B_0+\sum_{t=1}^{\infty}\frac{E_t-rB_{t-1}}{(1+r)^t}\\
&=B_0+\sum_{t=1}^{\infty}\frac{(ROE_t-r)B_{t-1}}{(1+r)^t}
\end{aligned}
$$

* 每股 RI = EPS − $r$ × **期初** BVPS。这里的 ROE 使用**期初**账面价值，而不是平均值。
* 该模型是利用**净盈余关系** $B_t=B_{t-1}+E_t-D_t$ 从 DDM 推导出来的。
* 如果未来 RI 的现值为正，价值就高于账面价值。

**例子（加拿大国家铁路）。** $r$ = 1.75% + 1.02 × 7.5% = **9.40%**；BVPS CAD24.32；EPS 6.23（2019 年）和 6.96（2020 年）；DPS 2.15 和 2.32。2019 年 RI = 6.23 − 0.094 × 24.32 = **3.94**；$B_{2019}$ = 24.32 + 6.23 − 2.15 = 28.40；2020 年 RI = 6.96 − 0.094 × 28.40 = **4.29**。

**例子（Bugg Properties，清算）。** EPS 2.00、2.50、4.00；DPS 1.00、1.25、12.25（清算）；$B_0$ \$6.00；$r$ 10%。

| 年份 | 1 | 2 | 3 |
| --- | --- | --- | --- |
| 期初账面价值 | 6.00 | 7.00 | 8.25 |
| ROE | 33.33% | 35.71% | 48.48% |
| 股权费用 | 0.60 | 0.70 | 0.825 |
| RI | 1.40 | 1.80 | 3.175 |
| 期末账面价值 | 7.00 | 8.25 | 0.00 |

* RI 模型：6.00 + 1.2727 + 1.4876 + 2.3854 = **\$11.15**。DDM：0.9091 + 1.0331 + 9.2036 = **\$11.15**。
* 价值相同，但 RI 模型在 $t$ = 0 时就确认了 \$6.00，而 DDM 从最后一年得到 \$9.20：**RI 更早确认价值**。

**例子（Alphabet，ROE 逐步下降）。** $r$ 8.2%；$B_0$ \$255.40；ROE 2019 年为 20.2%，每年下降 0.5 个百分点，到 2043 年降至 8.2%（此后 RI = 0）；不派股利。2019 年：EPS = 0.202 × 255.40 = \$51.59；费用 \$20.94；RI \$30.65；现值 \$28.33。加总到 2042 年得到 **\$972.25**，而价格为 \$1,037.39。

## 合理 P/B 与 RI 的驱动因素

在不变增长下，$g = b\times ROE$：

$$
\frac{P_0}{B_0}=\frac{ROE-g}{r-g}=1+\frac{ROE-r}{r-g}
$$

$$
V_0=B_0+\frac{ROE-r}{r-g}\,B_0
$$

* RI 由**相对于 $r$ 的 ROE** 以及账面价值驱动。
* ROE = $r$ → 价值 = 账面价值（P/B = 1）；ROE < $r$ → P/B 低于 1。
* RI 模型与 **P/B** 关系最紧密：恰好在预期 RI 的现值为正时，合理 P/B 大于 1。
* **托宾 q** = 债务和股权的市值 ÷ 总资产的**重置成本**。与 P/B 不同，它把总资本放在总资产之上，并使用重置成本（反映通胀）而不是历史成本。资产生产率越高 → q 越高（托宾预期 q 的平均值为 1）。重置成本很难衡量。

## 单阶段 RI 模型

单阶段模型假设 ROE 和 $g$ **永远**不变，因此超额回报会无限持续。实践中，ROE 会向均值回归：竞争者进入高 ROE 行业，而退出会提高低 ROE 行业的回报。

**例子（飞利浦）。** $B_0$ €13.22，价格 €35.40，ROE 12%，$g$ 6.75%，$r$ 8.5%（数值以 € 计）：

$$
\begin{aligned}
V_0&=13.22+\frac{0.12-0.085}{0.085-0.0675}\times13.22\\
&=39.66
\end{aligned}
$$

**隐含增长率**：求解 $35.40=13.22+\frac{0.12-0.085}{0.085-g}\times13.22$ → **$g$ = 6.41%**。由于 ROE 高于 $r$，市场价格约为账面价值的 2.7 倍。

## 多阶段 RI 与持续剩余收益

明确预测 $T$ 年的 RI，然后加上高于账面价值的终值溢价：

$$
\begin{aligned}
V_0={}&B_0+\sum_{t=1}^{T}\frac{E_t-rB_{t-1}}{(1+r)^t}\\
&+\frac{P_T-B_T}{(1+r)^T}
\end{aligned}
$$

* 当前账面价值通常占总价值的很大一部分，因此终值的重要性**低于** DDM 或 FCF 模型。
* $P_T$ 可以来自任何模型：DDM、P/E 或 P/B。
* **持续剩余收益**是预测期之后的 RI。常见假设：
  1. RI 以正的水平无限持续（可能随通胀增长，即实际值不变）。
  2. 从终值年起 RI 为零。
  3. 随着 ROE 回归到 $r$，RI 下降到零。
  4. RI 反映 ROE 回归到某个均值水平（如行业 ROE；Lee–Swaminathan 的向行业均值衰减）。

**持续性模型**（Dechow、Hutton 和 Sloan）：

$$
\begin{aligned}
V_0={}&B_0+\sum_{t=1}^{T-1}\frac{E_t-rB_{t-1}}{(1+r)^t}\\
&+\frac{E_T-rB_{T-1}}{(1+r-\omega)(1+r)^{T-1}}
\end{aligned}
$$

持续性因子 ω 介于 0 和 1 之间：ω = 1 → RI 作为永续年金持续；ω = 0 → RI 在第 $T$ 年后停止。ω 越高 → 价值越高。研究发现的平均 ω 约为 **0.62**（RI 每年衰减约 38%）。

| 持续性较低 | 持续性较高 |
| --- | --- |
| 极端的 ROE | 股利支付率低 |
| 极端的特殊（非经常性）项目 | 行业历史上的持续性高 |
| 极端的会计应计项目 | |

**例子（Zenlandia Chemical，三种终值假设）。** 价格 ZL\$95.6；$r$ 12%；$B_{2019}$ ZL\$28.8517；EPS 7.162 和 8.356，DPS 2.9995 和 3.2995；之后 ROE 为 25%（2022–26 年）和 20%（2027–39 年），留存率 60%。

| 持续 RI 的假设 | 价值 | 结论 |
| --- | --- | --- |
| 2039 年之后 RI = 0 | **ZL\$86.41** | 高估 |
| 2039 年的 RI 永远持续：TV = 23.8664/0.12 = 198.8867，PV = 198.8867/1.12²⁰ = 20.6179 | 86.41 + 20.62 = **ZL\$107.03** | 低估 |
| 持续性 ω = 0.60：23.8664/[(1 + 0.12 − 0.60)(1.12)¹⁹] = 5.33 | 83.93 + 5.33 = **ZL\$86.26** | 略微高估 |

**例子（URS Holdings，终值 P/B）。** $B_0$ €15.00；$r$ 7.95%；EPS = 期初账面价值的 25%；支付率 30%；$P_6$ = 1.80 × $B_6$。

* 第 1–6 年的 RI：2.558、3.005、3.531、4.149、4.875、5.728；现值 **17.755**；$B_6$ = 39.475。
* 终值溢价 = 0.8 × 39.475 = 31.580，现值为 **19.956**。
* $V_0$ = 15.000 + 17.755 + 19.956 = **€52.711**。
* DDM 核验：股利现值 7.810 + $P_6$（71.054）的现值 44.901 = **€52.711**。

## RI 与股利模型和自由现金流模型的比较

* 三者在理论上一致：只要预测一致且折现率相同（DDM、FCFE 和 RI 用 $r$；FCFF 用 WACC），它们给出相同的价值。
* DDM 和 FCF 模型折现未来现金流；RI 模型从账面价值出发并加上 RI 的现值，因此**价值确认得更早**，RI 对不确定的终值也不那么敏感。

**例子（永续年金）。** EPS 永远为 \$1.00，支付率 100%，账面价值 \$6.00，$r$ 10%。DDM：1.00/0.10 = **\$10.00**。RI = 1.00 − 0.60 = 每年 \$0.40 → 6.00 + 0.40/0.10 = **\$10.00**。在 RI 模型中账面价值占价值的 60%；在 DDM 中，前五年的股利只有 \$3.79（约 38%）。

RI 模型还可以给出合理乘数（RI 价值 ÷ EPS = 合理 P/E），并对其他模型进行交叉检验：如果结果差异很大，就检查假设是否一致。

| 优点 | 缺点 |
| --- | --- |
| 终值只占总价值的一小部分 | 会计数据可能被操纵 |
| 使用容易获得的会计数据 | 会计输入可能需要大幅调整 |
| 适用于不派息和近期 FCF 为负的公司 | 需要净盈余关系成立，否则需要调整 |
| 在现金流不可预测时适用 | 假设利息费用正确反映债务成本 |
| 关注经济盈利能力 | |

| 最适合 | 最不适合 |
| --- | --- |
| 不派股利，或股利不可预测 | 严重偏离净盈余关系 |
| 预测期内预期 FCF 为负 | 账面价值和 ROE 不可预测 |
| 在其他模型下终值的不确定性很大 | |

FCF 为正且可预测、但不派股利的公司，更适合使用 **FCF 模型**。

#### 考试陷阱

* 股权费用使用**期初**账面价值。
* RI 增长 ≠ NI 增长：在 Mannistore（下文）中，NI 增长 8%，但 RI 下降约 2%。
* RI 为负并不意味着净利润为负。

## 会计问题

**平衡效应**（Bauman）：激进的会计处理会提高账面价值，但降低未来盈利，**只要净盈余关系成立**，两者就会相互抵消。实践中它常常不成立，而且分析师会外推过去的盈利。例如，账面价值 \$1,000,000，费用化 \$50,000 后税前盈利 \$200,000 → ROE 20%。若把这 \$50,000 资本化，则为 \$250,000/\$1,050,000 = **23.81%**；简单外推这个 ROE 会高估价值。

### 1. 违反净盈余关系（非净盈余、OCI）

绕过利润表的项目：

* 某些金融工具的未实现公允价值变动（IFRS 下的 FVOCI 权益工具；US GAAP 下的可供出售证券）
* 外币折算调整
* 某些养老金调整
* 某些套期的部分利得和损失
* PP&E 和无形资产的重估盈余（**仅 IFRS**）
* 某些负债因自身信用风险而产生的公允价值变动（**仅 IFRS**）

账面价值是正确的（它包括累计 OCI），但对 RI 而言，**净利润和 ROE 被错报**。只有当这些违反项的现值不能相互抵消为零时才会产生偏差。按总额计算历史 ROE（NI ÷ 权益），因为回购和发行会扭曲每股 ROE。

**例子。**

* **诺基亚和 SAP（2018 年）**：绕过利润的折算调整为 +€3.41 亿（诺基亚）和 +€8.87 亿（SAP，"其他权益组成部分"）。两者都会提高利润，因此如果这一趋势持续，可能需要向上调整 ROE（但汇率可能反转）。
* **考虑 OCI 的预测**：NI \$120，权益 \$1,000（12%），OCI −\$100，$r$ 10%。明年 RI 的增长：如果未来没有 OCI，为 **12%**（与 ROE 一致）；如果 OCI 重复出现，为 **2.2%**；如果反转，为 **21.8%**。在 OCI 重复时使用综合收益：RI 为 22.40 − 102 = **−\$79.60**，而不是 +\$20.40。
* **Mannistore**：$r$ 10%；$P_5$ = \$68.40 的 DDM → **\$43.59**。只用 NI 计算的 RI → **\$44.42**（错误：忽略了第 2 年 −\$1.00 的 OCI）；用 NI + OCI 计算的 RI（第 2 年 RI 为 0.45 而不是 1.45）→ **\$43.59**，与 DDM 一致。第 6 年：NI 4.56 × 1.08 = 4.92；RI 4.92 − 2.204 = 2.72 → RI 增长约 **−2%**，尽管 NI 增长 8%。

### 2. 对资产负债表的公允价值调整

审查存货（LIFO，IFRS 不允许）、递延所得税、经营租赁（不影响权益，但影响未来盈利）、准备和备抵以及无形资产。

### 3. 无形资产

内部创造的无形资产（如通过广告建立的品牌）除非是外购的，否则不予确认。

**例子（Alpha 收购 Beta）。** Alpha：账面价值 5,000，ROE 12% → 价值 = 5,000 + (0.02/0.10)5,000 = **6,000**。Beta：账面价值 1,000，ROE 15% → **1,500**。合计 7,500。Alpha 支付 €1,500 现金；€500 的超额部分是 10 年期的许可。

* 有 €50 的摊销时：NI 700，ROE 14% → 价值 **7,000**（被低估）。
* 加回摊销：NI 750，ROE 15% → **7,500**，正确。
* 用股票支付：账面价值 6,500，ROE 11.538% → **7,500**（支付形式不改变价值）。

确认一项被遗漏的资产并在之后摊销，对 RI 价值**没有影响**（更高的 $B_0$ 被摊销加上资本费用所抵消）。与资本化相比，把研发费用化会降低当期 ROE，但会略微提高之后的 ROE；对成熟公司而言，ROE 无需调整即可反映研发的生产率。

### 4. 非经常性项目

根据**经常性**盈利预测 RI；不需要调整账面价值。检查异常项目、非常项目（仅 US GAAP）、重组费用、终止经营和会计变更。**每个**期间都记录的重组费用，实际上可能是普通的营业费用。注意与 SG&A 相抵的非经营利得。

### 5. 激进的会计处理

加速收入确认（发运未订购的商品）或递延费用（将其资本化）会同时夸大盈利和账面价值。"饼干罐"准备：提前多计费用，之后再转回以提高后来的利润。

### 6. 国际因素

Frankel 和 Lee 发现，未经调整的 RI 可以解释 20 个国家约 70% 的价格横截面差异。关键问题：盈利预测是否可靠；是否存在系统性的违反净盈余关系的情况；会计是否"质量差"，存在延迟确认？在这些问题严重的地方，使用较少依赖会计的模型（如 FCFE）。
