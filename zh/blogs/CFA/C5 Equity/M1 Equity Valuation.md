# 权益估值

"价值"意味着什么，感知到的错误定价从何而来；估值有什么用途；以及五步估值流程，包括绝对模型与相对模型、分部加总估值和如何选择模型。本单元为权益部分的其余内容打下基础。

## 价值与价格

**估值**是根据与资产未来回报相关的变量、与相似资产的比较，或（在相关时）根据清算时可得的价格来估计资产的价值。

### 内在价值与市场价格

* **内在价值**（IV）是投资者在完全了解资产投资特征的情况下会赋予它的价值。
* 在有效市场中，价格是 IV 的最佳估计。但根据 **Grossman–Stiglitz 悖论**，如果价格完全有效，就没有人会为分析付费，因此价格不可能完全有效。**理性有效市场**观点：投资者只有在预期更高的回报足以覆盖信息成本时才会收集信息。由于 IV 难以确定且交易有成本，价格可能偏离价值。
* **Alpha**（超额回报）是高于风险所应得回报的部分；**感知的错误定价**是估计的 IV 减去价格。
* 可能需要一个**催化剂**（市场或公司事件），才能使价格在投资者的期限内向价值收敛。

感知的错误定价有两个来源：

$$
\begin{aligned}
E(IV)-P ={}& \underbrace{(IV-P)}_{\text{true mispricing}}\\
&+\underbrace{(E(IV)-IV)}_{\text{valuation error}}
\end{aligned}
$$

只有真实的错误定价才能带来超额回报。要持续获胜，分析师的预期必须**与市场共识不同，而且平均而言是正确的**。

### 价值的定义

| 定义 | 含义 |
| --- | --- |
| **持续经营价值** | 假设公司在可预见的未来持续经营、以价值最大化的方式使用其资产并能获得最优融资时的价值。这些模块关注的重点 |
| **清算价值** | 公司解散、资产逐项出售时的价值。通常低于持续经营价值（资产协同运作，加上人力资本，会增加价值），但长期亏损的公司可能"死了比活着更值钱"。**有序**清算比被迫立即出售能卖得更多 |
| **公允市场价值** | 在自愿、知情的买卖双方之间、均无强迫情况下的价格。用于税务和私营公司的买卖协议；如果管理层为所有者利益行事，长期市场价格应趋向于它 |
| **公允价值**（财务报告） | 熟悉情况的自愿双方在公平交易中交换的金额，如用于减值测试；与公允市场价值相关但并不相同 |
| **投资价值** | 对**特定**买方的价值，包括该买方的协同效应和要求 |

> [!IMPORTANT]
> 对**上市股票**而言，相关的定义是**持续经营假设下的内在价值**。

## 权益估值的用途

* **选股**（主要用途）：相对于其 IV 和可比公司，股票是定价合理、被高估还是被低估？
* **推断市场预期**：令模型等于价格，代入除一个之外的所有输入，求解那一个（逆向工程）。
* **评估公司事件**：并购、剥离、分拆、私有化交易（以及用作货币的收购方股票的价值）。
* 对并购条款出具**公允性意见**。
* **评估业务战略和商业模式。**
* 与分析师和股东**沟通**。
* **评估私营企业**（交易、税务、IPO）。
* **股份支付**（薪酬）。

**例子（英特尔，Cornell 2001）。** 在收入增长不及预期后，股价在五天内从 \$61.50 跌至 \$43.31（约 30%）。公告前的价格隐含 10 年约 20% 的增长，之后为 6%；公告后的价格隐含的增长远低于 15%。要判断下跌是过度反应还是修正，需把**隐含增长**与公司历史、行业增长和经济预测进行比较。Cornell 发现 20% 远高于英特尔最近五年的增长：股票在公告**之前**就已被高估，而公告起到了催化剂的作用。

## 估值流程

1. **了解业务**：行业和竞争分析，以及盈利质量。
2. **预测**公司业绩。
3. **选择**合适的估值模型。
4. 把预测**转换**为估值。
5. **运用**估值结论。

### 1. 了解业务

**行业和竞争分析**提出三个问题：

* 公司所在行业的**吸引力**如何（持续盈利的前景）？→ 行业结构、波特五力。
* 公司的**相对竞争地位**和战略是什么？→ 市场份额的水平和趋势；通用战略。
* 它的战略**执行**得如何，前景如何？→ 历年的财务报告（10 年前、5 年前、最近 2 年）以及定性因素。避免简单外推：在长期，增长会**向均值回归**（经济增长率）。

| 波特五力 | 在以下情况下有利于行业盈利 |
| --- | --- |
| 行业内的竞争 | 竞争者少和/或品牌强 |
| 新进入者的威胁 | 进入成本高或有其他壁垒 |
| 替代品的威胁 | 替代品少，或转换成本高 |
| 供应商的议价能力 | 供应商众多 |
| 买方的议价能力 | 客户众多 |

波特的三种竞争战略：

1. **成本领先**：成为成本最低的生产者，以行业平均水平或接近的价格销售可比产品。
2. **差异化**：提供买方重视的独特产品，以溢价销售。
3. **聚焦**：在目标细分市场中取胜，可以是成本聚焦或差异化聚焦。

**商业模式**是公司赚钱的方式（客户、产品、交付和融资），例如只有一个舱位等级、一种机型的低成本航空公司。

**例子（油田服务：Schlumberger、Halliburton、Baker Hughes、Saipem、NOV、Weatherford）。** 需求取决于油气勘探和生产，而后者取决于油气价格，因此要研究油气的供需（库存、OPEC 产能、新发现、家庭、商业和发电用途、GDP 增长、资源枯竭）。要找出**成本领先者**，比较利润率的水平和趋势（按定价能力调整）以及**人均收入**。

* 对于新公司和新产品，**非财务指标**很重要（临床试验结果、独立访客数）。
* 信息来源：监管文件（10-K/20-F 中的业务描述和 MD&A；10-Q/6-K 中期报告）、盈利公告、电话会议、投资者关系和第三方。**Regulation FD** 和 CFA 准则禁止使用重大非公开信息。
* ESG 信息来源（如美国汽车业）：可持续发展报告、OSHA、EEOC、SASB、碳信息披露项目、Ceres。

**盈利质量分析**审查**所有**报表，关注（1）业绩的**可持续性**和（2）报告反映经济现实的准确程度。

* 包含大量非经常性部分（诉讼胜诉、临时减税、出售非经营资产的利得）的盈利质量较低。
* 从比较**净利润与经营现金流**开始。应计部分为 NI − (CFO + CFI)。现金部分**更具持续性**；高应计项目预示未来 ROA 较低（Sloan 1996），即盈利质量较低。
* 某个资产账户增长远快于销售（应收款、递延成本），可能表明会计处理激进。

| 领域 | 警示信号 | 可能的含义 |
| --- | --- | --- |
| 收入和利得 | 提前确认收入（开票持有；在安装和验收前确认销售） | 提高利润，掩盖业绩下滑 |
| | 把非经营收入或利得归为经营项目 | 可能是非经常性的；掩盖下滑 |
| 费用和损失 | 准备计提过多或过少（重组、贷款损失/坏账、递延所得税估值备抵） | 在期间之间转移利润 |
| | 把支出资本化（客户获取、产品开发） | 以未来利润为代价提高当期利润 |
| | 激进的估计（减值、较长的折旧年限和摊销期、较高的养老金折现率、较低的薪酬增长、较高的计划资产预期回报） | 提高当期利润；变更可能掩盖问题 |
| 资产负债表 | 表外融资（应收款证券化） | 资产和负债错报 |
| 经营现金流 | 把银行透支的增加归为经营活动 | CFO 被夸大 |

**例子。**

* **巴菲特论养老金假设**：标普公司假设计划资产回报率为 8%；在 28% 投资于收益 5% 的现金和债券的情况下，股票需要扣费后 9.2% 的回报。较高的假设回报意味着更大的"预期回报"扣减 → 养老金费用**被低估**，净利润**被高估**。该假设在**附注**中。
* **Tangoe**（SEC，2018 年）：从不太可能付款的客户处确认收入，坏账准备被低估 → 收入、盈利和应收款被夸大；NI 高于 CFO。警示信号：收入 +12%，而平均应收款 +32%；应收账款周转率 4.6 倍 → 4.2 倍；应收账款周转天数 **79 → 87**。
* **Livent**：把制作前成本（广告、布景、排练薪酬）资本化，提高了 EPS 并形成一项资产。在 EBITDA 中加回摊销夸大了财务实力：1996 年报告的债务/EBITDA 为 1.7，但不加回时为 **5.5**；1997 年报告的 EBITDA 为 +\$58.3m，实际为 **−\$52.6m**。1998 年破产。

**舞弊风险因素**（动机、机会、态度）：达成目标的压力加上强势的管理层；与利润或股价挂钩的薪酬；盈利压力；契约或预测压力；关联交易；复杂的结构；管理层、董事或法律顾问的高流动率；与审计师的争议或更换审计师；违规或延迟提交的历史。

### 2. 预测公司业绩

* **自上而下**：从经济到行业再到公司（如家电制造商的销量 = GDP × 市场份额 × 价格）。
* **自下而上**：汇总详细的预测（如现有门店和新门店的每平方米销售额）。

把行业分析与财务报表分析结合起来，并纳入定性因素（管理层的能力和诚信、会计透明度）。

### 3. 选择估值模型

**绝对模型**直接估计资产的**内在价值**，与其价格进行比较。

* **现值（DCF）模型**（基本方法；在私营企业评估中称为"收益法模型"）：
  * 股利折现模型：股东收到的现金流。
  * 自由现金流：FCFE（偿债之后）和 FCFF（偿债之前）。
  * 剩余收益：超过资本机会成本的应计盈利。
* 股票估值比债券估值更难：现金流不是合同约定的，没有到期日，折现率是主观的。因此要给出价值的**区间**（Graham 和 Dodd），并进行**敏感性分析**。
* **基于资产的估值**：所控制资产的市场价值。适合自然资源公司（如 Petrobras：储量减去开采成本；Weyerhaeuser：林木），或分部加总中的某个部门（如 Occidental）。

**相对模型**相对于其他资产为资产估值（相似资产应以相似价格出售），使用**价格乘数**（P/E、P/CF）或**企业价值乘数**（EV/营业利润）：即可比法。

* P/E 低于可比股票意味着**相对低估**，而不一定是低估：可比股票本身可能被高估。
* 保守的用法是相对基准超配或低配股票；激进的**相对价值投资**包括**配对交易**（做多相对低估的股票，做空高估的股票，不论市场方向）。
* 优点：简单、与市场价格挂钩、经济上合理且被广泛理解。只有当比较对象估值合理时，它才能给出内在价值。

**例子（Smithson Genomics）。** 一位分析师说它相对于行业 P/E 中位数被高估 15%；另一位说它相对于 Russell 3000 的 P/E 中位数被低估 10%。**两人都可能正确**：他们使用不同的基准，而且两者都是相对的（例如整个行业相对于市场可能都很便宜）。

**选择模型。** 模型应当适合：

* **公司的特征**：其资产的性质以及它们如何创造价值。银行（大部分是可交易资产）比服务公司更适合基于资产或相对估值（P/B）。
* **数据的质量和可得性**：没有股利历史时，"更简单"的 DDM 可能不如 FCF 可靠；EPS 波动或为负时，P/E 比较很困难。
* **分析的目的**，包括分析师的视角：**控股**买方可能使用 FCF 而不是股利，因为它可以重新安排现金流。阅读他人的报告时，注意作者的视角和偏见。

使用**多个模型**能增加见解（机构投资者平均使用约 17 个因素；综合排名和筛选很常见）。绝对模型和相对模型都假设**持续经营**。

**分部加总估值。** 把每项业务作为独立的持续经营企业估值，然后相加：即**拆分价值**或**私人市场价值**。

* 当各分部处于**估值特征不同**的行业时最有用，也适用于重组（分拆、拆股、追踪股票、股权分割上市）。
* 拆分价值高于持续经营价值时，可能促成剥离或分拆。

**例子（Donaldson）。** 发动机产品部门规模更大、增长更快；工业产品部门 2018 年的利润率更高（EBT/销售额 137.1/885.2 = **15.5%**，对 261.3/1,849.0 = **14.1%**）。管理层希望到 2021 年工业部门占组合 48% 的目标看起来不太可能实现。根据各分部自己的预测为其估值，然后对公司层面的项目（税收、管理费用、未分配的资产和负债）进行调整。

**综合企业折价。** 市场对从事多项**不相关**业务的公司估值低于专注型公司。解释包括：

* 内部资本配置效率低下（内部资本市场并不使股东价值最大化）。
* 内生因素（表现不佳的公司往往通过收购不相关的业务来扩张）。
* 研究的测量误差（折价实际上并不存在）。

当公司剥离与核心业务协同很少的业务时，它最为明显。

### 4. 把预测转换为估值

* **敏感性分析**：价值如何随输入变化（通过销售和利润率体现的增长、折现率、竞争者的反应）。
* **情境调整**：
  * **控制权溢价**：控股股份（控制董事会、重新部署资产、改变资本结构）比一般模型价值更值钱。
  * **缺乏市场流通性折扣**：**没有公开市场**的股票需要额外的回报。
  * **流动性不足折扣**：公开交易但交易**稀少**的股票。
  * **大宗折扣**：出售相对于交易量较大（但非控股）的大宗股票，所得低于小额交易的市场价格。

### 5. 运用估值结论

* 使用者：**卖方**分析师（为客户提供的券商研究）、**买方**分析师（向投资组合经理或委员会提交的报告；量化分析师对股票进行排名）、公司和投资银行分析师（收购目标）以及独立研究供应商。
* 分析师帮助客户作出更好的决策，使市场更有效（资本流向最佳用途），并**监督管理层**（降低代理成本）。
* 有效的研究报告应当及时、清晰；客观且经过充分研究，指明关键假设；**区分事实与观点**；分析、预测、估值和建议内部一致；提供足够的信息让读者评判估值；说明关键风险；并披露利益冲突。
* 目标价需要依据、时间框架及其不确定性。把"好公司"与"好投资"分开：价格很重要。
* **例子（两份研究报告）**：MXI 的报告含糊、留有余地，没有清晰的估值；TXI 的报告给出了明确的 DDM 价值 €3.08，对比 €2.25 的价格（上涨空间 +36.8%），并给出明确的建议。TXI 的沟通更好。
* 相关的 CFA 准则：I(B) 独立性与客观性；I(C) 虚假陈述；V(A) 勤勉与合理依据；V(B) 与客户的沟通（流程、局限和风险、重要因素、**事实与观点**）；V(C) 记录保存。
