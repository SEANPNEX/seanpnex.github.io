# 自由现金流估值

公司自由现金流（FCFF）和股权自由现金流（FCFE）：如何从净利润、CFO、EBIT 和 EBITDA 计算它们；如何预测它们；股利、回购和杠杆如何影响它们；以及单阶段、两阶段和三阶段估值，包括优先股、实际（经通胀调整）模型、敏感性分析、ESG 和非经营资产。

## FCFF 与 FCFE

| | FCFF | FCFE |
| --- | --- | --- |
| 现金流归属 | 所有资本提供者（债务、优先股、普通股） | 仅普通股股东 |
| 扣除项 | 营业费用、税收、固定资本（FCInv）和营运资本（WCInv）投资 | 同上，**再加上**利息和本金（扣除新增借款） |
| 折现率 | **WACC** | **股权要求回报率** $r$ |
| 得出 | 公司价值 → 股权 = 公司价值 − 债务（− 优先股） | 直接得出股权价值 |

$$\text{Firm value}=\sum_{t=1}^{\infty}\frac{FCFF_t}{(1+WACC)^t}$$

$$\text{Equity value}=\sum_{t=1}^{\infty}\frac{FCFE_t}{(1+r)^t}$$

$$WACC=w_d\,r_d(1-t)+w_e\,r$$

其中 $w_d=D/(D+E)$，$w_e=E/(D+E)$。使用**市值**（或目标）权重和**边际**税率。

**用哪一个：**

* 资本结构稳定 → **FCFE**（更简单、更直接）。
* 当公司有杠杆且其 FCFE 为**负**，或其**资本结构在变化**时，用 **FCFF**（FCFF 的增长反映基本面，WACC 对杠杆的敏感度低于 $r$）。
* **调整现值**（APV）：公司价值 = 无杠杆价值（以无杠杆股权成本折现 FCFF）+ 债务的净价值（税盾 − 困境成本）。

**FCFE 的所有权视角。** FCFE 是公司在不损害其价值的前提下**能够**派发的金额，而不是它实际派发的金额。**控股**股东可以重新安排它，因此 FCF 模型适合控制权视角（或收购目标）。

在不变增长下（FCFF 和 FCFE 的增长率不必相同）：

$$
\text{Firm value}=\frac{FCFF_0(1+g)}{WACC-g}
$$

$$
\text{Equity value}=\frac{FCFE_0(1+g)}{r-g}
$$

**例子（Cagiati）。** FCFF CHF7 亿；$r_d$ 5.7%；$r$ 11.8%；债务/股权权重 20/80；税率 33.33%；$g$ 5%；债务 CHF22 亿；2 亿股。

* WACC = 0.20(5.7%)(0.6667) + 0.80(11.8%) = **10.2%**。
* 公司价值 = 700(1.05)/(0.102 − 0.05) = 735/0.052 = CHF14,134.6m → 股权 = 14,134.6 − 2,200 = CHF11,934.6m → **每股 CHF59.67**。

## 计算 FCFF 和 FCFE

> [!IMPORTANT]
> 需要记住的六个公式：
>
> $$\begin{aligned}FCFF={}&NI+NCC+Int(1-t)\\&-FCInv-WCInv\end{aligned}$$
>
> $$FCFF=CFO+Int(1-t)-FCInv$$
>
> $$\begin{aligned}FCFF={}&EBIT(1-t)+Dep\\&-FCInv-WCInv\end{aligned}$$
>
> $$\begin{aligned}FCFF={}&EBITDA(1-t)+Dep\cdot t\\&-FCInv-WCInv\end{aligned}$$
>
> $$\begin{aligned}FCFE={}&FCFF-Int(1-t)\\&+\text{Net borrowing}\end{aligned}$$
>
> $$\begin{aligned}FCFE&=NI+NCC-FCInv-WCInv\\&\quad+\text{Net borrowing}\\&=CFO-FCInv+\text{Net borrowing}\end{aligned}$$

各组成部分：

* **NI**：归属于普通股股东的净利润（扣除优先股股利之后）。
* **NCC**：非现金费用净额（折旧、摊销以及下表中的项目）。
* **Int(1 − t)**：计算 FCFF 时加回，因为利息属于债权人。FCFF 与 WACC 必须一致：税后利息对应税后 WACC。
* **FCInv**：资本支出 − 出售资产所得。现金收购算作资本支出；以股票或债务支付的收购不出现在现金流量表中，但对**预测**很重要。
* **WCInv**：营运资本的增加，**不包括现金和短期债务**（应付票据和长期债务的当期部分属于融资）。
* **净借款**：新增债务 − 偿还。
* 从 EBIT 出发，折旧全额加回；从 EBITDA 出发，只加回其**税盾** $Dep\times t$（折旧从未被减去）。

**例子（Cane Distribution，\$000）。** 税率 30%，利率 7%。

| | 2018 | 2019 | 2020 |
| --- | --- | --- | --- |
| 净利润 | 97.52 | 107.28 | 118.00 |
| + 折旧 | 45.00 | 49.50 | 54.45 |
| + Int(1 − t) | 10.98 | 12.08 | 13.28 |
| − FCInv | 0.00 | (50.00) | (55.00) |
| − WCInv | (56.00) | (11.60) | (12.76) |
| **FCFF** | **97.50** | **107.26** | **117.97** |

* 从 CFO（86.52 / 145.18 / 159.69）+ Int(1 − t) − FCInv → 得到相同的 FCFF。
* FCFE = FCFF − Int(1 − t) + 净借款（22.40 / 24.64 / 27.10）= **108.92 / 119.82 / 131.79**。

**例子（Pitts Corporation，2020 年，\$m）。** NI 240，折旧 300，利息 100，税率 40%，资本支出 400，CFO 495，EBIT 500，EBITDA 800。WCInv = Δ应收账款 40 + Δ存货 30 − Δ应付账款 15 − Δ应计费用 10 = **45**（不包括现金和应付票据）。净借款 = Δ应付票据 50 + Δ长期债务 25 = **75**。

| 出发点 | 计算 | 结果 |
| --- | --- | --- |
| NI → FCFF | 240 + 300 + 60 − 400 − 45 | **155** |
| CFO → FCFF | 495 + 60 − 400 | **155** |
| EBIT → FCFF | 500(0.6) + 300 − 400 − 45 | **155** |
| EBITDA → FCFF | 800(0.6) + 300(0.4) − 400 − 45 | **155** |
| FCFF → FCFE | 155 − 60 + 75 | **170** |
| NI → FCFE | 240 + 300 − 400 − 45 + 75 | **170** |
| CFO → FCFE | 495 − 400 + 75 | **170** |

这里 FCFE 高于 FCFF，只是因为借款很多。

### 现金流量表中的利息和股利

| | IFRS | US GAAP |
| --- | --- | --- |
| 收到的利息 | 经营或投资 | 经营 |
| 支付的利息 | 经营**或融资** | 经营 |
| 收到的股利 | 经营或投资 | 经营 |
| 支付的股利 | 经营或融资 | 融资 |

> [!IMPORTANT]
> 从 CFO 计算 FCFF 时，**只有当支付的利息在 CFO 中被扣除时**才加回 Int(1 − t)。如果 IFRS 公司把支付的利息放在融资活动中，就不要加回。如果它把支付的股利放在经营活动中，要把它们加回到 CFO。

### 非现金项目与营运资本

| 非现金项目 | 从 NI 出发的调整 |
| --- | --- |
| 折旧 | 加回 |
| 无形资产的摊销和减值 | 加回 |
| 重组费用（费用） | 加回 |
| 重组费用（转回产生的收益） | 减去 |
| 债券**折价**的摊销 | 加回 |
| 债券**溢价**的摊销 | 减去 |
| 非经营活动的损失 | 加回 |
| 非经营活动的利得 | 减去 |
| 递延所得税 | 谨慎加回 |

* **出售利得**：账面价值 €60,000 的设备以 €100,000 出售 → 从 NI 中减去 €40,000 的利得；€100,000 出现在投资活动中（减少 FCInv）。
* **递延所得税负债**：如果很快会**转回**，不要加回；如果成长中的公司可以无限期递延，则加回（收购方之后可能仍需支付）。
* **递延所得税资产**（如来自不可扣除的重组费用）：只有预期会重复出现时才减去。
* **股票期权**：费用是非现金的，但行权现金和部分税收利益进入融资活动。不要预测不会持续的现金流，并使用**预期**股数（稀释）。
* 从基年中剔除**非经常性**项目。

**例子（Duplico，可持续的营运资本）。** 资本支出和折旧从 €9.978 亿和 €2.354 亿（2020 年）变为 €3.176 亿和 €3.092 亿（2022 年）。更高的折旧使 **NI 降低** Dep(1 − t)，但使 **CFO 增加** Dep × t（税盾）。存货和应收款增加会减少 CFO 和 FCFE；应付款和应计费用增加则会增加它们。资产缩减或应付款增长不可能永远持续，而成长中公司的营运资本需求也会增长。

### 自由现金流的用途

用途必须等于来源：这是一种一致性检验，也显示了资本结构政策。

* FCFF 的用途 = Δ现金 + Int(1 − t) + (偿还 − 新增借款) + 股利 + (回购 − 发行)。
* FCFE 的用途 = Δ现金 + 股利 + (回购 − 发行)。

**例子（Pitts）。** FCFF 155 = Δ现金 10 + 60 − 75 + 股利 160 + 0；FCFE 170 = 10 + 160 + 0。CFO（495）覆盖了资本支出（400），因此新债务实际上用于支付股利 → 杠杆上升。

## 预测 FCFF 和 FCFE

1. 在（正常化的）基数上**不变增长**。例如 Pitts 以 15% 增长：FCFF 155 → 178.25 → 204.99 → 235.74。
2. **预测各组成部分**，通常与销售挂钩，假设（FCInv − Dep）和 WCInv 是**销售增加额**的固定比例：

$$
\text{Incremental FC rate}=\frac{\text{Capex}-\text{Dep}}{\Delta\text{Sales}}
$$

$$
\text{Incremental WC rate}=\frac{\Delta WC}{\Delta\text{Sales}}
$$

$$
\begin{aligned}
FCFF={}&EBIT(1-t)\\
&-(FCInv-Dep)\\
&-WCInv
\end{aligned}
$$

如果以目标债务比率 DR 为净新增投资融资（折旧是唯一的非现金费用）：

$$
\begin{aligned}
FCFE={}&NI\\
&-(1-DR)(FCInv-Dep)\\
&-(1-DR)\,WCInv
\end{aligned}
$$

**例子（Pitts，基于销售）。** 销售额 \$30 亿（去年增加 \$3 亿），EBIT 利润率 16.67%，税率 40%；增量固定资本率 = (400 − 300)/300 = **33.33%**；增量营运资本率 = 45/300 = **15%**。明年销售 +10%：

| | FCFF | FCFE（净利润率 8%，DR 50%） |
| --- | --- | --- |
| 销售额 | 3,300 | 3,300 |
| EBIT(1 − t) / NI | 330 | 264 |
| 增量固定资本 | (100) | (100) |
| 增量营运资本 | (45) | (45) |
| 净借款 | | 72.50 |
| **结果** | **185** | **191.50** |

五年内，EBIT 利润率从 16.67% 降至 14.5%：FCFF 为 185.00、188.98、195.90、202.31、208.05。当存在折旧以外的重大非现金费用时，这种方法不够准确。

### 什么会改变 FCF，什么不会

* **股利、回购和发行股票不改变** FCFF 或 FCFE：它们是自由现金流的**用途**。
* **更高的杠杆**不改变 FCFF。FCFE 在新债务发行当年增加相应金额，之后减少 Int(1 − t)。更多的债务也提高了利息税盾。
* **FCFE 与 DDM**：输入一致时（FCFE = 股利），两者给出相同的价值。当股利为零或很低、具有任意性（对盈利能力的信号很差），或公司是收购目标时，更倾向于 FCF 模型。两者由相同的力量驱动：快速增长的公司股利低，**且** FCFE 也低。
* 第三方的"自由现金流"数据往往不是为估值设计的：要核对定义。

> [!IMPORTANT]
> **净利润不是 FCFE**：它忽略了资本支出、营运资本投资和净借款（只有当资本支出 = 折旧、没有营运资本投资和净借款时，两者才相等）。**EBITDA 不是 FCFF**：它是税前的，忽略了折旧税盾、资本支出和营运资本。作为 FCFE 的代理，它更差（还忽略了利息和借款）；折现 EBITDA 需要使用税前折现率。

### 优先股

* 从 NI 计算 FCFF：**加回优先股股利**（类似税后利息，但不可税前扣除）。
* 从 NI 计算 FCFE（已扣除优先股股利）：不需要进一步调整；优先股的净**发行**视同净借款。
* 股权价值 = 公司价值 − 债务 − 优先股。

**例子（Welch Corporation，\$m）。** 债券 400，利率 8%；优先股 100，股息率 8%；普通股 500，回报率 12%；NI 110，利息 32，优先股股利 8，折旧 40，FCInv 70，WCInv 20，净借款 25，税率 30%；FCFF 增长率 4%，FCFE 增长率 5.4%。

* WACC = 0.4(8%)(0.7) + 0.1(8%) + 0.5(12%) = **9.04%**。
* FCFF = 110 + 40 + 32(0.7) + 8 − 70 − 20 = **90.4** → 公司价值 = 90.4(1.04)/0.0504 = 1,865.40 → 股权 = 1,865.40 − 400 − 100 = **1,365.40**。
* FCFE = 110 + 40 − 70 − 20 + 25 = **85** → 股权 = 85(1.054)/(0.12 − 0.054) = **1,357.42**。

## 单阶段模型：变体和敏感性

**实际（经通胀调整）模型**适用于国际股票，以及通胀高或波动大的地方：

$$
V_0=\frac{FCFE_0(1+g_{\text{real}})}{r_{\text{real}}-g_{\text{real}}}
$$

实际 $r$ 是按行业、规模和杠杆调整后的该国实际回报；实际 $g$ 以该国的实际增长为基准。

**例子（Mukamba Ventures，刚果民主共和国）。** FCFE₀ CDF1,400；$r$ = 7.30% + 0.80% − 0.33% − 0.12% = **7.65%**；$g$ = 3.0% − 0.5% = 2.5% → $V_0$ = 1,435/0.0515 = **CDF27,864**。

**敏感性分析**一次改变一个输入，以查看哪个最重要。价值与**基年** FCF 成比例变化。

**例子（Petrobras）。** FCFE₀ BRL2.59，$g$ 7%，$r$ = 8.9% + 1.4(5.3%) = 16.32% → $V_0$ = 2.59(1.07)/0.0932 = **BRL29.73**。

| 输入 | 低 → 价值 | 高 → 价值 |
| --- | --- | --- |
| Beta 1.2 / 1.6 | 33.55 | 26.70 |
| $r_f$ 7.9% / 9.9% | 33.31 | 26.85 |
| ERP 4.3% / 6.3% | 34.99 | 25.85 |
| **FCFE 增长率 5% / 9%** | **24.02** | **38.57**（区间最宽） |

## 多阶段模型

$$
\begin{aligned}
V_{\text{firm}}={}&\sum_{t=1}^{n}\frac{FCFF_t}{(1+WACC)^t}\\
&+\frac{FCFF_{n+1}}{WACC-g}\\
&\quad\times\frac{1}{(1+WACC)^n}
\end{aligned}
$$

$$
\begin{aligned}
V_{\text{equity}}={}&\sum_{t=1}^{n}\frac{FCFE_t}{(1+r)^t}\\
&+\frac{FCFE_{n+1}}{(r-g)(1+r)^n}
\end{aligned}
$$

* 第二阶段的增长率是长期可持续增长率：对衰退行业略低于 GDP 增长，对成长行业略高于 GDP 增长。
* 第一阶段的增长可以是不变的，也可以是**下降的**（如 H 模型）。
* "增长率"可能指销售、净利润或 FCF 本身的增长：要核实是哪一个。终值来自对 $FCF_{n+1}$ 使用 GGM 或乘数（P/E × EPS），通常占价值的大部分。

> [!IMPORTANT]
> 当增长下降时，FCFE 可能**跳升**，因为投资需求比利润下降得更快。始终根据第二阶段的假设计算 $FCFE_{n+1}$；不要只是把 $FCFE_n$ 按 $g_L$ 增长。

**例子（TechnoSchaft，各阶段不变增长）。** 每股销售额 €25，3 年增长 20%，之后 6%；净利润率 10%；净 FCInv 为销售增加额的 50%，WCInv 为 20%；40% 以债务融资；$r$ = 7% + 1.2(4.5%) = 12.4%。

| 年份 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| 每股销售额 | 30.000 | 36.000 | 43.200 | 45.792 |
| EPS | 3.000 | 3.600 | 4.320 | 4.579 |
| 净 FCInv | 2.500 | 3.000 | 3.600 | 1.296 |
| WCInv | 1.000 | 1.200 | 1.440 | 0.518 |
| 债务融资 | 1.400 | 1.680 | 2.016 | 0.726 |
| **FCFE** | **0.900** | **1.080** | **1.296** | **3.491**（+169%） |

$TV_3$ = 3.491/(0.124 − 0.06) = €54.55，现值为 38.415 → **$V_0$ = 0.801 + 0.855 + 0.913 + 38.415 = €40.98**（终值约占 94%）。

**例子（Sindhuh，第一阶段 EPS 增长下降）。** EPS₀ \$2.40；增长率 30、18、12、9、7%，之后 7%；每股净资本支出 3.00、2.50、2.00、1.50、1.00（之后 +7%）；WCInv = 净资本支出的 50%；30% 以债务融资；$r$ = 6% + 1.1(4%) = 10.4%。

| | 2020 | 2021 | 2022 | 2023 | 2024 |
| --- | --- | --- | --- | --- | --- |
| EPS | 3.120 | 3.682 | 4.123 | 4.494 | 4.809 |
| FCFE | −0.030 | 1.057 | 2.023 | 2.919 | 3.759 |

$V_{2023}$ = 3.759/(0.104 − 0.07) = \$110.56，现值为 74.425 → **$V_0$ = \$78.73**。当前的历史 P/E 为 78.73/2.40 = 32.8，2024 年初为 110.56/4.494 = 24.6：随着增长消退，P/E 下降。

**例子（Medina Werks，销售增长和利润率下降）。** 销售额 C\$6 亿；增长率 20、16、12、10、8、7%；净利润率 14、13、12、11、10.5、10%；净资本支出为销售增加额的 60%，营运资本为 25%；40% 债务；$r$ = 6% + 1.1(4.5%) = 10.95%；7,000 万股。

* 第 1–5 年的 FCFE：39.600、49.824、61.137、65.480、74.703（现值 ≈ 208.57）；FCFE₆ = 79.235。
* $TV_5$ = 79.235/0.0395 = C\$2,005.95m，现值为 1,193.12。
* 股权 = **C\$1,401.69m → 每股 C\$20.02**。

**三阶段模型**组合了不变的第一阶段、下降（或不变）的第二阶段和稳定的第三阶段：当现金流实际上有波动时，这是一个很好的近似。

**例子（Reliant Home Furnishings，三阶段 FCFF）。** FCFF₀ \$7.45 亿；3.0939 亿股；$r$ = 5.04% + 0.9(5.5%) = 9.99%；WACC = 0.2(7.1%)(0.66) + 0.8(9.99%) = **8.93%**；债务 \$15.18 亿；增长率 8.8%（第 1–4 年），然后 7.4%、6.0%、4.6%，之后 3.2%。

* FCFF：811、882、959、1,044、1,121、1,188、1,243；第 8 年 1,283。
* 第 1–7 年的现值 = \$5,097m；$TV_7$ = 1,283/(0.0893 − 0.032) = \$22,391m，现值为 \$12,304m。
* 公司价值 \$17,401m → 股权 \$15,883m → **每股 \$51.34**。

**选择模型。** 稳定、成熟的公司（增长不超过经济增长）用单阶段；先高速增长再趋于稳定的用两阶段；经历增长 → 过渡 → 成熟的用三阶段。把价值与市场价格比较，以判断高估或低估。

## ESG 与非经营资产

* 可量化的 ESG 项目（罚款、额外资本支出）→ 调整**现金流**；难以量化的 ESG 风险 → 在**股权成本上加一个**判断性的**溢价**。

**例子（American Copper Mining Co.，含 ESG 的三阶段 FCFF）。** 各阶段：新矿投产前、运营期间、关闭之后。ESG 调整：许可证从 3 年推迟到 5 年，用水相关的资本支出使资本支出增加 10%，劳工风险使股权成本增加 **75 个基点**。$r_d$ = 5%(0.75) = 3.75%；$r_e$ = 3% + 1.2(5%) + 0.75% = 9.75%；WACC = 0.5(3.75%) + 0.5(9.75%) = **6.75%**。FCFF 总现值 \$19.36 亿 − 债务 \$9.68 亿 = 股权 \$9.68 亿 → **每股 \$97**，而价格为 \$110 → **卖出**。

**非经营资产**（多余的现金和有价证券、为投资而持有的土地、非经营性的金融投资）**按市值单独**估值并加上：

$$
\begin{aligned}
V_{\text{firm}}={}&\text{Operating assets}\\
&+\text{Non-operating assets}
\end{aligned}
$$
