# 薪酬

| 类型                    | 例子                                                     |
| ------------------------ | ------------------------------------------------------------ |
| 短期福利      | • 工资、年度奖金<br>• 医疗、社会保障缴款 |
| 长期福利       | • 长期带薪休假<br>• 长期残疾福利    |

## 以股份为基础的薪酬

### 限制性股票单位

成本取决于授予日（期初）

#### 资产负债表

期初：无

时点 1：留存收益 $\downarrow$，确认以股份为基础的薪酬储备增加。

时点 2：留存收益下降，SBCR 上升

时点 3：留存收益下降，SBCR 上升

归属/结算时：SBCR 清零，股本增加

#### 利润表

期初（0-1）：摊销以股份为基础的薪酬费用

* 根据领取人的不同，计入销货成本或销售及管理费用

（1-2）：摊销以股份为基础的薪酬费用

（2-3）：摊销以股份为基础的薪酬费用

#### 现金流量表

无需列示。

### 股票期权的会计处理

| 因素                 | 变化     | 看涨期权价值 |
| ---------------------- | ---------- | -------------------- |
| 波动率 (σ)         | 上升 ↑ | 上升 ↑           |
| 无风险利率 (Rₓ)    | 上升 ↑ | 上升 ↑           |
| 剩余期限 (T) | 上升 ↑ | 上升 ↑           |
| 股息率         | 上升 ↑ | 下降 ↓           |

#### 资产负债表

时点 0：留存收益下降，SBCR 上升

时点 1：留存收益下降，SBCR 上升

归属时：留存收益下降，SBCR 上升

结算时：SBCR 下降，股本上升

* 领取人行权：现金增加，股本增加

#### 利润表

（0-1）：摊销以股份为基础的薪酬费用（SBCE）

（1-2）：摊销以股份为基础的薪酬费用（SBCE）

归属时：无

结算时：无

#### 现金流量表

结算时：行权带来的现金（筹资活动现金流）

### 税务处理

| 条件                                                    | IFRS                                                   | US GAAP                                   |
| ------------------------------------------------------------ | ------------------------------------------------------ | ----------------------------------------- |
| **RSU：结算日股价 > 授予日股价**        | 超额税收利益 / 税收意外收益<br>**资产负债表**：权益 + | **利润表**：所得税费用 –<br>权益 + |
| **期权：行权时内在价值 > 授予日公允价值** | 超额税收利益 / 税收意外收益<br>**资产负债表**：权益 + | **利润表**：所得税费用 –             |
| **RSU：结算日股价 < 授予日股价**        | 税收不足<br>**资产负债表**：权益 –                     | **利润表**：所得税费用 +             |
| **期权：行权时内在价值 < 授予日公允价值** | 税收不足<br>**资产负债表**：权益 –                     | **利润表**：所得税费用 +             |

### 稀释股数

$$
\text{Diluted Shares}=\text{Basiac Shares}+\text{Unvested Shares}-\frac{\text{Assumed Proceeds}}{\text{Avg Share Price}}
$$

假定收入：

* RSU：未确认的以股份为基础的薪酬（期初+期末）/2
* 期权：未确认的以股份为基础的薪酬（期初+期末）/2 + 行权金额（价格 $\times$ 数量）

### 建模

按收入的百分比预测销货成本和销售及管理费用。

### 估值时的考虑

* 对已发行但尚未归属的股份奖励（SBA）使用稀释股数
* 未来 SBA 带来的稀释：从 FCFF 中扣除以股份为基础的费用（视为现金成本）



## 离职后福利（养老金）


计划资金状况 = PA - PBO

### 养老金成本的分类

一般考虑资金状况为负（PA < PBO）的情形

则 Net_PBO + PBO - PA = Net_PBO + I-AG+S-AR-C = Net_PBO_End

把 I-AG+S-AR 记为总定期养老金成本（TPPC）
