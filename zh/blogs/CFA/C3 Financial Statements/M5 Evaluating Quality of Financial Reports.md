# 财务报告质量评估

> [!Note]
>
> 在考试中的重要性很低。重点掌握概念、警示信号以及如何解读两个模型；公式无需记忆。

## 维度

财务报告质量有两个不同的维度：

* **报告质量**：信息是否**有助于决策**，即是否**相关**且**如实反映**（完整、中立、无差错）？它关注的是**报告**本身。
* **盈利（结果）质量**：盈利是否**可持续**，是否为投入的资本提供了**足够的回报**？它关注的是**基础业务**。

两者相互关联：只有在报告质量高的情况下，才能判断盈利质量。公司可以如实报告，但盈利质量仍然很低，例如它如实报告了低于资本成本的回报。

**质量谱系**，从最好到最差：

| | 报告 | 盈利 |
| --- | --- | --- |
| 1 | 符合 GAAP，有助于决策 | 可持续，回报充足 |
| 2 | 符合 GAAP，有助于决策 | **盈利质量低**：不可持续，或回报不足 |
| 3 | 符合 GAAP，但会计选择**有偏**（激进或保守） | |
| 4 | 符合 GAAP，但通过真实行为进行盈余**管理**（如为达到目标而调整销售时间或削减研发） | |
| 5 | **偏离 GAAP**：不合规的会计处理 | |
| 6 | **虚构**交易：舞弊 | |

在前两行之下，报告已不再有助于决策，因此无法评估盈利质量。

### 激进与保守的报告

两者都是**有偏**的选择，都会降低报告质量：

* **激进**的选择会提高**当期**报告的盈利或财务状况，例如提前确认收入、把应费用化的成本资本化，或使用较长的使用寿命。
* **保守**的选择会降低**当期**的盈利或财务状况，例如计提大额准备或提前减记，并常在准备转回时**抬高以后期间**的盈利（"**饼干罐**"准备）。

保守也不是中立的：它在期间之间转移盈利并加以平滑，掩盖了波动。有些保守已内置于准则本身，例如确认减值损失，但大多数非金融资产的未实现利得不予确认。

### 分类选择

即使金额正确，项目列报在**何处**也会改变整体图景：

* **在利润表上**：把经常性费用挪到"非经常性"或非营业项目中，会提高分析师常关注的**营业**利润。
* **在资产负债表上**：把应收款归为非流动，或把债务归为长期，会改变流动性比率。
* **在现金流量表上**：IFRS 允许把支付的利息和股利归入 CFO 或 CFF；把成本资本化会把其现金流出从 CFO 挪到 CFI。两者都会在总现金流不变的情况下提高 CFO。

### 并购问题

收购既提供了管理财务结果的**机会，也提供了动机**：

* **动机**：内生增长放缓的公司可能通过收购来**掩盖下滑**，并使报告结果难以跨年比较。
* **收购价格分摊**：把更多价格分配给**不摊销**的**商誉**，把更少分配给需折旧或摊销的可辨认资产（PP&E、客户名单），会**降低未来费用**。以这种方式高估的商誉，之后会以**减值**的形式出现。
* **现金流**：收购支付的现金计入 **CFI**，而被收购的营运资本之后转化为现金计入 **CFO**，因此收购公司可以提升 CFO。
* **目标公司的数字**：目标公司可能在交易前向上管理盈利以抬高价格，被收购公司的错报会转入收购方的账簿。

## 两个模型

两个统计模型利用财务比率来提示风险。无需理解其数学或背后的经济原理，只需知道得分的含义。

**Beneish 模型：盈余操纵的概率。** 一个 **probit** 模型把八个变量组合成 **M 分数**：

| 变量 | 反映什么 |
| --- | --- |
| **DSR** 指数：应收账款周转天数 | 应收款增长快于销售（虚增收入） |
| **GM** 指数：毛利率 | 毛利率下降（操纵压力） |
| **AQ** 指数：资产质量 | 更多成本被资本化 |
| **SG** 指数：销售增长 | 成长型公司面临更大的保持增长的压力 |
| **DEP** 指数：折旧 | 折旧率放缓 |
| **SGA** 指数：SG&A | SG&A 相对销售上升 |
| **LVG** 指数：杠杆 | 杠杆上升（契约压力） |
| **TATA**：总应计项目 / 总资产 | 没有现金支撑的盈利 |

* **M 分数越高**，**盈余操纵的概率越高**。
* M 分数是一个 z 值：概率为 $N(M)$，即标准正态概率。
* **M > −1.78** 被视为可能操纵的信号；−1.78 对应约 3.8% 的概率。

**例子。** 某公司的 M 分数为 −1.50。它高于 −1.78，因此被标记。其操纵概率为 $N(-1.50)=6.7\%$。

**Altman 模型：申请破产的概率。** 判别分析给出 **Z 分数**：

$$Z=1.2\,A+1.4\,B+3.3\,C+0.6\,D+1.0\,E$$

| | 比率 | 反映什么 |
| --- | --- | --- |
| A | 营运资本 / 总资产 | 流动性 |
| B | 留存收益 / 总资产 | 累计盈利能力 |
| C | EBIT / 总资产 | 当前盈利能力 |
| D | 权益市值 / 负债账面价值 | 市场眼中的偿债能力 |
| E | 销售额 / 总资产 | 资产周转率 |

**Z 分数越高**，**破产概率越低**：

| Z 分数 | 破产概率 |
| --- | --- |
| 高于 **3.0** | 低 |
| 介于 **1.81** 与 3.0 之间 | 灰色地带 |
| 低于 **1.81** | 高 |

**例子。** A 比率为 0.10，B 为 0.20，C 为 0.08，D 为 0.90，E 为 1.10：

$$Z=1.2(0.10)+1.4(0.20)+3.3(0.08)+0.6(0.90)+1.0(1.10)=2.30$$

该公司处于**灰色地带**。

> [!Note]
>
> **两个模型的局限。** 它们基于特定公司样本的**过去数据**估计，因此可能不适用于其他行业（Altman 模型以制造企业而非金融公司为样本）或其他时期。它们只使用单一期间的数据。而且由于模型广为人知，预期会被筛查的管理者可以自行**管理这些比率**。

## 盈利质量 {#quality-of-earnings}

**经常性盈利**是起点：剔除非经常性项目（重组费用、资产出售利得、终止经营），找到可预期持续的盈利。注意每年都会出现的"非经常性"项目。

**盈利持续性。** 如果盈利能延续到未来，盈利质量就高。用下一年的盈利对本年的盈利回归：

$$\text{Earnings}_{t+1}=\alpha+\beta_1\,\text{Earnings}_t+\varepsilon$$

$\beta_1$ 越高，盈利越持续。把盈利拆分为**现金**部分和**应计**部分，各用一个 beta：

$$\text{Earnings}_{t+1}=\alpha+\beta_1\,\text{Cash flow}_t+\beta_2\,\text{Accruals}_t+\varepsilon$$

研究发现 $\beta_2<\beta_1$：**应计部分的持续性低于**现金部分，因为应计项目涉及更多估计，并会随时间转回。因此，应计部分占比更大的盈利**质量更低**。

**例子。** 设 $\alpha=0$、$\beta_1=0.8$、$\beta_2=0.5$，两家公司今年各赚 100：

* A：现金流 90，应计 10。预计明年：$0.8(90)+0.5(10)=77$
* B：现金流 40，应计 60。预计明年：$0.8(40)+0.5(60)=62$

今年盈利相同，但 B 的盈利更不可能持续。

**应计比率**衡量应计部分，以平均净经营资产（NOA）进行标准化：

$$\text{Accruals ratio (balance sheet)}=\frac{\text{NOA}_{\text{end}}-\text{NOA}_{\text{beg}}}{\overline{\text{NOA}}}$$

$$\text{Accruals ratio (cash flow)}=\frac{\text{NI}-\text{CFO}-\text{CFI}}{\overline{\text{NOA}}}$$

**应计比率越高**，**盈利质量越低**。例如，NOA 从 1,000 升至 1,200，资产负债表应计比率为 $200/1{,}100=18.2\%$。

盈利质量的**其他警示信号**：

* 持续以小幅度**达到或刚好超过**分析师预测或其他基准
* 质量差的**外部迹象**：监管机构的执法行动、财务重述
* **收入**：应收款增长快于收入（应收账款周转天数上升）、开票持有销售、渠道塞货、以总额而非净额报告收入
* **费用**：成本资本化、延长使用寿命、存货增长快于销售（存货持有天数上升）
* **NI 持续高于 CFO**

## 均值回归

处于极端水平（高或低）的盈利，往往会随时间**向行业均值回归**：竞争会侵蚀异常高的回报，而回报差的公司会重组、被收购或退出。

* 分析师**不应外推**异常高或低的盈利；应预测它们回到正常水平。
* 由**应计项目**驱动的盈利比有现金支撑的盈利回归**更快**。

## 现金流质量

CFO 是主要标准，因为它比净利润**较少受会计估计影响**。高质量的经营现金流应当：

* 为**正**
* 来自**可持续的来源**：核心业务，而不是一次性的营运资本减少或资产出售
* **足以**覆盖资本支出、股利和偿债
* 与同行相比**波动性低**

CFO 较少被操纵，但仍可被管理：

* **时间**：拖延应付款、提前收回或出售应收款（保理、证券化）、削减存货，都能在一个期间内提高 CFO，而不改善业务本身。
* **分类**：把营业成本资本化会把流出挪到 CFI；在 IFRS 下，支付的利息和股利可以移出 CFO。

CFO 高于 NI 的公司通常质量更高，但要查明原因：由不可重复的营运资本减少推高的 CFO 是不可持续的。

## 资产负债表质量

高质量的资产负债表具有：

1. **完整性**：所有义务都在资产负债表上。在附注中寻找**表外**项目，如采购承诺（照付不议合同）、担保，以及对合营企业或未合并主体的投资。
2. **无偏的计量**：资产和负债得到公允计量。判断对**商誉**和其他无形资产、**第 3 层公允价值**、养老金义务和存货最为重要。大额商誉减值表明公司在过去的收购中**支付过高**。
3. **清晰的列报**：项目分类恰当，并且分解得足以让人理解。

## 风险信息的来源

* **财务报表**：杠杆、流动性和盈利能力比率，以及 Altman Z 分数等模型的结果。
* **审计报告**：**无保留**（干净）意见，或保留意见、否定意见、无法表示意见。关注**持续经营**段落和**关键审计事项**。审计报告只能提供有限且常常**滞后**的警示：它在期间结束后出具，干净的意见也不能排除舞弊。
* **报表附注**：会计政策和估计、或有事项、承诺、关联交易和风险披露。
* **MD&A**：管理层对主要风险、趋势和不确定性的看法。
* **SEC 文件**（美国）：
  * **Form NT 10-K**（或 NT 10-Q）：通知文件将**延迟**提交，常是会计问题的警示信号
  * **Form 8-K**：重大事项，如**更换审计师**、高管离职或财务重述
  * **Form 144**：**内部人计划出售股票**的通知
  * **委托书（proxy statement）**：高管薪酬和关联交易
* **财经媒体**：调查性新闻报道可能比监管机构或审计师更早发现问题。
