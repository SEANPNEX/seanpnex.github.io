# 金融机构分析

## 分类

金融机构从存款人、投保人或投资者那里吸收资金，并把资金投入金融资产。主要类型有：

* **银行**：吸收**存款**并发放**贷款**，赚取两者之间的利差
* **保险公司**：收取**保费**并支付**赔款**
  * **人寿与健康险**：长期保单（人寿保险、年金、健康保障）
  * **财产与意外险（P&C）**：主要是短期保单（财产损失、责任）
* **其他**：投资银行、经纪交易商、资产管理公司、信用卡公司

### 特征：系统重要性

金融机构的一个显著特征是**系统重要性**：一家机构的倒闭可能威胁整个金融体系和更广泛的经济。

银行最可能具有系统重要性，因为它们通过贷款、存款、支付和同业敞口，**在各类主体之间建立联系**：其他银行、企业、家庭和政府。

**金融传染**是一家机构的问题蔓延到其他机构的方式。当一家银行倒闭时，其交易对手在借给它的资金上遭受损失，其他银行的存款人可能失去信心并提取资金，承压的银行以甩卖价格出售资产，压低其他所有银行持有资产的价值。规模最大、关联最多的银行被认定为**全球系统重要性银行（G-SIB）**，必须持有额外资本。

### 受到严格监管

由于倒闭的代价由整个体系承担，金融机构**受到严格监管**。国际机构制定标准，由各国监管机构执行：

| 机构 | 作用 |
| --- | --- |
| **巴塞尔银行监管委员会** | 制定银行资本、流动性和资金的全球标准（**巴塞尔 III**） |
| **金融稳定理事会（FSB）** | 监测全球金融体系并协调各国监管机构；认定 G-SIB |
| **国际存款保险机构协会（IADI）** | 制定存款保险制度的标准 |
| **国际保险监督官协会（IAIS）** | 制定保险监管的标准 |
| **国际证监会组织（IOSCO）** | 制定证券市场监管的标准 |

### 资产与负债

金融机构的资产负债表与其他公司大不相同：

* **资产**以**金融资产**为主，如**贷款和证券**，而不是存货和 PP&E。许多资产按**公允价值**计量，或按接近公允价值的摊余成本计量，因此资产负债表更接近市场价值，也更多地暴露于信用、市场和流动性风险。
* 大多数银行的**负债**主要由**存款**构成，客户可以随时提取，而存款所支持的贷款是长期的。这种**期限错配**是银行业的核心风险。
* **杠杆**很高：权益通常只占总资产的一小部分，因此资产上的小额损失就可能抹去大部分资本。这就是资本和流动性处于分析中心的原因。

## 银行分析

### 资本充足率

2008 年金融危机后，巴塞尔委员会制定了被称为**巴塞尔 III** 的国际银行监管框架。其目标是：

* 提高银行**吸收**金融和经济压力所产生**冲击**的能力，无论冲击来自何处
* 改善**风险管理**和治理
* 加强银行的**透明度和信息披露**

它设定了三类要求：

1. **最低资本要求**：相对于资产的风险，有足够的资本吸收损失
2. **最低流动性**：有足够的流动资产度过短期压力（[LCR](#liquidity-position)）
3. **稳定资金**：为银行的长期资产提供足够的长期资金（[NSFR](#liquidity-position)）

#### CAMELS 方法 {#camels-approach}

**CAMELS** 是一个广泛使用的银行分析框架，最初由美国监管机构开发。它涵盖六个组成部分：

| 字母 | 组成部分 | 关键问题 |
| --- | --- | --- |
| **C** | 资本充足率 | 是否有足够的资本吸收损失？ |
| **A** | 资产质量 | 贷款和证券的风险有多大，损失是否计提了准备？ |
| **M** | 管理能力 | 风险是否被很好地识别、控制和报告？ |
| **E** | 盈利充足性 | 盈利是否足够高、是否可持续？ |
| **L** | 流动性状况 | 银行在压力下能否履行义务？ |
| **S** | 对市场风险的敏感性 | 利率和价格的变化对盈利和资本影响多大？ |

##### 资本充足率

资本充足率用**银行资产中由资本提供资金的比例**来描述。由于资产风险不同，资本要与**风险加权资产（RWA）**比较，而不是与总资产比较：

$$\text{Capital adequacy ratio}=\frac{\text{Capital}}{\text{Risk-weighted assets}}$$

**风险加权资产。** 每项资产（以及表外敞口）乘以监管机构设定的**风险权重**，或由银行经批准的内部模型估计的风险权重：

$$\text{RWA}=\sum_i \text{Exposure}_i\times\text{Risk weight}_i$$

更安全的资产权重更低：现金和高评级政府债券的权重为 **0%**，公司贷款通常为 **100%**，风险更高的敞口权重可以超过 100%。RWA 还包括**市场风险**和**操作风险**的资本要求。

**资本层级（巴塞尔 III）。** 资本按吸收损失的能力划分：

| 层级 | 包括什么 | 吸收损失 |
| --- | --- | --- |
| **普通股一级资本（CET1）** | 普通股、留存收益和 AOCI，**减去扣除项**，如商誉、其他无形资产和递延所得税资产 | 最先吸收，在银行**持续经营**时 |
| **其他一级资本（AT1）** | **无到期日**、支付**可自主决定且非累积**的工具，如永续非累积优先股和或有可转换债券 | 同样在持续经营时，在 CET1 之后 |
| **一级资本 = CET1 + AT1** | | |
| **二级资本** | 原始期限至少五年的**次级债**，以及某些贷款损失准备 | 只在银行倒闭时（**清算状态**），在存款人和优先债权人之前 |
| **总资本 = 一级资本 + 二级资本** | | |

**最低要求**，以占 RWA 的百分比表示：

| 比率 | 最低要求 |
| --- | ---: |
| CET1 / RWA | ≥ 4.5% |
| 一级资本 / RWA | ≥ 6% |
| 总资本 / RWA | ≥ 8% |

在最低要求之上，巴塞尔 III 还增加了 2.5% CET1 的**资本留存缓冲**（因此实际 CET1 要求为 7%）、信贷增长过快时最高 2.5% 的**逆周期缓冲**，以及对 **G-SIB** 的附加要求。一个不基于风险的**杠杆率**（一级资本 / 总敞口 ≥ 3%）为风险权重提供后盾，因为银行自己的模型可能低估风险权重。

**例子（示意性风险权重）。**

| 资产 | 敞口 | 风险权重 | RWA |
| --- | ---: | ---: | ---: |
| 现金 | 100 | 0% | 0 |
| 政府债券 | 300 | 0% | 0 |
| 住房抵押贷款 | 400 | 35% | 140 |
| 公司贷款 | 200 | 100% | 200 |
| **合计** | **1,000** | | **340** |

CET1 为 25，AT1 为 5，二级资本为 8：

* CET1 比率 $=25/340=7.4\%$（最低 4.5%，含留存缓冲为 7%）
* 一级资本比率 $=(25+5)/340=8.8\%$（最低 6%）
* 总资本比率 $=(25+5+8)/340=11.2\%$（最低 8%）

总资产为 1,000，但只有 340 计入要求。把同样的 1,000 从抵押贷款和政府债券转向公司贷款，会在总资产不变的情况下提高 RWA 以及所需资本。

##### 资产质量

**资产质量**涉及银行资产中**现有和潜在信用风险**的大小。分析师关注：

1. **资产组合**：高流动性资产（现金、政府证券）与贷款和风险较高证券的比例，以及证券如何计量（摊余成本、FVOCI、FVPL；以及公允价值层级的第 1、2 或 3 层）
2. **贷款的信用质量**以及针对其预期损失的**准备是否充足**

**贷款按摊余成本计量**，扣除准备：

* **贷款损失准备**是**资产负债表**上针对预期信用损失（减值）的资产备抵账户。
* **贷款损失拨备**是**利润表**上的费用，**增加**准备。
* **实际贷款损失**（核销，扣除收回）**减少**准备。

$$\text{Allowance}_{\text{end}}=\text{Allowance}_{\text{beg}}+\text{Provision}-\text{Net charge-offs}$$

由于拨备是管理层的估计，它是调节盈利的杠杆：拨备不足会提高当期利润，把损失留到以后。三个比率用来检验准备：

| 比率 | 显示什么 |
| --- | --- |
| **准备 / 不良贷款** | 已出问题的贷款中有多少被覆盖（拨备覆盖率） |
| **准备 / 净核销** | 准备能吸收多少年的实际损失 |
| **拨备 / 净核销** | 银行补充准备的速度是否跟得上损失消耗的速度：低于 1 意味着准备在被消耗 |

比率下降，或远低于同行，表明银行可能**准备不足**。

##### 管理能力

**有效的管理**体现在健全的**内部控制**、管理层**透明**的沟通、高**财务报告质量**，以及风险管理和治理的整体有效性上。它很难直接衡量；薄弱的迹象包括财务重述、监管处罚以及关键估计的频繁变更。

##### 盈利充足性

**高质量的盈利**是**可持续的**而非一次性的，并且足以覆盖银行的资本成本并积累资本。银行收入有三个主要来源：

1. **净利息收入**：贷款和证券赚取的利息减去为存款和借款支付的利息
2. **服务收入**：手续费和佣金（账户、支付、资产管理）
3. **交易收入**：为交易而持有的证券和衍生品的收益

**净利息收入和服务收入**所占比例越高，通常**越可持续**；交易收入波动大、难以预测。净利息收入内部的**波动性越低**也越好。

盈利质量还取决于其背后的**估计**：贷款损失拨备，以及依赖银行自身模型的第 3 层资产的公允价值。

##### 流动性状况 {#liquidity-position}

CFA 课程重点关注巴塞尔 III 的两个流动性比率：

$$\text{LCR}=\frac{\text{High-quality liquid assets}}{\text{Net cash outflows over 30 days under stress}}\ge100\%$$

$$\text{NSFR}=\frac{\text{Available stable funding}}{\text{Required stable funding}}\ge100\%$$

* **流动性覆盖率（LCR）**是**短期**的：银行能否凭所持有的流动资产度过 30 天的压力情景？
* **净稳定资金比率（NSFR）**是**结构性**的，期限为一年：银行的**资产基础**是否由稳定的**资金来源**（权益、长期债务、稳定的零售存款）提供资金？长期贷款等非流动资产需要更多的稳定资金。

分析师还关注：

* **资金集中度**：对少数大额存款人或短期批发融资的依赖，这些资金可能迅速消失
* **合同期限错配**：资产到期与负债到期之间的差距

##### 对市场风险的敏感性 {#sensitivity-to-market-risk}

**市场风险**是利率、汇率、股票和商品价格变动带来损失的风险。分析师关注：

* 交易账簿的**风险价值（VaR）**，以及**每单位 VaR 的交易收入**
* 资产和负债在期限、**重定价频率**和**参考利率**上的**错配**，它们决定了净利息收入和权益价值如何对利率变化作出反应
* 外汇敞口

## 保险公司分析

保险公司预先收取保费，之后支付赔款。在此期间，它们投资保费（**浮存金**），因此同时获得**承保**结果和**投资**结果。

**财产与意外险（P&C）**公司承保财产损失和责任。其业务：

* **具有周期性**：即**承保周期**。丰厚的利润吸引竞争，保费下降，损失上升，直到承保能力退出市场、保费回升。
* 依赖**赔款准备金**：赔案在保费赚取之后才报告和结算，因此保险公司必须估计未来赔款。**赔款准备金的管理**是自由裁量的主要来源：准备不足会提高当期利润，而后来对以往准备金的调整（**准备金发展**）会揭示估计的好坏。

**承保比率：**

| 比率 | 公式 | 显示什么 |
| --- | --- | --- |
| **赔付及理赔费用率** | (赔款费用 + 理赔费用) / 净**已赚**保费 | 评估所承保风险的成功程度；越低越好 |
| **承保费用率** | 承保费用 / 净**签单**保费 | 为获取新保费而花费资金的效率；越低越好 |
| **综合成本率** | 赔付及理赔费用率 + 承保费用率 | 承保业务的整体效率；**低于 100%** 意味着承保盈利 |
| **保单持有人（股东）红利率** | 给保单持有人（股东）的红利 / 净已赚保费 | 以红利形式返还的保费比例 |
| **红利后综合成本率** | 综合成本率 **+** 保单持有人红利率 | 扣除返还给保单持有人的现金后的承保效率 |

**例子。** 一家 P&C 保险公司的净签单保费为 1,000，净已赚保费为 980。赔款及理赔费用为 640，承保费用为 300，给保单持有人的红利为 20。

* 赔付及理赔费用率 $=640/980=65.3\%$
* 承保费用率 $=300/1{,}000=30.0\%$
* 综合成本率 $=65.3\%+30.0\%=95.3\%$：承保盈利
* 保单持有人红利率 $=20/980=2.0\%$
* 红利后综合成本率 $=95.3\%+2.0\%=97.3\%$

> [!Note]
>
> 综合成本率**高于 100%** 并不一定意味着亏损：如果浮存金的**投资收益**能覆盖承保亏损，保险公司整体仍可盈利。

**投资。** P&C 保险公司**保守地**投资所收取的保费，主要投资于高质量债券，因为赔款可能随时到来且必须支付。分析师关注投资组合、其流动性和投资收益率。

**资本。** 与银行的巴塞尔 III 不同，保险公司**没有全球统一的资本充足要求**。要求由各国制定，如美国的风险资本和欧盟的**偿付能力 II**，因此资本比率很难跨国比较。
