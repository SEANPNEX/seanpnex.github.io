# 公开交易的房地产证券

上市房地产证券的类型（REIT、REOC、MBS）；为什么使用每股 NAV，以及如何由现金 NOI 估计它；FFO 和 AFFO；用 NAV、P/FFO 和 P/AFFO，以及股利折现或 DCF 模型为 REIT 股票估值；以及公开与私募房地产的比较。（2026 年标题：*Investments in Real Estate through Publicly Traded Securities*。）

| 术语 | 含义 |
| --- | --- |
| **NAVPS** | （资产市值 − 负债市值）÷ 股数 |
| **现金 NOI** | 去掉非现金（直线法）租金后的 NOI |
| **非现金租金** | 作为收入入账的直线法（合同平均）租金 − 实际收到的现金租金 |
| **FFO** | 净利润 + 折旧 + 摊销 − 出售不动产的净收益 |
| **AFFO**（FAD、CAD） | FFO − 非现金租金 − 经常性（维护型）资本支出和租赁成本 |
| **TRS** | 应税 REIT 子公司，用于不合格的业务 |

## 上市房地产证券的类型

* **REIT** 拥有、融资并（在有限程度上）开发产生收入的房地产。它们必须分配应税收入的 **90%–100%**；股息可以抵扣（或 REIT 直接免税），因此实际上没有公司所得税。**权益型 REIT** 拥有物业；**抵押贷款型 REIT** 发放或投资房地产贷款。
* **REOC** 是普通的**应税**房地产公司。如果企业所在国家没有 REIT 制度、主要开发物业**用于出售**，或提供其他不合格的服务（经纪、为第三方提供物业管理），它就是 REOC 而不是 REIT。
* **MBS** 是对抵押贷款池的证券化索取权：CMBS（商业，从约 100 笔贷款到一笔大额贷款）和 RMBS（住宅，数千笔贷款）。房地产**债务**证券（尤其是 RMBS）的市值远超上市房地产股权。
* 也存在私募形式（私募 REIT 和 REOC、私人抵押贷款和债务）。

### REIT 规则

在大多数国家，REIT 必须：

* 分配原本应税收益的 **90%–100%**。
* 至少 **75%** 的资产投资于房地产。
* 至少 **75%** 的收入来自租金或抵押贷款利息。

其他可能的规则：最低股东人数和集中度限制（在美国至少 100 名股东，以及 **5/50 规则**：五个或更少的持有人不能拥有超过 50%），以及对非租金收入、开发和杠杆的限制。

* 大多数美国 REIT 是**自我管理、自我顾问**的（冲突较少）。**外部管理**的 REIT 向顾问支付费用；如果费用按资产计算，顾问可能想扩大资产，也可能推销关联服务。
* REIT 在北美占主导（占上市房地产股权的 98%）；由于税收制度，REOC 在欧洲（59%）和亚太（51%）更常见。

| REIT 的优点（与私募房地产相比） | 缺点 |
| --- | --- |
| 流动性 | 没有留存收益：必须不断筹集外部资本才能增长 |
| 透明度 | 上市公司的监管成本 |
| 多元化的物业持有（类型、地域、租户信用） | 分散化收益较少：股价部分跟随股市 |
| 高质量的组合 | 资产类型有限：不合格的业务放入需纳税的 **TRS** |
| 专业管理（规模经济） | |
| 可能稳定的收入（有时按月） | |
| 税收效率（单一征税） | |

## 估值

三种方法：资产价值（NAV）、价格乘数（P/FFO、P/AFFO、EV/EBITDA），以及现金流折现（DDM 或 DCF）。

### 资产净值

* **BVPS** 使用折旧后的历史成本；**NAVPS** 使用市值，是 REIT 和 REOC 的相关指标。
* NAVPS 是**欧洲和亚洲**的**主要**估值指标；美国分析师更常用 P/FFO。
* NAV 是内在价值的最大部分；它还应反映非来自资产的收入（费用）、非房地产资产（现金）、或有负债以及管理层创造的价值。
* 价格低于 NAVPS 意味着低估，高于则意味着高估，除非有合理理由（管理层、杠杆、治理、预期事件）。低于 NAV 或杠杆很高的 REIT 更难融资：以低于 NAV 的价格发行股票会产生**稀释**。
* **会计**：在 IFRS 下，投资性房地产可以采用**公允价值模式**（变动计入净利润）或**成本模式**（披露公允价值）。在 US GAAP 下，大多数业主使用历史成本，这会低估长期持有的升值资产，并可能高估折旧，因此必须用市场估计替换账面价值。

$$
NAVPS=\frac{\text{Assets}-\text{Liabilities}}{\text{Shares}}
$$

资产和负债均按市值计算。

**步骤：**

1. 从 NOI 开始（总租金 − 空置和收租损失 − 运营费用；在利息、税、折旧和摊销之前）。去掉**非现金租金**，并为年中收购补足全年 → 预估**现金 NOI**；增长一年 → 未来 12 个月现金 NOI。
2. 对该 NOI 资本化，为经营性房地产估值：价值 = $NOI_1$ ÷ 资本化率，资本化率来自可比交易。
3. 按账面价值加上其他有形资产：现金、应收款、预付和其他资产，以及**待开发土地**（通常按账面，因为土地难以估值）→ **总资产价值**。不包括商誉、递延融资成本和递延所得税资产。
4. 减去债务（若与市值差异重大则按市值）和其他负债，但**不减递延所得税负债**（这是会计准备，不是经济负债）。
5. 除以流通股数。

NAV 是**税前**价值：清算时的税被忽略，因为不清楚公司或其资产会如何出售。

#### 例子：从现金 NOI 计算 NAVPS

以 USD 千计；资本化率为 7.00%，共有 55,689 股。

**第 1 步。未来 12 个月现金 NOI。**

| | 金额 |
| --- | ---: |
| 过去 12 个月 NOI | 270,432 |
| 减：非现金租金 | (7,667) |
| 加：收购的全年影响 | 4,534 |
| 预估现金 NOI（过去 12 个月） | 267,299 |
| 加：未来 12 个月增长（1.5%） | 4,009 |
| **未来 12 个月现金 NOI** | **271,308** |

**第 2 步。为经营性房地产估值。**

$$
\begin{aligned}
\text{Real estate}&=\frac{271{,}308}{0.07}\\
&=3{,}875{,}829
\end{aligned}
$$

**第 3 步。总资产价值。** 加上现金 65,554、待开发土地 34,566、应收款 45,667，以及预付和其他资产 23,456（合计 169,243）：

$$
\begin{aligned}
GAV&=3{,}875{,}829+169{,}243\\
&=4{,}045{,}072
\end{aligned}
$$

**第 4 步。NAV。** 减去总债务 1,010,988 和其他负债 119,886（1,130,874）：

$$
\begin{aligned}
NAV&=4{,}045{,}072-1{,}130{,}874\\
&=2{,}914{,}198
\end{aligned}
$$

**第 5 步。NAVPS。**

$$
NAVPS=\frac{2{,}914{,}198}{55{,}689}=52.33
$$

NAVPS 为 **USD52.33**。

#### 例子：NAVPS 与账面价值

| 输入 | 数值 |
| --- | ---: |
| NOI | USD115m |
| 资本化率 | 7% |
| 权益账面价值 | USD1,005m |
| 债务市值 | USD505m |
| 股数 | 100m |

$$
\begin{aligned}
\text{Property}&=\frac{115}{0.07}=1{,}642.9\\
NAV&=1{,}642.9-505=1{,}137.9\\
NAVPS&=\frac{1{,}137.9}{100}=11.38
\end{aligned}
$$

NAVPS 为 **USD11.38**，而不是 USD10.05（每股账面价值）或 USD16.43（扣除债务前）。

> [!IMPORTANT]
> 资本化率越高 → 物业价值越低 → **NAV 越低**。NOI 增长越快 → NAV 越高。递延所得税负债**不**减少 NAV。按账面价值计量的老土地可以上调至其当前价值。

NAV 可以通过以下方式估计：(1) 资本化率和 NOI，(2) 每平方英尺或每单元价值，或 (3) IFRS 下披露的评估价值，若分析师不同意则加以调整。

**NAV 的局限：**

* 资本化率和每平方英尺价值来自私募市场交易，私人买家的折现率可能与 REIT 投资者不同。
* NAV 反映的是对**私人买家**的价值；股票投资者关注收入和资产价值的近期变化，而基于评估的 NAV 存在滞后。
* REIT 曾以相对 NAV 超过 **25%** 的溢价和折价交易。
* NAV 把 REIT 视为**静态的资产池**，而不是持续经营的企业：它忽略了管理层创造或毁灭价值的能力（更强的团队可以支持 10% 的溢价）。
* 当物业市场缺乏流动性（交易少）或 REIT 拥有数百处物业时，NAV 变得**主观**；大型组合可能有溢价或折价；而土地、独特物业、服务业务和合资企业难以估值。

当管理层创造价值时，REIT **应当**以高于 NAV 的溢价交易：每日的流动性使其所需回报低于私募市场，而公开市场会吸引高于平均水平的管理人。实践中，NAV 常被**相对地**使用：买入溢价最小的 REIT（或卖出折价最小的），或从股价反推**隐含资本化率**来比较相似的组合。

### 价格乘数

P/FFO 和 P/AFFO（以及较少使用的 EV/EBITDA）用于相对估值，通常基于下一年的估计，与历史、同类物业的同行或全部 REIT 比较。

**运营资金：**

$$
\begin{aligned}
FFO={}&\text{Net income}+\text{Depreciation}\\
&+\text{Amortization}\\
&-\text{Gains on property sales}
\end{aligned}
$$

更完整的（Nareit）定义：GAAP 净利润 + 物业出售损失（− 收益）+ 房地产折旧和摊销 + 房地产减值和减记。

* 加回折旧，是因为房地产往往保值或升值：账面折旧不反映经济现实。
* 出售已折旧物业的收益或损失不是可持续的收入。
* 加回的摊销包括租赁佣金、租户改良和补贴。
* FFO **不是**现金流：它忽略了维持现金流所需的资本支出和融资现金流。
* 它是**美国**最常用的指标（在亚太也越来越多），且容易从数据提供商获得。

**调整后的运营资金：**

$$
\begin{aligned}
AFFO={}&FFO-\text{Non-cash rent}\\
&-\text{Recurring capex}
\end{aligned}
$$

* 这里的经常性资本支出包括租赁成本。
* 减去非现金（直线法）租金：对于租金递增的租约，早年的入账租金高于现金租金。
* 减去经常性维护资本支出和租赁成本（租赁佣金、租户改良补贴）。
* AFFO（也称可分配资金 **FAD**，或可分配现金 **CAD**）比 FFO 更能衡量**经济收益**和**派息能力**。但它更主观（资本支出不均匀），方法各异，数据提供商一般**不汇编** AFFO 估计。

#### 例子：Office Equity REIT 的 FFO 与 AFFO

以 SGD 千计；55,689 股。

| 输入 | 金额 |
| --- | ---: |
| 净利润 | 160,638 |
| 折旧和摊销 | 76,100 |
| 出售可折旧房地产的损失 | 25,000 |
| 非现金（直线法）租金 | 21,103 |
| 经常性维护资本支出和租赁佣金 | 55,765 |

**第 1 步。FFO。** 加回出售损失（它不具经常性）：

$$
\begin{aligned}
FFO&=160{,}638+76{,}100\\
&\quad+25{,}000=261{,}738\\
\text{Per share}&=\frac{261{,}738}{55{,}689}=4.70
\end{aligned}
$$

**第 2 步。AFFO。**

$$
\begin{aligned}
AFFO&=261{,}738-21{,}103\\
&\quad-55{,}765=184{,}870\\
\text{Per share}&=\frac{184{,}870}{55{,}689}=3.32
\end{aligned}
$$

每股 FFO 为 **SGD4.70**，每股 AFFO 为 **SGD3.32**。

#### 例子：由 AFFO 计算 P/FFO

| 输入 | USD |
| --- | ---: |
| AFFO | 4,000,000 |
| 每股 AFFO | 5.00 |
| 非现金租金 | 215,000 |
| 经常性资本支出 | 700,000 |
| 股价 | 80 |

**第 1 步。股数。** $4{,}000{,}000/5.00=800{,}000$。

**第 2 步。FFO。** 冲回 AFFO 的调整项（不要加回折旧：它已经包含在 FFO 中）：

$$
\begin{aligned}
FFO&=4{,}000{,}000+215{,}000\\
&\quad+700{,}000=4{,}915{,}000\\
\text{Per share}&=\frac{4{,}915{,}000}{800{,}000}=6.14
\end{aligned}
$$

**第 3 步。乘数。**

$$
P/FFO=\frac{80}{6.14}=13.0\times
$$

P/FFO 为 **13.0×**。

**P/FFO、P/AFFO 和 EV/EBITDA 差异的驱动因素：**

1. **FFO 或 AFFO 的预期增长** → 乘数更高（开发成功、纽约或伦敦等供给受限的优质市场、管理层、租约结构）。
2. **房地产的风险**（类型、质量、楼龄、租约、位置）：公寓的乘数高于酒店；年轻、维护良好的组合高于需要资本支出的老旧组合。
3. **资本结构和融资渠道**：杠杆越高 → 所需回报越高 → 乘数**越低**；还可能造成股票供给压力。

> [!IMPORTANT]
> FFO 和 AFFO 是**带杠杆**的（利息之后），因此在其他条件相同时，杠杆更高的 REIT 的 P/FFO 更低。EV/EBITDA 不受杠杆影响，EBITDA/EV 近似于资本化率（NOI ÷ 价值）。P/FFO 是 REIT 版的 P/E；P/AFFO 是快速的现金流乘数。

| P/FFO 和 P/AFFO 的优点 | 缺点 |
| --- | --- |
| 广为接受的盈利乘数，因此可以把 REIT 与其他投资比较 | 忽略不产生收入的资产（待开发土地、空置建筑、开发项目）、未充分利用的资产和低于市场的租金的价值 |
| FFO 估计容易获得 | P/FFO 忽略经常性资本支出；P/AFFO 包括它，但 AFFO 估计差异很大 |
| 可以结合增长和杠杆做更深入的比较 | 一次性项目和新的收入确认规则使计算和比较更复杂 |

### 股利折现和 DCF 模型

REIT 把大部分收入分配出去，因此适合股利折现和 DCF 模型。使用**两阶段或三阶段** DDM（近期、中期和长期增长）；DCF 使用中期现金流预测，以及由历史现金流乘数得出的终值。

$$
\begin{aligned}
V_0={}&\sum_{t=1}^{n}\frac{D_t}{(1+r)^t}+\frac{P_n}{(1+r)^n}\\
P_n={}&\frac{D_{n+1}}{r-g}
\end{aligned}
$$

#### 例子：Baldwin REIT 两阶段 DDM

| 输入 | 数值 |
| --- | ---: |
| 无风险利率 | 4% |
| Beta | 0.9 |
| 股权风险溢价 | 5% |
| $D_1$ / $D_2$ | 1.00 / 1.06 |
| 第 3 年起增长率 | 5% |

**第 1 步。要求回报率（CAPM）。**

$$
r=4\%+0.9\times 5\%=8.5\%
$$

**第 2 步。第 2 年末的价格。**

$$
\begin{aligned}
D_3&=1.06\times 1.05\approx 1.11\\
P_2&=\frac{1.11}{0.085-0.05}=31.71
\end{aligned}
$$

**第 3 步。今日价值。**

$$
\begin{aligned}
V_0&=\frac{1.00}{1.085}+\frac{1.06+31.71}{1.085^2}\\
&=0.92+27.84=28.76
\end{aligned}
$$

每股价值为 **USD28.76**。

#### 例子：REIT C 三阶段 DDM

$r$ = 8%；$D_1$ = 4.00；第 2–3 年增长率为 4.5%，之后为 4%。

**第 1 步。股利。**

$$
\begin{aligned}
D_2&=4.00\times 1.045=4.18\\
D_3&=4.18\times 1.045=4.37\\
D_4&=4.37\times 1.04=4.54
\end{aligned}
$$

**第 2 步。第 3 年末的价格。**

$$
P_3=\frac{4.54}{0.08-0.04}=113.57
$$

（113.57 使用了未取整的 $D_4$，即 4.543。）

**第 3 步。今日价值。**

$$
\begin{aligned}
V_0={}&\frac{4.00}{1.08}+\frac{4.18}{1.08^2}\\
&+\frac{4.37+113.57}{1.08^3}\\
={}&3.704+3.584+93.625\\
={}&100.91
\end{aligned}
$$

每股价值为 **USD100.91**。

#### 例子：由 P/FFO 和 P/AFFO 估算价值

$$
\begin{aligned}
V&=\frac{FFO}{\text{Shares}}\times\text{Peer }P/FFO\\
V&=\frac{AFFO}{\text{Shares}}\times\text{Peer }P/AFFO
\end{aligned}
$$

**REIT B（P/FFO）。** FFO 为 290,612，股数 67,900；子行业交易倍数为 13.5×。

$$
\begin{aligned}
FFO/\text{share}&=\frac{290{,}612}{67{,}900}=4.28\\
V&=4.28\times 13.5=57.78
\end{aligned}
$$

**REIT A（P/AFFO）。** FFO 为 316,965，非现金租金 25,991，经常性资本支出 63,769，股数 56,100；倍数为 18.3×。

$$
\begin{aligned}
AFFO&=316{,}965-25{,}991\\
&\quad-63{,}769=227{,}205\\
AFFO/\text{share}&=\frac{227{,}205}{56{,}100}=4.05\\
V&=4.05\times 18.3=74.12
\end{aligned}
$$

REIT B 每股价值为 **USD57.78**，REIT A 每股价值为 **USD74.12**。

## 小案例：Capitol Shopping Center REIT

Capitol Shopping Center REIT（CSC）拥有华盛顿特区周边以杂货店和药店为主力店的购物中心（防御型租户、政府就业、严格的分区规划限制新供给）。

| 第 2 年（USD 千） | |
| --- | --- |
| 净利润 | 124,454 |
| + 折旧和摊销 | 115,110 |
| **FFO**（每股 3.95） | **239,564** |
| − 非现金租金（递延应收租金的变化） | (5,112) |
| − 经常性资本支出 | (20,006) |
| **AFFO**（每股 3.54） | **214,446** |
| 每股股息 2.80 → 派息率为 FFO 的 70.9%、AFFO 的 79.1% | |

* 资产负债表与同行比较：债务/总市值 40.5%（同行 47.1%），利息覆盖倍数 3.38×（2.35×），净债务/EBITDA 5.01×（7.10×）→ 资产负债表更强。
* 价格 USD69.85，第 3 年 FFO 估计 4.23 → P/FFO **16.5×**，而购物中心 REIT 为 14.5×（溢价 13.8%）；P/AFFO 18.6× 对 16.1×。
* 溢价与其更稳定的增长和更低的杠杆相符，但随着基本面复苏，CSC 的上行空间可能较小，因为它从未像同行跌得那么深。
* 不同方法得出不同价值：重新审视假设，然后使用最可靠的方法、中点或加权平均。

> [!IMPORTANT]
>
> * 在交易稀少的下行期，NAV 变得**不那么**有用（更主观），防御型 REIT 的 P/FFO 相对同行可能上升。
> * 待开发土地不产生 FFO 但有价值，这支持**更高**的乘数。
> * 要求的初始资本化率越高 → NAV **越低**。
> * 长期增长越低（如允许更多新供给的分区规划）→ DDM 价值越低。

## 公开与私募房地产

两者都提供对物业基本面的敞口、潜在的通胀对冲、有吸引力的风险调整回报和一定的分散化，许多机构两者都持有。上市房地产的流动性允许表达短期观点，并在公开与私募价值之间套利（股价远低于 NAV 时私有化；价值高时 IPO）。

| 私募（直接）房地产的优点 | 公开房地产（权益型 REIT 和 REOC）的优点 |
| --- | --- |
| 直接获得房地产基本面的敞口 | 长期跟踪房地产基本面 |
| 回报稳定，波动低 | 流动性 |
| 物业表现驱动回报 | 专业管理 |
| 与其他资产相关性低 | 潜在的通胀对冲 |
| 潜在的通胀对冲 | 利益可能高度一致 |
| 控制权（直接持有、独立账户） | 税收高效的结构，没有双重征税（仅 REIT） |
| 潜在的流动性不足溢价 | 获得多元化组合的敞口 |
| 策略范围广，限制少 | 可进入多种行业（数据中心、医疗办公、自助仓储） |
| 税收优惠（加速折旧；在一些市场，出售所得再投资可递延纳税） | 最低投资额和进出成本低 |
| | 对投资者没有特殊资格要求 |
| | 有限责任 |
| | 更多监管和投资者保护；透明度高 |

| 私募房地产的缺点 | 公开房地产的缺点 |
| --- | --- |
| 流动性低；基金难以退出；赎回压力大 | 波动性高于私募房地产 |
| 费用和开支高 | 短期内与股票相关性高 |
| 评估滞后于市场状况 | REIT 结构限制业务 |
| 投资者保护较少；透明度低 | 股价可能不反映物业价值（相对 NAV 折价） |
| 一些管理人重规模而轻盈利 | 股息按较高的所得税率征税 |
| 最低投资额和财富要求高 | 合规成本对小公司来说过高 |
| 高回报往往来自杠杆 | 治理不善或利益不一致可能损害业绩 |
| | 股票市场往往惩罚高杠杆 |

> [!IMPORTANT]
>
> * 最需要房地产专业知识的是**直接投资单一物业**。
> * 经营和财务灵活性最大的是 **REOC**（没有派息或业务限制）→ 最适合追求最大增长；REIT 和 REOC 最适合流动性。
> * REIT 相对直接持有物业的优势在于**物业持有**的分散化，而不是整个组合的分散化。
