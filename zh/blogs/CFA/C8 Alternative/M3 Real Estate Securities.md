# 公开交易的房地产证券

## 公开交易的房地产证券的类型

* REIT
* MBS
* REOC
* 股票

房地产投资信托（REITs）是享有税收优惠的实体，通常持有、运营并在有限程度上开发能产生收入的房地产物业。它们包括**权益型 REITs** 和**抵押型 REITs**。

房地产运营公司（REOCs）是需要纳税的房地产持有公司。它们在很大程度上从事房地产开发，往往以出售为目的，主要现金流来自销售。

抵押支持证券（MBS）是以资产为支持的证券化债务，包括商业 MBS 和住宅 MBS。

### REITs

REITs 需要：

* 分配 90% 以上的收益
* 至少 75% 的资产投资于房地产
* 至少 75% 的收入来自租金或抵押贷款利息

美国的大多数 REITs 是自我管理的，否则需要向第三方管理人支付管理费。

投资 REITs 的好处：

* 流动性
* 透明度
* 分散化
* 高质量的投资组合
* 主动管理
* 稳定的收入
* 税收效率

缺点：

* 缺乏留存收益
* 监管
* 组合分散化的好处减弱
* 可持有的资产类型有限



## 估值

### 资产净值

权益的市场价值（MV）：$\text{MV of asset}-\text{MV-liabilities}$，除以流通股数得到每股资产净值（NAVPS）。与 REITs 的股价比较可以判断市场状况。

步骤：

1. 用资本化率对 NOI 进行资本化，估计 REITs 和 REOCs 所持物业的价值：$P=\frac{NOI_1}{\text{r-g}}$，其中资本化率 = $r-g$，可以参考市场上类似物业。

> [!Note]
>
> NOI 需要年化，并乘以增长率得到 $NOI_1$

2. 加上现金、应收账款、预付费用、未来开发用地的账面价值，得到估计的**资产总值**。剔除商誉和递延所得税资产
3. 减去债务和其他负债。剔除递延所得税负债。
4. 除以流通股数得到 **NAVPS**

注意事项：

* 资本化率不准确
* NAV 反映的是对私人市场买家的价值
* NAV 隐含地把 REIT 当作静态的资产池
* 当物业市场缺乏流动性、或 REITs 持有大量物业时，NAV 的估计可能相当主观。

### 相对估值（价格乘数）

相对估值中使用 P/FFO 或 P/AFFO

#### FFO

运营资金（FFO）一般计算为：净利润 + 出售物业的损失 - 出售物业的利得 + 折旧与摊销。

#### AFFO

在 FFO 的基础上：

* 减去会计上的非现金租金调整
* 减去经常性的维护资本支出和租赁佣金。

>[!note]
>
>AFFO 也称为可分配资金（**FAD**）或可分配现金（**CAD**）。



## 私人与公开房地产投资的比较

### 优点

| **私人房地产**                     | **公开房地产**                                      |
| ------------------------------------------- | ----------------------------------------------------------- |
| 直接暴露于房地产基本面 | 长期跟踪房地产基本面          |
| 收益稳定 / 波动低             | 流动性                                                   |
| 收入与资本增值             | 获得专业管理                           |
| 收益由物业表现驱动         | 潜在的通胀对冲                                   |
| 与其他资产类别相关性低   | 利益可能高度一致                 |
| 潜在的通胀对冲                   | 税收高效的结构，避免双重征税（仅限 REITs） |
| 控制权                                     | 有机会投资于分散化的组合            |

| **私人房地产**                                      | **公开房地产**                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 有可能赚取非流动性溢价                        | 除一般股票投资外，没有特殊的投资者资格要求 |
| 策略多样 / 限制少                | 更严格的监管和投资者保护                  |
| 税收优惠（例如加速折旧；在某些市场，出售所得再投资于其他房地产时可递延纳税） | 可以投资于多种板块，包括数据中心、医疗办公楼和自助仓储 |
|                                                              | 投资门槛低                                  |
|                                                              | 进出成本低                                         |
|                                                              | 有限责任                                            |
|                                                              | 透明度高                                            |

### 缺点

| **私人房地产**                                      | **公开房地产**                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 流动性低                                                | 波动性高（与私人房地产相比）          |
| 难以退出                                            | 短期内与股市的相关性高              |
| 费用高                                       | REIT 结构限制了可开展的业务                    |
| 评估价值通常滞后于市场状况的变化 | 股价可能无法反映底层物业的价值（即相对 NAV 折价交易） |

| **私人房地产**                                      | **公开房地产**                                       |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 保护投资者的监管较少                       | 股利按较高的当期所得税率征税             |
| 一些管理人更注重扩大规模而非提高盈利 | 短期内与股市的相关性高              |
| 投资门槛高，对净资产要求高     | 对小公司而言，合规成本过高 |
| 透明度低                                             | 治理不善 / 利益不一致可能拖累股价表现 |
| 高收益往往来自杠杆                         | 股市往往会惩罚高杠杆的公司   |
