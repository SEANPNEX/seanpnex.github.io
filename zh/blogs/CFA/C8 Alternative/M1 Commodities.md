# 大宗商品

大宗商品的板块及其生命周期；大宗商品估值与股票和债券有何不同；谁交易商品期货；现货与期货的关系（升水与贴水）；期货回报的三种理论；全额抵押期货回报的组成部分；商品互换；以及指数构造如何决定指数回报。（2026 年标题：*Introduction to Commodities and Commodity Derivatives*。）

| 术语 | 含义 |
| --- | --- |
| **基差** | 现货价格 − 期货价格 |
| **跨期价差** | 近期期货价格 − 远期期货价格（同一商品） |
| **贴水（backwardation）** | 现货高于期货（或近月高于远月）：基差和跨期价差为正 |
| **升水（contango）** | 现货低于期货（或近月低于远月）：基差和跨期价差为负 |
| **便利收益** | 持有实物库存以缓冲供应中断的好处；**库存稀缺时较高** |
| **展期回报** | 平掉即将到期的合约、开立更远月合约所产生的盈亏 |
| **抵押回报** | 为期货头寸持有的现金或国库券所赚取的利息 |
| **全额抵押** | 抵押品 = 期货的名义价值：没有杠杆 |

## 大宗商品基础

### 板块

彭博商品指数把大宗商品分为六个板块：

* **能源**：原油、天然气、煤炭和成品油（汽油、取暖油）。
* **工业（基本）金属**：铜、铝、镍、锌、铅、锡、铁。
* **贵金属**：金、银、铂（价值储藏加工业用途）。
* **谷物**：玉米、大豆、小麦、稻米（食品、饲料以及乙醇等生物燃料）。
* **软商品**（经济作物）：棉花、可可、糖、咖啡。
* **牲畜**：生猪、牛、羊、家禽。

基本面分析从**存量**（潜在的供给和需求：油田、农田、存栏规模、冶炼产能）和**流量**（存量如何被使用：天气、管道、疫病、政策、GDP 增长）来刻画每个板块，再加上时间因素（季节、物流、冲击）和资金流（情绪、利率、补贴）。

| 主要影响因素 | 能源 | 基本金属 | 贵金属 | 谷物 | 软商品 | 牲畜 |
| --- | --- | --- | --- | --- | --- | --- |
| GDP 规模和增长 | ✓ | ✓ | ✓ | | ✓ | ✓ |
| 天气 | ✓ | | | ✓ | ✓ | ✓ |
| 消费者偏好 | | | | ✓ | ✓ | ✓ |
| 消费者收入 | | | | | ✓ | ✓ |
| 人口增长 | | | | ✓ | | |
| 生物燃料替代 | | | | ✓ | ✓ | |
| 疫病 | | | | ✓ | ✓ | ✓ |
| 货币政策、货币供应 | | | ✓ | | | |
| 地缘政治 | ✓ | | ✓ | | | |
| 产业和环境政策、基础设施 | ✓ | ✓ | | | | |

> [!IMPORTANT]
> 考试常考：工业活动驱动**铜**（天然气主要受天气驱动，软商品主要受收入驱动）。贵金属受短期天气的影响**最小**，因为它们容易储存。

### 生命周期

* 生产生命周期反映并**放大**储存、天气以及政治或经济事件的变化。
* **短**的生命周期能较快适应外部事件；**长**的生命周期限制了供给或需求的反应速度。
* 农产品和牲畜有明确的季节，且因地区（北半球与南半球）而异。能源和金属**全年**开采；它们的季节性主要来自产品需求（夏季的汽油、冬季的取暖油）。

| 板块 | 生命周期要点 |
| --- | --- |
| **能源** | 天然气开采后几乎可以立即使用（夏季的天然气常储存到冬季）；原油在**炼制**（“裂解”）之前没有用处。炼油厂和管道成本很高，而管道在冲突中常被切断 |
| **金属** | 生命周期**最灵活**：矿石和金属可以储存数月或数年而不变质。冶炼的规模经济巨大，使得供大于求时难以减产；新产能往往恰在需求下降时投产 |
| **牲畜** | 家禽几周成熟，生猪约 6 个月，牛需要几年（架子牛 → 在育肥场育成活牛）。美国牲畜历来是**出口导向最弱**的，因为屠宰后的肉会腐坏（冷冻正在改变这一点） |
| **谷物** | 播种 → 生长 → 结荚、抽穗或结穗 → 收获；全年储存在筒仓中，面临霉变和虫害风险 |
| **软商品** | 如咖啡，赤道附近全年都有地方在收获；罗布斯塔在伦敦交易，阿拉比卡在纽约交易，以未烘焙的“生”豆交付到保税仓库 |

### 与股票和债券估值的比较

| | 股票和债券 | 大宗商品 |
| --- | --- | --- |
| 性质 | 金融资产：对经济产出的索取权 | 几乎都是**实物**资产（例外：电力、天气） |
| 现金流 | 股息、票息 | **没有**；持有实物需要支付储存和运输**成本** |
| 估值 | 预期现金流的现值 | 根据**供求**和预期波动率预测价格 |
| 投资者的主要途径 | 持有证券 | 主要通过有期限的**衍生品**（期货、互换） |

储存和运输成本塑造远期曲线：储存成本高 → 期货价格随期限上升；当前需求强劲可能使现货高于期货。在一些参与者无法交割或收货的地方，套利只能把现货与期货的差距维持在一个**区间**内，而不是固定水平。

### 市场参与者

* **套期保值者**为对冲其商品敞口而交易。套期保值并不意味着做多，投机也不意味着做空：零食制造商通过**做多**玉米对冲；金矿商通过**做空**黄金对冲；一体化石油公司可以投机做多，CTA 可以做空。
* **交易者和投资者**：
  * **知情投资者**（套期保值者和投机者，包括指数投资者和机构投资者）认为自己有信息优势。
  * **流动性提供者**在生产者和消费者不同时在场时介入；他们实际上是在**为套期保值者提供保险**，以换取预期利润。
  * 拥有储存设施（仓库、筒仓、育肥场）的**套利者**利用实物商品（加上储存和融资成本）与期货价格之间的错误定价。
* **交易所**（及其清算所）制定规则、提供基础设施：CME 和 ICE（美国）、B3（巴西）、LME（工业金属，归港交所所有）、大连、上海、东京。
* **分析师**不持有头寸（研究人员、产品设计者、政策制定者、经纪人）。
* **监管机构**：美国为 CFTC（把大量监控工作委托给 NFA）；其他多数国家只有一个监管机构（如中国证券监督管理委员会）；欧盟为 ESMA 和 MiFID II；IOSCO 负责国际协调。

> [!NOTE]
> 期货市场是**净零**的（多头 = 空头），不同于投资者净做多的股票和债券市场。做空期货比做空股票简单：无需借券，无需偿还股息，保证金与多头相同。

## 现货价格与期货价格

* **现货价格**是在特定地点交付或接收实物商品的当前价格：高度**本地化**。
* **期货价格**是今天约定的、在未来某日交付标准数量和质量商品的价格：全球或区域性的、标准化且公开。
* **基差** = 现货 − 期货；**跨期价差** = 近期期货 − 远期期货。**贴水**（现货或近月高于期货或远月）使基差和价差为正；**升水**使其为负。
* 例如，WTI 7 月为 USD65.50、12 月为 USD64.00 → 跨期价差 **+USD1.50**（贴水）。瘦肉猪 7 月为 95 美分、8 月为 96 美分 → 价差 **−1 美分**（升水）。
* 曲线可能在升水和贴水之间切换，尤其是在压力或结构性变化之下。

**结算。**

* **现金结算**吸引了更多投机者和套利者，也让套期保值者无需交割就能转移价格风险。
* **实物结算**使期货向现货收敛；现金结算的市场可能不会完全收敛（因为交易成本）。
* 质量和品种很重要：罗布斯塔不能按阿拉比卡合约交割，有些合约会按产地或仓库位置给予升水或贴水。

## 期货回报的理论

### 保险理论

凯恩斯的**正常贴水**：

* 生产者天然持有实物多头，因此**卖出期货**以锁定收入。
* 生产者的持续卖出把期货压到现货**以下**；这一折价是投机者提供价格保险所得的报酬。
* 因此曲线处于**贴水**，随着期货价格向现货上升，做多的投机者获得正的超额回报。例如，在近月为 76.75 美分时以 74.50 美分买入 10 月棉花 → 每磅 +2.25 美分，× 50,000 磅 = 每份合约 USD1,125（若近月价格不变）。
* 证据很弱：Kolb（1992）发现“正常贴水并不正常”。贴水并不可靠地带来正回报，升水也不可靠地带来负回报。

### 对冲压力假说

生产者（卖出期货）和消费者（买入期货）都会对冲：

| 对冲压力 | 曲线 |
| --- | --- |
| 生产者 = 消费者 | **平坦**：对冲需求相互抵消，无需折价吸引投机者 |
| 生产者 > 消费者 | **贴水**（同凯恩斯）：投机者只在有折价时做多 |
| 消费者 > 生产者 | **升水**：买方抬高期货价格，以吸引投机者做空 |

局限：生产者的价格敞口通常比分散的消费者更集中；双方有时都在投机（如 1993 年的 Metallgesellschaft）；而对冲压力很难衡量。

### 储存理论

Kaldor（1939）：库存水平决定曲线形状。

$$
\begin{aligned}
\text{Futures price}={}&\text{Spot price}\\
&+\text{Storage costs}\\
&-\text{Convenience yield}
\end{aligned}
$$

* 经常储存的商品（供给主导）→ 储存成本占主导 → **升水**。
* 准时生产、库存很少（需求主导）→ 便利收益占主导 → **贴水**。
* 便利收益在**库存充足时较低**，**随库存减少而上升**。例如 2011 年利比亚事件中，近月原油的便利收益跳升，而远月几乎不动 → 贴水。

> [!IMPORTANT]
> 保险理论只预测贴水；对冲压力预测平坦曲线、贴水**或**升水；储存理论取决于储存成本与便利收益的对比。实践中，储存成本和便利收益无法观察或波动很大，因此三种理论都需要判断。

## 期货回报的组成部分

**全额抵押**的商品期货头寸的总回报：

$$
\begin{aligned}
\text{Total return}={}&\text{Price return}\\
&+\text{Roll return}\\
&+\text{Collateral return}
\end{aligned}
$$

对于指数，还要加上**再平衡回报**。

* **价格回报**（现货收益）：期货价格的变化，通常是近月合约：

$$
\text{Price return}=\frac{P_{\text{now}}-P_{\text{before}}}{P_{\text{before}}}
$$

* **展期回报**（展期收益）：来自平掉近月合约并开立更远月合约。它无法单独获取；它是一种会计计算：

$$
\text{Roll return}=\frac{F_{\text{near}}-F_{\text{far}}}{F_{\text{near}}}\times\%\text{ rolled}
$$

* **抵押回报**（抵押收益）：支持该头寸的现金或债券的利息。对于指数，抵押品 = 名义价值（无杠杆），通常为国库券；对于长期预测，使用期限匹配的政府债券。

#### 例子：S&P GSCI 中的 WTI 展期

S&P GSCI 在五天内展期，每天移动 20% 的头寸。

| 合约 | 价格 |
| --- | ---: |
| 近月（3 月） | USD52.64 |
| 远月（4 月） | USD53.00 |

**第 1 步。总展期回报。**

$$
\begin{aligned}
\text{Gross}&=\frac{52.64-53.00}{52.64}\\
&=-0.68\%
\end{aligned}
$$

**第 2 步。按展期比例缩放。**

$$
\text{Net}=-0.68\%\times 20\%=-0.13\%
$$

远月合约更贵（升水），因此每天的展期**成本为 0.13%**。

#### 例子：贴水中的总回报

| 输入 | 数值 |
| --- | ---: |
| 近月合约 | USD80.00 |
| 远月合约 | USD78.40 |
| 展期比例 | 100% |
| 全年价格回报 | +4% |
| 抵押品（全额，投资国库券） | 3% |

**第 1 步。展期回报。**

$$
\begin{aligned}
\text{Roll}&=\frac{80.00-78.40}{80.00}\times 100\%\\
&=2.0\%
\end{aligned}
$$

**第 2 步。总回报。**

$$
\begin{aligned}
\text{Total}&=4\%+2\%+3\%\\
&=9\%
\end{aligned}
$$

远月合约更便宜（贴水），因此展期**增加** 2%，总回报为 **9%**。

#### 例子：展期时保持相同敞口

做多 USD10,000 的头寸；近月合约为 USD4.00，远月合约为 USD2.50。

$$
\begin{aligned}
\text{Near sold}&=\frac{10{,}000}{4.00}=2{,}500\\
\text{Far bought}&=\frac{10{,}000}{2.50}=4{,}000
\end{aligned}
$$

远月合约更便宜（贴水），因此需要**更多**合约（4,000 份对 2,500 份）来保持 USD10,000 的敞口。

| 曲线 | 远月与近月 | 保持相同敞口 | 展期回报 |
| --- | --- | --- | --- |
| **贴水** | 远月更便宜 | 买入**更多**远月合约（如 £110 按 £10 → 11 份；按 £9 → 约 12 份） | **正** |
| **升水** | 远月更贵 | 买入**更少**远月合约（如 £108 按 £9 → 12 份；按 £10 → 约 11 份） | **负** |

**S&P GSCI，1970 年 1 月 – 2019 年 3 月：**

| | 总回报 | 现货 | 展期 | 抵押 |
| --- | --- | --- | --- | --- |
| 年回报 | 6.8% | 3.0% | −1.3% | 5.0% |
| 风险（标准差） | 19.8% | 19.8% | 4.2% | 1.1% |
| 与总回报的相关性 | | 0.97 | −0.11 | −0.14 |

* 总回报的波动几乎全部来自**价格**回报。
* 长期来看，抵押回报贡献最大；展期回报是拖累。（各部分加总为 6.7% 而不是 6.8%，因为总回报是几何复利计算的。）

### 实践中的展期回报

* 升水、贴水和展期回报反映了供求预期；两种状态都不会无限期**持续**。
* 展期回报与价格回报的相关性只有约 **3%**：展期回报不能可靠地预测价格回报。
* Ilmanen（2011）认为展期回报大致是一种风险溢价，但他研究的商品中约 40% 展期回报为负**而**总回报为正。
* 样本中每个板块的平均年展期回报都是**负**的：总体 −1.3%，能源 −1.5%，工业金属 −1.3%，农产品 −4.5%，牲畜 −1.1%，贵金属 −5.1%，软商品 −5.5%。
  * 储存类商品（金属、谷物、牲畜、软商品；黄金可以无限期储存）倾向于升水 → 展期回报为负。
  * 只有**能源**（实时消费）在统计上有获得正的平均展期回报的可能，而自 2010 年以来这一点已经减弱（美国页岩油、中国成为最大进口国、OPEC+）。
* 展期回报在**单一时期**可能非常重要，但长期来看相对价格回报**不大**。它在很大程度上取决于**板块**，因此板块权重决定了组合的展期回报。

## 商品互换

**商品互换**根据商品参考价格或指数（通常是一系列期货）在多个日期交换支付。它无需管理大量期货合约就能转移风险，并且可以**定制**（特定等级或混合品、随时间变化的数量、带交割灵活性的现金结算）。交易商可以用期货对冲、与另一交易商对冲、买入实物商品，或保留敞口。

| 互换 | 支付取决于 | 典型使用者 |
| --- | --- | --- |
| **超额回报互换** | 标的期货价格的变化（常相对于固定水平）× 名义金额 | 套期保值者（如炼油厂） |
| **总回报互换** | 指数水平的变化：期货价格变化**加上**抵押品利息；买方支付费用 | 希望获得商品多头敞口的机构（分散化、通胀对冲、资产负债管理） |
| **基差互换** | 两个相关但不完全相关的价格之差（流动与不流动，如布伦特与墨西哥湾重质原油） | 流动性较差品级的使用者 |
| **方差互换** | 实现方差与固定方差；若实现方差超过固定方差，买方收款（常设上限） | 波动率交易者 |
| **波动率互换** | 实现波动率与预期波动率；若实现波动率低于预期，卖方获利 | 波动率交易者 |

$$
\begin{aligned}
\text{TRS payment}&=\text{Notional}\\
&\quad\times\text{Index return}\\
\text{Call-style ERS}&=\max(0,\ P-\text{Strike})
\end{aligned}
$$

其中 TRS 是总回报互换，ERS 是构建为一串看涨期权的超额回报互换（每个结算日每单位的收益）。

#### 例子：炼油厂的超额回报互换

一家炼油厂做多一份互换，在 1 月至 9 月每个月末支付油价超过每桶 USD70 的部分，期权费为每桶 USD25。

| 月份 | 价格 | 收益 |
| --- | ---: | ---: |
| 1 月 | 70 | 0 |
| 2 月 | 75 | 5 |
| 3 月 | 71 | 1 |
| 4 月 | 66 | 0 |
| 5 月 | 65 | 0 |
| 6 月 | 63 | 0 |
| 7 月 | 66 | 0 |
| 8 月 | 72 | 2 |
| 9 月 | 78 | 8 |

**第 1 步。净结果。**

$$
\begin{aligned}
\text{Payoffs}&=5+1+2+8=16\\
\text{Net}&=16-25=-9
\end{aligned}
$$

炼油厂亏损**每桶 USD9**（每月约 USD1），但免受价格飙升的影响，且预先知道成本。

#### 例子：总回报互换

名义金额 USD1 亿，每月重置。

| 指数变动 | 支付 |
| --- | --- |
| +3% | 交易商向管理人支付 $0.03\times 100\text{m}=$ **USD300 万** |
| −2% | 管理人向交易商支付 $0.02\times 100\text{m}=$ **USD200 万** |

支付是每月进行的，不会推迟到到期。

## 商品指数

指数可用作基准、宏观和预测指标，以及投资产品的基础。它们的区别在于：

* **广度**：商品和板块的数量。
* **权重**，以及如何设定。
* **展期方法**：直接决定展期回报。
* **再平衡**方法和频率：决定再平衡回报。
* **治理**：基于规则还是委员会选择；资产价格、指数提供者和产品提供者的独立性。

| 截至 2019 年 4 月 | S&P GSCI | BCOM | DBLCI | TR/CC CRB | RICI |
| --- | --- | --- | --- | --- | --- |
| 推出时间 | 1991 | 1998 | 2003 | 2005（当前版本） | 1998 |
| 商品数量 | 24 | 23 | 14 | 19 | 38 |
| 权重 | *产量* | 产量**和流动性** | 固定 | 固定 | 固定 |
| 展期 | 最近的最活跃合约，每月 | 近月到下月或第二个月 | **为展期回报优化** | 近月到下月 | 近月到下月 |
| 再平衡 | 每年 | 每年 | 每年 | **每月** | **每月** |
| 面向个人的基金 | 有 | 有 | 有 | 部分地区有，另有基于相关指数的 ETF | 有 |

* **S&P GSCI**：按全球产值加权（类似市值加权）→ 集中；能源历史上最高约 80%。
* **BCOM**：由委员会选择；板块上限 33%，单一商品下限 2% → 能源约 30%，但天然气权重较高（约 9%，GSCI 中约 3%），而天然气的展期成本很高（每年约 19%）。
* **DBLCI**：不含牲畜；展期到 12 个月内**贴水最大或升水最小**的合约（主动的展期决策）。
* **TR/CC CRB**：延续第一个可投资指数（CRB，1978）；由委员会设定分层的固定权重。
* **RICI**：最广泛（38 种，包括木材、燕麦和橡胶）；部分合约以非美元货币计价，增加了货币敞口。

**再平衡。** 频繁再平衡（CRB、RICI）在**均值回归**的市场中有利（高位卖出、低位买入），但在**趋势性**市场中不利。按产量加权的指数（GSCI、BCOM）随价格漂移，因此再平衡较少，在趋势中可能跑赢固定权重、频繁再平衡的指数。

> [!IMPORTANT]
>
> * 按产量加权的指数比等权指数对能源**更**敏感。
> * 持有的合约通常处于贴水的指数往往回报更高（展期回报为正）；以升水为主的指数则落后。
> * 跨多个交易所投资带来的分散化很少：全球商品市场高度相关。主要指数彼此高度相关（70% 以上），与股票和债券的相关性约为 0%。没有哪种指数方法占绝对优势。
