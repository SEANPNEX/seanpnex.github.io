# 房地产

对估值重要的房地产特征（NOI、杠杆、覆盖率、税前和税后回报）；物业如何分类；经济价值驱动因素与房地产周期；各类商业物业；尽职调查；三种估值方法（收益法、成本法、销售比较法）；以及房地产指数及其偏差。大多数例子围绕三个物业：**Wallonia Transit**（单一租户仓库）、**Pinebranch Estates**（多户住宅）和 **Eastmain Plaza**（综合用途）。（2026 年标题：*Overview of Types of Real Estate Investment*。）

| 术语 | 含义 |
| --- | --- |
| **NOI** | 有效毛收入 − 运营费用 − 物业维护准备（融资和所得税之前） |
| **物业维护准备** | **维持**当前收入所需的资本支出（不包括改变物业用途的升级） |
| **GPRI** | 潜在总租金收入 = 市场租金 × 可出租面积（满租） |
| **租约损失** | GPRI − 总租金收入（市场租金与现有租约之差） |
| **LTV** | 未偿抵押贷款 ÷ 物业当前价值 |
| **DSC** | NOI ÷ 偿债额（利息**和**本金） |
| **资本化率** | 预期 NOI ÷ 物业价值 $= r-g$ |
| **初始 / 终端资本化率** | 基于第一年 NOI / 基于预期出售后 NOI 的资本化率 |
| **稳定化 NOI** | 预期 NOI 会变化时，直接资本化法所用的正常化 NOI |
| **续租风险** | 租约到期时失去租户及其收入的风险 |

## 投资特征

房地产从**核心型**（收入稳定，类似债券）到**机会型**（开发，类似股票）不等。决定其价值和可交易性的是：当前和潜在的**经济用途**、预期的**净现金流**，以及**资本结构**。

### 净营业收入

$$
\begin{aligned}
NOI={}&\text{Effective gross income}\\
&-\text{Operating expenses}\\
&-\text{Maintenance allowance}
\end{aligned}
$$

* 总租金 = 每单位面积基础租金 × 可出租面积。
* 有效毛收入 = 总租金 + 其他收入（费用回收、转嫁费用、停车）− 空置和优惠。
* 运营费用分为固定的（税、保险、服务、维修）或可变的（水电等公用事业），由业主承担或转嫁给租户。
* 维护准备在欧洲和北美很常见，在日本等地则较少见。

**例子（Wallonia Transit）。** 一个 10,000 m² 的仓库，只有一个租户；基础租金 EUR52.50/m²。租户支付房产税（12,500）和保险（40,000）；业主为服务和维修按 EUR10.25/m² 收回费用，实际成本为 120,750；维护准备 100,000。

| Wallonia Transit | EUR |
| --- | --- |
| 总租金（52.50 × 10,000） | 525,000 |
| 运营费用回收（10.25 × 10,000） | 102,500 |
| 转嫁的房产税 + 保险 | 52,500 |
| **有效毛收入** | **680,000** |
| 运营费用（120,750 + 12,500 + 40,000） | (173,250) |
| 物业维护准备 | (100,000) |
| **NOI** | **406,750** |

* 如果服务和维修超支 20%（144,900），多出的 24,150 **不能**收回（回收额固定为 102,500）→ NOI 降至 **382,600**。
* 若空置率为 10%（假如有多个租户），扣除总租金的 10%（52,500）→ NOI **354,250**。
* 只有降低服务和维修成本才能提高 NOI；税和保险全部转嫁。

### 杠杆与覆盖率

$$
LTV=\frac{\text{Mortgage debt outstanding}}{\text{Current property value}}
$$

$$
DSC=\frac{\text{NOI}}{\text{Debt service}}
$$

* LTV 越低，业主权益越多。LTV 随价值变动和本金偿还而变化。
* 偿债额 = **利息 + 本金**。贷款人在契约中设定 LTV 和 DSC 的限制。

**例子（Wallonia）。** 价格 3,750,000；20 年期完全摊还贷款 3,000,000，利率 4%，每年还款 220,745（第 1 年利息：120,000）。

* 第 1 年后的 LTV = [3,000,000 − (220,745 − 120,000)]/3,750,000 = 2,899,255/3,750,000 = **0.773**。
* 若物业价值上升 10%：LTV = 2,899,255/4,125,000 = **0.703**。
* DSC = 406,750/220,745 = **1.84**；NOI 为 382,600 时 → 1.73。

### 权益回报

$$
EDR=\frac{NOI-\text{Debt service}}{\text{Price}-\text{Loan}}
$$

EDR 是权益股息率；分子是税前现金流，分母是投入的权益。它是第一年、仅现金、税前的指标，忽略资本利得和损失。Wallonia：(406,750 − 220,745)/750,000 = 186,005/750,000 = **24.8%**；NOI 为 382,600 时 → 161,855/750,000 = 21.6%。

$$
\text{After-tax CF}=\text{Pretax CF}-\text{Taxes}
$$

$$
\begin{aligned}
\text{Taxes}={}&t\times(NOI-\text{Interest}\\
&-\text{Depreciation})
\end{aligned}
$$

可折旧基数是成本（加改良）减去**土地**：土地不折旧。Wallonia 土地为 750,000，使用年限 30 年：折旧 = 3,000,000/30 = 100,000；税 = 0.25 × (406,750 − 120,000 − 100,000) = 46,688；税后现金流 = 186,005 − 46,688 = **139,317**。

> [!IMPORTANT]
> 价格和 NOI 相同，但**土地价值更低** → 可折旧基数更大 → 折旧更多 → 税更少 → 税后现金流**更高**。

## 分类

* **GICS**：**REIT**（多元化、工业、酒店和度假村、办公、医疗保健、住宅、零售、专业）和**房地产管理与开发**（多元化业务、房地产运营公司、开发、服务）。抵押贷款和其他房地产债务归入金融业的固定收益。
* **对经济周期的敏感度**：防御型（如医疗保健 REIT，因为医疗需求稳定）与周期型（如工业和办公 REIT）。
* **物业等级**，按位置、楼龄、当地收入、近期升值和状况划分。以多户住宅为例：

| 等级 | 特征 |
| --- | --- |
| A | 近 10 年内建成，或经过大规模翻新；顶级配套设施；最好的材料 |
| B | 20 年以内，或经过翻新；配套设施较旧；质量良好，延迟维护很少 |
| C | 30 年以内，或经过翻新；配套设施有限且陈旧；有延迟维护 |
| D | 超过 30 年，位置较差；没有配套设施；状况差 |

* 等级越高，租金和价格越高，但升值空间**越小**；等级较低的物业更便宜、升值潜力更大（可能需要资本支出和当地条件改善）。
* 可持续性认证，**BREEAM**（英国和欧洲）和 **LEED**（美国；全球认可度最高），会提高建造成本，但可以降低运营成本、提高租金、降低空置率并带来税收优惠。
* 在大型数据集上使用机器学习有助于预测房价，但周期转向时模型会失灵（见下文的 Zillow）。

## 房地产投资形式

| | 债务 | 权益 |
| --- | --- | --- |
| **私募** | 抵押贷款；建筑贷款；夹层债务 | **直接**：独资、合资、有限合伙。**间接**：房地产基金、私募 REIT |
| **公开** | MBS、CMBS、CMO；担保债券；抵押贷款 REIT；抵押贷款 ETF | 建筑、运营或开发公司的股票；公开 REIT；UCITS、共同基金、ETF |

* **房地产运营公司**是应税公司，限制很少。**REIT** 主要拥有和经营出租物业或购买抵押贷款，并分配几乎全部收益以避免公司税。REIT 存在于 30 多个国家（美国和欧洲为公司形式；澳大利亚为外部管理的信托；中国 2021 年推出基础设施 REIT，2022 年推出保障性租赁住房 REIT）。
* REIT 的业绩指标：FFO = 净利润 + 折旧 + 摊销 − 物业出售净收益（详见 M3）。
* 物业贷款是长期的、有担保的第一顺位留置权，利率为浮动、固定或可调。美国和日本的抵押贷款投资者面临**提前还款风险**。
* **担保债券**：贷款留在银行的资产负债表上，具有**双重追索权**（银行 + 资产池）并替换不良抵押品 → 风险和回报较低。**MBS**：资产池转移到特殊目的实体，分为提前还款风险不同的分级。

| 策略，风险和回报由低到高 | 特征 |
| --- | --- |
| 优先债务 | 第一抵押贷款；类似债务，主要是公开的 |
| 核心型 | 稳定产生收入的物业 |
| 核心增益型 | 有一些翻修；现金流相当稳定 |
| 增值型 | 空置面积、升级和重新定位 |
| 机会型 | 新开发；类似股票的回报，主要是私募的 |

## 风险

* **经济和竞争**：经济活动的水平和类型、人口结构、相对供给，以及资本的成本和可得性 → 租金、出租率和价格。
* **物业特定**：管理（维护、租户和租约）、过时和技术变化、环境因素（能效规定、洪水、地震、飓风）、分区规划。
* **模型风险**：过度依赖统计或机器学习价格模型。Zillow Offers（2021）用估值算法买入房屋，无法应对价格波动，损失约 USD10 亿。

## 房地产周期

**经济驱动因素。**

* GDP 增长、就业创造和工资增长 → 对商业空间的需求和**家庭组建**。
* 利率和信贷：房地产高度依赖债务融资，因此对利率非常敏感。低按揭利率和低房价收入比有利于**购房**而非租住多户住宅。
* 建设周期长：新供给往往在条件变化之后才到来。
* 本地因素：营商环境、主要雇主、基础设施、税收、分区规划、交通、学校和治安；衰退的产业或人口会损害价值。

| | 复苏 | 扩张 | 供给过剩 | 衰退 |
| --- | --- | --- | --- | --- |
| 经济 | 经济周期谷底 | 增长，工资和信心提高 | 增长放缓 | 放缓 |
| 信贷 | 紧 | 放松 | | 收紧 |
| 建设 | 很少或没有 | 开始新建和升级 | **在建项目完工** → 物业**过剩** | 开工处于低位 |
| 市场 | 家庭推迟组建；出租率**下降**；业主降低租金；价格和租金走低 | 出租率、租赁价格、租金和价格**上升** | 出租率和租金**下降**；价格先持平后下跌 | 出租率**加速**下降；价格下跌；房东提供优惠条件 |

| 阶段 | 利率 | NOI | DSC | LTV |
| --- | --- | --- | --- | --- |
| **复苏** | 见底，然后上升 | 见底，然后上升 | 见底，然后上升 | **见顶**，然后下降 |
| **扩张** | 上升 | 上升 | 上升 | 下降 |
| **供给过剩** | 见顶，然后下降 | **见顶**，然后下降 | **见顶**，然后下降 | **见底**，然后上升 |
| **衰退** | 低 | 下降 | 下降 | 上升 |

> [!IMPORTANT]
> NOI 和 DSC 在**供给过剩阶段见顶**，在复苏阶段见底；LTV 正好相反（复苏阶段见顶，供给过剩阶段见底）。在**供给过剩**阶段，重置成本高于市场价格。

## 在组合中的作用

房地产提供当期收入、资本增值、通胀对冲、分散化和税收优惠。

* **当期收入**：租约条款往往不同于固定租金。
  * **递增条款**：预先设定的未来租金上调（不是或有的，不同于债券的递增条款）。
  * **指数化租金**：随 CPI 等市场变量变化。
  * **超额租金**：零售商销售额超过目标（盈亏平衡）水平时的额外租金。
  * 费用：业主全部承担、部分转嫁，或对超过限额的增加部分收费；外加公共区域费用。
* **资本增值**：只有物业出售时才能精确衡量。
* **通胀对冲**：租金和价格往往随通胀上升 → 长期获得实际回报。
* **分散化**：与股票、债券和现金的相关性低；但**公开**房地产（REIT、MBS）在短中期内与股票和债券的相关性更高。
* **税收优惠**：税收折旧快于使用寿命（如在美国）；REIT 避免双重征税。

**例子（Chandra Shops，超额租金）。** 一家 500 ft² 的商店；基础租金下调 10%，从每月 INR300/ft² 降至 INR270/ft²，另加月销售额超过 INR1,000,000 部分的 8% 作为超额租金。销售额为 INR1,250,000 时：基础租金 270 × 500 = 135,000 + 超额租金 0.08 × 250,000 = 20,000 = **INR155,000**，而旧租约下为 INR150,000。（下调 9.6% 加 5.6% 超额租金得到 INR149,600，Chandra 会更喜欢这个方案。）

## 商业物业类型

目标是获得**租金收入**。

* **住宅**：单户住宅（多为自住）和**多户住宅**物业（住宅类商业房地产的大部分），按位置、高度和配套设施分组。需求取决于收入、就业、当地条件和购房的可负担性。租户可能受到保护（限制租金上涨或驱逐），租约比非住宅物业**短**得多。
* **非住宅**物业与行业用途联系更紧密，因此更容易受到**结构性**变化的影响：
  * **办公**：为关键租户建造（如医院附近的医疗办公楼）或主力租户承租大部分面积时，开发风险较低。远程和混合办公降低了需求。
  * **工业和仓储**：电子商务结构性地提高了需求。通常为特定用途设计，**难以改造**（最不可能被改造），不过位置好的会被改造利用。
  * **零售**：有主力店的区域购物中心、社区中心、独立门店。网购降低了购物中心的需求，推动了改造；靠近上班族和居民决定租金、出租率和价格。
  * **酒店**：商务酒店是**周期性**的；面向过路人的小型汽车旅馆周期性较弱；旅游酒店取决于消费者信心和可支配收入；目的地度假村管理密集，固定成本高。
  * **其他**：学生和老年住房（老年需求随老龄化上升，但竞争也在加剧）；自助仓储（资本支出和运营成本低，**按月**租约 → 定价灵活，但受需求影响）；医院、通信塔、数据中心、停车场。
  * **综合用途**：结合不同租户类型（如办公 + 零售）：收入多元化，但与当地经济挂钩且相关，因为办公租户往往就是零售商的顾客。

### 现金流分析 {#cash-flow-analysis}

$$
GPRI=\text{Market rent}\times\text{Space}
$$

$$
GRI=\text{Current rent}\times\text{Space}
$$

* **租约损失** = GPRI − GRI。为正：现有租约**低于**市场租金。为负：高于市场租金（如供给过剩、市场租金下降）。
* 净租金收入 = GRI − 空置和收租损失 − 优惠和调整。
* 总（有效毛）收入 = 净租金收入 + 其他收入 + 费用回收。
* NOI = 总收入 − 运营和租赁费用 − 维护准备。

**例子（Pinebranch Estates）。** 240 个单元，每个 1,200 ft²；市场租金每月 AUD2.00/ft²；业主支付税和保险。

| Pinebranch Estates | AUD |
| --- | --- |
| 潜在总租金收入（240 × 1,200 × 2.00 × 12） | 6,912,000 |
| 减：租约损失 | (128,200) |
| **总租金收入** | 6,783,800 |
| 减：空置和收租损失 | (791,236) |
| 减：优惠和调整 | (485,124) |
| **净租金收入** | 5,507,440 |
| 加：其他收入 | 295,211 |
| 加：向租户回收的费用 | 525,800 |
| **总收入** | 6,327,651 |
| 减：运营和租赁费用 | (2,753,000) |
| 减：维护准备 | (655,000) |
| **NOI** | **2,919,651** |

与 Wallonia 不同，租户多、租约短使租金扣减项重要得多。

**例子（Eastmain Plaza，综合用途）。** 350,000 ft²：90% 为办公，MYR100/ft²；10% 为零售，MYR250/ft² → 总租金 = 0.9 × 100 × 350,000 + 0.1 × 250 × 350,000 = **MYR40,250,000**；当前 NOI 13,085,217。在下行情景中（附近出现新的零售物业），它损失 450,800 的超额租金和一半的零售租金 4,375,000 → NOI 下降 4,825,800（37%），至 **8,259,417**。

## 尽职调查

房地产不如公开证券透明和标准化，因此尽职调查更为详细：

* **市场审查**：宏观和当地条件；报价与实际成交价（以实际成交为准）；环境风险（山火、洪水 → 保险）；达到能效标准的成本。
* **现有租约**：租金与市场的比较、空置、租期、到期时间表、付款记录和租户信用。
* **未来租赁**：续租和重新出租的成本（经纪佣金、空档期、免租期、装修补贴，通常资本化并在租期内摊销）；当地供给；法律变化（柏林 2020 年的租金上限使租金下降 11%，但受管制房源的供给下降约 59%；次年被裁定无效）。
* **财务审查**：若干年经审计的报表和运营账单；检查 NOI 是否因维护投入不足或大量租户激励而被夸大。
* **文件**：对产权的法律和税务审查，确认没有留置权或税务义务，符合分区规划和环境规定。这对购买很重要，但**最不可能**用于 NOI 预测。
* **检查和服务协议**：测量；实物、工程和环境检查；评估物业管理人；审查服务合同。

发现差异会导致整改、降价或放弃交易。

## 估值

### 收益法：直接资本化

$$
\text{Property value}=\frac{\text{Expected NOI}}{\text{Cap rate}}
$$

$$
\text{Cap rate}=r-g=\frac{\text{Expected NOI}}{\text{Property value}}
$$

* $r$ = 无风险利率 + 物业特定风险溢价。$r$ 越高（基准利率上升、物业风险更大、供给过剩）→ 价值越低；NOI 增长越快（$g$ 越高）→ 资本化率越低 → 价值越高。$g$ < 0 表明物业接近使用寿命终点。
* 资本化率通常来自可比交易；可与债券的当期收益率或 EV/EBITDA 的倒数相比较。
* NOI **稳定**时最好用；否则使用**稳定化 NOI**。

**例子（Wallonia）。** $r$ = 12.5%，$g$ = 2%：价值 = 406,750/0.105 = **EUR3,873,810**；NOI 为 382,600 时 → EUR3,643,810（−6%）。只有在较高成本会反复出现时才计入。

### 收益法：DCF

$$
\text{Value}=\sum_{i=1}^{n}\frac{NOI_{i}}{(1+r)^i}+\frac{TV}{(1+r)^n}
$$

$$
TV=\frac{NOI_n(1+g)}{r-g}
$$

当分析师能看出 NOI 将如何变化时更合适。终值也可以通过对可比物业的 NOI 资本化得到。

**例子（Eastmain，持有 5 年，$r$ = 14%，第 5 年后 $g$ = 3%）。** NOI 8,259,417；6,092,385；13,539,114；14,020,153；14,515,622。

* NOI 的现值 = **MYR36,911,526**。
* 终值 = 14,515,622 × 1.03/0.11 = **MYR135,919,006**。
* 价值 = 36,911,526 + 135,919,006/1.14⁵ = **MYR107,503,599**。
* 初始资本化率 8,259,417/107,503,599 = 7.68%，低于终端资本化率 14% − 3% = 11%，因为第 1–2 年的 NOI 被下行情景压低（风险 $r$ 每年相同）。

### 成本法

$$
\begin{aligned}
\text{Value}={}&\text{Replacement cost}\\
&-\text{Depreciation}\\
&-\text{Other adjustments}
\end{aligned}
$$

* 重置成本 = 土地 + 建造 + 开发商利润：买地并建造一处**经济用途相同**的物业的成本，包括软成本、融资和**开发商利润**。
* 针对楼龄、不够理想的位置或今天无法建造（建筑规范、历史保护）向下调整；调整幅度可能大于或小于会计折旧。
* 投资者不应支付超过建造可比物业的成本；在**供给过剩**时，重置成本高于市场价格。

**例子（Wallonia）。** 成本估计 4,350,000（硬成本 2,675,000 + 软成本、利息和利润 925,000 + 土地 750,000）；可折旧基数 4,350,000 − 750,000 = 3,600,000；使用年限 30 年 → 每年 120,000；楼龄 4 年 → 价值 4,350,000 − 480,000 = **EUR3,870,000**。

### 销售比较法

* 使用可比物业的近期交易；比较单位通常是**每 m² 或 ft² 的价格**（或价格与租金或收入之比）。
* 针对交易日期（上涨市场中较早的交易 → **向上**调整）、面积（更大 → 折价）、位置（离中心更远的可比物业价值更低 → 向上调整）和楼龄（可比物业更新 → 标的**向下**调整）进行调整。
* 将调整后的单价平均 × 标的面积；越近的交易权重越大。

**例子（Pinebranch，288,000 ft²）。** 调整后每 ft² 价格为 89.27、104.23、103.60 → 平均 **AUD99.03** → 价值 ≈ **AUD2852 万**（用 99.03 为 28,520,640；用未取整的平均值为 28,521,036）。

| 方法 | 最常用于 |
| --- | --- |
| 收益法 | 可比交易少、由收入决定决策的大型商业物业 |
| 销售比较法 | 类似交易很多的市场（单户住宅）；评估师非常倚重 |
| 成本法 | 用于核对价值；新建或特殊用途物业 |

## 房地产指数

私募市场指数（基于评估或交易）一般**不可投资**；公开指数（REIT、MBS、担保债券）通常可以通过基金、ETF 或 UCITS 投资。

### 基于评估的指数

如 GREFI（NCREIF + INREV + ANREV）：按季度、按市值加权。

$$
HPR=\frac{NOI-\text{Capex}+\Delta MV}{MV_{\text{begin}}}
$$

其中 $\Delta MV=MV_{\text{end}}-MV_{\text{begin}}$，即评估市场价值的变化。这等于用评估价值计算的单期 IRR。

**例子（Wallonia）。** 两年前以 3,750,000 买入；INREV 回报先为 +5.6%，后为 +3.2% → $MV_{\text{begin}}$ = 3,960,000，$MV_{\text{end}}$ = 4,086,720；NOI 406,750；资本支出 100,000：

$$
\begin{aligned}
HPR&=\frac{306{,}750+126{,}720}{3{,}960{,}000}\\
&=10.95\%
\end{aligned}
$$

一个缺点：收入部分（NOI − 资本支出）**并不是**基金或 REIT 投资者实际收到的分配。

**评估滞后。**

* 无论在**上涨还是下跌**市场中，评估都滞后于成交价格，而且并非每处物业每个季度都会被评估。
* 结果是指数被**平滑** → 波动率被**低估**，与其他资产的相关性**更低**，夏普比率被**高估** → 对私募房地产配置过多。
* 在比较都使用评估的管理人时影响不大，在与交易型资产比较时影响很大。
* 解决办法：对指数**去平滑**，或使用**基于交易**的指数。

**去平滑。** 评估回报 $R_t^*$ 是真实回报与上期评估回报的加权平均：

$$
R_t^*=aR_t+(1-a)R_{t-1}^*
$$

$$
R_t=\frac{R_t^*}{a}+\frac{1-a}{a}\,R_{t-1}^*
$$

其中 $0\le a\le 1$；$a$ 越高，调整越快。例如 $a$ = 0.6，$R_1^*$ = 0.50%，$R_0^*$ = 2.70% → $R_1$ = 0.50/0.6 + (0.4/0.6) × 2.70 = **2.63%**；第 6 期：−8.70/0.6 + (0.4/0.6) × 1.00 = **−13.83%**。去平滑后的回报波动更大。

### 基于交易的指数

* **重复销售指数**：使用至少出售过**两次**的物业；用回归把价值变化分配到各期（如 RCA CPPI）。只出售过一次的物业不被使用；交易越多越可靠。
* **特征价格指数**：不需要重复销售；回归控制面积、楼龄、质量和位置。对数据需求大，在全国层面最可靠。
* 基于交易的指数领先于基于评估的指数，但每季度会增加统计**噪音**；长期来看是准确的。

### 其他指数

* **REIT 指数**（公开股权）：按自由流通市值加权会使指数向最大的市场倾斜，例如亚太 REIT 指数偏向新加坡等市场。
* **MBS 指数**：提前还款风险（利率下降时缩短、上升时延长 → 有效久期变长）；在美国最普遍。
* **担保债券指数**：双重追索权和提前还款罚金 → 回报稳定、风险低（丹麦是最大的市场）。
